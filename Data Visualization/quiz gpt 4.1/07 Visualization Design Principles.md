## 8. Visualization Design Principles

## Questions

#### 1. Which of the following best describes the concept of "data-ink ratio" in visualization design?

A) Increasing the number of colors and patterns for visual appeal  
B) Using minimalistic chart designs  
C) Adding 3D effects to highlight data points  
D) Removing non-essential gridlines and redundant labels

B) 3D visualizations always increase data density

A) Using nominal units for time-series displays of money  
B) Showing comparative data sets  
C) Including historical trends alongside current data

B) Using misleading scales can distort the viewer’s perception of the data  
C) The physical representation of numbers should be directly proportional to the values they represent

A) Providing alternative text descriptions for images

B) When the goal is to maximize aesthetic appeal regardless of data type

#### 9. Which statements reflect the principle "eyes beat memory" in visualization design?
A) Small multiples are preferred over animations for comparing many states  
B) Relying on internal memory is less effective than external visual comparison  
C) Users should be able to compare information side-by-side visually  
D) Animations are always better for detailed analysis than static displays  


#### 10. Which practices align with the mantra "function first, form next" in visualization design?
A) Starting with a visually appealing design and adding functionality later  
B) Collaborating with graphic designers to enhance visual hierarchy and flow  
C) Improving aesthetics as a refinement after ensuring functionality  
D) Prioritizing the purpose and clarity of the visualization before aesthetics

## Answers

#### 1. Which of the following best describes the concept of "data-ink ratio" in visualization design?
A) ✗ Gridlines and axes are often non-data ink, not the focus of the ratio.  
B) ✗ Decorative ink is not the focus; data-ink ratio is about data representation.  
C) ✗ This is unrelated to the definition of data-ink ratio.  
D) ✓ It measures the proportion of ink used to represent actual data versus total ink.  

**Correct:** D


#### 2. Which actions help maximize the data-ink ratio in a data graphic?
A) ✗ More colors and patterns often add unnecessary ink, reducing the ratio.  
B) ✓ Minimalistic designs focus on data, not decoration.  
C) ✗ 3D effects usually add non-data ink and clutter.  
D) ✓ Removing non-essential elements increases the proportion of ink used for data.  

**Correct:** B, D


#### 3. Which of the following are potential problems with using 3D visualizations for abstract data?
A) ✓ Perspective distortion can mislead viewers about data values.  
B) ✗ 3D does not inherently increase data density; it often reduces clarity.  
C) ✓ Tilted text in 3D is harder to read, reducing legibility.  
D) ✓ Occlusion can hide parts of the data, making interpretation harder.  

**Correct:** A, C, D


#### 4. What are effective ways to provide context and enable comparisons in a data visualization?
A) ✗ Nominal units can mislead in time-series; deflated/standardized units are better.  
B) ✓ Comparative data sets allow for meaningful comparisons.  
C) ✓ Historical trends help viewers understand changes over time.  
D) ✓ Benchmarks/reference lines give points of comparison.  

**Correct:** B, C, D


#### 5. Which of the following statements about graphical integrity are correct?
A) ✗ Quoting data out of context is discouraged; it can mislead.  
B) ✓ Misleading scales distort the data’s message.  
C) ✓ Proportional representation is a core principle of graphical integrity.  
D) ✓ Detailed labeling prevents ambiguity and distortion.  

**Correct:** B, C, D


#### 6. Which features support universal accessibility in data visualizations?
A) ✓ Alternative text helps those using screen readers.  
B) ✓ Color-blind-friendly schemes ensure more people can interpret the data.  
C) ✓ Readable text is essential for visually impaired users.  
D) ✗ Relying only on color excludes those with color vision deficiencies.  

**Correct:** A, B, C


#### 7. Which of the following are recommended when designing interactive visualizations?
A) ✓ Details on demand allow users to access more information as needed.  
B) ✗ Forcing users to rely on memory is discouraged; side-by-side comparison is better.  
C) ✓ Zoom and filter features support exploration.  
D) ✓ Overviews help users understand the big picture before diving into details.  

**Correct:** A, C, D


#### 8. In which situations is 3D visualization justified and beneficial?
A) ✓ Interactive navigation can make 3D useful for synthesizing multiple viewpoints.  
B) ✗ Aesthetics alone do not justify 3D; function must come first.  
C) ✗ 3D is not recommended for abstract data like time series.  
D) ✓ 3D is justified for true 3D spatial data where shape perception matters.  

**Correct:** A, D


#### 9. Which statements reflect the principle "eyes beat memory" in visualization design?
A) ✓ Small multiples allow direct visual comparison, reducing memory load.  
B) ✓ External visual comparison is more effective than relying on memory.  
C) ✓ Side-by-side visual comparison is easier than remembering previous states.  
D) ✗ Animations are not always better; they can overload memory for complex comparisons.  

**Correct:** A, B, C


#### 10. Which practices align with the mantra "function first, form next" in visualization design?
A) ✗ Starting with aesthetics can undermine the visualization’s purpose.  
B) ✓ Graphic designers can help improve visual hierarchy and flow after function is established.  
C) ✓ Aesthetics should be refined after ensuring the visualization works well.  
D) ✓ Functionality and clarity should be prioritized before aesthetics.  

**Correct:** B, C, D
