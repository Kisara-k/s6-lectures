## 5. Marks and Channels

## Questions

#### 1. Which of the following are considered "marks" in the context of data visualization?
A) Color hue  
B) Areas  
C) Lines  
D) Points  


#### 2. Which statements about channels are TRUE?
A) Channels control the appearance of marks based on data attributes  
B) Channels are also known as visual variables or retinal channels  
C) Channels can include properties like size, color, and position  
D) Channels are geometric primitives like points and lines  


#### 3. Which of the following best describe the constraints imposed by different types of marks?
A) Areas have two constraints (length and width), so size or shape cannot encode additional attributes  
B) Points cannot encode attributes using color  
C) Lines have one constraint on size (length), but width can encode another attribute  
D) Points have no constraints on size and can encode multiple attributes  


#### 4. Which channels are generally most effective for encoding quantitative data for precise comparison?
A) Length  
B) Color hue  
C) Shape  
D) Position on a common aligned scale  


#### 5. Which of the following statements about redundant encoding are correct?
A) Redundant encoding can use up available channels, limiting what else can be encoded  
B) Redundant encoding always increases the accuracy of perception  
C) Redundant encoding uses multiple channels to represent the same attribute  
D) Redundant encoding is only useful for categorical data  


#### 6. Which factors can negatively impact the accuracy of visual judgments in a visualization?
A) Presence of many distractors  
B) Using position along an aligned scale  
C) Lack of alignment on a common scale  
D) Large spatial distance between marks  


#### 7. Which of the following are examples of grouping in visualizations?
A) Using color hue to indicate similarity  
B) Containment using interlocking areas  
C) Connection using lines  
D) Proximity by placing items close together  


#### 8. Which statements about channel effectiveness are TRUE?
A) All channels are equally effective for all data types  
B) Discriminability refers to how many distinct steps can be perceived in a channel  
C) Popout occurs when an item is easily found due to a unique channel value  
D) Separability means one channel can be interpreted independently of others  


#### 9. Which of the following statements about relative and absolute judgments in perception are correct?
A) Absolute judgments are always more accurate than relative judgments  
B) Using a common frame or scale can improve the accuracy of relative judgments  
C) Our perceptual system is generally better at relative than absolute judgments  
D) Weber’s Law explains why we notice differences based on ratios rather than absolute values  


#### 10. Which of the following are TRUE about the use of color and luminance in visual encoding?
A) Color hue is highly effective for encoding precise quantitative differences  
B) Context can affect how we perceive both color and luminance in a visualization  
C) Color constancy allows us to perceive colors consistently under different lighting  
D) Perception of luminance is influenced by the contrast with surrounding areas

## Answers

#### 1. Which of the following are considered "marks" in the context of data visualization?
A) ✗ Color hue is a channel, not a mark.  
B) ✓ Areas are marks, often used for containment or grouping.  
C) ✓ Lines are marks representing links or connections.  
D) ✓ Points are basic geometric elements used as marks.  

**Correct:** B, C, D


#### 2. Which statements about channels are TRUE?
A) ✓ Channels modify the appearance of marks based on data.  
B) ✓ Channels are also called visual variables or retinal channels.  
C) ✓ Size, color, and position are all examples of channels.  
D) ✗ Channels are not geometric primitives; marks are.  

**Correct:** A, B, C


#### 3. Which of the following best describe the constraints imposed by different types of marks?
A) ✓ Areas have two constraints (length and width), so further size/shape encoding is limited.  
B) ✗ Points can encode attributes using color; this is a common practice.  
C) ✓ Lines have one constraint (length), but width can encode another attribute.  
D) ✓ Points have no fixed size, so multiple attributes can be encoded.  

**Correct:** A, C, D


#### 4. Which channels are generally most effective for encoding quantitative data for precise comparison?
A) ✓ Length is also accurate for quantitative data.  
B) ✗ Color hue is not precise for quantitative comparisons.  
C) ✗ Shape is not effective for precise quantitative encoding.  
D) ✓ Position on a common aligned scale is highly accurate for quantitative data.  

**Correct:** A, D


#### 5. Which of the following statements about redundant encoding are correct?
A) ✓ Using multiple channels for one attribute can limit what else can be encoded.  
B) ✗ It does not always increase accuracy; it can help but may also clutter.  
C) ✓ Redundant encoding uses multiple channels for the same attribute.  
D) ✗ Redundant encoding can be useful for both categorical and quantitative data.  

**Correct:** A, C


#### 6. Which factors can negatively impact the accuracy of visual judgments in a visualization?
A) ✓ Distractors can interfere with accurate perception.  
B) ✗ Using position along an aligned scale improves accuracy.  
C) ✓ Lack of alignment makes comparisons harder and less accurate.  
D) ✓ Large spatial distance can make comparisons more difficult.  

**Correct:** A, C, D


#### 7. Which of the following are examples of grouping in visualizations?
A) ✓ Similarity (e.g., color hue) groups items by shared visual properties.  
B) ✓ Containment (e.g., interlocking areas) groups items visually.  
C) ✓ Connection (e.g., lines) shows relationships and groups items.  
D) ✓ Proximity groups items by placing them close together.  

**Correct:** A, B, C, D


#### 8. Which statements about channel effectiveness are TRUE?
A) ✗ Not all channels are equally effective; effectiveness varies by channel and data type.  
B) ✓ Discriminability is about how many distinct steps a channel can show.  
C) ✓ Popout is when an item stands out due to a unique channel value.  
D) ✓ Separability means channels can be interpreted independently.  

**Correct:** B, C, D


#### 9. Which of the following statements about relative and absolute judgments in perception are correct?
A) ✗ Absolute judgments are usually less accurate than relative ones.  
B) ✓ A common frame or scale improves relative judgment accuracy.  
C) ✓ Our perception is generally better at relative judgments.  
D) ✓ Weber’s Law describes how we notice differences based on ratios.  

**Correct:** B, C, D


#### 10. Which of the following are TRUE about the use of color and luminance in visual encoding?
A) ✗ Color hue is not precise for encoding quantitative differences.  
B) ✓ Context affects perception of both color and luminance.  
C) ✓ Color constancy helps us perceive colors consistently under different lighting.  
D) ✓ Luminance perception is influenced by surrounding contrast.  

**Correct:** B, C, D
