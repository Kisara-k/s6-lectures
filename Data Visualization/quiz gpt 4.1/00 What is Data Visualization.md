## 1. What is Data Visualization

## Questions

#### 1. Which of the following are primary reasons for involving humans in the data visualization process?
A) Visualization helps verify and build trust in automatic solutions  
B) Fully automatic solutions are always more effective than visualization  
C) Visualization always replaces the need for computational decision-making  
D) Many analysis problems are ill-specified and require human judgment  


#### 2. What are some advantages of using vision as the main channel for data visualization?
A) Vision supports a subjective experience of seeing everything simultaneously  
B) The human visual system processes information in parallel and pre-attentively  
C) Vision is limited to sequential information processing, like sound  
D) Vision provides a high-bandwidth channel to the brain  


#### 3. Why might it be important to visualize all the data rather than just summary statistics?
A) Summaries can hide important details or outliers  
B) Visualizing all data helps confirm the validity of statistical models  
C) Identical summary statistics always mean identical data distributions  
D) Unexpected patterns can be discovered through full data visualization  


#### 4. Which of the following are examples of resource limitations that visualization designers must consider?
A) The number of pixels available on a display  
B) Human attention and memory  
C) The taste and smell capabilities of users  
D) System memory and computation time  


#### 5. In what situations is data visualization particularly suitable?
A) When the analysis problem is well-defined and fully automatable  
B) When there is a need to augment human capabilities in understanding data  
C) When presenting known results to a broad audience  
D) When end users need to verify or build trust in computational results  


#### 6. What are some reasons for using external representations, such as visualizations, in data analysis?
A) They replace cognition with perception, making data easier to understand  
B) They are only useful for presenting final results, not for exploration  
C) They allow for more efficient use of the human visual system  
D) They require users to memorize all data points  


#### 7. Which statements accurately describe the tradeoffs involved in display resource limitations?
A) Too much clutter can make a visualization confusing  
B) The goal is to find a balance between dense and sparse representations  
C) Too much whitespace can waste valuable display space  
D) Increasing information density always improves clarity  


#### 8. How does visualization analysis help in the design process?
A) It ensures that all possible visualizations are equally effective  
B) It serves as a scaffold for systematic thinking about design choices  
C) It helps in analyzing existing visualizations to inform new designs  
D) It imposes structure on the vast design space of visualization options  


#### 9. Which of the following are limitations of using senses other than vision for data representation?
A) Sound provides a lower bandwidth and supports only sequential streams  
B) Sound allows for simultaneous overview of complex data  
C) Taste and smell have no viable devices for recording or replaying data  
D) Touch/haptics currently have limited capacity for record and replay  


#### 10. What are some ways visualization can support the development and use of automatic solutions?
A) By making it unnecessary for end users to verify results  
B) By serving as a stepping stone to assess requirements before modeling  
C) By helping developers refine and determine model parameters  
D) By enabling end users to visually inspect and build trust in outputs

## Answers

#### 1. Which of the following are primary reasons for involving humans in the data visualization process?
A) ✓ Visualization helps users verify and build trust in automated solutions.  
B) ✗ Automatic solutions are not always more effective; human involvement is often needed.  
C) ✗ Visualization augments, not replaces, computational decision-making.  
D) ✓ Many analysis problems are ill-specified and need human insight.  

**Correct:** A, D


#### 2. What are some advantages of using vision as the main channel for data visualization?
A) ✓ Vision allows us to see everything at once, supporting overview.  
B) ✓ The visual system processes information in parallel and pre-attentively.  
C) ✗ Vision is not limited to sequential processing; that describes sound.  
D) ✓ Vision provides a high-bandwidth channel to the brain.  

**Correct:** A, B, D


#### 3. Why might it be important to visualize all the data rather than just summary statistics?
A) ✓ Summaries can hide details or outliers that are visible in full data.  
B) ✓ Visualization helps confirm if statistical models fit the data.  
C) ✗ Identical summary statistics can hide very different data distributions (e.g., Anscombe’s Quartet).  
D) ✓ Unexpected patterns are often discovered only by visualizing all data.  

**Correct:** A, B, D


#### 4. Which of the following are examples of resource limitations that visualization designers must consider?
A) ✓ Display space (pixels) is a key limitation for visualization.  
B) ✓ Human attention and memory are human resource limits.  
C) ✗ Taste and smell are not relevant or viable for data visualization.  
D) ✓ Computation time and memory are computational resource limits.  

**Correct:** A, B, D


#### 5. In what situations is data visualization particularly suitable?
A) ✗ Visualization is less needed when problems are fully automatable.  
B) ✓ Visualization is used to augment human understanding of data.  
C) ✓ Visualization is useful for presenting known results to others.  
D) ✓ Visualization helps users verify and trust computational results.  

**Correct:** B, C, D


#### 6. What are some reasons for using external representations, such as visualizations, in data analysis?
A) ✓ Visualization shifts cognitive load to perception, aiding understanding.  
B) ✗ Visualizations are useful for both exploration and presentation.  
C) ✓ Visualizations leverage the efficiency of the human visual system.  
D) ✗ Visualization reduces the need for memorization, not increases it.  

**Correct:** A, C


#### 7. Which statements accurately describe the tradeoffs involved in display resource limitations?
A) ✓ Too much clutter makes visualizations hard to interpret.  
B) ✓ The goal is to balance density and clarity for effective visualization.  
C) ✓ Excess whitespace wastes valuable display space.  
D) ✗ Higher density can cause clutter, not always improve clarity.  

**Correct:** A, B, C


#### 8. How does visualization analysis help in the design process?
A) ✗ Not all visualizations are equally effective; analysis helps identify what works.  
B) ✓ Analysis provides a scaffold for systematic design thinking.  
C) ✓ Analyzing existing visualizations informs the design of new ones.  
D) ✓ Analysis structures the design space, making choices clearer.  

**Correct:** B, C, D


#### 9. Which of the following are limitations of using senses other than vision for data representation?
A) ✓ Sound is lower bandwidth and sequential, limiting overview.  
B) ✗ Sound does not allow for simultaneous overview of complex data.  
C) ✓ Taste and smell lack viable devices for data representation.  
D) ✓ Touch/haptics have limited record/replay capacity.  

**Correct:** A, C, D


#### 10. What are some ways visualization can support the development and use of automatic solutions?
A) ✗ Visualization is important for verification; it does not make verification unnecessary.  
B) ✓ Visualization can clarify requirements before modeling.  
C) ✓ Visualization helps developers refine and tune model parameters.  
D) ✓ Visualization enables users to inspect and build trust in outputs.  

**Correct:** B, C, D
