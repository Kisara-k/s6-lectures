## 6. Perception

## Questions

#### 1. Which of the following statements accurately describe System 1 thinking?
A) It operates automatically and unconsciously  
B) It handles the majority of our daily thinking  
C) It requires significant mental effort and self-awareness  
D) It is responsible for deliberate, logical reasoning  


#### 2. Which factors can influence what we actually perceive in a visual scene?
A) The physical properties of the environment  
B) The total number of objects present, regardless of attention  
C) Our expectations and prior knowledge  
D) Where our attention is directed  


#### 3. Select all statements that are true about selective attention:
A) It allows us to perceive everything in our environment equally  
B) It is not influenced by our current goals or tasks  
C) It is demonstrated by the "door study" and "basketball pass test"  
D) It can cause us to miss obvious changes if we are focused elsewhere  


#### 4. Which of the following are examples of pre-attentive visual attributes?
A) Color hue  
B) Line length  
C) Enclosure  
D) Solving a complex math problem  


#### 5. Which statements about visual working memory are correct?
A) It can hold an unlimited number of complex objects at once  
B) Its limitations affect how much information we can process from a scene at a time  
C) Its capacity is limited to about 3-4 simple shapes  
D) It is responsible for storing detailed images for long periods  


#### 6. Which of the following best illustrate Gestalt principles in visual perception?
A) Grouping elements that share similar colors  
B) Grouping elements that move in the same direction  
C) Grouping elements based on alphabetical order  
D) Grouping elements that are close together  


#### 7. Which of the following can affect our perception of color?
A) Our expectations and context  
B) The presence of shadows  
C) The actual pigment of the object only  
D) The color of the light source  


#### 8. Which statements about pre-attentive and post-attentive perception are correct?
A) Post-attentive perception is involved when interpreting complex patterns  
B) Pre-attentive perception is slower than post-attentive perception  
C) Pre-attentive perception is immediate and automatic  
D) Post-attentive perception requires conscious effort and searching  


#### 9. Which of the following are true about the way our brain processes visual information, according to Stephen Few?
A) Visual perception is highly selective  
B) Our short-term visual memory is unlimited  
C) We are more likely to notice familiar objects  
D) We are especially sensitive to contrast and change  


#### 10. Which of the following scenarios demonstrate the influence of attention on perception?
A) Failing to notice a person in a gorilla suit during a focused task  
B) Not noticing a change in the person you are speaking to after an interruption  
C) Instantly recognizing a red dot among green dots  
D) Automatically reading a word without conscious effort

## Answers

#### 1. Which of the following statements accurately describe System 1 thinking?
A) ✓ Operates automatically and unconsciously, as described in the lecture.  
B) ✓ System 1 handles about 98% of our daily thinking.  
C) ✗ System 1 does not require significant mental effort or self-awareness; that is System 2.  
D) ✗ System 2 is responsible for deliberate, logical reasoning.  

**Correct:** A, B


#### 2. Which factors can influence what we actually perceive in a visual scene?
A) ✓ Physical properties of the environment affect what is available to perceive.  
B) ✗ The number of objects alone does not determine perception; attention is key.  
C) ✓ Expectations and prior knowledge shape what we notice and interpret.  
D) ✓ Attention determines which parts of the scene we process.  

**Correct:** A, C, D


#### 3. Select all statements that are true about selective attention:
A) ✗ Selective attention means we do NOT perceive everything equally.  
B) ✗ Selective attention is influenced by our goals and tasks.  
C) ✓ Both the "door study" and "basketball pass test" demonstrate selective attention.  
D) ✓ Focused attention can cause us to miss obvious changes (inattentional blindness).  

**Correct:** C, D


#### 4. Which of the following are examples of pre-attentive visual attributes?
A) ✓ Color hue is processed pre-attentively.  
B) ✓ Line length is a pre-attentive attribute.  
C) ✓ Enclosure is a pre-attentive visual feature.  
D) ✗ Solving a math problem is a post-attentive, conscious process.  

**Correct:** A, B, C


#### 5. Which statements about visual working memory are correct?
A) ✗ Visual working memory is limited, not unlimited.  
B) ✓ Its limitations restrict how much we can process at once.  
C) ✓ Its capacity is about 3-4 simple shapes.  
D) ✗ It does not store detailed images for long periods; that's long-term memory.  

**Correct:** B, C


#### 6. Which of the following best illustrate Gestalt principles in visual perception?
A) ✓ Similarity is a Gestalt principle (grouping by shared features).  
B) ✓ Common fate is a Gestalt principle (grouping by shared movement).  
C) ✗ Alphabetical order is not a Gestalt visual principle.  
D) ✓ Proximity is a Gestalt principle (grouping by closeness).  

**Correct:** A, B, D


#### 7. Which of the following can affect our perception of color?
A) ✓ Expectations and context can influence color perception.  
B) ✓ Shadows can change how we perceive color.  
C) ✗ Perception is not determined by pigment alone; context matters.  
D) ✓ The color of the light source affects color perception.  

**Correct:** A, B, D


#### 8. Which statements about pre-attentive and post-attentive perception are correct?
A) ✓ Post-attentive perception is used for interpreting complex patterns.  
B) ✗ Pre-attentive perception is faster, not slower, than post-attentive.  
C) ✓ Pre-attentive perception is immediate and automatic.  
D) ✓ Post-attentive perception requires conscious effort and searching.  

**Correct:** A, C, D


#### 9. Which of the following are true about the way our brain processes visual information, according to Stephen Few?
A) ✓ Visual perception is highly selective.  
B) ✗ Short-term visual memory is limited, not unlimited.  
C) ✓ We are more likely to notice familiar objects.  
D) ✓ We are especially sensitive to contrast and change.  

**Correct:** A, C, D


#### 10. Which of the following scenarios demonstrate the influence of attention on perception?
A) ✓ Missing the gorilla shows inattentional blindness due to focused attention.  
B) ✓ Not noticing a person change in the "door study" is due to selective attention.  
C) ✗ Instantly recognizing a red dot is pre-attentive, not about selective attention.  
D) ✗ Automatically reading a word is an example of System 1, not selective attention.  

**Correct:** A, B
