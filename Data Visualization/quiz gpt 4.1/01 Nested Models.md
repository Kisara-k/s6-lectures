## 2. Nested Models

## Questions

#### 1. Which of the following best describes the purpose of the "domain situation" level in the nested model?
A) Translating domain-specific details into abstract data and tasks  
B) Identifying the computational complexity of the visualization algorithm

D) Understanding the real-world context and needs of the target users  


#### 2. Which of the following are potential consequences of misunderstanding the domain situation in visualization design?
A) The visualization may address irrelevant user needs  
B) The chosen data abstraction may not match user goals  
C) The algorithm may be inefficient  
D) The visual encoding may be confusing even if the data is correct  


#### 3. Which validation methods are most appropriate for evaluating the effectiveness of a visual encoding/interaction idiom?
A) Qualitative image analysis  
B) Observing users in their real-world environment  
C) Computational benchmarks of system speed  
D) Lab studies measuring user performance  


#### 4. What are the main questions addressed at the data/task abstraction level?
A) Why is the user looking at the data?  
B) Who are the target users?  
C) How should the data be visually encoded?  
D) What data should be shown?  


#### 5. Which statements about the relationship between the levels in the nested model are correct?
A) Each level can be validated independently without considering the others  
B) Mistakes at a higher level can cause problems at lower levels  
C) Iterative refinement may involve moving both upstream and downstream between levels  
D) Changes at the algorithm level can require revisiting the domain situation  


#### 6. Which of the following are examples of validation methods used at the algorithm level?
A) Conducting field studies with target users  
B) Qualitative analysis of visual results  
C) Measuring system time and memory usage  
D) Analyzing computational complexity  


#### 7. Why is it important to use methods from different fields (such as computer science, design, and anthropology) when validating a visualization?

#### 9. Which of the following are common pitfalls when validating a visualization system?

B) Failing to observe users after deployment  
C) Ignoring qualitative feedback from target users  
D) Assuming computational benchmarks confirm the effectiveness of visual encoding  


#### 10. In the context of the nested model, which of the following are true about the process of visualization design and validation?
A) A single research paper may only address a subset of validation methods  
B) Downstream effects mean that errors at lower levels can invalidate higher-level decisions  
C) It is often necessary to iterate between levels based on feedback

## Answers

#### 1. Which of the following best describes the purpose of the "domain situation" level in the nested model?
A) ✗ Data/task abstraction is the next level, not domain situation.  
B) ✗ Focuses on algorithm, not user context.  
C) ✗ Visual encoding is addressed at a later level.  
D) ✓ The domain situation is about understanding users and their context.  

**Correct:** D


#### 2. Which of the following are potential consequences of misunderstanding the domain situation in visualization design?
A) ✓ If user needs are misunderstood, the visualization may be irrelevant.  
B) ✓ Wrong data abstraction can result from misunderstanding user goals.  
C) ✗ Algorithm efficiency is not directly affected by domain misunderstanding.  
D) ✗ Visual encoding issues stem from poor idiom choices, not domain misunderstanding.  

**Correct:** A, B


#### 3. Which validation methods are most appropriate for evaluating the effectiveness of a visual encoding/interaction idiom?
A) ✓ Qualitative image analysis helps assess the effectiveness of visual encodings.  
B) ✗ Field studies are more relevant for domain situation and adoption, not encoding idioms.  
C) ✗ Computational benchmarks are for algorithm validation, not visual encoding.  
D) ✓ Lab studies test how well users perform tasks with the encoding/interaction.  

**Correct:** A, D


#### 4. What are the main questions addressed at the data/task abstraction level?
A) ✓ Task abstraction asks why the user is looking at the data.  
B) ✗ Identifying users is part of the domain situation, not abstraction.  
C) ✗ Visual encoding is addressed at the idiom level, not abstraction.  
D) ✓ Data abstraction asks what data is shown.  

**Correct:** A, D


#### 5. Which statements about the relationship between the levels in the nested model are correct?
A) ✗ Levels are interdependent; validation often requires considering multiple levels.  
B) ✓ Higher-level mistakes cascade down and affect lower levels.  
C) ✓ Iterative refinement means moving both up and down between levels.  
D) ✓ Algorithm issues can reveal problems that require revisiting higher levels.  

**Correct:** B, C, D


#### 6. Which of the following are examples of validation methods used at the algorithm level?
A) ✗ Field studies are for domain/user validation, not algorithms.  
B) ✗ Qualitative visual analysis is for encoding/interaction, not algorithms.  
C) ✓ Measuring system time/memory is a standard algorithm validation method.  
D) ✓ Computational complexity analysis is specific to algorithms.  

**Correct:** C, D


#### 7. Why is it important to use methods from different fields (such as computer science, design, and anthropology) when validating a visualization?
A) ✓ Both technical and human-centered perspectives are necessary for comprehensive validation.  
B) ✓ Each level has unique challenges requiring different expertise.  
C) ✗ Computer science alone is insufficient for all levels.  
D) ✓ Some methods are not suitable for all levels, so multiple fields are needed.  

**Correct:** A, B, D


#### 8. Which of the following statements about visual encoding and interaction idioms are true?
A) ✗ They are directly related to abstraction, as abstraction informs idiom choice.  
B) ✓ Poor choices here can make a visualization ineffective, even with correct data.  
C) ✓ They define how data is shown and manipulated.  
D) ✓ Comparing alternatives and user feedback are ways to justify idiom choices.  

**Correct:** B, C, D


#### 9. Which of the following are common pitfalls when validating a visualization system?
A) ✓ Lab studies do not validate whether the right tasks were chosen.  
B) ✓ Not observing users post-deployment can miss real-world issues.  
C) ✓ Ignoring user feedback can lead to undetected usability problems.  
D) ✓ Computational benchmarks do not confirm visual encoding effectiveness.  

**Correct:** A, B, C, D


#### 10. In the context of the nested model, which of the following are true about the process of visualization design and validation?
A) ✓ Research papers may only address some validation methods, not all.  
B) ✗ Downstream effects mean higher-level errors affect lower levels, not the reverse.  
C) ✓ Iteration between levels is often necessary based on feedback.  
D) ✓ Both qualitative and quantitative methods are needed for thorough validation.  

**Correct:** A, C, D
