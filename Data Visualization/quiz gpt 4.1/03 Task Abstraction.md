## 4. Task Abstraction

## Questions

#### 1. Which of the following best describes the purpose of task abstraction in visualization design?
A) To translate domain-specific problems into generalized tasks  
B) To map user actions and data into a common vocabulary  
C) To create new data types for every domain  
D) To ensure visualization tools are only usable in one specific field  


#### 2. In the process of domain characterization, which aspects are typically considered?
A) The specific questions users have  
B) The group of users  
C) The types of data available  
D) The algorithms used for visualization  


#### 3. Which of the following are examples of {action, target} pairs in task abstraction?
A) Locate outliers  
B) Browse topology  
C) Compare trends  
D) Summarize algorithms  


#### 4. Which statements about the interplay between task abstraction and data abstraction are correct?
A) Task abstraction and data abstraction are completely independent  
B) Data abstraction is always completed before task abstraction  
C) Task abstraction can lead to transforming the data  
D) The process is often iterative, requiring multiple passes  


#### 5. Which of the following are considered "actions" in the context of task abstraction?
A) Analyze  
B) Query  
C) Topology  
D) Search  


#### 6. Which scenarios best illustrate the "search" action in task abstraction?
A) Summarizing the distribution of a dataset  
B) Exploring a new neighborhood in a city  
C) Looking up a word in a dictionary  
D) Browsing books in a bookstore  


#### 7. When mapping domain-language data descriptions to data abstraction, which of the following should be avoided?
A) Iterating between data and task abstraction  
B) Transforming data to fit abstract tasks  
C) Expressing data in generalized terms  
D) Using domain-specific jargon  


#### 8. Which of the following statements about "analyze" actions are true?
A) They can include presenting known findings  
B) They never involve producing new data or annotations  
C) They can involve discovering unknown patterns in data  
D) They are only relevant for expert users  


#### 9. Which of the following are correct about the "query" action in task abstraction?
A) It is only used for summarizing all data  
B) It can involve identifying a single item  
C) It can involve comparing a subset of items  
D) It is unrelated to the amount of data considered  


#### 10. In the visualization design process, which steps are typically iterative and may require revisiting previous decisions?
A) Mapping domain-language tasks to abstract tasks  
B) Mapping data descriptions to data abstractions  
C) Characterizing the domain situation  
D) Identifying suitable visualization idioms or techniques

## Answers

#### 1. Which of the following best describes the purpose of task abstraction in visualization design?
A) ✓ Translates specific domain problems into generalized tasks for broader applicability.  
B) ✓ Mapping actions and data into a common vocabulary is a core part of task abstraction.  
C) ✗ Task abstraction does not create new data types for every domain; it generalizes tasks.  
D) ✗ The goal is not to restrict tools to one field, but to make them flexible.  

**Correct:** A, B


#### 2. In the process of domain characterization, which aspects are typically considered?
A) ✓ Identifying users' specific questions is a key part of domain characterization.  
B) ✓ Understanding the user group is essential for domain characterization.  
C) ✓ Knowing the types of data available is necessary for characterizing the domain.  
D) ✗ Algorithm selection comes later in the design process, not during domain characterization.  

**Correct:** A, B, C


#### 3. Which of the following are examples of {action, target} pairs in task abstraction?
A) ✓ "Locate" (action) and "outliers" (target) is a valid pair.  
B) ✓ "Browse" (action) and "topology" (target) is a valid pair.  
C) ✓ "Compare" (action) and "trends" (target) is a valid pair.  
D) ✗ "Summarize algorithms" is not a standard {action, target} pair; algorithms are not typical targets.  

**Correct:** A, B, C


#### 4. Which statements about the interplay between task abstraction and data abstraction are correct?
A) ✗ They are closely linked, not independent.  
B) ✗ The process is iterative; data and task abstraction can influence each other at any stage.  
C) ✓ Task abstraction can reveal the need to transform or derive new data.  
D) ✓ The process is often iterative, requiring multiple passes between task and data abstraction.  

**Correct:** C, D


#### 5. Which of the following are considered "actions" in the context of task abstraction?
A) ✓ "Analyze" is a core action in task abstraction.  
B) ✓ "Query" is a core action in task abstraction.  
C) ✗ "Topology" is a type of target, not an action.  
D) ✓ "Search" is a core action in task abstraction.  

**Correct:** A, B, D


#### 6. Which scenarios best illustrate the "search" action in task abstraction?
A) ✗ Summarizing a distribution is a "query" action, not "search."  
B) ✓ Exploring a new neighborhood is an "explore" search action.  
C) ✓ Looking up a word is a classic "lookup" search action.  
D) ✓ Browsing books is a "browse" search action.  

**Correct:** B, C, D


#### 7. When mapping domain-language data descriptions to data abstraction, which of the following should be avoided?
A) ✗ Iteration between data and task abstraction is encouraged, not avoided.  
B) ✗ Transforming data to fit abstract tasks is often necessary.  
C) ✗ Expressing data in generalized terms is the goal, not something to avoid.  
D) ✓ Domain-specific jargon should be systematically removed for abstraction.  

**Correct:** D


#### 8. Which of the following statements about "analyze" actions are true?
A) ✓ "Analyze" can include presenting known findings (explain/present).  
B) ✗ "Analyze" can involve producing new data or annotations.  
C) ✓ "Analyze" can involve discovering unknown patterns (explore/discover).  
D) ✗ "Analyze" actions are relevant for all users, not just experts.  

**Correct:** A, C


#### 9. Which of the following are correct about the "query" action in task abstraction?
A) ✗ "Query" is not limited to summarizing all data; it also includes identifying and comparing.  
B) ✓ "Query" can involve identifying a single item.  
C) ✓ "Query" can involve comparing a subset of items.  
D) ✗ "Query" is directly related to the amount of data considered.  

**Correct:** B, C


#### 10. In the visualization design process, which steps are typically iterative and may require revisiting previous decisions?
A) ✓ Mapping tasks often requires iteration as understanding deepens.  
B) ✓ Mapping data descriptions to abstractions is often revisited as tasks evolve.  
C) ✓ Characterizing the domain may need to be revisited as new insights emerge.  
D) ✓ Choosing visualization techniques may change as tasks and data are refined.  

**Correct:** A, B, C, D
