## 7. Interactive Views

## Questions

#### 1. Which of the following are examples of manipulating the view in interactive data visualizations?
A) Printing the visualization on paper  
B) Changing the aggregation level of displayed data  
C) Rearranging the order of data elements  
D) Filtering data using a slider  


#### 2. What are potential drawbacks of using widgets and controls (like sliders, buttons, and dropdowns) in interactive visualizations?
A) They can make the visualization less self-documenting  
B) They can use up valuable screen space  
C) They always make the interface more intuitive  
D) They may clutter the interface if overused  


#### 3. Which statements about animated transitions in data visualization are correct?
A) They always reduce cognitive load, regardless of context  
B) They are best avoided when many scattered changes occur simultaneously  
C) They are especially useful for showing smooth changes in visual encoding  
D) They help users track changes between different visual states  


#### 4. When designing for touch interaction on mobile devices, which considerations are important?
A) Hover-based interactions are not available  
B) Ergonomic realities may limit the types of interactions possible  
C) Large screens allow for more complex controls  
D) Only tap and gesture-based interactions are possible  


#### 5. Which of the following are true about selection and highlighting in interactive visualizations?
A) Highlighting can use visual channels like color, outline, or motion  
B) Highlighting always changes the underlying data  
C) Selection can be designed to allow multiple items to be chosen at once  
D) Selection is always performed using a mouse click  


#### 6. What are the differences between constrained and unconstrained navigation in interactive views?
A) Unconstrained navigation can lead to overshooting or undershooting the target view  
B) Unconstrained navigation is easier for users to control precisely  
C) Constrained navigation often uses animated transitions to guide the user  
D) Constrained navigation automatically computes the trajectory based on user selection  


#### 7. Which statements about multiple coordinated views are correct?
A) Linked highlighting allows selections in one view to affect others  
B) Bidirectional linking is generally more effective than unidirectional linking  
C) Small multiples always share the same data subset across all views  
D) Overview-detail views always use the same data encoding in both views  


#### 8. In the context of partitioning and layering data in visualizations, which are true?
A) Partitioning can be achieved by splitting data into regions based on attributes  
B) Too many visual layers can make the visualization cluttered and hard to interpret  
C) Recursive subdivision allows for hierarchical exploration of data  
D) Layering is limited to static overlays and cannot be interactive  


#### 9. What are some limitations of interactive visualizations?
A) Invisible functionality may be difficult for users to discover  
B) Remembering previous states can increase cognitive load  
C) Users may not interact with the visualization as designers expect  
D) Interactive controls always make the visualization easier to use  


#### 10. Which of the following statements about juxtaposing and animating views are correct?
A) Superimposing many layers is always preferable to using small multiples for comparison tasks  
B) Juxtaposing multiple views divides available display area among them  
C) Juxtaposing views can reduce cognitive load by allowing direct visual comparison  
D) Animating many scattered changes is always easier to follow than juxtaposing

## Answers

#### 1. Which of the following are examples of manipulating the view in interactive data visualizations?
A) ✗ Printing is not an interactive manipulation; it’s static.  
B) ✓ Changing aggregation level is a form of manipulating the view.  
C) ✓ Rearranging order is a manipulation to highlight patterns.  
D) ✓ Filtering data with a slider is a manipulation of the view.  

**Correct:** B, C, D


#### 2. What are potential drawbacks of using widgets and controls (like sliders, buttons, and dropdowns) in interactive visualizations?
A) ✗ Widgets are generally self-documenting with labels, not less so.  
B) ✓ Widgets can consume valuable screen space.  
C) ✗ Widgets do not always make interfaces more intuitive; poor design can confuse users.  
D) ✓ Overuse of controls can clutter the interface.  

**Correct:** B, D


#### 3. Which statements about animated transitions in data visualization are correct?
A) ✗ They do not always reduce cognitive load; too many changes can be confusing.  
B) ✓ When many scattered changes occur, animation can be hard to follow and is best avoided.  
C) ✓ They are especially useful for smooth changes in visual encoding.  
D) ✓ Animated transitions help users track changes between states.  

**Correct:** B, C, D


#### 4. When designing for touch interaction on mobile devices, which considerations are important?
A) ✓ Hover is not available on most touchscreens.  
B) ✓ Ergonomic realities (like finger size and reach) limit interaction types.  
C) ✗ Mobile screens are small, limiting complex controls.  
D) ✓ Tap and gesture-based interactions are the main options on mobile.  

**Correct:** A, B, D


#### 5. Which of the following are true about selection and highlighting in interactive visualizations?
A) ✓ Highlighting can use color, outline, or motion as visual channels.  
B) ✗ Highlighting changes only the visual encoding, not the data itself.  
C) ✓ Selection can be designed for multiple items (multi-select).  
D) ✗ Selection can be performed by various methods, not just mouse click (e.g., tap, hover).  

**Correct:** A, C


#### 6. What are the differences between constrained and unconstrained navigation in interactive views?
A) ✓ Unconstrained navigation can lead to overshooting or undershooting the target view.  
B) ✗ Unconstrained navigation is harder for users to control precisely; easy to overshoot.  
C) ✓ Constrained navigation often uses animated transitions to guide users.  
D) ✓ Constrained navigation computes the trajectory automatically based on selection.  

**Correct:** A, C, D


#### 7. Which statements about multiple coordinated views are correct?
A) ✓ Linked highlighting allows selections in one view to affect others.  
B) ✓ Bidirectional linking is generally more effective for coordination.  
C) ✗ Small multiples do not necessarily share the same data subset; each can show a different slice.  
D) ✗ Overview-detail views can use the same or different encodings.  

**Correct:** A, B


#### 8. In the context of partitioning and layering data in visualizations, which are true?
A) ✓ Partitioning splits data into regions by attributes.  
B) ✓ Too many layers can clutter the visualization and reduce clarity.  
C) ✓ Recursive subdivision enables hierarchical exploration of data.  
D) ✗ Layering can be interactive, not just static.  

**Correct:** A, B, C


#### 9. What are some limitations of interactive visualizations?
A) ✓ Invisible functionality (e.g., hidden controls) can be hard to discover.  
B) ✓ Remembering previous states increases cognitive load.  
C) ✓ Users may not interact as designers expect (e.g., most users only scroll).  
D) ✗ Controls do not always make visualizations easier; they can add complexity.  

**Correct:** A, B, C


#### 10. Which of the following statements about juxtaposing and animating views are correct?
A) ✗ Superimposing many layers is not always preferable; small multiples are better for many comparisons.  
B) ✓ Juxtaposing divides display area among views, reducing space per view.  
C) ✓ Juxtaposing views allows direct visual comparison, reducing cognitive load.  
D) ✗ Animating many scattered changes is harder to follow than juxtaposing.  

**Correct:** B, C
