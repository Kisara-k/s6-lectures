## 6. Perception

## Questions

#### 1. Which of the following statements accurately describe System 1 thinking?  
A) It operates unconsciously and automatically without self-awareness.  
B) It is responsible for about 98% of all our thinking.  
C) It involves deliberate, effortful, and logical reasoning.  
D) It controls functions such as solving complex math problems.  

#### 2. What factors influence what we actually see with our mind?  
A) The physical stimuli present in the environment.  
B) The direction of our attention.  
C) Our expectations about what we will see.  
D) The total amount of information in the visual field.  

#### 3. Which of the following are true about selective attention?  
A) We perceive all stimuli present in our environment equally.  
B) We only perceive what our mind attends to.  
C) The "Invisible Gorilla" basketball pass test demonstrates selective attention.  
D) Selective attention can be overridden by conscious effort in all cases.  

#### 4. Regarding color perception, which factors can alter how we perceive color?  
A) The color of the light source illuminating the object.  
B) The presence of shadows on the object.  
C) The shape and size of the object.  
D) The speed at which the object moves.  

#### 5. According to Stephen Few, which statements about visual perception are correct?  
A) We can process unlimited visual information at once if we focus hard enough.  
B) Visual perception is selective and sensitive to contrast and change.  
C) We tend to perceive unfamiliar objects more easily than familiar ones.  
D) Our short-term visual memory has a limited capacity.  

#### 6. What distinguishes pre-attentive perception from post-attentive perception?  
A) Post-attentive perception occurs without any mental lookup or calculation.  
B) Pre-attentive perception is immediate and primal, requiring no conscious effort.  
C) Pre-attentive perception requires deliberate searching for patterns.  
D) Post-attentive perception is slower and involves conscious mental activity.  

#### 7. Which Gestalt principles relate to grouping elements in data visualization?  
A) Similarity, where elements with shared visual properties are grouped.  
B) Enclosure, where related elements are surrounded by a visual boundary.  
C) Color intensity, which groups elements based on brightness differences.  
D) Proximity, where elements close to each other are perceived as related.  

#### 8. How do Gestalt principles related to movement influence perception?  
A) Movement principles override all other Gestalt grouping rules.  
B) Connectedness groups elements based on their color similarity.  
C) Parallelism groups lines with similar slopes as part of the same group.  
D) Common Fate groups shapes moving in the same direction and speed.  

#### 9. Which of the following are examples of pre-attentive visual attributes?  
A) Line width and line length.  
B) Color hue and color intensity.  
C) Spatial position and orientation.  
D) Logical reasoning and conscious control.  

#### 10. Which statements about human visual working memory and perception capacity are true?  
A) We can perceive all details in a complex image simultaneously.  
B) Visual working memory can hold about 3-4 simple shapes at a time.  
C) Attention can expand the capacity of visual working memory indefinitely.  
D) Our perception is limited by the capacity of short-term visual memory.

## Answers

#### 1. Which of the following statements accurately describe System 1 thinking?  
A) ✓ System 1 operates unconsciously and automatically without self-awareness.  
B) ✓ It is responsible for about 98% of all our thinking.  
C) ✗ Deliberate, effortful, and logical reasoning describes System 2, not System 1.  
D) ✗ Solving complex math problems is a System 2 function, not System 1.  

**Correct:** A, B


#### 2. What factors influence what we actually see with our mind?  
A) ✓ Physical stimuli are the raw input for perception.  
B) ✓ Attention direction determines which parts of the stimuli we process.  
C) ✓ Our expectations shape what we perceive beyond raw stimuli.  
D) ✗ The total amount of information is not fully perceived due to limited capacity.  

**Correct:** A, B, C


#### 3. Which of the following are true about selective attention?  
A) ✗ We do not perceive all stimuli equally; selective attention filters what we notice.  
B) ✓ We only perceive what our mind attends to, filtering out other stimuli.  
C) ✓ The "Invisible Gorilla" test demonstrates how selective attention causes us to miss obvious events.  
D) ✗ Conscious effort cannot always override selective attention, as some stimuli remain unnoticed.  

**Correct:** B, C


#### 4. Regarding color perception, which factors can alter how we perceive color?  
A) ✓ The color of the light source changes the color appearance of objects.  
B) ✓ Shadows affect the perceived color by changing light and contrast.  
C) ✗ Shape and size do not directly influence color perception.  
D) ✗ Speed of movement does not affect color perception.  

**Correct:** A, B


#### 5. According to Stephen Few, which statements about visual perception are correct?  
A) ✗ We cannot process unlimited visual information simultaneously, no matter the effort.  
B) ✓ Visual perception is selective and sensitive to contrast and change.  
C) ✗ We are more drawn to familiar objects, not unfamiliar ones.  
D) ✓ Short-term visual memory has limited capacity, restricting perception.  

**Correct:** B, D


#### 6. What distinguishes pre-attentive perception from post-attentive perception?  
A) ✗ Post-attentive perception requires mental lookup or calculation, not absence of it.  
B) ✓ Pre-attentive perception is immediate and requires no conscious effort.  
C) ✗ Searching for patterns is a post-attentive activity, not pre-attentive.  
D) ✓ Post-attentive perception is slower and involves conscious mental activity.  

**Correct:** B, D


#### 7. Which Gestalt principles relate to grouping elements in data visualization?  
A) ✓ Similarity groups elements with shared visual properties.  
B) ✓ Enclosure groups elements surrounded by a visual boundary.  
C) ✗ Color intensity is a pre-attentive attribute but not a Gestalt grouping principle.  
D) ✓ Proximity groups elements close to each other spatially.  

**Correct:** A, B, D


#### 8. How do Gestalt principles related to movement influence perception?  
A) ✗ Movement principles do not override all other Gestalt rules; they work alongside them.  
B) ✗ Connectedness groups elements based on physical connection, not color similarity.  
C) ✓ Parallelism groups lines with similar slopes visually.  
D) ✓ Common Fate groups shapes moving in the same direction and speed.  

**Correct:** C, D


#### 9. Which of the following are examples of pre-attentive visual attributes?  
A) ✓ Line width and line length are pre-attentive visual attributes.  
B) ✓ Color hue and color intensity are classic pre-attentive features.  
C) ✓ Spatial position and orientation are pre-attentive attributes.  
D) ✗ Logical reasoning and conscious control are cognitive processes, not visual attributes.  

**Correct:** A, B, C


#### 10. Which statements about human visual working memory and perception capacity are true?  
A) ✗ We cannot perceive all details in a complex image simultaneously due to memory limits.  
B) ✓ Visual working memory can hold about 3-4 simple shapes at a time.  
C) ✗ Attention cannot expand visual working memory capacity indefinitely; it is limited.  
D) ✓ Perception is limited by the capacity of short-term visual memory.  

**Correct:** B, D
