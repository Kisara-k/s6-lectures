## Answers

#### 1. Which of the following best describe the concept of maximizing the data-ink ratio in a visualization?  
A) ✓ Removing non-essential ink that does not represent data — Correct; it focuses on eliminating redundant or decorative ink.  
B) ✓ Ensuring that the majority of ink used directly represents the core data — This is the core idea of maximizing data-ink ratio.  
C) ✗ Using as much ink as possible to make the graphic visually appealing — This increases non-data ink, which contradicts maximizing data-ink ratio.  
D) ✗ Increasing the amount of decorative elements to highlight data points — Decorative elements add non-data ink, reducing the ratio.  

**Correct:** A, B


#### 2. When considering data density in a visualization, which statements are true?  
A) ✗ Simple data sets are best visualized with high data density graphics — Simple data sets often do not require high data density visuals.  
B) ✓ Data reduction techniques like clustering can be used to manage overcrowding — Correct; these techniques help maintain clarity.  
C) ✓ Data density is the ratio of the number of data entries to the area of the graphic — This matches the definition of data density.  
D) ✗ High data density always improves clarity regardless of the visualization type — High density can reduce clarity if overcrowded.  

**Correct:** B, C


#### 3. What are the implications of a Lie Factor significantly greater than 1.05 or less than 0.95 in a graph?  
A) ✗ The graph uses proportional scaling between data and visual representation — Proportional scaling would yield a Lie Factor near 1.  
B) ✗ The graph accurately represents the data without distortion — A Lie Factor outside this range indicates distortion.  
C) ✓ The visualization may mislead viewers by exaggerating or minimizing effects — Distortion can mislead interpretation.  
D) ✓ The graphical effect size is substantially distorted compared to the actual data change — Correct; this is the definition of distortion.  

**Correct:** C, D


#### 4. Which of the following are recommended practices to ensure integrity and accuracy in data visualizations?  
A) ✗ Employing multiple unrelated time scales in the same chart for variety — This confuses viewers and reduces integrity.  
B) ✓ Using consistent scales that reflect the true numerical values — Essential to avoid distortion.  
C) ✗ Avoiding context or comparative data to keep the visualization simple — Context is important for accurate interpretation.  
D) ✓ Providing clear and detailed labeling directly on the graph — Helps prevent ambiguity and distortion.  

**Correct:** B, D


#### 5. Regarding the use of 3D in data visualization, which statements are correct?  
A) ✗ 3D bar charts are generally preferable to 2D bar charts due to better clarity — 3D bars cause occlusion and distortion, reducing clarity.  
B) ✓ Perspective distortion and occlusion are common problems with unjustified 3D use — These are key drawbacks of unjustified 3D.  
C) ✗ Immersive 3D environments always enhance understanding of abstract data — Immersion often does not help abstract data comprehension.  
D) ✓ 3D is justified primarily for true 3D spatial data where shape perception is critical — Correct; justified 3D use is for spatial data.  

**Correct:** B, D


#### 6. Which principles or guidelines apply when designing visualizations for universal accessibility?  
A) ✓ Use color schemes distinguishable by individuals with color blindness — Important for inclusivity.  
B) ✗ Avoid providing alternative text for images to reduce clutter — Alternative text is necessary for accessibility.  
C) ✗ Rely solely on color to convey critical information — Sole reliance on color excludes color-blind users.  
D) ✓ Consider readability for visually impaired audiences — Essential for universal design.  

**Correct:** A, D


#### 7. What are the advantages of external cognition (eyes) over internal memory in visualization design?  
A) ✗ Relying on memory reduces cognitive load and improves data comprehension — Relying on memory increases cognitive load.  
B) ✗ Animation is always superior to small multiples for comparing many states — Animation is poor for many states with widespread changes.  
C) ✓ Small multiples help users track changes across multiple states more effectively than animation — Small multiples support better comparison.  
D) ✓ It allows easier comparison by viewing side-by-side data rather than recalling from memory — External cognition reduces cognitive load.  

**Correct:** C, D


#### 8. According to Shneiderman’s mantra "Overview first, zoom and filter, details on demand," which statements are true?  
A) ✗ Immediate detailed views are preferable to overviews for initial data exploration — Overviews help orient users first.  
B) ✓ Responsiveness in interaction is critical to maintain user engagement — Fast feedback is important for usability.  
C) ✓ Overview provides a summary or microcosm of the entire data set — This is the purpose of the overview.  
D) ✓ Details should be shown only after zooming and filtering to avoid overwhelming users — Details on demand means showing details after filtering.  

**Correct:** B, C, D


#### 9. Which of the following are risks or drawbacks of using tilted text in visualizations?  
A) ✓ Tilted text is generally less legible than text aligned with the image plane — Correct; legibility suffers when text is tilted.  
B) ✗ Tilted text improves legibility by aligning with visual flow — Tilted text generally reduces legibility.  
C) ✗ Text legibility issues are negligible in 3D visualizations — Legibility issues are often worse in 3D due to tilt and perspective.  
D) ✓ Orientation effects can significantly reduce readability in volumetric displays — Supported by research cited in the lecture.  

**Correct:** A, D


#### 10. When prioritizing function and form in visualization design, which approaches are advisable?  
A) ✓ Collaborate with graphic designers if in-house expertise is lacking — Expertise improves aesthetics without sacrificing function.  
B) ✗ Aesthetics are unimportant and can be ignored if the data is accurate — Aesthetics matter as a level of function (e.g., hierarchy, flow).  
C) ✗ Start with aesthetics and add functionality later as needed — Starting with aesthetics risks losing core function.  
D) ✓ Focus first on functionality before refining aesthetics — Function should come first for effective design.  

**Correct:** A, D
