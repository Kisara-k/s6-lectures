## 5. Marks and Channels

## Questions

#### 1. Which of the following statements correctly describe the roles of marks and channels in visual encoding?  
A) Marks are geometric primitives that represent items or links.  
B) Channels are geometric shapes used to represent data points.  
C) Marks determine the color and size of visual elements.  
D) Channels control the appearance of marks based on data attributes.  

#### 2. Considering constraints on marks, which of the following are true?  
A) Points have zero constraints on size and can encode multiple attributes using size and shape.  
B) Interlocking areas have two constraints on size and cannot encode additional attributes by size or shape.  
C) Interlocking areas allow free encoding of size and shape without constraints.  
D) Lines have one constraint on size (length) but can still encode other attributes by width.  

#### 3. Which of the following are valid reasons to use redundant encoding in visualization?  
A) To avoid using color channels altogether.  
B) To send a stronger message by using multiple channels for the same attribute.  
C) To improve the accuracy of perception by reinforcing the encoded information.  
D) To reduce the number of channels used and simplify the visualization.  

#### 4. When analyzing visual encoding idioms, which assumptions simplify the scope of analysis?  
A) One mark per item and a single view.  
B) Multiple marks per item and multiple views.  
C) Some items not represented by marks due to aggregation or filtering.  
D) Using interlocking areas for all items.  

#### 5. Which of the following statements about channel effectiveness are correct?  
A) Popout occurs when a visual element can be detected quickly regardless of distractor count.  
B) Discriminability is the number of unique perceptible steps in a channel.  
C) Accuracy refers to how precisely differences between encoded items can be perceived.  
D) Separability means the channel’s effectiveness is unaffected by other channels.  

#### 6. Regarding perceptual accuracy and graphical perception, which statements are true?  
A) Weber’s Law states that the absolute difference between stimuli is constant.  
B) Alignment and common scale improve accuracy of visual judgments.  
C) Perceptual accuracy is generally absolute rather than relative.  
D) Length is considered the most accurate visual channel for encoding quantitative data.  

#### 7. Which of the following best describe the concept of popout in visual channels?  
A) Serial search is required for most combinations of channels, with speed depending on distractor number.  
B) Popout allows parallel processing of individual channels, making detection speed independent of distractor count.  
C) Popout is strongest for channels like tilt, size, shape, and proximity.  
D) Popout occurs equally for all combinations of visual channels.  

#### 8. Which of the following statements about grouping channels are correct?  
A) Proximity groups items by placing them in the same spatial region.  
B) Connection groups items by linking them with lines or edges.  
C) Similarity groups items by assigning them different values in the same channel.  
D) Containment groups items by enclosing them within a shared boundary.  

#### 9. Which of the following are true about relative luminance and color judgments?  
A) Color constancy allows perception of consistent colors under varying illumination.  
B) Perception of luminance depends on contrast with surrounding areas, not absolute luminance.  
C) Absolute luminance values are the primary factor in human color perception.  
D) Relative judgments are less important than absolute judgments in visual encoding.  

#### 10. Which of the following statements about marks and channels are accurate?  
A) The choice of mark type constrains which channels can be used for encoding additional attributes.  
B) Channels can be called visual variables, retinal channels, or visual dimensions.  
C) Marks are geometric primitives such as points, lines, and areas.  
D) Channels always convey the same amount and type of information regardless of mark type.

## Answers

#### 1. Which of the following statements correctly describe the roles of marks and channels in visual encoding?  
A) ✓ Marks are geometric primitives that represent items or links.  
B) ✗ Channels are not geometric shapes; they modify marks’ appearance.  
C) ✗ Marks do not determine color or size; channels do.  
D) ✓ Channels control the appearance of marks based on data attributes.  

**Correct:** A, D


#### 2. Considering constraints on marks, which of the following are true?  
A) ✓ Points have zero constraints on size and can encode multiple attributes with size and shape.  
B) ✓ Interlocking areas have two size constraints and cannot encode additional attributes by size or shape.  
C) ✗ Interlocking areas are constrained and cannot freely encode size or shape.  
D) ✓ Lines have one size constraint (length) but can encode other attributes by width.  

**Correct:** A, B, D


#### 3. Which of the following are valid reasons to use redundant encoding in visualization?  
A) ✗ Redundant encoding does not aim to avoid color channels; it can include them.  
B) ✓ Redundant encoding sends a stronger message by using multiple channels for the same attribute.  
C) ✓ It improves perception accuracy by reinforcing the encoded information.  
D) ✗ Redundant encoding uses more channels, not fewer, so it does not simplify visualization.  

**Correct:** B, C


#### 4. When analyzing visual encoding idioms, which assumptions simplify the scope of analysis?  
A) ✓ One mark per item and a single view simplify analysis.  
B) ✗ Multiple marks and views complicate analysis, not simplify it.  
C) ✗ Some items not represented by marks is a later consideration, not a simplifying assumption.  
D) ✗ Using interlocking areas for all items is not a simplifying assumption.  

**Correct:** A


#### 5. Which of the following statements about channel effectiveness are correct?  
A) ✓ Popout means quick detection independent of distractor count.  
B) ✓ Discriminability is the number of unique perceptible steps.  
C) ✓ Accuracy is about how precisely differences can be perceived.  
D) ✗ Separability means channel effectiveness can be affected by other channels, so this is false.  

**Correct:** A, B, C


#### 6. Regarding perceptual accuracy and graphical perception, which statements are true?  
A) ✗ Weber’s Law states the ratio of increment to background is constant, not the absolute difference.  
B) ✓ Alignment and common scale improve accuracy.  
C) ✗ Perceptual accuracy is mostly relative, not absolute.  
D) ✓ Length is the most accurate visual channel for quantitative data.  

**Correct:** B, D


#### 7. Which of the following best describe the concept of popout in visual channels?  
A) ✓ Serial search is required for most combinations, with speed depending on distractors.  
B) ✓ Popout allows parallel processing, making detection speed independent of distractors.  
C) ✓ Popout is strongest for channels like tilt, size, shape, and proximity.  
D) ✗ Popout does not occur equally for all channel combinations.  

**Correct:** A, B, C


#### 8. Which of the following statements about grouping channels are correct?  
A) ✓ Proximity groups items by placing them in the same spatial region.  
B) ✓ Connection groups items by linking them with lines or edges.  
C) ✗ Similarity groups items by assigning them the same values, not different values.  
D) ✓ Containment groups items by enclosing them within a shared boundary.  

**Correct:** A, B, D


#### 9. Which of the following are true about relative luminance and color judgments?  
A) ✓ Color constancy allows consistent color perception under varying illumination.  
B) ✓ Luminance perception depends on contrast with surroundings, not absolute luminance.  
C) ✗ Absolute luminance values are not the primary factor; context matters more.  
D) ✗ Relative judgments are more important than absolute judgments in visual encoding.  

**Correct:** A, B


#### 10. Which of the following statements about marks and channels are accurate?  
A) ✓ Mark type constrains which channels can be used for encoding additional attributes.  
B) ✓ Channels have many names including visual variables, retinal channels, and visual dimensions.  
C) ✓ Marks are geometric primitives such as points, lines, and areas.  
D) ✗ Channels do not always convey the same amount or type of information; it depends on mark type.  

**Correct:** A, B, C
