## Answers

#### 1. What is the primary purpose of task abstraction in visualization design?  
A) ✗ Designing algorithms without user needs ignores task focus  
B) ✓ To translate domain-specific questions into generalized tasks  
C) ✗ Creating detailed domain jargon is opposite to abstraction  
D) ✓ Identifying data types supports user tasks, part of abstraction  

**Correct:** B, D


#### 2. Which of the following are components of domain characterization?  
A) ✓ Target domain defines the application area  
B) ✓ Users’ questions and data define domain problems  
C) ✓ Group of users is essential to understand context  
D) ✗ Visualization color schemes are design details, not domain characterization  

**Correct:** A, B, C


#### 3. When mapping domain-language tasks to abstract tasks, what is a key consideration?  
A) ✗ Retaining jargon contradicts abstraction goals  
B) ✓ Removing jargon helps generalize tasks across domains  
C) ✓ Creating {action, target} vocabulary is fundamental  
D) ✗ Ignoring user questions defeats purpose of task abstraction  

**Correct:** B, C


#### 4. Which of the following best describes the relationship between task abstraction and data abstraction?  
A) ✗ They are interdependent, not independent  
B) ✓ Data abstraction helps specify targets within task abstraction  
C) ✗ Task abstraction can lead to changes in data abstraction  
D) ✗ Task abstraction and data abstraction evolve together, not strictly sequential  

**Correct:** B


#### 5. Which of these are examples of {action, target} pairs in task abstraction?  
A) ✗ Designing color palettes is a design activity, not a task pair  
B) ✓ Discover distribution is a valid pair  
C) ✓ Locate outliers is a valid pair  
D) ✓ Compare trends is a valid pair  

**Correct:** B, C, D


#### 6. In the design process, what is the correct order of steps?  
A) ✗ Idioms are identified after task mapping and domain characterization  
B) ✗ Algorithms come after domain characterization and task mapping  
C) ✗ Domain characterization must come first  
D) ✓ Characterize domain → Map tasks → Identify idioms → Identify algorithms is correct order  

**Correct:** D


#### 7. Which of the following are true about the "Analyze" action category?  
A) ✓ Includes both discovering and presenting data  
B) ✓ Can involve producing new data or annotations  
C) ✗ Relevant for all users, not only experts  
D) ✗ Analyze is broader than just searching  

**Correct:** A, B


#### 8. What distinguishes "lookup" from "locate" in the context of search actions?  
A) ✗ Lookup is precise, not casual browsing  
B) ✗ Both require some prior knowledge  
C) ✓ Lookup requires exact key; locate is finding without exact key  
D) ✗ Opposite of correct definitions  

**Correct:** C


#### 9. Which of the following statements about query actions is correct?  
A) ✗ Query actions relate directly to how much data is considered  
B) ✗ Identify queries focus on one item, not summarizing all data  
C) ✓ Compare queries involve some subset of data  
D) ✓ Summarize queries involve understanding the entire dataset  

**Correct:** C, D


#### 10. How can task abstraction influence data abstraction?  
A) ✗ Task abstraction affects more than just color choices  
B) ✗ Data abstraction is not fixed; it evolves with tasks  
C) ✓ Task abstraction can lead to transforming or deriving new data  
D) ✗ Task abstraction and data abstraction are iterative, not strictly sequential  

**Correct:** C


#### 11. Which of the following are valid reasons to iterate between task and data abstraction?  
A) ✓ Adjusting data to support tasks is necessary  
B) ✓ Refining vocabulary improves clarity  
C) ✗ Color scheme finalization is unrelated to abstraction iteration  
D) ✗ Removing user input contradicts user-centered design  

**Correct:** A, B


#### 12. What is a key rule of thumb when creating task abstractions?  
A) ✗ Ignoring user actions misses task essence  
B) ✗ Keeping jargon reduces generality  
C) ✓ Removing jargon helps generalize tasks  
D) ✗ Mixing task and data abstractions is necessary and beneficial  

**Correct:** C


#### 13. Which of the following best describes the "enjoy" action in analysis?  
A) ✗ Producing annotations is a different action  
B) ✗ Searching is separate from enjoyment  
C) ✓ Casual or social interaction, often by newcomers  
D) ✗ Formal presentation is "present" action, not enjoy  

**Correct:** C


#### 14. Which of these are examples of search actions?  
A) ✓ Browse is a search action  
B) ✓ Lookup is a search action  
C) ✓ Locate is a search action  
D) ✗ Summarize is a query action, not search  

**Correct:** A, B, C


#### 15. What does the "browse" search action imply about user knowledge?  
A) ✓ User scans data without a specific target  
B) ✗ User does not know exactly what or where  
C) ✗ Summarizing is a query action  
D) ✗ Comparing known items is a query action  

**Correct:** A


#### 16. How do "analyze," "search," and "query" actions relate to each other?  
A) ✗ Query is not a subset of analyze  
B) ✓ They are independent and can be mixed and matched  
C) ✗ They can be combined, not mutually exclusive  
D) ✗ No fixed order; analyze does not always precede others  

**Correct:** B


#### 17. Which of the following is NOT typically a target in task abstraction?  
A) ✗ Outliers are common targets  
B) ✗ Trends over time are common targets  
C) ✗ Individual data points are common targets  
D) ✓ Visualization color schemes are design elements, not targets  

**Correct:** D


#### 18. Why is it important to remove domain jargon in task abstraction?  
A) ✗ Data abstraction is still needed regardless of jargon  
B) ✓ To make tasks understandable across domains  
C) ✗ Increasing complexity is opposite goal  
D) ✗ Goal is to make system usable by many, not only experts  

**Correct:** B


#### 19. Which of the following statements about the design process is true?  
A) ✗ Domain characterization is essential, not optional  
B) ✓ Iterative refinement between domain, task, and data abstraction is essential  
C) ✗ The process is iterative, not linear  
D) ✗ Algorithms come after understanding tasks  

**Correct:** B


#### 20. What does the "produce" action in analysis typically involve?  
A) ✗ Browsing is a search action  
B) ✓ Annotating or recording new information  
C) ✗ Summarizing is a query action  
D) ✗ Discovering unknown patterns is "discover" action  

**Correct:** B
