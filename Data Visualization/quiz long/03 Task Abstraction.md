## Answers

#### 1. What is the primary purpose of task abstraction in visualization design?  
A) ✓ Identifying data types supports user tasks, part of abstraction  
B) ✓ To translate domain-specific questions into generalized tasks  
C) ✗ Designing algorithms without user needs ignores task focus  
D) ✗ Creating detailed domain jargon is opposite to abstraction  

**Correct:** A, B


#### 2. Which of the following are components of domain characterization?  
A) ✗ Visualization color schemes are design details, not domain characterization  
B) ✓ Target domain defines the application area  
C) ✓ Group of users is essential to understand context  
D) ✓ Users’ questions and data define domain problems  

**Correct:** B, C, D


#### 3. When mapping domain-language tasks to abstract tasks, what is a key consideration?  
A) ✓ Removing jargon helps generalize tasks across domains  
B) ✓ Creating {action, target} vocabulary is fundamental  
C) ✗ Ignoring user questions defeats purpose of task abstraction  
D) ✗ Retaining jargon contradicts abstraction goals  

**Correct:** A, B


#### 4. Which of the following best describes the relationship between task abstraction and data abstraction?  
A) ✓ Data abstraction helps specify targets within task abstraction  
B) ✗ They are interdependent, not independent  
C) ✗ Task abstraction can lead to changes in data abstraction  
D) ✗ Task abstraction and data abstraction evolve together, not strictly sequential  

**Correct:** A


#### 5. Which of these are examples of {action, target} pairs in task abstraction?  
A) ✓ Locate outliers is a valid pair  
B) ✓ Discover distribution is a valid pair  
C) ✓ Compare trends is a valid pair  
D) ✗ Designing color palettes is a design activity, not a task pair  

**Correct:** A, B, C


#### 6. In the design process, what is the correct order of steps?  
A) ✗ Domain characterization must come first  
B) ✗ Algorithms come after domain characterization and task mapping  
C) ✓ Characterize domain → Map tasks → Identify idioms → Identify algorithms is correct order  
D) ✗ Idioms are identified after task mapping and domain characterization  

**Correct:** C


#### 7. Which of the following are true about the "Analyze" action category?  
A) ✗ Relevant for all users, not only experts  
B) ✓ Includes both discovering and presenting data  
C) ✓ Can involve producing new data or annotations  
D) ✗ Analyze is broader than just searching  

**Correct:** B, C


#### 8. What distinguishes "lookup" from "locate" in the context of search actions?  
A) ✗ Both require some prior knowledge  
B) ✗ Lookup is precise, not casual browsing  
C) ✗ Opposite of correct definitions  
D) ✓ Lookup requires exact key; locate is finding without exact key  

**Correct:** D


#### 9. Which of the following statements about query actions is correct?  
A) ✗ Identify queries focus on one item, not summarizing all data  
B) ✓ Summarize queries involve understanding the entire dataset  
C) ✓ Compare queries involve some subset of data  
D) ✗ Query actions relate directly to how much data is considered  

**Correct:** B, C


#### 10. How can task abstraction influence data abstraction?  
A) ✓ Task abstraction can lead to transforming or deriving new data  
B) ✗ Task abstraction and data abstraction are iterative, not strictly sequential  
C) ✗ Task abstraction affects more than just color choices  
D) ✗ Data abstraction is not fixed; it evolves with tasks  

**Correct:** A


#### 11. Which of the following are valid reasons to iterate between task and data abstraction?  
A) ✗ Removing user input contradicts user-centered design  
B) ✓ Adjusting data to support tasks is necessary  
C) ✗ Color scheme finalization is unrelated to abstraction iteration  
D) ✓ Refining vocabulary improves clarity  

**Correct:** B, D


#### 12. What is a key rule of thumb when creating task abstractions?  
A) ✗ Keeping jargon reduces generality  
B) ✗ Ignoring user actions misses task essence  
C) ✗ Mixing task and data abstractions is necessary and beneficial  
D) ✓ Removing jargon helps generalize tasks  

**Correct:** D


#### 13. Which of the following best describes the "enjoy" action in analysis?  
A) ✗ Formal presentation is "present" action, not enjoy  
B) ✓ Casual or social interaction, often by newcomers  
C) ✗ Searching is separate from enjoyment  
D) ✗ Producing annotations is a different action  

**Correct:** B


#### 14. Which of these are examples of search actions?  
A) ✓ Lookup is a search action  
B) ✓ Locate is a search action  
C) ✗ Summarize is a query action, not search  
D) ✓ Browse is a search action  

**Correct:** A, B, D


#### 15. What does the "browse" search action imply about user knowledge?  
A) ✗ User does not know exactly what or where  
B) ✓ User scans data without a specific target  
C) ✗ Comparing known items is a query action  
D) ✗ Summarizing is a query action  

**Correct:** B


#### 16. How do "analyze," "search," and "query" actions relate to each other?  
A) ✗ No fixed order; analyze does not always precede others  
B) ✓ They are independent and can be mixed and matched  
C) ✗ Query is not a subset of analyze  
D) ✗ They can be combined, not mutually exclusive  

**Correct:** B


#### 17. Which of the following is NOT typically a target in task abstraction?  
A) ✗ Individual data points are common targets  
B) ✓ Visualization color schemes are design elements, not targets  
C) ✗ Outliers are common targets  
D) ✗ Trends over time are common targets  

**Correct:** B


#### 18. Why is it important to remove domain jargon in task abstraction?  
A) ✗ Data abstraction is still needed regardless of jargon  
B) ✗ Increasing complexity is opposite goal  
C) ✓ To make tasks understandable across domains  
D) ✗ Goal is to make system usable by many, not only experts

#### 19. Which of the following statements about the design process is true?  
A) ✓ Iterative refinement between domain, task, and data abstraction is essential  
B) ✗ The process is iterative, not linear  
C) ✗ Domain characterization is essential, not optional

#### 20. What does the "produce" action in analysis typically involve?  
A) ✗ Browsing is a search action  
B) ✓ Annotating or recording new information  
C) ✗ Discovering unknown patterns is "discover" action  
D) ✗ Summarizing is a query action  

**Correct:** B
