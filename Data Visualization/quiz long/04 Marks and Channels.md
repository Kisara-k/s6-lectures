## Answers

#### 1. Which of the following are considered marks in visual encoding?  
A) ✗ Size is a channel that modifies marks, not a mark itself.  
B) ✗ Color hue is a channel, not a mark.  
C) ✓ Lines are geometric elements representing links or relationships.  
D) ✓ Points are basic geometric elements representing data items.  

**Correct:** C, D


#### 2. Channels in visualization primarily serve to:  
A) ✓ Channels control how marks appear based on data attributes.  
B) ✗ Spatial layout is not controlled by channels but by positioning rules or marks.  
C) ✗ Representing data items as shapes is the role of marks, not channels.  
D) ✓ Channels encode data by changing mark properties like color or size.  

**Correct:** A, D


#### 3. Which of the following statements about marks and their constraints is true?  
A) ✗ Lines have one fixed dimension (length), not two, and can encode other attributes with width or color.  
B) ✗ Interlocking areas impose constraints and cannot encode multiple quantitative attributes freely.  
C) ✓ Points have no fixed size constraints and can encode multiple attributes with size and shape.  
D) ✓ Areas have fixed length and width, limiting encoding with size or shape.  

**Correct:** C, D


#### 4. Redundant encoding refers to:  
A) ✗ Encoding different attributes with the same channel is not redundant encoding.  
B) ✗ Using multiple marks for the same item is not redundant encoding.  
C) ✓ Encoding the same attribute using multiple channels strengthens the message.  
D) ✗ Using color and size for unrelated attributes is not redundancy but multiplexing.  

**Correct:** C


#### 5. Which of the following channels are generally more effective for encoding quantitative data?  
A) ✗ Color hue is better for categorical data, less precise for quantitative.  
B) ✓ Position along a common scale is highly accurate for quantitative data.  
C) ✗ Shape is better for categorical distinctions, not precise quantitative encoding.  
D) ✓ Length is accurate and effective for quantitative data.  

**Correct:** B, D


#### 6. When encoding categorical data, which channels are most appropriate?  
A) ✓ Color hue effectively distinguishes categories.  
B) ✓ Shape can differentiate categories well.  
C) ✗ Position along a continuous scale is better for quantitative data.  
D) ✗ Size (area) is less effective for categorical data and better for quantitative.  

**Correct:** A, B


#### 7. Which factors improve the accuracy of visual judgments in a visualization?  
A) ✓ Relative judgments are easier and more accurate than absolute ones.  
B) ✗ Many distractors reduce accuracy.  
C) ✓ Alignment on a common scale improves accuracy.  
D) ✗ Large spatial distance can reduce comparison accuracy.  

**Correct:** A, C


#### 8. Which of the following statements about channel effectiveness is correct?  
A) ✓ Length is one of the most accurate channels for perceiving differences.  
B) ✓ Discriminability is about how many distinct levels can be perceived.  
C) ✓ Separability means perception of one channel is unaffected by others.  
D) ✗ Color saturation is less precise for quantitative judgments than length or position.  

**Correct:** A, B, C


#### 9. Popout effects occur when:  
A) ✗ Redundant encoding strengthens messages but does not cause popout.  
B) ✓ An item differs on a single channel and is detected quickly via parallel processing.  
C) ✗ Serial search is slow and happens when popout does not occur.  
D) ✗ Color differences usually cause popout, not blending in.  

**Correct:** B


#### 10. Which of the following are true about relative versus absolute perceptual judgments?  
A) ✗ Weber’s Law states the ratio (relative difference) is constant, not absolute difference.  
B) ✓ Judgments improve with common frame or scale.  
C) ✓ The visual system is better at relative than absolute judgments.  
D) ✗ Absolute luminance is perceived relative to context, not independently.  

**Correct:** B, C


#### 11. Which of the following are examples of visual channels?  
A) ✓ Texture is a visual channel.  
B) ✗ Volume is a mark type, not a channel.  
C) ✓ Position is a visual channel.  
D) ✓ Orientation is a visual channel.  

**Correct:** A, C, D


#### 12. Which of the following statements about interlocking areas is true?  
A) ✗ They cannot encode multiple quantitative attributes simultaneously with size and shape.  
B) ✓ They impose constraints because length and width are fixed.  
C) ✓ They can be nested to show containment.  
D) ✗ They can encode categorical data, so this is false.  

**Correct:** B, C


#### 13. Which of the following best describes the concept of separability in visual channels?  
A) ✓ Separability is the ability to perceive one channel independently of others.  
B) ✗ Popout speed relates to popout, not separability.  
C) ✗ Number of unique steps is discriminability, not separability.  
D) ✗ Accuracy comparison is unrelated to separability.  

**Correct:** A


#### 14. Why is position along a common aligned scale more effective than position along an unaligned scale?  
A) ✗ Popout effects are unrelated to scale alignment.  
B) ✗ It does not affect discriminability of color hue.  
C) ✓ It reduces cognitive load by providing a shared reference frame.  
D) ✗ It improves relative, not absolute, judgments.  

**Correct:** C


#### 15. Which of the following are limitations of using color hue as a channel?  
A) ✗ Color hue can interfere with other channels, so it is not always highly separable.  
B) ✓ Affected by color constancy and illumination changes.  
C) ✓ Less precise for quantitative data than length or position.  
D) ✗ It does not allow unlimited discriminable levels; human perception is limited.  

**Correct:** B, C


#### 16. Which of the following statements about marks and channels is false?  
A) ✓ Channels control appearance and encode attributes.  
B) ✓ Mark type constrains which channels can be used.  
C) ✓ Marks are geometric primitives representing data.  
D) ✗ Marks cannot encode data independently of channels; channels modify marks to encode data.  

**Correct:** D


#### 17. Which of the following are true about the concept of popout in visual search?  
A) ✓ Serial search is required when multiple channels are combined in complex ways.  
B) ✓ Popout speed is independent of distractor count for certain channels.  
C) ✗ Popout is not equally strong for all channel combinations; some combinations require serial search.  
D) ✓ Popout occurs due to parallel processing of individual channels.  

**Correct:** A, B, D


#### 18. Which of the following best explains why filled rectangles differing in length by 1:9 are harder to judge than white rectangles differing by 1:2?  
A) ✓ Visual system relies on relative luminance judgments affected by background contrast.  
B) ✗ Alignment is relevant but not the main reason in this example.  
C) ✗ Color hue does not interfere here; luminance and contrast do.  
D) ✗ Absolute length differences are harder, not easier, to perceive than relative differences.  

**Correct:** A


#### 19. Which of the following are examples of grouping channels in visualization?  
A) ✓ Containment using interlocking areas groups items visually.  
B) ✓ Similarity using color or shape groups categories.  
C) ✗ Size encodes quantitative data, not grouping per se.  
D) ✓ Connection using lines or links groups related items.  

**Correct:** A, B, D


#### 20. Which of the following statements about the scope of analysis in marks and channels is true?  
A) ✓ Multiple marks in a region (glyphs) allow richer data but complicate encoding.  
B) ✓ Simplifying assumptions often consider one mark per item and a single view.  
C) ✗ Marks do not always represent individual items; aggregation can omit some.  
D) ✓ Aggregation and filtering mean some items may not be represented by marks.  

**Correct:** A, B, D
