## Answers

#### 1. Which of the following best describes the concept of "data-ink ratio"?  
A) ✓ Correct: It is the proportion of ink used to represent actual data.  
B) ✗ This describes data density, not data-ink ratio.  
C) ✗ It refers to decorative ink, not data ink.  
D) ✗ Total ink includes both data and non-data ink, not the ratio.  

**Correct:** A


#### 2. What are effective ways to maximize the data-ink ratio in a visualization?  
A) ✗ 3D effects usually add clutter and reduce data-ink ratio.  
B) ✗ Colorful backgrounds add non-data ink, reducing ratio.  
C) ✓ Removing unnecessary gridlines reduces non-data ink.  
D) ✓ Eliminating redundant labels focuses ink on data.  

**Correct:** C, D


#### 3. Data density in a visualization refers to:  
A) ✗ Number of colors is unrelated to data density.  
B) ✗ Ink amount is unrelated to data density.  
C) ✗ Ratio of data points to variables is not data density.  
D) ✓ Correct: Number of data entries divided by graphic area.  

**Correct:** D


#### 4. Which of the following statements about data density is true?  
A) ✓ Small multiples and sparklines increase data density effectively.  
B) ✗ Visual appeal does not guarantee clarity or data density.  
C) ✓ Layering information carefully can increase data density.  
D) ✗ Increasing data density can reduce clarity if overdone.  

**Correct:** A, C


#### 5. Why is providing context and comparisons important in data visualization?  
A) ✗ Context does not help ignore data points; it aids interpretation.  
B) ✓ Context helps viewers understand data significance.  
C) ✗ Context is not for decoration but for understanding.  
D) ✓ Comparisons enable meaningful interpretation.  

**Correct:** B, D


#### 6. The "Lie Factor" in a visualization measures:  
A) ✓ Correct: Ratio of graphical distortion to actual data change.  
B) ✗ It is unrelated to 2D vs 3D visualization.  
C) ✗ Lie Factor is about distortion, not count of misrepresented points.  
D) ✗ It does not measure decorative ink.  

**Correct:** A


#### 7. A Lie Factor value of 1.2 indicates:  
A) ✗ Understatement would be less than 1.  
B) ✗ Distortion is present, so not free from distortion.  
C) ✗ 1.2 means distortion, not perfect representation.  
D) ✓ Correct: Graphic exaggerates data by 20%.  

**Correct:** D


#### 8. Which of the following are principles of graphical integrity?  
A) ✗ Quoting data out of context causes distortion.  
B) ✓ Show data variation, not design variation.  
C) ✗ Labeling should be clear and thorough, not minimal.  
D) ✓ Size should be proportional to data values.  

**Correct:** B, D


#### 9. When is the use of 3D visualization justified?  
A) ✓ Interactive navigation can justify 3D use.  
B) ✗ Abstract data usually does not benefit from 3D.  
C) ✓ True 3D spatial data benefits from 3D visualization.  
D) ✗ Using 3D just for impressiveness is not justified.  

**Correct:** A, C


#### 10. What are common problems caused by unjustified 3D visualizations?  
A) ✓ Perspective distortion misleads size perception.  
B) ✓ Occlusion hides data behind other elements.  
C) ✗ 3D usually reduces clarity and legibility.  
D) ✓ Tilted text in 3D is harder to read.  

**Correct:** A, B, D


#### 11. Which of the following statements about interactivity in visualizations is true?  
A) ✓ Interactivity helps users explore and find insights.  
B) ✗ Clear labeling remains important even with interactivity.  
C) ✗ Interactivity generally aids understanding, not confusion.  
D) ✓ Drill-down helps focus on details.

#### 12. Designing for universal accessibility includes:  
A) ✗ Ignoring readability excludes visually impaired users.  
B) ✓ Provide alternative text for images.  
C) ✓ Use color schemes distinguishable by color-blind users.
