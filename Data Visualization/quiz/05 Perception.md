## 6. Perception

## Questions

#### 1. Which of the following statements accurately describe System 1 thinking?  
A) It requires self-awareness and effortful control.  
B) It handles about 98% of our daily thinking.  
C) It operates unconsciously and automatically.  
D) It is responsible for deliberate, logical reasoning.  

#### 2. What factors influence what we actually perceive when we look at a scene?  
A) Where our attention is focused.  
B) The total number of objects in the environment.  
C) The physical presence of objects only.  
D) Our expectations and prior knowledge.  

#### 3. Which of the following best explain the concept of selective attention?  
A) We perceive all stimuli in our environment equally.  
B) We only perceive what our mind actively attends to.  
C) Attention can cause us to miss obvious changes or objects.  
D) Selective attention is unrelated to memory capacity.  

#### 4. How does the capacity of visual working memory affect perception?  
A) It has no impact on how we interpret complex visual scenes.  
B) It limits us to holding about 3-4 simple shapes simultaneously.  
C) It influences how much information we can process from an image at a time.  
D) It allows us to remember unlimited visual details at once.  

#### 5. Which of the following are examples of pre-attentive visual attributes?  
A) Conscious mental calculations.  
B) Color hue and intensity.  
C) Logical reasoning and problem-solving.  
D) Line width and spatial position.  

#### 6. According to Gestalt principles, which factors contribute to grouping visual elements together?  
A) Proximity or closeness of elements.  
B) Random distribution of elements.  
C) Movement in the same direction and speed.  
D) Similarity in color or shape.  

#### 7. What distinguishes post-attentive perception from pre-attentive perception?  
A) Post-attentive perception is immediate and unconscious.  
B) Post-attentive perception requires conscious effort and mental search.  
C) Post-attentive perception involves interpreting complex patterns.  
D) Pre-attentive perception involves slow, deliberate analysis.  

#### 8. Which of the following statements about color perception are true?  
A) Shadows can alter how we perceive the color of an object.  
B) The color of the light source influences color perception.  
C) Color perception is entirely determined by the physical properties of objects.  
D) Color perception is fixed and unaffected by lighting conditions.  

#### 9. How does System 2 thinking interact with System 1 in processing visual information?  
A) System 2 handles most of our everyday automatic responses.  
B) System 1 provides quick intuitive assessments, while System 2 analyzes details.  
C) System 1 constantly seeks new information to update System 2.  
D) System 2 overrides System 1 when deliberate, logical decisions are needed.  

#### 10. Which of the following best describe the limitations and characteristics of human visual perception?  
A) We are highly sensitive to contrast and changes in the visual field.  
B) Short-term visual memory limits the amount of information we can process at once.  
C) Our perception is unaffected by familiarity or prior knowledge.  
D) We perceive every detail in a complex image simultaneously without effort.

## Answers

#### 1. Which of the following statements accurately describe System 1 thinking?  
A) ✗ It requires self-awareness and effortful control. System 1 works without conscious control.  
B) ✓ It handles about 98% of our daily thinking. System 1 manages the vast majority of our thinking.  
C) ✓ It operates unconsciously and automatically. System 1 is fast, automatic, and unconscious.  
D) ✗ It is responsible for deliberate, logical reasoning. This describes System 2, not System 1.  

**Correct:** B, C


#### 2. What factors influence what we actually perceive when we look at a scene?  
A) ✓ Where our attention is focused. Attention directs perception to specific parts of the scene.  
B) ✗ The total number of objects in the environment. Quantity alone does not determine perception.  
C) ✗ The physical presence of objects only. Perception depends on more than just physical presence.  
D) ✓ Our expectations and prior knowledge. What we expect influences what we see.  

**Correct:** A, D


#### 3. Which of the following best explain the concept of selective attention?  
A) ✗ We perceive all stimuli in our environment equally. Selective attention means we do not perceive everything equally.  
B) ✓ We only perceive what our mind actively attends to. Attention filters what we consciously perceive.  
C) ✓ Attention can cause us to miss obvious changes or objects. Experiments show people miss obvious things when focused elsewhere.  
D) ✗ Selective attention is unrelated to memory capacity. Memory limits affect what we can attend to and perceive.  

**Correct:** B, C


#### 4. How does the capacity of visual working memory affect perception?  
A) ✗ It has no impact on how we interpret complex visual scenes. Memory capacity directly affects interpretation.  
B) ✓ It limits us to holding about 3-4 simple shapes simultaneously. This is the typical capacity of visual working memory.  
C) ✓ It influences how much information we can process from an image at a time. Limited memory restricts perception detail.  
D) ✗ It allows us to remember unlimited visual details at once. Visual working memory is limited, not unlimited.  

**Correct:** B, C


#### 5. Which of the following are examples of pre-attentive visual attributes?  
A) ✗ Conscious mental calculations. These require effort and attention, not pre-attentive processing.  
B) ✓ Color hue and intensity. These are processed quickly and automatically.  
C) ✗ Logical reasoning and problem-solving. These are conscious, post-attentive processes.  
D) ✓ Line width and spatial position. Both are pre-attentive visual features.  

**Correct:** B, D


#### 6. According to Gestalt principles, which factors contribute to grouping visual elements together?  
A) ✓ Proximity or closeness of elements. Close elements tend to be grouped.  
B) ✗ Random distribution of elements. Randomness does not create grouping.  
C) ✓ Movement in the same direction and speed. Common fate groups moving elements together.  
D) ✓ Similarity in color or shape. Similar elements are perceived as a group.  

**Correct:** A, C, D


#### 7. What distinguishes post-attentive perception from pre-attentive perception?  
A) ✗ Post-attentive perception is immediate and unconscious. This describes pre-attentive perception.  
B) ✓ Post-attentive perception requires conscious effort and mental search. It is slower and deliberate.  
C) ✓ Post-attentive perception involves interpreting complex patterns. It requires conscious processing.  
D) ✗ Pre-attentive perception involves slow, deliberate analysis. It is fast and automatic.  

**Correct:** B, C


#### 8. Which of the following statements about color perception are true?  
A) ✓ Shadows can alter how we perceive the color of an object. Shadows change perceived color.  
B) ✓ The color of the light source influences color perception. Different light sources shift color appearance.  
C) ✗ Color perception is entirely determined by the physical properties of objects. Context and lighting also influence perception.  
D) ✗ Color perception is fixed and unaffected by lighting conditions. Lighting strongly affects color perception.  

**Correct:** A, B


#### 9. How does System 2 thinking interact with System 1 in processing visual information?  
A) ✗ System 2 handles most of our everyday automatic responses. System 1 handles most automatic responses.  
B) ✓ System 1 provides quick intuitive assessments, while System 2 analyzes details. They complement each other.  
C) ✗ System 1 constantly seeks new information to update System 2. System 1 provides quick assessments but does not actively seek info.  
D) ✓ System 2 overrides System 1 when deliberate, logical decisions are needed. System 2 controls reasoning and correction.  

**Correct:** B, D


#### 10. Which of the following best describe the limitations and characteristics of human visual perception?  
A) ✓ We are highly sensitive to contrast and changes in the visual field. Contrast draws attention.  
B) ✓ Short-term visual memory limits the amount of information we can process at once. Memory capacity is limited.  
C) ✗ Our perception is unaffected by familiarity or prior knowledge. Familiarity strongly influences perception.  
D) ✗ We perceive every detail in a complex image simultaneously without effort. We cannot process all details at once.  

**Correct:** A, B
