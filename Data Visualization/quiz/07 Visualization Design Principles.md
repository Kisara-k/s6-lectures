## Answers

#### 1. Which of the following best describes the concept of "data-ink ratio"?  
A) ✗ Total ink includes both data and non-data ink, not the ratio.  
B) ✓ Correct: It is the proportion of ink used to represent actual data.  
C) ✗ It refers to decorative ink, not data ink.  
D) ✗ This describes data density, not data-ink ratio.  

**Correct:** B


#### 2. What are effective ways to maximize the data-ink ratio in a visualization?  
A) ✓ Removing unnecessary gridlines reduces non-data ink.  
B) ✓ Eliminating redundant labels focuses ink on data.  
C) ✗ 3D effects usually add clutter and reduce data-ink ratio.  
D) ✗ Colorful backgrounds add non-data ink, reducing ratio.  

**Correct:** A, B


#### 3. Data density in a visualization refers to:  
A) ✗ Number of colors is unrelated to data density.  
B) ✗ Ratio of data points to variables is not data density.  
C) ✓ Correct: Number of data entries divided by graphic area.  
D) ✗ Ink amount is unrelated to data density.  

**Correct:** C


#### 4. Which of the following statements about data density is true?  
A) ✓ Layering information carefully can increase data density.  
B) ✗ Visual appeal does not guarantee clarity or data density.  
C) ✓ Small multiples and sparklines increase data density effectively.  
D) ✗ Increasing data density can reduce clarity if overdone.  

**Correct:** A, C


#### 5. Why is providing context and comparisons important in data visualization?  
A) ✗ Context does not help ignore data points; it aids interpretation.  
B) ✓ Context helps viewers understand data significance.  
C) ✓ Comparisons enable meaningful interpretation.  
D) ✗ Context is not for decoration but for understanding.  

**Correct:** B, C


#### 6. The "Lie Factor" in a visualization measures:  
A) ✗ It is unrelated to 2D vs 3D visualization.  
B) ✗ Lie Factor is about distortion, not count of misrepresented points.  
C) ✗ It does not measure decorative ink.  
D) ✓ Correct: Ratio of graphical distortion to actual data change.  

**Correct:** D
