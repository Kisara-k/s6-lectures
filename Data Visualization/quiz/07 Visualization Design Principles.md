## Answers

#### 1. Which of the following best describes the concept of "data-ink ratio"?  
A) ✗ It refers to decorative ink, not data ink.  
B) ✓ Correct: It is the proportion of ink used to represent actual data.  
C) ✗ Total ink includes both data and non-data ink, not the ratio.  
D) ✗ This describes data density, not data-ink ratio.  

**Correct:** B


#### 2. What are effective ways to maximize the data-ink ratio in a visualization?  
A) ✓ Removing unnecessary gridlines reduces non-data ink.  
B) ✗ Colorful backgrounds add non-data ink, reducing ratio.  
C) ✓ Eliminating redundant labels focuses ink on data.  
D) ✗ 3D effects usually add clutter and reduce data-ink ratio.  

**Correct:** A,C


#### 3. Data density in a visualization refers to:  
A) ✓ Correct: Number of data entries divided by graphic area.  
B) ✗ Ink amount is unrelated to data density.  
C) ✗ Number of colors is unrelated to data density.  
D) ✗ Ratio of data points to variables is not data density.  

**Correct:** A


#### 4. Which of the following statements about data density is true?  
A) ✗ Increasing data density can reduce clarity if overdone.  
B) ✓ Layering information carefully can increase data density.  
C) ✗ Visual appeal does not guarantee clarity or data density.  
D) ✓ Small multiples and sparklines increase data density effectively.  

**Correct:** B,D


#### 5. Why is providing context and comparisons important in data visualization?  
A) ✓ Context helps viewers understand data significance.  
B) ✗ Context does not help ignore data points; it aids interpretation.  
C) ✓ Comparisons enable meaningful interpretation.  
D) ✗ Context is not for decoration but for understanding.  

**Correct:** A,C


#### 6. The "Lie Factor" in a visualization measures:  
A) ✗ It does not measure decorative ink.  
B) ✓ Correct: Ratio of graphical distortion to actual data change.  
C) ✗ Lie Factor is about distortion, not count of misrepresented points.  
D) ✗ It is unrelated to 2D vs 3D visualization.  

**Correct:** B


#### 7. A Lie Factor value of 1.2 indicates:  
A) ✗ 1.2 means distortion, not perfect representation.  
B) ✓ Correct: Graphic exaggerates data by 20%.  
C) ✗ Understatement would be less than 1.  
D) ✗ Distortion is present, so not free from distortion.  

**Correct:** B


#### 8. Which of the following are principles of graphical integrity?  
A) ✓ Size should be proportional to data values.  
B) ✗ Labeling should be clear and thorough, not minimal.  
C) ✓ Show data variation, not design variation.  
D) ✗ Quoting data out of context causes distortion.  

**Correct:** A,C


#### 9. When is the use of 3D visualization justified?
