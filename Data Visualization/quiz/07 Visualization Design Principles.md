## Answers

#### 1. Which of the following best describes the concept of "data-ink ratio"?  
A) ✗ It refers to decorative ink, not data ink.  
B) ✓ Correct: It is the proportion of ink used to represent actual data.  
C) ✗ This describes data density, not data-ink ratio.  
D) ✗ Total ink includes both data and non-data ink, not the ratio.  

**Correct:** B


#### 2. What are effective ways to maximize the data-ink ratio in a visualization?  
A) ✓ Eliminating redundant labels focuses ink on data.  
B) ✓ Removing unnecessary gridlines reduces non-data ink.  
C) ✗ 3D effects usually add clutter and reduce data-ink ratio.  
D) ✗ Colorful backgrounds add non-data ink, reducing ratio.  

**Correct:** A, B


#### 3. Data density in a visualization refers to:  
A) ✗ Ratio of data points to variables is not data density.  
B) ✗ Number of colors is unrelated to data density.  
C) ✗ Ink amount is unrelated to data density.  
D) ✓ Correct: Number of data entries divided by graphic area.  

**Correct:** D


#### 4. Which of the following statements about data density is true?  
A) ✓ Small multiples and sparklines increase data density effectively.  
B) ✗ Increasing data density can reduce clarity if overdone.  
C) ✗ Visual appeal does not guarantee clarity or data density.  
D) ✓ Layering information carefully can increase data density.  

**Correct:** A, D


#### 5. Why is providing context and comparisons important in data visualization?  
A) ✓ Comparisons enable meaningful interpretation.  
B) ✗ Context is not for decoration but for understanding.  
C) ✗ Context does not help ignore data points; it aids interpretation.  
D) ✓ Context helps viewers understand data significance.  

**Correct:** A, D


#### 6. The "Lie Factor" in a visualization measures:  
A) ✗ It does not measure decorative ink.  
B) ✗ Lie Factor is about distortion, not count of misrepresented points.  
C) ✓ Correct: Ratio of graphical distortion to actual data change.  
D) ✗ It is unrelated to 2D vs 3D visualization.  

**Correct:** C


#### 7. A Lie Factor value of 1.2 indicates:  
A) ✗ 1.2 means distortion, not perfect representation.  
B) ✗ Distortion is present, so not free from distortion.  
C) ✗ Understatement would be less than 1.  
D) ✓ Correct: Graphic exaggerates data by 20%.  

**Correct:** D


#### 8. Which of the following are principles of graphical integrity?  
A) ✓ Size should be proportional to data values.  
B) ✓ Show data variation, not design variation.  
C) ✗ Quoting data out of context causes distortion.  
D) ✗ Labeling should be clear and thorough, not minimal.  

**Correct:** A, B


#### 9. When is the use of 3D visualization justified?  
A) ✓ Interactive navigation can justify 3D use.  
B) ✓ True 3D spatial data benefits from 3D visualization.  
C) ✗ Abstract data usually does not benefit from 3D.  
D) ✗ Using 3D just for impressiveness is not justified.  

**Correct:** A, B


#### 10. What are common problems caused by unjustified 3D visualizations?  
A) ✓ Tilted text in 3D is harder to read.  
B) ✓ Occlusion hides data behind other elements.  
C) ✗ 3D usually reduces clarity and legibility.  
D) ✓ Perspective distortion misleads size perception.

#### 11. Which of the following statements about interactivity in visualizations is true?

B) ✓ Interactivity helps users explore and find insights.

#### 12. Designing for universal accessibility includes:  
A) ✓ Consider all users regardless of ability.  
B) ✓ Use color schemes distinguishable by color-blind users.
