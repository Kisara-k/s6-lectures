## Answers

#### 1. What is the primary purpose of task abstraction in visualization design?  
A) ✓ To translate domain-specific questions into generalized tasks  
B) ✗ Creating detailed domain jargon is opposite to abstraction  
C) ✓ Identifying data types supports user tasks, part of abstraction  
D) ✗ Designing algorithms without user needs ignores task focus  

**Correct:** A, C


#### 2. Which of the following are components of domain characterization?  
A) ✓ Group of users is essential to understand context  
B) ✓ Target domain defines the application area  
C) ✗ Visualization color schemes are design details, not domain characterization  
D) ✓ Users’ questions and data define domain problems  

**Correct:** A, B, D


#### 3. When mapping domain-language tasks to abstract tasks, what is a key consideration?  
A) ✗ Retaining jargon contradicts abstraction goals  
B) ✓ Removing jargon helps generalize tasks across domains  
C) ✗ Ignoring user questions defeats purpose of task abstraction  
D) ✓ Creating {action, target} vocabulary is fundamental  

**Correct:** B, D


#### 4. Which of the following best describes the relationship between task abstraction and data abstraction?  
A) ✗ They are interdependent, not independent  
B) ✓ Data abstraction helps specify targets within task abstraction  
C) ✗ Task abstraction and data abstraction evolve together, not strictly sequential  
D) ✗ Task abstraction can lead to changes in data abstraction  

**Correct:** B


#### 5. Which of these are examples of {action, target} pairs in task abstraction?  
A) ✓ Discover distribution is a valid pair  
B) ✓ Compare trends is a valid pair  
C) ✓ Locate outliers is a valid pair  
D) ✗ Designing color palettes is a design activity, not a task pair  

**Correct:** A, B, C


#### 6. In the design process, what is the correct order of steps?  
A) ✗ Algorithms come after domain characterization and task mapping  
B) ✓ Characterize domain → Map tasks → Identify idioms → Identify algorithms is correct order  
C) ✗ Domain characterization must come first  
D) ✗ Idioms are identified after task mapping and domain characterization  

**Correct:** B


#### 7. Which of the following are true about the "Analyze" action category?  
A) ✓ Includes both discovering and presenting data  
B) ✗ Analyze is broader than just searching  
C) ✓ Can involve producing new data or annotations  
D) ✗ Relevant for all users, not only experts  

**Correct:** A, C


#### 8. What distinguishes "lookup" from "locate" in the context of search actions?  
A) ✓ Lookup requires exact key; locate is finding without exact key  
B) ✗ Opposite of correct definitions  
C) ✗ Lookup is precise, not casual browsing  
D) ✗ Both require some prior knowledge  

**Correct:** A


#### 9. Which of the following statements about query actions is correct?  
A) ✗ Identify queries focus on one item, not summarizing all data  
B) ✓ Compare queries involve some subset of data  
C) ✓ Summarize queries involve understanding the entire dataset  
D) ✗ Query actions relate directly to how much data is considered  

**Correct:** B, C


#### 10. How can task abstraction influence data abstraction?  
A) ✓ Task abstraction can lead to transforming or deriving new data  
B) ✗ Data abstraction is not fixed; it evolves with tasks  
C) ✗ Task abstraction affects more than just color choices  
D) ✗ Task abstraction and data abstraction are iterative, not strictly sequential  

**Correct:** A


#### 11. Which of the following are valid reasons to iterate between task and data abstraction?  
A) ✓ Refining vocabulary improves clarity  
B) ✓ Adjusting data to support tasks is necessary  
C) ✗ Color scheme finalization is unrelated to abstraction iteration  
D) ✗ Removing user input contradicts user-centered design  

**Correct:** A, B


#### 12. What is a key rule of thumb when creating task abstractions?  
A) ✗ Keeping jargon reduces generality  
B) ✓ Removing jargon helps generalize tasks  
C) ✗ Ignoring user actions misses task essence  
D) ✗ Mixing task and data abstractions is necessary and beneficial  

**Correct:** B


#### 13. Which of the following best describes the "enjoy" action in analysis?  
A) ✓ Casual or social interaction, often by newcomers  
B) ✗ Formal presentation is "present" action, not enjoy  
C) ✗ Producing annotations is a different action  
D) ✗ Searching is separate from enjoyment  

**Correct:** A


#### 14. Which of these are examples of search actions?  
A) ✓ Lookup is a search action  
B) ✓ Locate is a search action  
C) ✓ Browse is a search action  
D) ✗ Summarize is a query action, not search  

**Correct:** A, B, C


#### 15. What does the "browse" search action imply about user knowledge?  
A) ✗ User does not know exactly what or where  
B) ✓ User scans data without a specific target  
C) ✗ Comparing known items is a query action  
D) ✗ Summarizing is a query action

#### 16. How do "analyze," "search," and "query" actions relate to each other?

#### 18. Why is it important to remove domain jargon in task abstraction?
