## Answers

#### 1. What is the primary purpose of task abstraction in visualization design?  
A) ✓ To translate domain-specific questions into generalized tasks  
B) ✓ Identifying data types supports user tasks, part of abstraction  
C) ✗ Designing algorithms without user needs ignores task focus  
D) ✗ Creating detailed domain jargon is opposite to abstraction  

**Correct:** A, B


#### 2. Which of the following are components of domain characterization?  
A) ✗ Visualization color schemes are design details, not domain characterization  
B) ✓ Group of users is essential to understand context  
C) ✓ Users’ questions and data define domain problems  
D) ✓ Target domain defines the application area  

**Correct:** B, C, D


#### 3. When mapping domain-language tasks to abstract tasks, what is a key consideration?  
A) ✗ Ignoring user questions defeats purpose of task abstraction  
B) ✓ Removing jargon helps generalize tasks across domains  
C) ✗ Retaining jargon contradicts abstraction goals  
D) ✓ Creating {action, target} vocabulary is fundamental  

**Correct:** B, D


#### 4. Which of the following best describes the relationship between task abstraction and data abstraction?  
A) ✗ Task abstraction can lead to changes in data abstraction  
B) ✓ Data abstraction helps specify targets within task abstraction  
C) ✗ They are interdependent, not independent  
D) ✗ Task abstraction and data abstraction evolve together, not strictly sequential  

**Correct:** B


#### 5. Which of these are examples of {action, target} pairs in task abstraction?  
A) ✓ Locate outliers is a valid pair  
B) ✓ Discover distribution is a valid pair  
C) ✗ Designing color palettes is a design activity, not a task pair  
D) ✓ Compare trends is a valid pair  

**Correct:** A, B, D


#### 6. In the design process, what is the correct order of steps?  
A) ✗ Domain characterization must come first  
B) ✗ Idioms are identified after task mapping and domain characterization  
C) ✓ Characterize domain → Map tasks → Identify idioms → Identify algorithms is correct order  
D) ✗ Algorithms come after domain characterization and task mapping  

**Correct:** C


#### 7. Which of the following are true about the "Analyze" action category?  
A) ✗ Relevant for all users, not only experts  
B) ✗ Analyze is broader than just searching  
C) ✓ Can involve producing new data or annotations  
D) ✓ Includes both discovering and presenting data  

**Correct:** C, D


#### 8. What distinguishes "lookup" from "locate" in the context of search actions?  
A) ✗ Both require some prior knowledge  
B) ✗ Opposite of correct definitions  
C) ✓ Lookup requires exact key; locate is finding without exact key  
D) ✗ Lookup is precise, not casual browsing  

**Correct:** C


#### 9. Which of the following statements about query actions is correct?  
A) ✗ Query actions relate directly to how much data is considered  
B) ✓ Compare queries involve some subset of data  
C) ✗ Identify queries focus on one item, not summarizing all data  
D) ✓ Summarize queries involve understanding the entire dataset  

**Correct:** B, D


#### 10. How can task abstraction influence data abstraction?  
A) ✓ Task abstraction can lead to transforming or deriving new data  
B) ✗ Data abstraction is not fixed; it evolves with tasks  
C) ✗ Task abstraction affects more than just color choices  
D) ✗ Task abstraction and data abstraction are iterative, not strictly sequential  

**Correct:** A


#### 11. Which of the following are valid reasons to iterate between task and data abstraction?  
A) ✗ Removing user input contradicts user-centered design  
B) ✓ Adjusting data to support tasks is necessary  
C) ✗ Color scheme finalization is unrelated to abstraction iteration  
D) ✓ Refining vocabulary improves clarity  

**Correct:** B, D


#### 12. What is a key rule of thumb when creating task abstractions?  
A) ✗ Mixing task and data abstractions is necessary and beneficial  
B) ✓ Removing jargon helps generalize tasks  
C) ✗ Keeping jargon reduces generality  
D) ✗ Ignoring user actions misses task essence  

**Correct:** B


#### 13. Which of the following best describes the "enjoy" action in analysis?  
A) ✗ Producing annotations is a different action  
B) ✗ Searching is separate from enjoyment  
C) ✓ Casual or social interaction, often by newcomers  
D) ✗ Formal presentation is "present" action, not enjoy  

**Correct:** C


#### 14. Which of these are examples of search actions?  
A) ✓ Lookup is a search action  
B) ✗ Summarize is a query action, not search  
C) ✓ Browse is a search action  
D) ✓ Locate is a search action  

**Correct:** A, C, D


#### 15. What does the "browse" search action imply about user knowledge?  
A) ✓ User scans data without a specific target  
B) ✗ User does not know exactly what or where  
C) ✗ Comparing known items is a query action  
D) ✗ Summarizing is a query action  

**Correct:** A


#### 16. How do "analyze," "search," and "query" actions relate to each other?  
A) ✓ They are independent and can be mixed and matched  
B) ✗ They can be combined, not mutually exclusive  
C) ✗ Query is not a subset of analyze  
D) ✗ No fixed order; analyze does not always precede others  

**Correct:** A


#### 17. Which of the following is NOT typically a target in task abstraction?  
A) ✗ Trends over time are common targets  
B) ✗ Outliers are common targets  
C) ✗ Individual data points are common targets  
D) ✓ Visualization color schemes are design elements, not targets  

**Correct:** D


#### 18. Why is it important to remove domain jargon in task abstraction?  
A) ✗ Goal is to make system usable by many, not only experts  
B) ✗ Data abstraction is still needed regardless of jargon  
C) ✓ To make tasks understandable across domains

**Correct:** C


#### 19. Which of the following statements about the design process is true?  
A) ✗ The process is iterative, not linear  
B) ✗ Domain characterization is essential, not optional  
C) ✓ Iterative refinement between domain, task, and data abstraction is essential  
D) ✗ Algorithms come after understanding tasks  

**Correct:** C


#### 20. What does the "produce" action in analysis typically involve?  
A) ✗ Discovering unknown patterns is "discover" action  
B) ✗ Summarizing is a query action  
C) ✗ Browsing is a search action  
D) ✓ Annotating or recording new information  

**Correct:** D
