## 5. Marks and Channels

## Questions

#### 1. Which of the following statements about marks in visual encoding are true?  
A) Volumes (3D marks) are commonly used because they provide the most accurate data representation.  
B) Points have no fixed size constraints and can encode multiple attributes using size and shape.  
C) Areas have constraints on both length and width, limiting their ability to encode more attributes via size or shape.  
D) Lines have two fixed dimensions, so size and shape cannot be used to encode additional data.  

#### 2. Which channels are generally considered most effective for encoding quantitative data due to their high perceptual accuracy?  
A) Length  
B) Color hue  
C) Shape  
D) Position along a common aligned scale  

#### 3. When might redundant encoding (using multiple channels for the same data attribute) be beneficial?  
A) To conserve visual channels for encoding other attributes  
B) When channels used are highly separable and do not interfere with each other  
C) When the mark type restricts the use of size or shape encoding  
D) To strengthen the message and improve clarity  

#### 4. Which of the following factors can negatively affect the accuracy of visual encoding?  
A) Using a common frame or scale for comparison  
B) Alignment of marks on a common scale  
C) Large spatial distance between marks  
D) Presence of many distractors in the visualization  

#### 5. Regarding channel discriminability, which statements are correct?  
A) Color saturation generally allows fewer distinct levels than position.  
B) Discriminability is irrelevant if the channel is highly expressive.  
C) The number of perceivable steps in a channel must be sufficient to represent the number of attribute levels.  
D) Line width can reliably encode many distinct levels of data attributes.  

#### 6. Which of the following best describe the concept of "popout" in visual perception?  
A) Parallel line pairs always pop out from tilted pairs.  
B) Channels like color hue and size can produce popout effects.  
C) It allows certain items to be detected quickly regardless of the number of distractors.  
D) It occurs when an item differs on a channel that is processed serially, making it harder to find.  

#### 7. How do marks constrain what can be encoded using channels?  
A) Points allow encoding of multiple attributes using size and shape because they have no fixed size constraints.  
B) Lines fix length but allow width and color to encode other attributes.  
C) If size or shape is already used to encode an attribute, it cannot be reused for another attribute without confusion.  
D) Interlocking areas can encode additional attributes by varying size and shape freely.  

#### 8. Which of the following statements about relative versus absolute judgments in visual perception are true?  
A) The perceptual system primarily operates with absolute judgments of data values.  
B) Judging length differences is easier when rectangles are filled rather than white.  
C) Weber’s Law explains why the ratio of increment to background affects detectability.  
D) Accuracy improves when marks are aligned on a common scale due to relative judgment.  

#### 9. Which of the following are valid reasons why color channels can be challenging for precise quantitative encoding?  
A) Human perception of luminance is absolute and unaffected by contrast.  
B) Color perception is highly contextual and depends on surrounding colors (color constancy).  
C) Saturation and brightness channels have limited discriminability compared to position or length.  
D) Color hue is better suited for categorical data than for continuous quantitative data.  

#### 10. When analyzing a visualization idiom, which assumptions simplify the scope of marks and channels analysis?  
A) Some items may not be represented by marks due to aggregation or filtering.  
B) The analysis always assumes multiple views and complex mark interactions.  
C) Each data item is represented by exactly one mark.  
D) Multiple marks can be combined in a single region to form glyphs.

## Answers

#### 1. Which of the following statements about marks in visual encoding are true?  
A) ✗ Volumes (3D marks) are rarely used because they are harder to interpret accurately.  
B) ✓ Points have no fixed size constraints and can encode multiple attributes using size and shape.  
C) ✓ Areas have constraints on both length and width, limiting their ability to encode more attributes via size or shape.  
D) ✗ Lines have one fixed dimension (length), not two, so size and shape can still encode other attributes.  

**Correct:** B, C


#### 2. Which channels are generally considered most effective for encoding quantitative data due to their high perceptual accuracy?  
A) ✓ Length is accurate and effective for quantitative encoding.  
B) ✗ Color hue is better for categorical data, less precise for quantitative.  
C) ✗ Shape is better for categorical distinctions, not precise for quantitative data.  
D) ✓ Position along a common aligned scale is highly accurate for quantitative data.  

**Correct:** A, D


#### 3. When might redundant encoding (using multiple channels for the same data attribute) be beneficial?  
A) ✗ Redundant encoding uses more channels, so it does not conserve them.  
B) ✓ Works best when channels are separable and do not interfere.  
C) ✓ Useful when mark type restricts size or shape encoding, so redundancy helps.  
D) ✓ It strengthens the message and improves clarity.  

**Correct:** B, C, D


#### 4. Which of the following factors can negatively affect the accuracy of visual encoding?  
A) ✗ Using a common frame or scale improves accuracy.  
B) ✗ Alignment improves accuracy, it does not negatively affect it.  
C) ✓ Large spatial distance can reduce perceptual accuracy.  
D) ✓ Many distractors make it harder to judge differences accurately.  

**Correct:** C, D


#### 5. Regarding channel discriminability, which statements are correct?  
A) ✓ Color saturation generally allows fewer distinct levels than position or length.  
B) ✗ Discriminability is crucial even if a channel is expressive; poor discriminability limits usefulness.  
C) ✓ The number of perceivable steps must match the number of attribute levels to show.  
D) ✗ Line width can only encode a few distinct levels before differences become hard to perceive.  

**Correct:** A, C


#### 6. Which of the following best describe the concept of "popout" in visual perception?  
A) ✗ Parallel line pairs do not pop out from tilted pairs; this is a known exception.  
B) ✓ Channels like color hue and size can produce popout effects.  
C) ✓ Popout allows quick detection regardless of distractor count.  
D) ✗ Popout occurs with parallel processing, not serial, so items are found quickly.  

**Correct:** B, C


#### 7. How do marks constrain what can be encoded using channels?  
A) ✓ Points have no fixed size constraints, allowing multiple attribute encodings.  
B) ✓ Lines fix length but allow width and color to encode other attributes.  
C) ✓ Reusing size or shape for multiple attributes causes confusion and is not recommended.  
D) ✗ Interlocking areas have fixed size constraints, so size and shape cannot be freely varied.  

**Correct:** A, B, C


#### 8. Which of the following statements about relative versus absolute judgments in visual perception are true?  
A) ✗ Perception mostly operates with relative judgments, not absolute.  
B) ✗ Filled rectangles make length differences harder to judge than white rectangles.  
C) ✓ Weber’s Law explains the constant ratio needed for detectability.  
D) ✓ Accuracy improves with aligned scales due to relative comparison.  

**Correct:** C, D


#### 9. Which of the following are valid reasons why color channels can be challenging for precise quantitative encoding?  
A) ✗ Luminance perception is relative, affected by contrast, not absolute.  
B) ✓ Color perception depends on context and surrounding colors (color constancy).  
C) ✓ Saturation and brightness have limited discriminability compared to position or length.  
D) ✓ Color hue is better suited for categorical data than continuous quantitative data.  

**Correct:** B, C, D


#### 10. When analyzing a visualization idiom, which assumptions simplify the scope of marks and channels analysis?  
A) ✓ Some items may be omitted due to aggregation or filtering, simplifying analysis.  
B) ✗ Assuming multiple views and complex interactions increases complexity, not simplification.  
C) ✓ Assuming one mark per item simplifies analysis.  
D) ✗ Multiple marks combined in a region (glyphs) complicate analysis, so not assumed.  

**Correct:** A, C
