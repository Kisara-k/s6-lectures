## 7. Interactive Views

## Key Points

#### 1. 🔄 Manipulating the View
- Interaction entails a change in encoding, parameters, arrangement, or aggregation level.
- Widgets like sliders, buttons, checkboxes, and dropdowns provide parameter control but consume screen space.
- Data-driven reordering helps find extreme values, trends, or correlations by changing order or arrangement.

#### 2. 🎨 Animated Transitions
- Animated transitions provide smooth changes between visual states, helping users track items and reduce cognitive load.
- Best used for changing visual encodings or navigating hierarchical data.
- Animation is preferable to jump cuts for maintaining user orientation.

#### 3. 🖱️ Interaction Technology
- Desktop interaction supports mouse, keyboard, hover, and multiple clicks.
- Mobile interaction relies on taps and gestures, with no hover capability.
- Emerging technologies include eye tracking and gesture sensors, each with unique ergonomic considerations.

#### 4. 🔍 Selection and Highlighting
- Selection can be single, multiple, or grouped, with different interaction modalities (click, tap, hover).
- Highlighting changes visual encoding (color, outline, size, shape) to provide feedback on selection.
- Motion as a highlighting channel is usually avoided in single views but can be justified in multiple views.

#### 5. 🧭 Navigation
- Navigation changes the viewpoint by panning, zooming, rotating, or scrolling.
- Scrollytelling uses scrolling to navigate visualizations but can cause unexpected behavior.
- Constrained navigation uses animated transitions to frame selected data automatically, improving control.

#### 6. 🗂️ Multiple Views and Coordination
- Linked views share data items and support brushing and linking for coordinated interaction.
- Bidirectional linking (updates in both views) is generally better than unidirectional.
- Overview-detail views share navigation and data subsets, supporting focused exploration.
- Small multiples show different data slices with the same encoding, often linked by highlighting.
- Juxtaposing views reduces cognitive load by allowing side-by-side comparison but uses more screen space.

#### 7. 🧩 Partitioning and Layering
- Partitioning divides data spatially or categorically to reveal patterns (e.g., recursive subdivision by attributes).
- Changing the order of partitioning or color encoding reveals different insights.
- Layering overlays multiple data sets distinguished by visual channels; typically limited to two or three layers to avoid clutter.
- Dynamic layering can highlight data interactively based on selection.

#### 8. ⚖️ Interaction Benefits and Limitations
- Interaction enables flexible, powerful, and intuitive exploratory data analysis.
- Animated transitions empirically help users stay oriented.
- Interaction imposes a time and cognitive cost and may require screen space for controls.
- Many users do not fully engage with interactive features (e.g., ~90% do not interact beyond scrollytelling in some studies).
