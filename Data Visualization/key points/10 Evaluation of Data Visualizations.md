## 11. Evaluation of Data Visualizations

## Key Points

#### 1. ✅ Data Visualization Checklist
- Titles should be 6-12 words, descriptive sentences, left-justified in the upper left corner.
- Text size must be hierarchical: titles > subtitles > labels > axis labels > source info; axis labels at least 9 pt (print) or 20 pt (screen).
- Data labels should be placed directly near data points, minimizing use of legends.
- Bar charts must start y-axis at zero; other charts can have scales reflecting meaningful data ranges.
- Axis intervals must be equidistant.
- Avoid 3D effects and decorative clipart unless they support interpretation.
- Use intentional color schemes that are legible for colorblind viewers and when printed in black and white.
- Gridlines, if used, must be faint gray or omitted; graphs should not have border lines.
- Use one horizontal and one vertical axis; avoid dual y-axes unless absolutely necessary.
- Graphs must highlight significant findings and use appropriate graph types for the data.

#### 2. 💡 Visualization Value Model
- Visualization transforms data (D) via specification (S) into images (I), which increase user knowledge (K).
- Knowledge gain depends on image, user’s prior knowledge, and perceptual abilities.
- Users interactively explore data by adjusting visualization parameters over time.
- Total costs include initial development (Ci), user adoption (Cu), session setup (Cs), and exploration time (Ce).
- Total benefit is the value of knowledge gained (W(∆K)) multiplied by number of sessions and users.
- Profitability formula: $F = nm(W(∆K) - Cs - kCe) - Ci - nCu$.

#### 3. 🔍 Key Challenges in Visualization
- Insight and knowledge gained from visualization are difficult to measure or quantify.
- Visualization is subjective; outcomes depend on method parameters and user expertise.
- Visualization can produce misleading or false patterns (negative knowledge) if improperly designed.
- High initial user costs (learning, setup) limit adoption of new visualization methods.
- Interaction enhances understanding but increases subjectivity and exploration costs.

#### 4. 🛠️ Adoption Examples
- Texture-based flow visualization is technically advanced but rarely adopted due to small user base, unclear knowledge gain, and high user costs.
- Cushion treemaps (SequoiaView) succeeded due to large user base, clear actionable insights, low costs, and few alternatives.
- Presentation visualizations have high value due to large audiences with low prior knowledge and clear economic impact.

#### 5. 🎯 Perspectives on Visualization
- As technology, visualization must prove effectiveness and efficiency to be adopted.
- As art, visualization can be valued for aesthetics and intellectual challenge but may lack practical impact.
- As science, visualization research needs taxonomies, empirical evaluation, and predictive models based on user perception and cognition.

#### 6. 🎨 Color and Text Guidelines
- Avoid red-green and yellow-blue color combinations that touch.
- Use color schemes compatible with colorblindness and black-and-white printing.
- Text must have strong contrast with background (e.g., dark text on white).
- Titles and labels should be horizontal for readability.

#### 7. 📈 Graph Arrangement and Lines
- Graph proportions must accurately reflect data values measurable by length or area.
- Avoid unnecessary tick marks, axis lines, and borders to reduce clutter.
- Use muted or no gridlines, especially if numeric labels are present on data points.

#### 8. 📊 Graph Types and Precision
- Use graph types appropriate to data relationships (e.g., line graphs for time series).
- Numeric precision should match audience needs; avoid unnecessary decimals or statistical jargon in public-facing charts.
- All chart elements should reinforce the main takeaway message consistently.
