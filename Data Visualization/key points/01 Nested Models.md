## 2. Nested Models

## Key Points

#### 1. 🎯 Domain Situation  
- The domain situation level identifies the target users and their real-world context.  
- Misunderstanding user needs at this level leads to failure of the entire visualization.  
- Observing users with existing tools helps understand their needs and workflows.

#### 2. 🔍 Data and Task Abstraction  
- Data abstraction translates domain-specific data into a structured form suitable for visualization.  
- Task abstraction defines why users look at the data and what tasks they want to perform.  
- Choosing the wrong data or tasks results in an ineffective visualization.

#### 3. 🎨 Visual Encoding and Interaction Idioms  
- Visual encoding idioms define how data is graphically represented (e.g., bars, lines, colors).  
- Interaction idioms define how users manipulate the visualization (e.g., zoom, filter, select).  
- Poor visual or interaction design reduces usability and insight extraction.

#### 4. ⚙️ Algorithm  
- Algorithms handle efficient computation and rendering of the visualization.  
- Slow or resource-heavy algorithms make visualizations unusable despite good design.

#### 5. 🔄 Cascading Effects and Iterative Refinement  
- Errors at higher levels cascade downstream and affect lower levels.  
- Feedback from lower levels can lead to iterative refinement of higher levels.

#### 6. 🧪 Validation Challenges  
- Validation is difficult because each level can fail in different ways (domain misunderstanding, wrong data, poor encoding, slow algorithms).  
- Effective validation requires methods from multiple fields: computer science, design, cognitive psychology, anthropology/ethnography.

#### 7. 🔍 Validation Methods by Level  
- Domain: Observe users in natural settings, conduct interviews and field studies.  
- Data/Task: Justify data and task choices by comparing alternatives.  
- Visual/Interaction: Use lab studies to measure user performance and qualitative feedback.  
- Algorithm: Measure system time/memory and analyze computational complexity.

#### 8. 📚 Examples of Application  
- MatrixExplorer combined qualitative image analysis with user testing.  
- LinLog focused on algorithmic efficiency for graph clustering.  
- Flow Map Layout used qualitative analysis and user feedback.  
- LiveRAC measured system performance and user effectiveness.  
- Animation in Trend Visualization used lab studies to test animation effectiveness.  
- Interactive Genealogical Graphs used field studies and interviews for validation.
