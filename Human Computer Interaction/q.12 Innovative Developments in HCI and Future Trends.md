## Answers

#### 1. Which of the following are advantages of curved UHD (4K) displays compared to traditional flat HD monitors?  
A) ✓ Better viewing angles improve user comfort and immersion.  
B) ✗ Curved UHD displays are generally more expensive, not cheaper.  
C) ✓ Reduced reflections due to curved surface improve visibility.  
D) ✗ Curved displays are harder to mount on walls compared to flat ones.  

**Correct:** A, C


#### 2. Flexible displays often use polyimide film as a backplane because:  
A) ✗ Polyimide is flexible, not rigid, enabling bending.  
B) ✓ Polyimide allows a thinner, flexible backplane for high curvature.  
C) ✗ Transparency is about 30%, not 100%, and not all flexible displays are transparent.  
D) ✗ Polyimide is chosen for flexibility and strength, not primarily cost.  

**Correct:** B


#### 3. Virtual projection keyboards provide which of the following benefits?  
A) ✗ They lack physical tactile feedback since keys are projected.  
B) ✓ Highly portable, no need to carry a physical keyboard.  
C) ✓ Connect wirelessly to multiple devices like phones and laptops.  
D) ✗ Projection works best on flat surfaces, not curved ones.  

**Correct:** B, C


#### 4. Hand gesture recognition in smart devices can typically detect which of the following gestures?  
A) ✓ Thumb up is a common recognized gesture.  
B) ✓ Rotation gestures are supported for interaction.  
C) ✗ Eye blinking is not typically detected by hand gesture systems.  
D) ✓ Swipe left or right is a standard gesture for navigation.  

**Correct:** A, B, D


#### 5. Brain signal capturing headsets rely on which technology to interpret user intent?  
A) ✓ EEG measures electrical brain activity, used in these headsets.  
B) ✗ fMRI is a large, non-portable imaging technique, not used here.  
C) ✗ EMG measures muscle activity, not brain signals.  
D) ✗ ECG measures heart activity, unrelated to brain signals.  

**Correct:** A


#### 6. Microsoft HoloLens differs from Oculus Rift primarily because:  
A) ✓ HoloLens overlays holograms on the real world (augmented reality).  
B) ✓ Oculus Rift provides fully immersive virtual reality environments.  
C) ✗ HoloLens is a standalone device, does not require a smartphone.  
D) ✗ Oculus Rift does not support hologram customization; it’s VR only.  

**Correct:** A, B


#### 7. Virtual fitting rooms help reduce online clothing returns by:  
A) ✗ Customers do not physically try clothes; it’s virtual.  
B) ✓ Virtual mannequins based on measurements simulate fit.  
C) ✓ Real-time virtual try-on allows quick visualization without changing clothes.  
D) ✗ Clothing sizes are not adjusted during shipping.  

**Correct:** B, C


#### 8. Which of the following statements about Google Cardboard are true?  
A) ✓ It is a low-cost VR headset made mainly from cardboard.  
B) ✗ It uses the smartphone’s processor, no external processor needed.  
C) ✓ Uses smartphone to create stereoscopic 3D views for VR.  
D) ✗ It does not use transparent display technology.  

**Correct:** A, C


#### 9. Haptic feedback controllers enhance user experience by:  
A) ✓ Providing force and vibration sensations to simulate touch.  
B) ✗ They do not display 3D holograms; that’s AR/VR hardware.  
C) ✓ Some controllers use sliding plates for motion and force feedback.  
D) ✗ Eye movement tracking is a separate technology.

#### 10. Standalone smartwatches differ from paired smartwatches because they:
