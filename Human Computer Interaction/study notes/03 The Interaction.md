## 3. The Interaction

## Study Notes

### 1. 🤝 What is Interaction?

Interaction is the fundamental process where a user communicates with a system. At its simplest, it’s about exchanging information: the user sends commands or inputs, and the system responds with outputs or feedback. But interaction is more than just communication—it involves understanding the context, the goals, and the physical and social environment in which this communication happens.

Interaction models help us understand how this communication works by breaking it down into parts. Ergonomics looks at the physical side of interaction—how the user physically engages with the system. Interaction styles describe the nature of the dialogue between user and system, such as typing commands or clicking icons. Context includes social, organizational, and motivational factors that influence how interaction unfolds.

#### Key Terms in Interaction:
- **Domain:** The specific area or field where the interaction takes place (e.g., graphic design).
- **Goal:** What the user wants to achieve (e.g., create a red triangle).
- **Task:** The steps or actions the user takes to reach the goal (e.g., select fill tool, click on triangle).

Understanding these terms helps clarify how users approach systems and what designers need to consider.


### 2. 🧠 Models of Interaction

#### Donald Norman’s Seven-Stage Model

Norman’s model focuses on the user’s perspective during interaction. It breaks down the process into seven stages:

1. **Establish the Goal:** The user decides what they want to accomplish.
2. **Formulate Intention:** The user plans how to achieve the goal.
3. **Specify Actions:** The user decides what actions to perform on the interface.
4. **Execute Action:** The user carries out the action.
5. **Perceive System State:** The user observes how the system responds.
6. **Interpret System State:** The user makes sense of the system’s feedback.
7. **Evaluate System State:** The user compares the system’s response to their original goal.

This cycle is called the **execution/evaluation loop** and highlights how users continuously interact with the system, adjusting their actions based on feedback.

#### Gulf of Execution and Gulf of Evaluation

- **Gulf of Execution:** The gap between what the user wants to do and what the system allows them to do. If the system’s actions don’t match the user’s intentions, the user struggles to execute their goal.
- **Gulf of Evaluation:** The gap between the system’s actual state and the user’s perception of that state. If the system’s feedback is unclear or misleading, the user cannot properly evaluate if their goal was met.

#### Human Errors: Slips and Mistakes

- **Slips:** The user knows the correct goal and action but makes a wrong move (e.g., clicking the wrong button). These are often due to poor interface design.
- **Mistakes:** The user has the wrong goal or misunderstanding of the system, leading to incorrect actions. These require better system understanding or training.


### 3. 🔄 Abowd and Beale’s Interaction Framework

This framework extends Norman’s model by emphasizing the translation between different "languages" in interaction:

- **User:** Has intentions and mental models.
- **Input:** The actions the user performs (e.g., clicks, typing).
- **System:** Processes input and changes its internal state.
- **Output:** The system’s feedback or display that the user perceives.

Interaction is seen as a continuous translation between these languages. Problems in interaction often arise from poor translation—when the user’s intentions don’t match the system’s responses or when the system’s output is unclear.

This model is broad and applies beyond computers, helping compare different systems by focusing on how well they translate user intentions into system actions and feedback.


### 4. 🖐 Ergonomics: The Physical Side of Interaction

Ergonomics, also called human factors, studies how physical characteristics affect interaction. It focuses on designing systems that fit human physical needs and limitations to improve comfort, safety, and efficiency.

#### Examples of Ergonomic Considerations:
- **Control and Display Arrangement:** Grouping controls by function or frequency of use to make them easier to find and use.
- **Environment:** Designing seating, lighting, temperature, and noise levels to suit users.
- **Health:** Preventing strain or injury by considering posture and repetitive movements.
- **Use of Color:** Using colors like red for warnings and green for safe states, while considering color blindness.

#### Industrial vs. Office Interfaces

- **Office Interfaces:** Usually clean, textual, and slow-changing data.
- **Industrial Interfaces:** Often numeric, fast-changing, and used in harsh environments (e.g., oil-soaked mouse).
- **Glass Interfaces:** Modern touchscreens offer flexibility and precision but can lose physical context and be complex.


### 5. 🎮 Interaction Styles: How Users and Systems Communicate

Interaction styles define the nature of the dialogue between user and system. Different styles suit different tasks and users.

#### Common Interaction Styles:

- **Command Line Interface (CLI):** Users type commands directly. Efficient for experts but hard for novices.
- **Menus:** Options displayed on screen for users to select. Easier to use because options are visible, reducing memory load.
- **Natural Language:** Users speak or type in everyday language. Challenging due to ambiguity but intuitive.
- **Question/Answer Dialogue:** System guides users through questions. Good for novices but limited flexibility.
- **Form-Fills and Spreadsheets:** Structured data entry and manipulation.
- **WIMP (Windows, Icons, Menus, Pointer):** The dominant style for desktop systems.
- **Point and Click:** Clicking icons or links, common in multimedia and web browsing.
- **Three-Dimensional Interfaces:** Virtual reality and 3D workspaces for immersive interaction.


### 6. 🖥 Elements of WIMP Interfaces

WIMP interfaces are the standard for most desktop systems, combining several key elements:

- **Windows:** Independent screen areas that can be moved, resized, and overlapped.
- **Icons:** Small images representing objects or actions.
- **Menus:** Lists of options, often hierarchical, that users select from.
- **Pointers:** Graphical indicators controlled by mouse or keyboard to select items.

Additional elements include:

- **Buttons:** Clickable areas that trigger actions.
- **Toolbars:** Rows of icons for quick access to common functions.
- **Palettes:** Floating windows with tools or options.
- **Dialog Boxes:** Pop-up windows requesting user input or providing information.

#### Menu Types and Design

- **Pull-down Menus:** Drop down from a menu bar.
- **Pop-up Menus:** Appear near the pointer, often context-sensitive.
- **Pie Menus:** Circular menus designed for quick selection.

Menus should be logically grouped, use meaningful names, and include keyboard shortcuts for efficiency.


### 7. 🗣 Speech-Driven Interfaces and Look & Feel

Speech interfaces are improving but still face challenges with accuracy and natural dialogue. Effective speech systems confirm understanding and handle errors gracefully.

**Look and Feel** refers to the visual design and behavior of interface elements. Different systems (e.g., MacOS vs Windows) may have similar elements but behave differently, affecting user experience.


### 8. ⚠️ Error and Repair in Interaction

Errors are inevitable. Good systems help users detect and fix errors easily.

- **Error Detection:** Clear feedback when something goes wrong.
- **Error Recovery:** Simple ways to undo or correct mistakes.
- Example: A booking system confirming user input step-by-step to avoid misunderstandings.


### 9. 🌍 Context: Social, Organizational, and Motivational Factors

Interaction doesn’t happen in isolation. The social and organizational context influences how users behave:

- **Social:** Desire to impress, competition, or fear of failure.
- **Organizational:** Rules, culture, and motivation within a workplace.
- **Motivational:** Personal goals, fear, ambition, or satisfaction.

Systems that ignore context risk frustration and poor adoption.


### 10. 🎉 Experience, Engagement, and Fun

Beyond usability, systems should be enjoyable and engaging. People use systems not just because they can, but because they want to.

- **Flow:** A psychological state where users are fully immersed, balancing challenge and skill.
- **Zone of Proximal Development:** Tasks that users can do with some help, encouraging learning and growth.

Designing for experience means considering emotional and motivational factors, not just functionality.


### 11. ⚙️ Physical Design and Trade-offs

Physical design must balance many constraints:

- **Ergonomic:** Controls must be easy and comfortable to use.
- **Physical:** Size and placement depend on environment and safety.
- **Legal and Safety:** Some controls must be large or protected.
- **Aesthetic:** The system should look appealing.
- **Economic:** Cost must be reasonable.

Often these constraints conflict, requiring trade-offs. For example, making buttons bigger for safety might conflict with limited space, so multifunction controls or reduced functionality may be used.


### 12. 🔄 Fluidity and Affordance in Physical Controls

Good physical design reflects the logical state of the system:

- **Affordance:** Controls should suggest their function (e.g., a button looks pressable).
- **Logical State:** The physical state of a control should reveal its status (e.g., a switch position).
- **Inverse Actions:** Some controls have opposite effects depending on direction (e.g., volume knobs).

Spring-back controls and joysticks provide tactile feedback and natural control.


### 13. 💡 Managing Value: Why People Use Systems

People use systems only if the **perceived value** exceeds the **cost** (effort, money, time).

- **Value:** Helps get work done, is fun, or benefits others.
- **Cost:** Includes learning effort, money, and time.

People often discount future value and cost, preferring immediate benefits. This explains resistance to learning new systems and the importance of low barriers to entry.

#### Organizational Value

In organizations, value can be enforced by:

- **Coercion:** Rules and mandates.
- **Enculturation:** Sharing corporate values and support.
- **Emergence:** Designing systems so individual value aligns with organizational goals.


### Summary

Interaction is a complex, multi-faceted process involving communication, physical engagement, social context, and motivation. Models like Norman’s and Abowd & Beale’s help us understand the flow of actions and feedback. Ergonomics ensures physical comfort and safety, while interaction styles and interface elements shape how users communicate with systems. Context and experience influence motivation and success, and good design balances many constraints to create usable, enjoyable, and valuable systems.
