## 4. Paradigms

## Key Points

#### 1. 🧠 Paradigms in HCI  
- Paradigms are predominant theoretical frameworks or worldviews shaping system design.  
- Understanding HCI history involves recognizing a series of paradigm shifts.  
- New computing technologies create new paradigms that redefine human-computer relationships.

#### 2. 🖥️ Early Paradigms of Interaction  
- Batch processing was the initial paradigm, characterized by impersonal, non-interactive computing.  
- Time-sharing allowed multiple users to interact with a single computer simultaneously.  
- Networking enabled community computing by connecting multiple computers.  
- Graphical displays introduced visual interaction replacing text-only interfaces.  
- Microprocessors enabled personal computing with small, powerful individual machines.  
- The World Wide Web created a global information paradigm.  
- Ubiquitous computing integrates computing seamlessly into everyday physical environments.

#### 3. ⏳ Time-Sharing  
- Developed in the 1960s to allow multiple users to share a single computer’s resources.  
- J.C.R. Licklider at ARPA was a key proponent of time-sharing.

#### 4. 🖼️ Video Display Units (VDUs)  
- Introduced as a more suitable medium than paper for visualizing and manipulating data.  
- Sutherland’s Sketchpad (1962) was a pioneering system for graphical interaction.

#### 5. 🛠️ Programming Toolkits  
- Engelbart’s NLS/Augment system (1968) demonstrated augmenting human intellect with programming toolkits.  
- Toolkits provide building blocks for creating complex interactive systems.

#### 6. 🧒 Personal Computing  
- Papert’s LOGO language (1970s) enabled simple graphics programming for children.  
- Alan Kay’s Dynabook concept envisioned a personal, portable computer for individual use.

#### 7. 🪟 Window Systems and WIMP Interface  
- Windows allow multitasking by partitioning the screen into multiple dialogue areas.  
- WIMP stands for Windows, Icons, Menus, and Pointers.  
- Xerox Star (1981) was the first commercial windowing system.

#### 8. 🪞 Metaphors in Interaction  
- Metaphors relate computing tasks to real-world activities (e.g., desktop metaphor).  
- Metaphors aid learning but can cause cultural bias or limit applicability.

#### 9. 🖱️ Direct Manipulation  
- Described by Shneiderman in 1982 as graphically-based interaction with visible objects, rapid feedback, and reversible actions.  
- Apple Macintosh (1984) popularized direct manipulation and WYSIWYG interfaces.

#### 10. 🗣️ Language vs. Action  
- Interfaces can act as mediators translating language commands into actions.  
- Programming by example combines language and action.  
- Intelligent agents use natural language and proactivity in interfaces.

#### 11. 🔗 Hypertext  
- Vannevar Bush’s memex (1945) inspired managing information explosion via linked documents.  
- Ted Nelson coined “hypertext” in the 1960s as non-linear browsing.  
- Hypermedia extends hypertext to include multimedia.  
- Nelson’s Xanadu project aimed to create a universal hypertext system but remains unrealized.

#### 12. 🎤 Multimodality  
- Multimodality involves simultaneous use of multiple human communication channels for input and output.

#### 13. 🤝 Computer Supported Cooperative Work (CSCW)  
- CSCW focuses on systems supporting multiple users and social aspects of computing.  
- Electronic mail is a prominent example of CSCW success.

#### 14. 🌐 The World Wide Web  
- The Web uses simple protocols (HTTP) and markup languages (HTML) for easy publishing and access.  
- The Web transformed hypertext into a global, open information system.

#### 15. 🤖 Agent-Based Interfaces  
- Early interfaces were command-based (language).  
- Direct manipulation replaced commands with actions on visible objects.  
- Agent-based interfaces reintroduce language with proactive, intelligent agents (e.g., avatars, natural language processing).

#### 16. 🌍 Ubiquitous Computing  
- Mark Weiser (1991) stated the most profound technologies disappear into the background.  
- Ubiquitous computing embeds computing into physical environments, making it less apparent.

#### 17. 📡 Sensor-Based and Context-Aware Interaction  
- Sensors detect physical phenomena (light, temperature, location, identity).  
- Context-aware systems use sensor data to adapt interactions based on the environment.
