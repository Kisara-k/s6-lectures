## 6. Heuristics

## Key Points

#### 1. 🧠 Heuristics Overview  
- Heuristics are practical rules or guidelines used to improve usability in user interfaces.  
- Heuristic evaluation is a method where experts use heuristics to identify usability issues.  
- Two prominent heuristic sets are Nielsen’s 10 Usability Heuristics (1994) and Shneiderman & Plaisant’s 8 Golden Rules (2010).  

#### 2. 📋 Nielsen’s 10 Usability Heuristics (1994)  
- Visibility of system status: system should keep users informed with timely feedback.  
- Match between system and the real world: use familiar language and concepts.  
- User control and freedom: allow undo/redo and easy exit from unwanted states.  
- Consistency and standards: maintain uniformity in design and terminology.  
- Error prevention: design to avoid errors before they occur.  
- Recognition rather than recall: minimize user memory load by making options visible.  
- Flexibility and efficiency of use: provide shortcuts for expert users.  
- Aesthetic and minimalist design: avoid irrelevant information.  
- Help users recognize, diagnose, and recover from errors: clear, plain-language error messages.  
- Help and documentation: provide searchable, task-focused help when needed.  

#### 3. ✨ Shneiderman & Plaisant’s 8 Golden Rules (2010)  
- Strive for consistency in design and behavior.  
- Cater to universal usability for diverse users.  
- Offer informative feedback for every user action.  
- Design dialogues to yield closure, confirming task completion.  
- Prevent errors through design.  
- Permit easy reversal of actions (undo/redo).  
- Support internal locus of control, empowering users.  
- Reduce short-term memory load by displaying necessary information.  

#### 4. 🔍 Comparison of Nielsen vs. Shneiderman & Plaisant  
- Both emphasize consistency, error prevention, and feedback.  
- Nielsen focuses more on system behavior and minimalist design.  
- Shneiderman & Plaisant emphasize user empowerment and psychological interaction aspects.  

#### 5. 🖥️ Vendor-Specific Guidelines  
- Apple’s Mac OS X Human Interface Guidelines provide platform-specific design advice.  
- Microsoft’s Official User Interface Guidelines offer extensive Windows design standards.  
- Vendor guidelines are more prescriptive and platform-centered than general heuristics.  

#### 6. 🕵️ Usability Inspection Methods  
- Usability inspection involves experts evaluating interfaces without user involvement.  
- It is cheaper and faster than user studies.  
- Two main methods: heuristic evaluation and cognitive walk-through (not covered here).  

#### 7. ✅ Heuristic Evaluation Details  
- Developed by Jakob Nielsen in the late 1980s.  
- Experts evaluate the entire system based on heuristics.  
- Single experts find fewer issues; 3-5 experts together find significantly more.  
- It is an informal, holistic usability analysis method.  
- Key reference: Nielsen & Molich (1990), CHI Conference paper.
