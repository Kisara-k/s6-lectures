## 9. Evalutaion Techniques

## Key Points

#### 1. 🧪 Evaluation Basics  
- Evaluation tests usability and functionality of a system.  
- Evaluation occurs in laboratory, field, and/or with user collaboration.  
- Evaluation assesses both design and implementation.  
- Evaluation should be considered at all stages of the design life cycle.  
- Goals include assessing system functionality, user interface effects, and identifying specific problems.  

#### 2. 🧠 Cognitive Walkthrough  
- Proposed by Polson et al.  
- Evaluates how well a design supports user learning of tasks.  
- Performed by experts in cognitive psychology.  
- Experts "walk through" the design using psychological principles to identify problems.  
- Focuses on whether the design leads users to generate correct goals.  

#### 3. 🔍 Heuristic Evaluation  
- Proposed by Nielsen and Molich.  
- Uses usability heuristics to evaluate design (e.g., predictability, consistency, feedback).  
- Experts check if design violates these heuristics.  
- Helps "debug" the design for usability issues.  

#### 4. 📚 Review-Based Evaluation  
- Uses existing literature to support or refute design elements.  
- Requires caution to ensure transferability of results.  
- Includes model-based evaluation using cognitive models like GOMS.  

#### 5. 👥 Laboratory Studies  
- Advantages: specialist equipment, uninterrupted environment.  
- Disadvantages: lack of real-world context, difficult to observe multiple users cooperating.  
- Suitable for dangerous or impractical system locations and controlled single-user systems.  

#### 6. 🌳 Field Studies  
- Advantages: natural environment, context retained, possible longitudinal studies.  
- Disadvantages: distractions, noise, observer effect.  
- Suitable when context is crucial and for long-term studies.  

#### 7. ⚙️ Experimental Evaluation  
- Controlled evaluation testing specific interactive behaviors.  
- Hypothesis-driven with controlled variables.  
- Independent Variable (IV): characteristic changed (e.g., interface style).  
- Dependent Variable (DV): measured outcome (e.g., time, errors).  
- Null hypothesis states no difference between conditions and is tested to be disproved.  

#### 8. 📊 Experimental Design Types  
- Within-groups: each subject experiences all conditions; risk of learning transfer; less costly.  
- Between-groups: each subject experiences one condition; no learning transfer; more subjects needed.  

#### 9. 📈 Data Analysis  
- Choose statistical tests based on data type (discrete or continuous) and information needed.  
- Parametric tests assume normal distribution; non-parametric do not.  
- Contingency tables classify data by discrete attributes.  
- Analysis answers if differences exist, their size, and accuracy of estimates.  

#### 10. 👥 Group Experiments Challenges  
- Larger subject groups increase cost, time, and variation.  
- Tasks must encourage cooperation (e.g., creative tasks, decision games).  
- Data gathering involves multiple cameras and logging, causing synchronization and volume issues.  
- Solutions include within-groups design, micro-analysis, and qualitative analysis.  

#### 11. 🗣️ Think Aloud Method  
- Users verbalize thoughts while performing tasks.  
- Advantages: simple, little expertise needed, insight into actual use.  
- Disadvantages: subjective, selective, may alter task performance.  

#### 12. 🤝 Cooperative Evaluation  
- Variation of think aloud with user-evaluator collaboration.  
- Allows questions from both sides during evaluation.  
- Encourages user criticism and clarification.  

#### 13. 🎥 Protocol Analysis Methods  
- Paper and pencil: cheap, limited by writing speed.  
- Audio: good for think aloud, hard to synchronize.  
- Video: accurate, realistic, requires equipment, obtrusive.  
- Computer logging: automatic, unobtrusive, large data volume.  
- User notebooks: subjective, useful for longitudinal studies.  

#### 14. 🖥️ Post-Task Walkthroughs  
- Users review recorded sessions and comment on actions.  
- Can be immediate or delayed.  
- Helps identify reasons for actions and alternatives considered.  

#### 15. ❓ Query Techniques: Interviews and Questionnaires  
- Interviews: one-to-one, flexible, subjective, time-consuming.  
- Questionnaires: fixed questions, quick, reach large groups, less flexible.  
- Questionnaires require careful design and can include open-ended, scalar, multiple-choice, and ranked questions.  

#### 16. 👁️ Eye Tracking  
- Tracks eye position using head or desk-mounted equipment.  
- Measures fixations (stable gaze), saccades (rapid eye movements), and scan paths.  
- Fixation number and duration indicate display difficulty.  

#### 17. 💓 Physiological Measurements  
- Include heart activity, sweat gland activity (GSR), muscle activity (EMG), brain activity (EEG).  
- Indicate emotional responses but are difficult to interpret reliably.  

#### 18. 🧩 Choosing Evaluation Methods Depends On:  
- Stage in process (design vs. implementation).  
- Style (laboratory vs. field).  
- Objectivity (subjective vs. objective).  
- Type of measures (qualitative vs. quantitative).  
- Level of information detail (high vs. low).  
- Level of interference (obtrusive vs. unobtrusive).  
- Available resources (time, subjects, equipment, expertise).
