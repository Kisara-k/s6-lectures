## Answers

#### 1. What are the primary goals of HCI evaluation?  
A) ✓ To assess the extent of system functionality — This is a core goal of evaluation.  
B) ✓ To identify specific usability problems — Identifying problems is essential.  
C) ✗ To increase the system’s processing speed — Not a goal of HCI evaluation.  
D) ✓ To evaluate the effect of the interface on the user — Understanding user impact is key.  

**Correct:** A, B, D


#### 2. Which of the following best describes the Cognitive Walkthrough method?  
A) ✓ Experts simulate user tasks focusing on learning difficulties — This is the essence of cognitive walkthrough.  
B) ✗ Users provide feedback through think-aloud protocols — This is a user-based method, not cognitive walkthrough.  
C) ✗ Experts check the design against established usability heuristics — This describes heuristic evaluation.  
D) ✗ Users participate in field studies to observe natural behavior — Not related to cognitive walkthrough.  

**Correct:** A


#### 3. In heuristic evaluation, which of the following are typical heuristics used?  
A) ✓ System behavior is consistent — Consistency is a standard heuristic.  
B) ✗ System behavior is unpredictable to challenge users — Predictability, not unpredictability, is desired.  
C) ✓ Feedback is provided for user actions — Feedback is a key heuristic.  
D) ✗ The system should minimize user input at all costs — Not a general heuristic; depends on context.  

**Correct:** A, C


#### 4. What is a key difference between laboratory and field studies in HCI evaluation?  
A) ✗ Laboratory studies always involve multiple users cooperating — Labs often focus on single users.  
B) ✓ Field studies preserve the natural context of use — Field studies occur in real environments.  
C) ✗ Laboratory studies are more prone to distractions and noise — Labs are controlled and less noisy.  
D) ✓ Field studies allow for longitudinal observation — Field studies can track long-term use.  

**Correct:** B, D


#### 5. Which of the following statements about experimental evaluation are true?  
A) ✗ Independent variables are characteristics measured in the experiment — IVs are manipulated, not measured.  
B) ✗ Dependent variables are manipulated to create different conditions — DVs are measured outcomes.  
C) ✓ Hypotheses predict how changes in independent variables affect dependent variables — This is the purpose of hypotheses.  
D) ✓ Null hypotheses state that there is no difference between experimental conditions — Null hypothesis assumes no effect.  

**Correct:** C, D


#### 6. What are the advantages of within-groups experimental design?  
A) ✓ Each subject experiences all conditions — This is the defining feature.  
B) ✗ It eliminates transfer of learning effects — Transfer of learning is a risk in within-groups design.  
C) ✓ It requires fewer participants than between-groups design — Because each participant serves as their own control.  
D) ✗ It completely removes user variation — User variation is reduced but not eliminated.  

**Correct:** A, C


#### 7. When analyzing experimental data, which factors influence the choice of statistical test?  
A) ✓ The type of data (discrete or continuous) — Data type affects test selection.  
B) ✗ The number of independent variables only — Number alone is not the only factor.  
C) ✓ The information required from the analysis — What you want to find out matters.  
D) ✓ Whether the data is parametric or non-parametric — Distribution assumptions affect test choice.  

**Correct:** A, C, D


#### 8. Which challenges are commonly associated with group experiments in HCI evaluation?  
A) ✓ Difficulty in recruiting enough participants — Groups require more participants.  
B) ✗ Easy synchronization of multiple data sources — Synchronization is difficult, not easy.  
C) ✓ Large variation between group solutions — Group dynamics cause variability.  
D) ✗ Simple and straightforward data analysis — Data analysis is complex and challenging.  

**Correct:** A, C


#### 9. What is a major limitation of think-aloud protocols?  
A) ✗ They require expensive equipment — Usually minimal equipment needed.  
B) ✓ Users may selectively verbalize their thoughts — Users often omit some thoughts.  
C) ✗ They provide objective and complete data — Data is subjective and incomplete.  
D) ✓ The act of verbalizing can alter task performance — Talking aloud can change behavior.  

**Correct:** B, D


#### 10. How does cooperative evaluation differ from standard think-aloud methods?  
A) ✓ It involves collaboration between user and evaluator during the task — This is the key difference.  
B) ✗ It restricts user criticism to maintain objectivity — It actually encourages criticism.  
C) ✓ It allows for clarification and questioning throughout the session — Interaction is ongoing.  
D) ✗ It eliminates the need for post-task analysis — Post-task analysis may still be needed.  

**Correct:** A, C


#### 11. Which of the following are true about post-task walkthroughs?  
A) ✓ They allow users to reflect on their actions after task completion — Reflection is the main purpose.  
B) ✗ They provide immediate, fresh insights during task performance — They occur after the task, not during.  
C) ✓ They reduce interruptions during the actual task — Avoids disrupting the user.  
D) ✗ They eliminate the risk of post-hoc interpretation — Post-hoc bias is still possible.  

**Correct:** A, C


#### 12. What are the advantages of using questionnaires in HCI evaluation?  
A) ✓ They can reach a large number of users quickly — Questionnaires scale well.  
B) ✗ They allow for deep, flexible exploration of user opinions — They are less flexible than interviews.  
C) ✓ They can be analyzed rigorously using statistical methods — Structured data allows analysis.  
D) ✗ They are always more reliable than interviews — Reliability depends on design and context.  

**Correct:** A, C


#### 13. Which physiological measurements can be used to assess user emotional response?  
A) ✓ Galvanic Skin Response (GSR) — Reflects emotional arousal.  
B) ✓ Electroencephalogram (EEG) — Measures brain activity linked to emotions.  
C) ✓ Heart rate and blood pressure — Indicators of stress and emotional state.  
D) ✗ User verbal feedback — Not a physiological measurement.  

**Correct:** A, B, C


#### 14. Eye tracking data includes which of the following components?  
A) ✓ Fixations indicating cognitive processing difficulty — Longer fixations suggest difficulty.  
B) ✓ Saccades representing rapid eye movements between points — Saccades are quick jumps.  
C) ✓ Scan paths showing the efficiency of eye movement to targets — Paths show search strategy.  
D) ✗ Heart rate variability during task performance — Heart rate is separate from eye tracking.  

**Correct:** A, B, C


#### 15. What factors should influence the choice of an HCI evaluation method?  
A) ✓ Stage of design (early vs. implementation) — Different methods suit different stages.  
B) ✓ Whether the evaluation is subjective or objective — Depends on goals and resources.  
C) ✗ The number of developers on the project team — Not directly relevant to evaluation choice.  
D) ✓ Available resources such as time and expertise — Practical constraints matter.  

**Correct:** A, B, D


#### 16. Which of the following statements about review-based evaluation are correct?  
A) ✓ It relies on existing literature to support or refute design decisions — Core feature of review-based evaluation.  
B) ✗ It guarantees that all findings are transferable to new designs — Transferability must be carefully considered.  
C) ✓ It can include model-based evaluation using cognitive models like GOMS — Model-based evaluation is a form of review-based.  
D) ✗ It is primarily focused on user participation and feedback — It is expert and literature based, not user-based.  

**Correct:** A, C


#### 17. In experimental design, what is the main risk of using a between-groups design?  
A) ✗ Transfer of learning between conditions — This risk is mainly in within-groups design.  
B) ✓ Increased variation due to differences between participant groups — Different groups may vary widely.  
C) ✗ Fewer participants are required compared to within-groups design — Between-groups needs more participants.  
D) ✗ Each participant experiences all experimental conditions — This describes within-groups design.  

**Correct:** B


#### 18. Which of the following are true about protocol analysis methods?  
A) ✗ Video recording is unobtrusive and requires no special equipment — Video requires equipment and can be obtrusive.  
B) ✓ Audio recordings are useful but can be difficult to synchronize with other data — Synchronization is a known challenge.  
C) ✓ Computer logging provides large amounts of data but can be hard to analyze — Data volume and complexity are issues.  
D) ✗ User notebooks provide objective, quantitative data — They are subjective and qualitative.  

**Correct:** B, C


#### 19. What are the disadvantages of field studies in HCI evaluation?  
A) ✓ They may introduce distractions and noise affecting data quality — Natural environments are less controlled.  
B) ✗ They lack the natural context of system use — Field studies preserve natural context.  
C) ✓ Observation may alter user behavior — Known as the observer effect.  
D) ✗ They are unsuitable for longitudinal studies — Field studies are ideal for longitudinal research.  

**Correct:** A, C


#### 20. Which of the following best describe the null hypothesis in experimental evaluation?  
A) ✗ It predicts a specific difference between conditions — That is the alternative hypothesis.  
B) ✓ It states that there is no difference between experimental conditions — Null hypothesis assumes no effect.  
C) ✓ The goal is to disprove the null hypothesis — Experiments aim to reject the null.  
D) ✗ It is always accepted as true after the experiment — It is accepted only if not disproved.  

**Correct:** B, C
