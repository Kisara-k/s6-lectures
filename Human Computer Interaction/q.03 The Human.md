## Answers

#### 1. Which of the following are true about the human information processing system?  
A) ✗ Information is stored in sensory, short-term, and long-term memory, not only long-term.  
B) ✓ Emotion influences cognitive capabilities, affecting reasoning and problem-solving.  
C) ✓ Sensory input includes visual, auditory, and haptic (touch) information.  
D) ✗ Each person processes information differently; humans are not identical in this.  

**Correct:** B, C


#### 2. What roles do rods and cones play in vision?  
A) ✗ Rods do not detect color; they are for low light vision.  
B) ✓ Cones are responsible for color vision.  
C) ✓ Rods help us see in low light conditions.  
D) ✗ Cones detect color, not movement; ganglion cells detect movement.  

**Correct:** B, C


#### 3. Which statements about the retina and image formation are correct?  
A) ✗ Images are focused upside-down on the retina, not right-side up.  
B) ✓ Ganglion cells detect patterns and movement and send signals to the brain.  
C) ✓ The image on the retina is upside-down due to the optics of the eye.  
D) ✗ Rods and cones are photoreceptors, not ganglion cells.  

**Correct:** B, C


#### 4. Visual angle is important because it:  
A) ✓ It measures how much of the visual field an object occupies.  
B) ✓ Visual angle changes with object distance from the eye.  
C) ✗ Visual angle is relevant to size perception; it helps judge size and distance.  
D) ✓ Visual angle helps the brain interpret size and depth cues.  

**Correct:** A, B, D


#### 5. Which factors affect visual acuity?  
A) ✓ Luminance (brightness) of the object improves acuity.  
B) ✗ Color alone does not affect acuity; brightness and contrast do.  
C) ✓ Brightness of the environment affects visual acuity.  
D) ✓ Flicker detection improves with increased luminance, affecting acuity.  

**Correct:** A, C, D


#### 6. Regarding color vision, which are true?  
A) ✓ Hue, intensity, and saturation are components of color perception.  
B) ✗ Blue light has the lowest acuity, not the highest.  
C) ✓ About 8% of males are color blind, a significant percentage.  
D) ✗ Color blindness affects more males than females, not the other way around.  

**Correct:** A, C


#### 7. The visual system compensates for which of the following?  
A) ✓ It compensates for movement of objects or observer.  
B) ✓ It compensates for changes in luminance.  
C) ✗ Optical illusions occur due to overcompensation, not lack of compensation.  
D) ✓ Context helps resolve ambiguous images.  

**Correct:** A, B, D


#### 8. Which of the following are examples of optical illusions caused by visual system compensation?  
A) ✓ Ponzo illusion is a classic optical illusion.  
B) ✓ Müller-Lyer illusion is another well-known optical illusion.  
C) ✗ Cocktail party phenomenon relates to hearing, not vision.  
D) ✗ Negative contrast improves reading but is not an optical illusion.  

**Correct:** A, B


#### 9. During reading, which statements are accurate?  
A) ✗ Saccades are quick jumps, not smooth movements.  
B) ✓ Fixations are brief pauses where perception occurs.  
C) ✗ Word shape is important for recognition.  
D) ✓ Negative contrast can improve reading on screens.  

**Correct:** B, D


#### 10. The outer ear’s main functions include:  
A) ✓ Protecting the inner ear.  
B) ✓ Amplifying sound.  
C) ✗ Transmitting sound waves as vibrations is the middle ear’s role.  
D) ✗ Chemical transmitters are released in the inner ear, not outer ear.  

**Correct:** A, B


#### 11. Which statements about sound and hearing are correct?  
A) ✓ Pitch corresponds to sound frequency.  
B) ✓ Loudness relates to amplitude.  
C) ✗ Humans hear up to about 15 kHz, not 20 kHz.  
D) ✓ Timbre is the quality or type of sound.  

**Correct:** A, B, D


#### 12. The cocktail party phenomenon demonstrates:  
A) ✓ Auditory system’s ability to filter sounds.  
B) ✗ It is easier to distinguish low frequencies, not harder.  
C) ✓ Brain’s capacity to focus on one conversation amid noise.  
D) ✗ Humans can hear sounds below 20 Hz, but not well; this is not related to the phenomenon.  

**Correct:** A, C


#### 13. Touch receptors include:  
A) ✓ Thermoreceptors detect temperature changes.  
B) ✓ Nociceptors detect pain.  
C) ✓ Mechanoreceptors detect pressure.  
D) ✗ Rods and cones are visual receptors, not touch receptors.  

**Correct:** A, B, C


#### 14. Kinesthesia refers to:  
A) ✓ Awareness of body position without visual input.  
B) ✗ Detecting pain is nociception, not kinesthesia.  
C) ✗ Sensitivity to temperature is thermoreception.  
D) ✗ Hearing is unrelated to kinesthesia.  

**Correct:** A


#### 15. Reaction time varies depending on stimulus type. Which are true?  
A) ✓ Auditory reaction time (~150 ms) is faster than visual (~200 ms).  
B) ✗ Pain stimuli have the slowest reaction time (~700 ms), not shortest.  
C) ✓ Visual reaction time is about 200 ms.  
D) ✗ Increasing reaction time usually decreases accuracy for unskilled operators.  

**Correct:** A, C


#### 16. According to Fitts’ Law, movement time increases when:  
A) ✓ Distance to the target increases, movement time increases.  
B) ✗ Increasing target size decreases movement time.  
C) ✓ Decreasing target size increases movement time.  
D) ✗ Decreasing distance decreases movement time.  

**Correct:** A, C


#### 17. Which of the following statements about memory are correct?  
A) ✗ Sensory memory holds information for milliseconds to seconds, not minutes.  
B) ✓ Short-term memory requires rehearsal to maintain information.  
C) ✓ Long-term memory stores information for extended periods.

**Correct:** B, C, D


#### 18. Which of the following best describe the relationship between reaction time and accuracy?  
A) ✓ Skilled operators maintain accuracy even with increased reaction time.

#### 19. Which of the following are true about brightness perception?

**Correct:** B, C


#### 20. Which of the following statements about reading and perception are true?  
A) ✗ Perception occurs mainly during fixations, not saccades.  
B) ✓ Internal language knowledge helps decode visual patterns.

**Correct:** B, C, D
