## Answers

#### 1. Which of the following best describes the relationship between principles, guidelines, and standards in design rules?  
A) ✗ Principles have low authority, not high  
B) ✓ Standards have high authority and limited application  
C) ✗ Guidelines have lower authority than standards  
D) ✓ Principles are more general than guidelines  

**Correct:** B, D


#### 2. Learnability in usability primarily focuses on:  
A) ✗ This relates to robustness, not learnability  
B) ✓ Learnability is about how easily new users start effective interaction  
C) ✗ This is about flexibility, not learnability  
D) ✗ Flexibility principle, not learnability  

**Correct:** B


#### 3. Predictability as a principle of learnability means:  
A) ✓ Users anticipate future effects based on past actions  
B) ✗ Error prevention is robustness, not predictability  
C) ✗ Customization relates to flexibility  
D) ✗ Multitasking relates to flexibility  

**Correct:** A


#### 4. Which of the following are examples of flexibility principles?  
A) ✓ Dialogue initiative is a flexibility principle  
B) ✗ Observability is a robustness principle  
C) ✓ Task migratability is a flexibility principle  
D) ✗ Recoverability is a robustness principle  

**Correct:** A, C


#### 5. Task migratability refers to:  
A) ✗ This is recoverability, not task migratability  
B) ✓ Passing task responsibility between user and system  
C) ✗ Multitasking is multithreading, not task migratability  
D) ✗ Responsiveness, not task migratability  

**Correct:** B


#### 6. Which statements about standards are true?  
A) ✓ Standards are often set by international bodies  
B) ✗ Standards tend to change slowly, not rapidly  
C) ✗ Standards have higher authority than guidelines  
D) ✓ Hardware standards are more common than software standards  

**Correct:** A, D


#### 7. Which of the following are characteristics of HCI design patterns?  
A) ✗ Patterns capture practical design knowledge, not just theory  
B) ✓ They represent common properties of good design examples  
C) ✓ They are intuitive and readable for communication  
D) ✗ Patterns are linked, not isolated  

**Correct:** B, C


#### 8. Observability as a robustness principle means:  
A) ✓ Users can evaluate system state through visible cues  
B) ✗ Automatic error correction is not observability  
C) ✗ Undoing actions is recoverability  
D) ✗ Multiple input methods relate to flexibility  

**Correct:** A


#### 9. Which of the following are included in Norman’s 7 Principles?  
A) ✓ Exploit constraints is one of Norman’s principles  
B) ✗ Internal locus of control is Shneiderman’s rule, not Norman’s  
C) ✓ Simplify task structure is Norman’s principle  
D) ✗ Error prevention is Shneiderman’s rule, not Norman’s  

**Correct:** A, C


#### 10. Which of the following best describes the concept of “dialogue initiative”?  
A) ✗ Dialogue initiative means user freedom, not system control  
B) ✓ Users have freedom from system-imposed input constraints  
C) ✗ Multitasking is unrelated to dialogue initiative  
D) ✗ Adaptivity is customizability, not dialogue initiative  

**Correct:** B


#### 11. Which of the following are true about guidelines?  
A) ✓ Guidelines are more suggestive and general than standards  
B) ✗ Guidelines have lower authority than standards  
C) ✓ Guidelines can be abstract or detailed depending on lifecycle stage  
D) ✓ Understanding justification helps resolve conflicts  

**Correct:** A, C, D


#### 12. What does “substitutivity” in flexibility principles allow?  
A) ✓ Equivalent input/output values can be substituted  
B) ✗ Undoing actions is recoverability, not substitutivity  
C) ✗ Automatic error recovery is robustness, not substitutivity  
D) ✗ Customizability is a separate flexibility principle  

**Correct:** A


#### 13. Which of the following are examples of Shneiderman’s 8 Golden Rules?  
A) ✓ Reduce short-term memory load is one of Shneiderman’s rules  
B) ✗ Design for error is Norman’s principle, not Shneiderman’s  
C) ✓ Enable frequent users to use shortcuts is Shneiderman’s rule  
D) ✗ Make things visible is Norman’s principle, not Shneiderman’s  

**Correct:** A, C


#### 14. Which of the following statements about robustness are correct?  
A) ✓ Responsiveness is about communication speed with the user  
B) ✓ Task conformance means supporting all user tasks adequately  
C) ✗ Recoverability means user can correct errors, not prevent all errors  
D) ✓ Observability includes operation visibility and persistence  

**Correct:** A, B, D


#### 15. Which of the following best describes the role of design patterns in HCI?  
A) ✗ Patterns are practical solutions, not just theoretical frameworks  
B) ✓ They provide reusable solutions to common design problems  
C) ✗ Patterns are linked, not isolated  
D) ✓ Patterns help generate complete designs through linked patterns  

**Correct:** B, D


#### 16. Generalizability as a principle of learnability means:  
A) ✓ Users apply knowledge from one system to similar systems  
B) ✗ Multimodality relates to flexibility, not generalizability  
C) ✗ Customization is flexibility, not generalizability  
D) ✗ Immediate feedback relates to observability, not generalizability  

**Correct:** A


#### 17. Which of the following are true about the authority and generality of design rules?  
A) ✓ Standards have high authority and low generality  
B) ✓ Principles have low authority and high generality  
C) ✗ Guidelines have lower authority than standards  
D) ✗ Principles are more general, not more specific than guidelines  

**Correct:** A, B


#### 18. Which of the following are examples of flexibility principles that support multitasking?  
A) ✓ Multithreading supports multitasking  
B) ✓ Task migratability supports multitasking by shifting responsibility  
C) ✗ Recoverability is robustness, not multitasking  
D) ✓ Dialogue initiative supports flexible multitasking interaction  

**Correct:** A, B, D


#### 19. Which of the following statements about the use of design rules is correct?  
A) ✓ Standards require sound theory and slowly changing technology  
B) ✗ Guidelines are suggestive, not mandatory  
C) ✗ Principles are abstract and applied early, not detailed and late  
D) ✗ Golden rules and heuristics are useful, not less useful than guidelines  

**Correct:** A


#### 20. Which of the following best describe the concept of “internal locus of control” in Shneiderman’s Golden Rules?  
A) ✓ Users feel in control rather than controlled by the system  
B) ✗ Automatic error correction is robustness, not locus of control  
C) ✗ Customization is flexibility, not locus of control  
D) ✗ Error prevention is a different principle  

**Correct:** A
