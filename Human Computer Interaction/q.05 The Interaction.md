## Answers

#### 1. What does the "Gulf of Execution" refer to in interaction design?  
A) ✗ It describes evaluation, not execution.  
B) ✓ It is the gap between user’s intended actions and system’s allowed actions.  
C) ✗ This is about feedback delay, not Gulf of Execution.  
D) ✗ This describes the Gulf of Evaluation, not Execution.  

**Correct:** B


#### 2. Which of the following are stages in Donald Norman’s seven-stage model of interaction?  
A) ✓ Formulating intention is a key stage.  
B) ✓ Executing action is part of the model.  
C) ✗ Designing the interface is outside the user’s interaction stages.  
D) ✓ Evaluating system state with respect to the goal is included.  

**Correct:** A, B, D


#### 3. In Abowd and Beale’s interaction framework, which components are involved in the translation process?  
A) ✓ User intentions are translated into actions.  
B) ✓ System output is translated back to the user.  
C) ✗ Environmental context is not a core component in this model.  
D) ✓ Input actions are part of the translation process.  

**Correct:** A, B, D


#### 4. Which of the following best describe ergonomics in the context of human-computer interaction?  
A) ✓ Ergonomics studies physical interaction characteristics.  
B) ✗ Ergonomics is not only about aesthetics.  
C) ✓ It defines standards for controls and environment.  
D) ✗ Ergonomics focuses on physical, not just cognitive factors.  

**Correct:** A, C


#### 5. What are typical differences between office and industrial interfaces?  
A) ✗ Office interfaces usually handle textual, slow-changing data.  
B) ✓ Industrial interfaces often operate in harsh, dirty environments.  
C) ✓ Office interfaces tend to be textual and slower changing.  
D) ✗ Industrial interfaces increasingly use glass interfaces.  

**Correct:** B, C
