## Answers

#### 1. Which of the following are essential requirements for effective user support?  
A) ✓ Continuous availability concurrent with the main application — Help must be accessible anytime alongside the main system.  
B) ✗ Support that only covers the most common user errors — Help should be complete, covering all relevant behaviors, not just common errors.  
C) ✓ Consistency between help system and printed documentation — Consistency avoids confusion and improves usability.  
D) ✗ Help that interrupts the user to ensure attention — Help should be unobtrusive and not interrupt work.

**Correct:** A, C


#### 2. What distinguishes help from documentation in user support systems?  
A) ✓ Help is problem-oriented and specific — Help targets immediate user problems.  
B) ✓ Documentation is system-oriented and general — Documentation provides broad system information.  
C) ✗ Help is always presented as tutorials — Help can be quick reference, explanations, or tutorials, not always tutorials.  
D) ✗ Documentation focuses on immediate user issues — Documentation is general, not problem-specific.

**Correct:** A, B


#### 3. Which of the following are true about command assistance as a user support approach?  
A) ✓ It assumes the user knows the command they need help with — Users must know what to look for.  
B) ✓ It is best suited for quick reference needs — Command assistance is designed for quick lookups.  
C) ✗ It provides context-sensitive advice based on user behavior — This is context-sensitive help, not command assistance.  
D) ✗ It automatically corrects user errors without user input — Command assistance only provides information, not automatic correction.

**Correct:** A, B


#### 4. Context-sensitive help typically involves:  
A) ✓ Providing help based on the current user interface element — It adapts to the user’s current context.  
B) ✗ Offering generic help unrelated to the user’s current task — This contradicts the idea of context sensitivity.  
C) ✓ Using tooltips to display relevant information — Tooltips are a common form of context-sensitive help.  
D) ✗ Requiring the user to manually search for help topics — Context-sensitive help is automatic or triggered by context.

**Correct:** A, C


#### 5. What are the main challenges in designing adaptive help systems?  
A) ✓ Acquiring and representing detailed knowledge about users and tasks — Adaptive systems need rich knowledge.  
B) ✗ Ensuring the system always controls the interaction without user input — User control is a key design question, not a given.  
C) ✓ Deciding what aspects of the system to adapt and how broadly — Scope and effect of adaptation are challenging.  
D) ✗ Ignoring user privacy concerns in user modeling — Privacy is important and cannot be ignored.

**Correct:** A, C


#### 6. Which user modeling approaches involve comparing actual user behavior to an ideal expert model?  
A) ✗ Quantification — Measures expertise level but does not compare to an ideal model.  
B) ✓ Overlay — Compares actual use to an idealized expert model.  
C) ✗ Stereotypes — Classifies users into categories, not behavior comparison.  
D) ✓ Error catalog comparison — Compares user errors to known errors, a special case of overlay.

**Correct:** B, D


#### 7. Which of the following are valid knowledge representation techniques used in help systems?  
A) ✓ Rule-based systems using logic and production rules — Common for large domains.  
B) ✓ Frame-based systems with slot-filling structures — Useful for smaller domains.  
C) ✓ Network-based systems representing relationships between facts — Link frames and facts.  
D) ✗ Randomized decision trees without training data — Not a recognized technique here; example-based systems require training.

**Correct:** A, B, C


#### 8. What is a key difference between wizards and assistants in user support?  
A) ✓ Wizards guide users step-by-step through a task, assistants offer contextual advice — This is the main difference.  
B) ✗ Assistants constrain task execution more than wizards — Wizards constrain tasks; assistants offer advice without constraining.  
C) ✓ Wizards allow users to go back and change answers, assistants often do not — Wizards provide controlled navigation.  
D) ✗ Assistants are always under full user control by default — They must be under user control but often are not by default.

**Correct:** A, C


#### 9. Which of the following statements about command prompts are true?  
A) ✓ They provide information about correct command usage after an error — Command prompts help correct syntax errors.  
B) ✗ They are effective for complex semantic errors — They mainly handle simple syntactic errors.  
C) ✓ They assume the user has some knowledge of the command syntax — Users must know the command to interpret prompts.  
D) ✗ They replace the need for tutorials — Tutorials cover broader learning, not replaced by prompts.

**Correct:** A, C


#### 10. When designing user support, which presentation principles are important?  
A) ✓ Use instructional rather than descriptive language — Instructional language guides user action.  
B) ✗ Present large blocks of text for thoroughness — Large blocks reduce usability and readability.  
C) ✓ Use clear, familiar, and consistent language — Clarity and consistency improve comprehension.  
D) ✗ Avoid indicating summaries or examples to reduce clutter — Summaries and examples help users find key info.

**Correct:** A, C


#### 11. Which of the following are potential problems when implementing adaptive help systems?  
A) ✓ Determining who has initiative in offering help — Control of interaction is a key issue.  
B) ✗ Modeling user expertise at the system level only — Expertise varies by application; system-level only is insufficient.  
C) ✗ Ensuring the system interrupts the user frequently to offer help — Frequent interruptions reduce usability.  
D) ✓ Deciding the scope of adaptation between application and system levels — Scope complexity is a challenge.

**Correct:** A, D


#### 12. Which of the following best describe the flexibility requirement in user support?  
A) ✓ Allowing users to interact in ways appropriate to their experience and task — Flexibility adapts to user needs.  
B) ✗ Preventing users from deviating from a fixed help path — This reduces flexibility.  
C) ✓ Adapting help content dynamically based on user input — Flexibility includes dynamic adaptation.  
D) ✗ Forcing users to follow a strict tutorial sequence — This is inflexible.

**Correct:** A, C


#### 13. What are the main issues related to knowledge acquisition in help systems?  
A) ✓ It requires significant resources and expertise — Knowledge acquisition is resource-intensive.  
B) ✗ It is straightforward and quick to implement — It is complex and time-consuming.  
C) ✓ It involves interpreting user behavior accurately — Understanding behavior is essential.  
D) ✗ It can be avoided by using generic help content — Generic content does not replace detailed knowledge acquisition.

**Correct:** A, C


#### 14. Which of the following are true about online tutorials?  
A) ✓ They allow users to work through basics in a test environment — Tutorials provide controlled learning.  
B) ✗ They are always flexible and adapt to user needs — Tutorials are often inflexible.  
C) ✓ They can be useful for beginners but may lack flexibility — Tutorials help beginners but can be rigid.  
D) ✗ They replace the need for context-sensitive help — Tutorials and context-sensitive help serve different purposes.

**Correct:** A, C


#### 15. Which of the following statements about the robustness requirement in user support are correct?  
A) ✓ The help system should handle errors gracefully — Robustness means correct error handling.  
B) ✗ The help system can behave unpredictably if the user makes mistakes — Unpredictability is undesirable.  
C) ✓ Robustness ensures the system does not crash when help is requested — Stability is part of robustness.  
D) ✗ Robustness is only important for the main application, not the help system — Help system must also be robust.

**Correct:** A, C


#### 16. What are the advantages of using hypertext in online documentation?  
A) ✓ It supports easier browsing and navigation — Hypertext allows quick jumps between topics.  
B) ✗ It makes the documentation harder to update — Hypertext can be easier to update than paper.  
C) ✓ It allows linking between related topics — Linking is a core feature of hypertext.  
D) ✗ It eliminates the need for printed manuals — Printed manuals may still be needed for offline use.

**Correct:** A, C


#### 17. Which of the following are true about the initiative in adaptive help systems?  
A) ✗ The system should always take control and interrupt the user — This can annoy users; control is a design choice.  
B) ✓ The user may retain control over when and how help is offered — User control is important for acceptance.  
C) ✓ Initiative decisions affect user satisfaction and effectiveness — Who controls help impacts usability.  
D) ✗ Initiative is irrelevant if the help system is adaptive — Initiative is a key issue regardless of adaptivity.

**Correct:** B, C


#### 18. Which of the following are valid structures for storing help data?  
A) ✓ Single file containing all help content — Simple but less flexible.  
B) ✓ Hierarchical file system organizing topics — Common for organizing help topics.  
C) ✓ Database-driven help systems — Useful for large, complex help content.  
D) ✗ Randomly scattered files without indexing — This would hinder browsing and retrieval.

**Correct:** A, B, C


#### 19. What are some challenges in representing tasks in knowledge models for help systems?  
A) ✓ Tasks can be interleaved and not strictly sequential — Real user tasks often overlap.  
B) ✓ User intentions may be difficult to infer — Intention is complex to model.  
C) ✗ Tasks are always simple and linear — Tasks are often complex and non-linear.  
D) ✗ Command sequences are easy to analyze and represent — Analyzing sequences is challenging.

**Correct:** A, B


#### 20. Which of the following statements about assistants like the Microsoft Office paperclip are true?  
A) ✓ They monitor user behavior and offer contextual advice — Assistants provide context-aware suggestions.  
B) ✗ They are always welcomed by users without irritation — They can be annoying if intrusive.  
C) ✓ They must be under user control to avoid annoyance — User control is essential for acceptance.  
D) ✗ They provide step-by-step task guidance like wizards — Wizards guide step-by-step; assistants offer advice.

**Correct:** A, C
