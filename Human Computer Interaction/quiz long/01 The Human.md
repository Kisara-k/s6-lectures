## Answers

#### 1. Which of the following are true about the physical reception of visual stimuli?  
A) ✓ Ganglion cells detect patterns and movement and send signals to the brain.  
B) ✗ Images are focused upside-down, not right-side up, on the retina.  
C) ✗ Rods are for low light vision, cones are for color vision.  
D) ✓ Light is transformed into electrical energy by photoreceptors in the retina.  

**Correct:** A, D


#### 2. Visual acuity is influenced by which of the following factors?  
A) ✓ Familiarity helps perceive objects as constant size despite changes in visual angle.  
B) ✓ Visual angle relates to how much of the view an object occupies, affecting acuity.  
C) ✓ Luminance affects visual acuity; higher luminance improves detail perception.  
D) ✗ Size of the retina is not a factor discussed in visual acuity.  

**Correct:** A, B, C


#### 3. Which statements about color vision are correct?  
A) ✗ Blue cones have the lowest acuity, not the highest.  
B) ✓ About 8% of males are color blind; much fewer females are affected.  
C) ✗ Color blindness affects more males than females, not the other way around.  
D) ✓ Hue, intensity, and saturation are components of color perception.  

**Correct:** B, D


#### 4. The visual system compensates for which of the following to maintain stable perception?  
A) ✓ Compensates for movement to keep stable images.  
B) ✓ Adjusts for changes in luminance to maintain perception.  
C) ✗ Auditory input is unrelated to visual compensation.  
D) ✓ Uses context to resolve ambiguity in perception.  

**Correct:** A, B, D


#### 5. Which of the following are characteristics of reading as a visual process?  
A) ✓ Negative contrast improves reading from computer screens.  
B) ✓ Syntax, semantics, and pragmatics are involved in interpreting text.  
C) ✓ Word shape is important for word recognition.  
D) ✗ Perception occurs mainly during fixations, not saccades.  

**Correct:** A, B, C


#### 6. Regarding the human auditory system, which are true?  
A) ✗ Loudness depends on amplitude, not frequency.  
B) ✓ Cocktail party phenomenon shows selective auditory attention.  
C) ✓ Humans hear roughly 20 Hz to 15 kHz frequencies.  
D) ✗ Middle ear transmits vibrations, chemical signals are released in the inner ear.  

**Correct:** B, C


#### 7. Which receptors in the skin are responsible for detecting pressure?  
A) ✗ Photoreceptors are in the eye, not skin.  
B) ✗ Thermoreceptors detect temperature, not pressure.  
C) ✗ Nociceptors detect pain, not pressure.  
D) ✓ Mechanoreceptors detect pressure stimuli.  

**Correct:** D


#### 8. Kinesthesia refers to:  
A) ✗ Temperature sense is thermoreception.  
B) ✗ Visual pattern recognition is unrelated to kinesthesia.  
C) ✓ Awareness of body position and movement.  
D) ✗ Detecting pain is nociception, not kinesthesia.  

**Correct:** C


#### 9. Reaction time varies depending on stimulus type. Which of the following correctly orders reaction times from fastest to slowest?  
A) ✗ Visual is slower than auditory, so this order is incorrect.  
B) ✓ Auditory (~150 ms) is fastest, then visual (~200 ms), then pain (~700 ms).  
C) ✗ Pain is slowest, but auditory is faster than visual.  
D) ✗ Visual reaction time (~200 ms) is slower than auditory (~150 ms).  

**Correct:** B


#### 10. According to Fitts’ Law, which design choice will reduce movement time?  
A) ✓ Placing targets closer reduces movement time.  
B) ✓ Larger targets reduce movement time.  
C) ✗ Increasing distance increases movement time.  
D) ✗ Decreasing target size increases movement time.  

**Correct:** A, B


#### 11. Which of the following statements about short-term memory (STM) are correct?  
A) ✓ STM capacity is about 7 ± 2 chunks.  
B) ✓ STM allows rapid access (~70 ms).  
C) ✗ STM decay is about 20 seconds, not 200 milliseconds (lecture states rapid decay ~200 ms but typical STM decay is longer; 200 ms here refers to rapid decay of sensory memory).  
D) ✗ STM is temporary, not permanent storage.  

**Correct:** A, B


#### 12. Long-term memory (LTM) differs from STM in that:  
A) ✓ LTM includes episodic and semantic memory types.  
B) ✗ LTM capacity is huge or unlimited, not limited to 7 ± 2 chunks.  
C) ✓ LTM decay is very slow or negligible.  
D) ✓ LTM access is slower than STM.  

**Correct:** A, C, D


#### 13. Which of the following best describe semantic networks in LTM?  
A) ✗ Relationships are explicit, not vague.  
B) ✓ Supports inference through inheritance.  
C) ✗ Information is connected, not unconnected facts.  
D) ✓ Child nodes inherit properties from parent nodes.  

**Correct:** B, D


#### 14. Scripts in memory models are:  
A) ✗ Condition-action rules describe production rules, not scripts.  
B) ✓ Instantiated with values depending on context.  
C) ✗ Scripts include roles, props, and scenes.  
D) ✓ Data structures representing stereotypical event sequences.  

**Correct:** B, D


#### 15. Which of the following are true about deductive reasoning?  
A) ✗ Logical validity alone does not guarantee truth if premises are false.  
B) ✓ If premises are true and reasoning valid, conclusion must be true.  
C) ✓ False premises can lead to false conclusions despite valid logic.  
D) ✓ Deduction derives necessary conclusions from premises.  

**Correct:** B, C, D


#### 16. Inductive reasoning is characterized by:  
A) ✓ Induction is unreliable but useful.  
B) ✗ Induction cannot prove hypotheses true with certainty, only falsify.  
C) ✓ Generalizing from specific to broader cases.  
D) ✗ Humans are generally poor at using negative evidence.  

**Correct:** A, C, D


#### 17. Abductive reasoning involves:  
A) ✓ Reasoning from effect to cause (inferring cause from observed event).  
B) ✗ Abduction can be unreliable, not always reliable.  
C) ✓ Can lead to false explanations due to assumptions.  
D) ✗ Reasoning from cause to effect is deduction or induction.  

**Correct:** A, C


#### 18. Which of the following statements about problem solving are correct?  
A) ✓ Skilled problem solving involves chunking information.  
B) ✓ Problem space theory involves generating states with legal operators.  
C) ✓ Gestalt theory emphasizes insight and restructuring.  
D) ✗ Analogical mapping is difficult when domains differ semantically.  

**Correct:** A, B, C


#### 19. Errors in human behavior can be classified as:  
A) ✓ Slips occur when intention is correct but execution fails.  
B) ✓ Incorrect mental models can cause errors.  
C) ✗ Errors are not always caused by lack of attention; other causes exist.  
D) ✓ Mistakes occur when intention itself is wrong.  

**Correct:** A, B, D


#### 20. Emotion influences human capabilities in which ways?  
A) ✗ Relaxed users tend to be more forgiving, not less.  
B) ✗ Positive affect broadens thinking and enhances creativity, not narrows it.  
C) ✓ Negative affect can make even easy tasks harder.  
D) ✓ Stress increases difficulty in problem solving.  

**Correct:** C, D
