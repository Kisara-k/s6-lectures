## Answers

#### 1. Which of the following are true about the physical reception of visual stimuli?  
A) ✗ Rods are for low light vision, cones are for color vision.  
B) ✗ Images are focused upside-down, not right-side up, on the retina.  
C) ✓ Light is transformed into electrical energy by photoreceptors in the retina.  
D) ✓ Ganglion cells detect patterns and movement and send signals to the brain.  

**Correct:** C, D


#### 2. Visual acuity is influenced by which of the following factors?  
A) ✓ Luminance affects visual acuity; higher luminance improves detail perception.  
B) ✓ Familiarity helps perceive objects as constant size despite changes in visual angle.  
C) ✓ Visual angle relates to how much of the view an object occupies, affecting acuity.  
D) ✗ Size of the retina is not a factor discussed in visual acuity.  

**Correct:** A, B, C


#### 3. Which statements about color vision are correct?  
A) ✗ Color blindness affects more males than females, not the other way around.  
B) ✓ About 8% of males are color blind; much fewer females are affected.  
C) ✓ Hue, intensity, and saturation are components of color perception.  
D) ✗ Blue cones have the lowest acuity, not the highest.  

**Correct:** B, C


#### 4. The visual system compensates for which of the following to maintain stable perception?  
A) ✓ Adjusts for changes in luminance to maintain perception.  
B) ✓ Compensates for movement to keep stable images.  
C) ✗ Auditory input is unrelated to visual compensation.  
D) ✓ Uses context to resolve ambiguity in perception.  

**Correct:** A, B, D


#### 5. Which of the following are characteristics of reading as a visual process?  
A) ✓ Syntax, semantics, and pragmatics are involved in interpreting text.  
B) ✓ Word shape is important for word recognition.  
C) ✗ Perception occurs mainly during fixations, not saccades.  
D) ✓ Negative contrast improves reading from computer screens.  

**Correct:** A, B, D


#### 6. Regarding the human auditory system, which are true?  
A) ✓ Humans hear roughly 20 Hz to 15 kHz frequencies.  
B) ✓ Cocktail party phenomenon shows selective auditory attention.  
C) ✗ Loudness depends on amplitude, not frequency.  
D) ✗ Middle ear transmits vibrations, chemical signals are released in the inner ear.  

**Correct:** A, B


#### 7. Which receptors in the skin are responsible for detecting pressure?  
A) ✗ Photoreceptors are in the eye, not skin.  
B) ✗ Nociceptors detect pain, not pressure.  
C) ✗ Thermoreceptors detect temperature, not pressure.  
D) ✓ Mechanoreceptors detect pressure stimuli.  

**Correct:** D


#### 8. Kinesthesia refers to:  
A) ✗ Visual pattern recognition is unrelated to kinesthesia.  
B) ✗ Detecting pain is nociception, not kinesthesia.  
C) ✓ Awareness of body position and movement.  
D) ✗ Temperature sense is thermoreception.  

**Correct:** C


#### 9. Reaction time varies depending on stimulus type. Which of the following correctly orders reaction times from fastest to slowest?  
A) ✗ Visual is slower than auditory, so this order is incorrect.  
B) ✗ Pain is slowest, but auditory is faster than visual.  
C) ✓ Auditory (~150 ms) is fastest, then visual (~200 ms), then pain (~700 ms).  
D) ✗ Visual reaction time (~200 ms) is slower than auditory (~150 ms).  

**Correct:** C


#### 10. According to Fitts’ Law, which design choice will reduce movement time?  
A) ✓ Larger targets reduce movement time.  
B) ✗ Decreasing target size increases movement time.  
C) ✓ Placing targets closer reduces movement time.  
D) ✗ Increasing distance increases movement time.  

**Correct:** A, C


#### 11. Which of the following statements about short-term memory (STM) are correct?  
A) ✗ STM is temporary, not permanent storage.  
B) ✓ STM allows rapid access (~70 ms).  
C) ✗ STM decay is about 20 seconds, not 200 milliseconds (lecture states rapid decay ~200 ms but typical STM decay is longer; 200 ms here refers to rapid decay of sensory memory).  
D) ✓ STM capacity is about 7 ± 2 chunks.  

**Correct:** B, D


#### 12. Long-term memory (LTM) differs from STM in that:  
A) ✓ LTM access is slower than STM.  
B) ✗ LTM capacity is huge or unlimited, not limited to 7 ± 2 chunks.  
C) ✓ LTM includes episodic and semantic memory types.  
D) ✓ LTM decay is very slow or negligible.  

**Correct:** A, C, D


#### 13. Which of the following best describe semantic networks in LTM?  
A) ✓ Supports inference through inheritance.  
B) ✗ Information is connected, not unconnected facts.  
C) ✗ Relationships are explicit, not vague.  
D) ✓ Child nodes inherit properties from parent nodes.  

**Correct:** A, D


#### 14. Scripts in memory models are:  
A) ✗ Condition-action rules describe production rules, not scripts.  
B) ✗ Scripts include roles, props, and scenes.  
C) ✓ Data structures representing stereotypical event sequences.  
D) ✓ Instantiated with values depending on context.  

**Correct:** C, D


#### 15. Which of the following are true about deductive reasoning?  
A) ✓ Deduction derives necessary conclusions from premises.  
B) ✓ False premises can lead to false conclusions despite valid logic.  
C) ✓ If premises are true and reasoning valid, conclusion must be true.  
D) ✗ Logical validity alone does not guarantee truth if premises are false.  

**Correct:** A, B, C


#### 16. Inductive reasoning is characterized by:  
A) ✓ Induction is unreliable but useful.  
B) ✓ Generalizing from specific to broader cases.  
C) ✗ Humans are generally poor at using negative evidence.  
D) ✗ Induction cannot prove hypotheses true with certainty, only falsify.  

**Correct:** A, B, C


#### 17. Abductive reasoning involves:  
A) ✓ Can lead to false explanations due to assumptions.  
B) ✗ Abduction can be unreliable, not always reliable.  
C) ✓ Reasoning from effect to cause (inferring cause from observed event).  
D) ✗ Reasoning from cause to effect is deduction or induction.  

**Correct:** A, C


#### 18. Which of the following statements about problem solving are correct?  
A) ✓ Problem space theory involves generating states with legal operators.  
B) ✗ Analogical mapping is difficult when domains differ semantically.  
C) ✓ Skilled problem solving involves chunking information.  
D) ✓ Gestalt theory emphasizes insight and restructuring.  

**Correct:** A, C, D


#### 19. Errors in human behavior can be classified as:  
A) ✗ Errors are not always caused by lack of attention; other causes exist.  
B) ✓ Incorrect mental models can cause errors.  
C) ✓ Slips occur when intention is correct but execution fails.  
D) ✓ Mistakes occur when intention itself is wrong.  

**Correct:** B, C, D


#### 20. Emotion influences human capabilities in which ways?  
A) ✓ Negative affect can make even easy tasks harder.  
B) ✗ Positive affect broadens thinking and enhances creativity, not narrows it.  
C) ✓ Stress increases difficulty in problem solving.  
D) ✗ Relaxed users tend to be more forgiving, not less.  

**Correct:** A, C
