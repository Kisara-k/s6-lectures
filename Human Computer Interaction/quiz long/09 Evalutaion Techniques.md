## Answers

#### 1. What are the primary goals of evaluation in HCI?  
A) ✓ Evaluation assesses if the system functions as intended.  
B) ✓ Understanding the interface’s effect on users is essential.  
C) ✗ Reducing costs is a benefit but not a primary goal of evaluation.  
D) ✓ Identifying user problems is a key goal of evaluation.  

**Correct:** A, B, D


#### 2. Which of the following best describes a Cognitive Walkthrough?  
A) ✗ Statistical analysis is unrelated to cognitive walkthrough.  
B) ✗ Think aloud is a user-driven method, not a cognitive walkthrough.  
C) ✓ It involves an expert simulating user tasks to evaluate learning support.  
D) ✗ Heuristic evaluation checks heuristics, not cognitive walkthrough.  

**Correct:** C


#### 3. In Heuristic Evaluation, which of the following are typical heuristics used?  
A) ✓ Predictability is a key heuristic.  
B) ✓ Providing feedback is a standard heuristic.  
C) ✓ Consistency is a core heuristic.  
D) ✗ Full customization is not a common heuristic.  

**Correct:** A, B, C


#### 4. What is a key limitation of Review-Based Evaluation?  
A) ✗ Cognitive models can be combined with review-based evaluation.  
B) ✓ Literature results may not always apply to new designs.  
C) ✗ It does not require user participation necessarily.  
D) ✗ It can be used at various stages, not only full implementation.  

**Correct:** B


#### 5. Which of the following are advantages of laboratory studies in user evaluation?  
A) ✗ Natural environment is a field study advantage, not lab.  
B) ✓ Labs provide an uninterrupted environment.  
C) ✗ Observing multiple cooperating users is difficult in labs.  
D) ✓ Labs have specialist equipment available.  

**Correct:** B, D


#### 6. Field studies are most appropriate when:  
A) ✓ Context is crucial and must be preserved.  
B) ✗ Single-user constrained tasks are better suited to labs.  
C) ✓ Longitudinal studies are possible in the field.  
D) ✗ Dangerous locations favor lab studies for safety.  

**Correct:** A, C


#### 7. In experimental evaluation, what does the independent variable represent?  
A) ✗ This describes the dependent variable.  
B) ✗ Hypothesis is a prediction, not a variable.  
C) ✗ Subjects are participants, not variables.  
D) ✓ The independent variable is what the experimenter changes.  

**Correct:** D


#### 8. Which of the following statements about within-groups experimental design is true?  
A) ✗ Within-groups usually requires fewer participants.  
B) ✗ This describes between-groups design.  
C) ✓ Within-groups reduces variability from subject differences.  
D) ✗ Transfer of learning is a risk in within-groups design.  

**Correct:** C


#### 9. When analyzing experimental data, parametric tests:  
A) ✓ Parametric tests are more powerful when assumptions hold.  
B) ✗ Parametric tests are generally more powerful than non-parametric.  
C) ✓ Assume data follows a normal distribution.  
D) ✗ Parametric tests are less reliable if data is non-normal.  

**Correct:** A, C


#### 10. What are common challenges when conducting group experiments in HCI?  
A) ✓ Managing large data volumes like video is challenging.  
B) ✓ Tasks must encourage cooperation for valid group data.  
C) ✓ Recruiting enough subjects is difficult and costly.  
D) ✗ Variation in user behavior is inevitable, not avoidable.  

**Correct:** A, B, C


#### 11. Which of the following are true about Think Aloud protocols?  
A) ✓ Users verbalize thoughts during task performance.  
B) ✗ Think Aloud requires little technical equipment.  
C) ✓ Verbalizing can alter how users perform tasks.  
D) ✗ Data is subjective, not completely objective.  

**Correct:** A, C


#### 12. Cooperative evaluation differs from Think Aloud in that:  
A) ✗ Post-task analysis is still often needed.  
B) ✗ It is less constrained and more flexible, not more constrained.  
C) ✓ User and evaluator collaborate and ask questions.  
D) ✓ It encourages open criticism from users.  

**Correct:** C, D


#### 13. Which of the following are advantages of post-task walkthroughs?  
A) ✓ Helps identify reasons behind user actions.  
B) ✗ Interpretation bias can still occur in analysis.  
C) ✓ Useful when Think Aloud is not feasible.  
D) ✓ Immediate playback helps keep memory fresh.  

**Correct:** A, C, D


#### 14. What is a major disadvantage of questionnaires compared to interviews?  
A) ✗ Questionnaires can be analyzed rigorously.  
B) ✗ Questionnaires are quicker, not more time-consuming.  
C) ✓ Questionnaires are less flexible and probing.  
D) ✗ Questionnaires can reach large groups quickly.  

**Correct:** C


#### 15. Eye tracking measurements include:  
A) ✓ Fixations indicate cognitive effort and difficulty.  
B) ✗ Heart rate is a physiological measure but not eye tracking.  
C) ✓ Scan paths show the route of eye movement.  
D) ✓ Saccades are rapid eye movements between points.  

**Correct:** A, C, D


#### 16. Physiological measurements such as Galvanic Skin Response (GSR) and EEG:  
A) ✗ Interpretation is complex, not straightforward.  
B) ✗ They are rarely used alone as the sole method.  
C) ✓ More research is needed to improve interpretation.  
D) ✓ They provide insights into emotional reactions.  

**Correct:** C, D


#### 17. Which factors should influence the choice of an evaluation method?  
A) ✓ Stage of design or implementation matters.  
B) ✓ Whether the evaluation is subjective or objective is important.  
C) ✓ Available resources like time and equipment are crucial.  
D) ✗ Programming language does not affect evaluation method choice.  

**Correct:** A, B, C


#### 18. In experimental design, the null hypothesis:  
A) ✗ This describes the alternative hypothesis.  
B) ✓ States no difference between conditions.  
C) ✓ The experiment aims to disprove the null hypothesis.  
D) ✗ Null hypothesis is rejected if data shows difference, not accepted.  

**Correct:** B, C


#### 19. Which of the following statements about field studies is correct?  
A) ✗ Field studies are well suited for longitudinal studies.  
B) ✓ They allow study of real-world social and physical contexts.  
C) ✓ Observer presence may alter user behavior.  
D) ✗ Field studies are not controlled and have distractions.  

**Correct:** B, C


#### 20. Which of the following are true about protocol analysis methods?  
A) ✗ Video recording requires special equipment and can be obtrusive.  
B) ✓ Computer logging produces large, complex data sets.  
C) ✓ Audio is good for Think Aloud but hard to synchronize.  
D) ✗ User notebooks are subjective, not objective.  

**Correct:** B, C
