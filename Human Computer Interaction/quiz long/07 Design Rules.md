## 7. Design Rules

## Questions

B) Standards have higher authority and are more specific

A) Recoverability  
B) Multithreading  
C) Predictability  
D) Familiarity  

#### 4. How does **predictability** support learnability?  
A) By providing multiple ways to input data  
B) By ensuring the system supports concurrent tasks

#### 5. Which of these are examples of **flexibility** principles?  
A) Responsiveness  
B) Task migratability  
C) Observability  
D) Dialogue initiative  

#### 6. What does **task migratability** mean in the context of flexibility?  
A) The system adapts its interface based on user preferences

#### 7. Which of the following are aspects of **robustness** in usability?  
A) Synthesizability  
B) Customizability  
C) Recoverability  
D) Observability  

#### 8. What is the role of **observability** in robustness?  
A) It supports multiple input methods  
B) It enables users to customize the interface  
C) It prevents users from making errors  
D) It allows users to evaluate the system’s internal state through perceivable feedback  

#### 9. Which statements about **ISO 9241** are true?  
A) It defines usability as effectiveness, efficiency, and satisfaction

B) They emphasize system control over user control

D) They promote consistency in design  

#### 12. Norman’s principle “Use both knowledge in the world and knowledge in the head” means:  
A) Avoid using visible controls to reduce clutter  
B) Design tasks to be as complex as possible

#### 13. What is a key characteristic of **design patterns** in HCI?

B) They exist independently and are not linked to other patterns

#### 14. Which of the following statements about **multithreading** in flexibility are correct?

B) It allows users to interact with the system on multiple tasks at once

A) By reducing the number of available input methods  
B) By preventing users from changing system behavior

#### 16. Which of the following are examples of **recoverability** features?  
A) Providing informative feedback after errors  
B) Undo and redo functions  
C) Predicting user actions before they occur  
D) Forward and backward navigation  

#### 17. What does **consistency** in usability principles imply?  
A) Similar situations or tasks should behave similarly to reduce user confusion  
B) Different tasks should have completely different input/output behaviors  
C) The system should change behavior frequently to keep users alert  
D) Users should memorize unique commands for each task  

#### 18. Which of the following statements about **dialogue initiative** are true?  
A) It allows users freedom from system-imposed constraints on input  
B) It supports user-driven interaction rather than system pre-emptiveness  
C) It refers to the system controlling all user inputs  
D) It limits users to predefined dialogue paths  

#### 19. How do **golden rules and heuristics** differ from standards and guidelines?  
A) They are less useful than having no design rules at all  
B) They are legally enforced design requirements  
C) They are broad, practical checklists rather than strict rules  
D) They provide detailed, specific instructions for implementation  

#### 20. Which of the following best describe the relationship between **authority** and **generality** in design rules?  
A) Principles have high generality but low authority  
B) Standards have high authority but low generality  
C) Guidelines have the highest authority and generality  
D) As authority increases, generality always increases

## Answers

#### 1. Which of the following best describe the characteristics of design **principles**?  
A) ✗ Principles are not specific or strictly enforced.  
B) ✓ Principles are abstract and broadly applicable across contexts.  
C) ✓ Principles have low authority but high generality, meaning they apply widely.  
D) ✗ Principles have low authority, not high.  

**Correct:** B, C


#### 2. What distinguishes **standards** from guidelines in design rules?  
A) ✓ Guidelines are more general and flexible than standards.  
B) ✓ Standards have higher authority and are more specific than guidelines.  
C) ✗ Standards do not apply broadly across all contexts; they are more limited.  
D) ✗ Guidelines are not legally binding; standards may be mandatory.  

**Correct:** A, B


#### 3. Which of the following are components of **learnability** in usability?  
A) ✗ Recoverability is part of robustness, not learnability.  
B) ✗ Multithreading relates to flexibility, not learnability.  
C) ✓ Predictability is key to learnability.  
D) ✓ Familiarity helps users learn new systems.  

**Correct:** C, D


#### 4. How does **predictability** support learnability?  
A) ✗ Multiple input methods relate to flexibility, not predictability.  
B) ✗ Supporting concurrent tasks is flexibility, not predictability.  
C) ✓ Predictability means users can anticipate future effects based on past actions.  
D) ✗ Undoing errors relates to recoverability, not predictability.  

**Correct:** C


#### 5. Which of these are examples of **flexibility** principles?  
A) ✗ Responsiveness relates to robustness, not flexibility.  
B) ✓ Task migratability is a flexibility principle.  
C) ✗ Observability is part of robustness, not flexibility.  
D) ✓ Dialogue initiative is a flexibility principle.  

**Correct:** B, D


#### 6. What does **task migratability** mean in the context of flexibility?  
A) ✗ Customizability relates to interface modification, not task migratability.  
B) ✗ It is not about switching users automatically.  
C) ✗ Multitasking is multithreading, not task migratability.  
D) ✓ It means passing responsibility for task execution between user and system.  

**Correct:** D


#### 7. Which of the following are aspects of **robustness** in usability?  
A) ✗ Synthesizability relates to learnability, not robustness.  
B) ✗ Customizability is a flexibility principle, not robustness.  
C) ✓ Recoverability is a robustness principle.  
D) ✓ Observability is part of robustness.  

**Correct:** C, D


#### 8. What is the role of **observability** in robustness?  
A) ✗ Supporting multiple input methods relates to flexibility, not observability.  
B) ✗ Customizability is unrelated to observability.  
C) ✗ It does not prevent errors but helps users understand system state.  
D) ✓ It allows users to evaluate the system’s internal state via feedback.  

**Correct:** D


#### 9. Which statements about **ISO 9241** are true?  
A) ✓ It defines usability as effectiveness, efficiency, and satisfaction.  
B) ✗ It is a standard, not a low-authority guideline.  
C) ✓ It is a standard requiring compliance by designers.  
D) ✗ It covers both hardware and software usability, not just hardware.  

**Correct:** A, C


#### 10. How do **guidelines** differ from **principles**?  
A) ✗ Principles apply to all design, not only hardware.  
B) ✗ Guidelines are not legally enforced.  
C) ✓ Principles are more flexible and less authoritative than guidelines.  
D) ✓ Guidelines are more detailed and specific than principles.  

**Correct:** C, D


#### 11. Which of the following are true about **Shneiderman’s 8 Golden Rules**?  
A) ✓ “Reduce short-term memory load” is one of the rules.  
B) ✗ They promote user control, not system control.  
C) ✗ They encourage error prevention, not discourage it.  
D) ✓ Consistency is emphasized in the rules.  

**Correct:** A, D


#### 12. Norman’s principle “Use both knowledge in the world and knowledge in the head” means:  
A) ✗ It encourages visible controls, not avoiding them.  
B) ✗ It aims to simplify tasks, not make them complex.  
C) ✗ It does not rely solely on user memory.  
D) ✓ It means providing external cues to support user memory.  

**Correct:** D


#### 13. What is a key characteristic of **design patterns** in HCI?  
A) ✗ They apply to many design aspects, not only visual elements.  
B) ✗ Patterns are linked to other patterns in a language.  
C) ✓ They provide invariant solutions to recurring problems.  
D) ✗ They capture practical design knowledge, not just theory.  

**Correct:** C


#### 14. Which of the following statements about **multithreading** in flexibility are correct?  
A) ✗ It is unrelated to error recovery.  
B) ✓ It allows users to interact on multiple tasks simultaneously.  
C) ✗ It does not limit users to one task at a time.  
D) ✓ It supports concurrent or interleaved task execution.  

**Correct:** B, D


#### 15. How does **customizability** enhance usability?  
A) ✗ It does not reduce input methods but may increase options.  
B) ✗ It encourages user modification, not prevention.  
C) ✗ It does not enforce strict layout standards.  
D) ✓ By allowing users or the system to modify the interface to suit preferences.  

**Correct:** D


#### 16. Which of the following are examples of **recoverability** features?  
A) ✓ Informative feedback after errors aids recovery.  
B) ✓ Undo and redo functions support recoverability.  
C) ✗ Predicting user actions is related to predictability, not recoverability.  
D) ✓ Forward and backward navigation help users recover from errors.  

**Correct:** A, B, D


#### 17. What does **consistency** in usability principles imply?  
A) ✓ Similar situations or tasks should behave similarly to reduce confusion.  
B) ✗ Different tasks should behave similarly when appropriate.  
C) ✗ Frequent behavior changes confuse users.  
D) ✗ Users should not memorize unique commands unnecessarily.  

**Correct:** A


#### 18. Which of the following statements about **dialogue initiative** are true?  
A) ✓ It allows users freedom from system-imposed input constraints.  
B) ✓ It supports user-driven interaction rather than system pre-emptiveness.  
C) ✗ It does not mean system controls all input.  
D) ✗ It does not limit users to predefined dialogue paths.  

**Correct:** A, B


#### 19. How do **golden rules and heuristics** differ from standards and guidelines?  
A) ✗ They are more useful than having no design rules at all.  
B) ✗ They are not legally enforced requirements.  
C) ✓ They are broad, practical checklists rather than strict rules.  
D) ✗ They do not provide detailed instructions but general advice.  

**Correct:** A, C


#### 20. Which of the following best describe the relationship between **authority** and **generality** in design rules?  
A) ✓ Principles have high generality but low authority.  
B) ✓ Standards have high authority but low generality.  
C) ✗ Guidelines have medium authority and generality, not the highest.  
D) ✗ Authority and generality do not always increase together.  

**Correct:** A, B
