## Answers

#### 1. Which of the following are advantages of curved UHD (4K) displays compared to traditional flat HD monitors?  
A) ✓ Enhanced 3D experience and sharper image quality — UHD resolution provides crisper images; curvature enhances 3D perception.  
B) ✗ Lower manufacturing cost and easier wall mounting — Curved UHD displays are generally more expensive and harder to mount.  
C) ✗ Reduced power consumption and longer lifespan — These are not primary advantages of curved UHD displays.  
D) ✓ Improved viewing angles and reduced reflections — Curved displays reduce glare and offer better viewing angles.  

**Correct:** A, D


#### 2. Flexible displays often use polyimide film as a backplane because:  
A) ✗ It increases the display’s resolution beyond 4K — Resolution depends on other factors, not the backplane material.  
B) ✓ It enables transparency with about 30% light transmittance — Some flexible displays are transparent due to this material.  
C) ✓ It is a strong, flexible plastic allowing high curvature — Polyimide film enables bending without damage.  
D) ✗ It is cheaper than conventional plastic backplanes — Cost is not the main reason for its use.  

**Correct:** B, C


#### 3. Virtual projection keyboards provide which of the following benefits?  
A) ✗ Wireless connectivity to multiple devices simultaneously — Usually connect to one device at a time.  
B) ✓ Portability without carrying a physical keyboard — They project a keyboard, eliminating the need to carry one.  
C) ✗ Ability to project keyboards on uneven or curved surfaces — Projection works best on flat surfaces.  
D) ✗ Physical tactile feedback identical to mechanical keyboards — They lack physical keys and tactile feedback.  

**Correct:** B


#### 4. Brain signal capturing headsets like Emotiv EPOC use EEG signals primarily to:  
A) ✗ Detect muscle movements for gesture control — EEG measures brain activity, not muscle movements.  
B) ✗ Monitor heart rate and body temperature — These are measured by other sensors, not EEG.  
C) ✓ Control robotic devices or vehicles through thought — Brain signals can be used to operate external devices.  
D) ✓ Convert brain electrical activity into digital commands — EEG signals are digitized for computer processing.  

**Correct:** C, D


#### 5. Microsoft HoloLens differs from VR headsets like Oculus Rift mainly because:  
A) ✗ It provides a fully immersive virtual environment — HoloLens overlays virtual objects on the real world (AR), not full VR.  
B) ✓ It overlays holograms onto the real world (augmented reality) — This is the core feature of HoloLens.  
C) ✗ It requires a smartphone to function — HoloLens is a standalone device.  
D) ✓ It is compatible with Windows 10 operating system — HoloLens runs Windows 10.  

**Correct:** B, D


#### 6. Which of the following statements about Google Cardboard are true?  
A) ✗ It requires a dedicated external processor for rendering — Uses the smartphone’s processor.  
B) ✓ It uses a smartphone to create stereoscopic 3D views — The phone provides the display and processing.  
C) ✗ It supports transparent display technology — Cardboard is opaque and does not support transparency.  
D) ✓ It is a low-cost VR headset made primarily from cardboard — Designed to be affordable and simple.  

**Correct:** B, D


#### 7. Haptic feedback controllers enhance user experience by:  
A) ✗ Projecting virtual keyboards on surfaces — This is unrelated to haptics.

D) ✓ Delivering motion feedback through sliding contactor plates — Some controllers use this for realistic feedback.
