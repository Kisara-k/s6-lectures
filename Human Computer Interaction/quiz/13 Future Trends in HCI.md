## Answers

#### 1. Which of the following are advantages of curved UHD (4K) displays compared to traditional flat HD monitors?  
A) ✓ Improved viewing angles and reduced reflections — Curved displays reduce glare and offer better viewing angles.  
B) ✗ Lower manufacturing cost and easier wall mounting — Curved UHD displays are generally more expensive and harder to mount.  
C) ✓ Enhanced 3D experience and sharper image quality — UHD resolution provides crisper images; curvature enhances 3D perception.  
D) ✗ Reduced power consumption and longer lifespan — These are not primary advantages of curved UHD displays.  

**Correct:** A, C


#### 2. Flexible displays often use polyimide film as a backplane because:  
A) ✓ It is a strong, flexible plastic allowing high curvature — Polyimide film enables bending without damage.  
B) ✗ It is cheaper than conventional plastic backplanes — Cost is not the main reason for its use.  
C) ✓ It enables transparency with about 30% light transmittance — Some flexible displays are transparent due to this material.  
D) ✗ It increases the display’s resolution beyond 4K — Resolution depends on other factors, not the backplane material.  

**Correct:** A, C


#### 3. Virtual projection keyboards provide which of the following benefits?  
A) ✗ Physical tactile feedback identical to mechanical keyboards — They lack physical keys and tactile feedback.  
B) ✓ Portability without carrying a physical keyboard — They project a keyboard, eliminating the need to carry one.  
C) ✗ Wireless connectivity to multiple devices simultaneously — Usually connect to one device at a time.  
D) ✗ Ability to project keyboards on uneven or curved surfaces — Projection works best on flat surfaces.  

**Correct:** B


#### 4. Brain signal capturing headsets like Emotiv EPOC use EEG signals primarily to:  
A) ✗ Detect muscle movements for gesture control — EEG measures brain activity, not muscle movements.  
B) ✓ Convert brain electrical activity into digital commands — EEG signals are digitized for computer processing.  
C) ✗ Monitor heart rate and body temperature — These are measured by other sensors, not EEG.  
D) ✓ Control robotic devices or vehicles through thought — Brain signals can be used to operate external devices.  

**Correct:** B, D


#### 5. Microsoft HoloLens differs from VR headsets like Oculus Rift mainly because:  
A) ✗ It provides a fully immersive virtual environment — HoloLens overlays virtual objects on the real world (AR), not full VR.  
B) ✓ It overlays holograms onto the real world (augmented reality) — This is the core feature of HoloLens.  
C) ✗ It requires a smartphone to function — HoloLens is a standalone device.  
D) ✓ It is compatible with Windows 10 operating system — HoloLens runs Windows 10.  

**Correct:** B, D


#### 6. Which of the following statements about Google Cardboard are true?  
A) ✓ It is a low-cost VR headset made primarily from cardboard — Designed to be affordable and simple.  
B) ✗ It requires a dedicated external processor for rendering — Uses the smartphone’s processor.  
C) ✓ It uses a smartphone to create stereoscopic 3D views — The phone provides the display and processing.  
D) ✗ It supports transparent display technology — Cardboard is opaque and does not support transparency.  

**Correct:** A, C


#### 7. Haptic feedback controllers enhance user experience by:  
A) ✓ Providing force and vibration sensations — Core function of haptic devices.  
B) ✗ Enabling voice recognition capabilities — Voice recognition is separate technology.  
C) ✓ Delivering motion feedback through sliding contactor plates — Some controllers use this for realistic feedback.  
D) ✗ Projecting virtual keyboards on surfaces — This is unrelated to haptics.  

**Correct:** A, C


#### 8. Standalone smartwatches differ from regular smartwatches because they:  
A) ✓ Can operate independently with cellular connectivity — They have SIM slots for direct network access.  
B) ✗ Require constant pairing with a smartphone to function — Standalone watches can work without pairing.  
C) ✓ Include integrated SIM card slots for 3G/4G networks — This enables independent communication.  
D) ✗ Are limited to fitness tracking without communication features — They offer full phone capabilities.  

**Correct:** A, C


#### 9. Smart jewellery devices like the CSR Bluetooth Pendant can:  
A) ✓ Change LED colors based on user mood or clothing — Designed to reflect mood or style.  
B) ✗ Monitor heart rate and blood pressure continuously — Not typical features of these jewellery devices.  
C) ✓ Notify users of incoming calls or messages via LED signals — Used as notification indicators.  
D) ✗ Function as standalone smartphones without pairing — They rely on connection to smartphones.  

**Correct:** A, C


#### 10. Smart footwear technologies generate power primarily through:
