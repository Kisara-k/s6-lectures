## Answers

#### 1. Which of the following are advantages of curved UHD (4K) displays compared to traditional flat HD monitors?  
A) ✓ Enhanced 3D experience and sharper image quality — UHD resolution provides sharper images; curvature enhances 3D immersion.  
B) ✗ Lower manufacturing cost and easier wall mounting — Curved UHD displays are generally more expensive and harder to mount on walls.  
C) ✗ Ability to display holograms without additional hardware — Hologram display requires specialized AR devices, not just curved UHD screens.  
D) ✓ Improved viewing angles and reduced reflections — Curved displays wrap around the user’s field of view, reducing reflections and improving viewing angles.  

**Correct:** A, D


#### 2. Flexible and transparent displays often use polyimide film as a backplane because:  
A) ✗ It is a rigid material that supports high resolution — Polyimide is flexible, not rigid.  
B) ✓ It allows for a thinner, bendable structure enabling high curvature — Polyimide film is strong and flexible, enabling curved and foldable displays.  
C) ✓ It enables transparency with about 30% light transmittance — Transparent displays with polyimide film can achieve ~30% transmittance.  
D) ✗ It increases the display’s brightness by 70% — Brightness increase is not a primary feature of polyimide film.  

**Correct:** B, C


#### 3. Virtual projection keyboards provide which of the following benefits?  
A) ✗ Wireless connectivity to multiple devices simultaneously — Usually connect to one device at a time via Bluetooth.  
B) ✓ Portability without carrying a physical keyboard — They project a keyboard on any flat surface, eliminating the need to carry a physical keyboard.  
C) ✗ Ability to project keyboards on uneven or curved surfaces without accuracy loss — Projection requires a flat surface for accurate key detection.  
D) ✗ Physical tactile feedback identical to mechanical keyboards — Projection keyboards lack physical keys and tactile feedback.  

**Correct:** B


#### 4. Brain signal capturing headsets rely on which technology to interpret user thoughts?  
A) ✗ Infrared sensors measuring blood flow in the brain — Not used in these headsets.  
B) ✗ Magnetic resonance imaging (MRI) for real-time brain mapping — MRI is a large, stationary imaging technique, not used in wearable headsets.  
C) ✓ Electroencephalography (EEG) sensors detecting voltage changes on the scalp — EEG sensors detect electrical brain activity via scalp electrodes.  
D) ✗ Ultrasonic waves scanning brain tissue for neural activity — Ultrasound is not used for brain signal capture in this context.  

**Correct:** C


#### 5. Which features distinguish Microsoft HoloLens from typical virtual reality headsets like Oculus Rift?  
A) ✗ Oculus Rift is compatible with Windows 10, while HoloLens is not — Both are compatible with Windows 10.  
B) ✓ HoloLens overlays 3D holograms onto the real world (augmented reality) — HoloLens is an AR device blending virtual objects with reality.  
C) ✗ HoloLens requires external sensors placed around the room for tracking — HoloLens uses onboard sensors, no external sensors needed.  
D) ✓ Oculus Rift provides a fully immersive virtual environment with 360° tracking — Oculus Rift is a VR headset creating a fully virtual environment.  

**Correct:** B, D


#### 6. Smartwatches with standalone cellular connectivity differ from standard smartwatches because they:  
A) ✓ Include integrated SIM card slots for direct 3G/4G network access — SIM slots enable direct cellular connection.  
B) ✓ Can operate independently without pairing to a smartphone — Standalone smartwatches have SIM slots and cellular connectivity.  
C) ✗ Are unable to run third-party applications — They can run apps like standard smartwatches.  
D) ✗ Lack fitness tracking and health monitoring features — They usually include these features as well.  

**Correct:** A, B


#### 7. In biomedical applications, what is a key advantage of ultrasound fingerprint sensors over traditional optical scanners?  
A) ✓ Use of sound waves to capture fingerprint details beneath the skin surface — Ultrasound captures 3D fingerprint data beneath the skin surface.  
B) ✗ Requirement for direct skin contact without any obstruction — Ultrasound sensors can scan through covers, so direct contact is not always needed.  
C) ✓ Ability to scan fingerprints through glass, metal, and plastic covers — Ultrasound can penetrate these materials.  
D) ✗ Inability to function if the finger is sweaty or covered with lotion — Ultrasound works even with sweat or lotion present.  

**Correct:** A, C


#### 8. Which of the following statements about autonomous driving features in modern cars are true?  
A) ✓ Active cruise control maintains a safe distance from the vehicle ahead automatically — This is a core function of active cruise control.  
B) ✓ Lane drift warnings alert the driver to take corrective action to avoid collisions — Lane drift alerts warn drivers to stay in their lane.  
C) ✓ Auto lane change systems require driver activation of indicators before maneuvering — Drivers must signal intent before the system acts.  
D) ✗ Tesla’s Autopilot mode can fully replace the driver in all driving conditions without intervention — Autopilot requires driver supervision and is not fully autonomous.  

**Correct:** A, B, C


#### 9. Smart home devices like Nest thermostat and STACK. smart bulbs improve energy efficiency by:  
A) ✓ Detecting room occupancy and ambient light to optimize usage — Sensors enable automatic adjustments based on presence and light.  
B) ✗ Operating solely based on pre-set schedules without sensor input — Some devices use schedules, but many rely on sensors and learning.  
C) ✓ Learning user behavior and adjusting settings automatically — Nest thermostat learns patterns to optimize energy use.  
D) ✗ Turning off lights and heating only when manually controlled by the user — These devices automate control beyond manual input.  

**Correct:** A, C


#### 10. Which of the following describe the capabilities of FitGuard mouth-guards and M-Tracer golf swing analyzers?  
A) ✓ FitGuard uses accelerometers to detect impacts exceeding safety thresholds and alerts coaches — It monitors impacts and sends warnings.  
B) ✗ Both devices provide real-time haptic feedback to the user during activity — Neither device provides haptic feedback.  
C) ✓ M-Tracer attaches to golf clubs to record swing data for performance analysis — It collects swing metrics for feedback.  
D) ✗ FitGuard can diagnose heart conditions by monitoring ECG signals during sports activities — FitGuard detects impacts, not heart conditions.  

**Correct:** A, C
