## Answers

#### 1. Which of the following are advantages of curved UHD (4K) displays compared to traditional flat HD monitors?  
A) ✓ Improved viewing angles and reduced reflections — Curved displays reduce glare and offer better viewing angles.  
B) ✓ Enhanced 3D experience and sharper image quality — UHD resolution provides crisper images; curvature enhances 3D perception.  
C) ✗ Lower manufacturing cost and easier wall mounting — Curved UHD displays are generally more expensive and harder to mount.  
D) ✗ Reduced power consumption and longer lifespan — These are not primary advantages of curved UHD displays.  

**Correct:** A, B


#### 2. Flexible displays often use polyimide film as a backplane because:  
A) ✓ It is a strong, flexible plastic allowing high curvature — Polyimide film enables bending without damage.  
B) ✗ It increases the display’s resolution beyond 4K — Resolution depends on other factors, not the backplane material.  
C) ✗ It is cheaper than conventional plastic backplanes — Cost is not the main reason for its use.  
D) ✓ It enables transparency with about 30% light transmittance — Some flexible displays are transparent due to this material.  

**Correct:** A, D


#### 3. Virtual projection keyboards provide which of the following benefits?  
A) ✗ Ability to project keyboards on uneven or curved surfaces — Projection works best on flat surfaces.  
B) ✗ Physical tactile feedback identical to mechanical keyboards — They lack physical keys and tactile feedback.  
C) ✓ Portability without carrying a physical keyboard — They project a keyboard, eliminating the need to carry one.  
D) ✗ Wireless connectivity to multiple devices simultaneously — Usually connect to one device at a time.  

**Correct:** C


#### 4. Brain signal capturing headsets like Emotiv EPOC use EEG signals primarily to:  
A) ✗ Monitor heart rate and body temperature — These are measured by other sensors, not EEG.  
B) ✗ Detect muscle movements for gesture control — EEG measures brain activity, not muscle movements.  
C) ✓ Control robotic devices or vehicles through thought — Brain signals can be used to operate external devices.  
D) ✓ Convert brain electrical activity into digital commands — EEG signals are digitized for computer processing.  

**Correct:** C, D


#### 5. Microsoft HoloLens differs from VR headsets like Oculus Rift mainly because:  
A) ✓ It is compatible with Windows 10 operating system — HoloLens runs Windows 10.  
B) ✗ It requires a smartphone to function — HoloLens is a standalone device.  
C) ✗ It provides a fully immersive virtual environment — HoloLens overlays virtual objects on the real world (AR), not full VR.  
D) ✓ It overlays holograms onto the real world (augmented reality) — This is the core feature of HoloLens.  

**Correct:** A, D


#### 6. Which of the following statements about Google Cardboard are true?  
A) ✗ It supports transparent display technology — Cardboard is opaque and does not support transparency.  
B) ✗ It requires a dedicated external processor for rendering — Uses the smartphone’s processor.  
C) ✓ It is a low-cost VR headset made primarily from cardboard — Designed to be affordable and simple.  
D) ✓ It uses a smartphone to create stereoscopic 3D views — The phone provides the display and processing.  

**Correct:** C, D


#### 7. Haptic feedback controllers enhance user experience by:  
A) ✓ Providing force and vibration sensations — Core function of haptic devices.  
B) ✗ Enabling voice recognition capabilities — Voice recognition is separate technology.  
C) ✗ Projecting virtual keyboards on surfaces — This is unrelated to haptics.  
D) ✓ Delivering motion feedback through sliding contactor plates — Some controllers use this for realistic feedback.  

**Correct:** A, D


#### 8. Standalone smartwatches differ from regular smartwatches because they:  
A) ✓ Can operate independently with cellular connectivity — They have SIM slots for direct network access.

**Correct:** A, C
