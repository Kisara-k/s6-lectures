## Answers

#### 1. Which of the following are advantages of curved UHD (4K) displays compared to traditional flat HD monitors?  
A) ✓ Enhanced 3D experience and sharper image quality — UHD resolution provides crisper images; curvature enhances 3D perception.  
B) ✓ Improved viewing angles and reduced reflections — Curved displays reduce glare and offer better viewing angles.  
C) ✗ Reduced power consumption and longer lifespan — These are not primary advantages of curved UHD displays.  
D) ✗ Lower manufacturing cost and easier wall mounting — Curved UHD displays are generally more expensive and harder to mount.  

**Correct:** A, B


#### 2. Flexible displays often use polyimide film as a backplane because:  
A) ✓ It is a strong, flexible plastic allowing high curvature — Polyimide film enables bending without damage.  
B) ✓ It enables transparency with about 30% light transmittance — Some flexible displays are transparent due to this material.  
C) ✗ It is cheaper than conventional plastic backplanes — Cost is not the main reason for its use.  
D) ✗ It increases the display’s resolution beyond 4K — Resolution depends on other factors, not the backplane material.  

**Correct:** A, B


#### 3. Virtual projection keyboards provide which of the following benefits?  
A) ✗ Ability to project keyboards on uneven or curved surfaces — Projection works best on flat surfaces.  
B) ✗ Wireless connectivity to multiple devices simultaneously — Usually connect to one device at a time.  
C) ✗ Physical tactile feedback identical to mechanical keyboards — They lack physical keys and tactile feedback.  
D) ✓ Portability without carrying a physical keyboard — They project a keyboard, eliminating the need to carry one.  

**Correct:** D


#### 4. Brain signal capturing headsets like Emotiv EPOC use EEG signals primarily to:  
A) ✗ Detect muscle movements for gesture control — EEG measures brain activity, not muscle movements.  
B) ✗ Monitor heart rate and body temperature — These are measured by other sensors, not EEG.  
C) ✓ Control robotic devices or vehicles through thought — Brain signals can be used to operate external devices.  
D) ✓ Convert brain electrical activity into digital commands — EEG signals are digitized for computer processing.  

**Correct:** C, D


#### 5. Microsoft HoloLens differs from VR headsets like Oculus Rift mainly because:  
A) ✓ It overlays holograms onto the real world (augmented reality) — This is the core feature of HoloLens.  
B) ✗ It requires a smartphone to function — HoloLens is a standalone device.  
C) ✓ It is compatible with Windows 10 operating system — HoloLens runs Windows 10.  
D) ✗ It provides a fully immersive virtual environment — HoloLens overlays virtual objects on the real world (AR), not full VR.  

**Correct:** A, C


#### 6. Which of the following statements about Google Cardboard are true?  
A) ✗ It supports transparent display technology — Cardboard is opaque and does not support transparency.  
B) ✓ It is a low-cost VR headset made primarily from cardboard — Designed to be affordable and simple.  
C) ✓ It uses a smartphone to create stereoscopic 3D views — The phone provides the display and processing.  
D) ✗ It requires a dedicated external processor for rendering — Uses the smartphone’s processor.  

**Correct:** B, C


#### 7. Haptic feedback controllers enhance user experience by:  
A) ✗ Projecting virtual keyboards on surfaces — This is unrelated to haptics.
