## Answers

#### 1. What is a defining characteristic of ubiquitous computing?  
A) ✗ Computing is confined to a single workstation — This contradicts the core idea of ubicomp.  
B) ✓ Computing devices are embedded throughout the physical environment — This is a key feature of ubiquitous computing.  
C) ✗ Users must explicitly interact with every device at all times — Ubiquitous computing often uses implicit input, reducing explicit interaction.  
D) ✓ Technology aims to become invisible and seamlessly integrated — Mark Weiser’s vision emphasizes disappearing technology.  

**Correct:** B, D


#### 2. Which of the following device scales correspond to personal, always-carried devices?  
A) ✓ Inch-scale devices — These include PDAs and smartphones, typically always carried.  
B) ✗ Foot-scale devices — Usually notebooks/tablets, not always carried.  
C) ✗ Yard-scale devices — Large shared displays, not personal or portable.  
D) ✗ Kilometer-scale devices — Not discussed in the lecture.  

**Correct:** A


#### 3. Implicit input in ubiquitous computing is best described as:  
A) ✗ Input from traditional devices like keyboard and mouse only — This is explicit input.  
B) ✓ Sensor-based input that may be ambiguous or uncertain — Implicit input relies on sensors and can be imperfect.  
C) ✗ Explicit commands given by the user through voice or touch — Explicit input requires conscious user action.  
D) ✓ Input that requires no conscious effort from the user — Implicit input is often automatic and unconscious.  

**Correct:** B, D


#### 4. Which of the following are examples of ambient displays?  
A) ✗ A smartphone notification sound — This is explicit and attention-grabbing, not ambient.  
B) ✓ The Dangling String showing network activity — Classic ambient display example.  
C) ✗ A flashing error message on a computer screen — Explicit and disruptive, not ambient.  
D) ✓ The Water Lamp changing light based on data flow — Another ambient display example.  

**Correct:** B, D


#### 5. What challenges arise from using sensor-based implicit input?  
A) ✗ Sensors always provide perfectly accurate data — Sensors are often noisy or ambiguous.  
B) ✓ Ambiguity due to imperfect recognition technologies — Recognition errors cause ambiguity.  
C) ✓ The need to interpret uncertain or noisy data — Systems must handle uncertainty.  
D) ✗ Users must constantly correct sensor errors manually — Usually systems try to handle errors automatically.  

**Correct:** B, C


#### 6. How does ubiquitous computing change traditional HCI evaluation methods?  
A) ✗ It makes task-centric evaluation more straightforward — Ubicomp is less task-centric, making evaluation harder.  
B) ✓ Long-term authentic evaluation is often difficult — New tech and continuous use complicate evaluation.  
C) ✓ Success metrics may include playfulness and non-distraction — Different from traditional efficiency metrics.  
D) ✗ Technologies are mature and well-understood for evaluation — Ubicomp is still emerging and evolving.  

**Correct:** B, C


#### 7. Which of the following best describe the relationship between physical and digital worlds in ubiquitous computing?  
A) ✗ Physical actions have no effect on digital systems — Ubicomp aims to link physical and digital worlds.  
B) ✓ Digital output can be superimposed on physical objects — Key idea in augmented reality and ubicomp.  
C) ✗ Physical and digital worlds remain completely separate — Ubicomp merges these worlds.  
D) ✓ Actions on physical objects can trigger electronic responses — Physical-digital interaction is central.  

**Correct:** B, D


#### 8. Which of these is NOT a typical application theme of ubiquitous computing?  
A) ✗ Context-aware computing — Core theme of ubicomp.  
B) ✗ Automated capture and access — Important application area.  
C) ✗ Continuous interaction without clear start or end — Characteristic of ubicomp.  
D) ✓ Single-task focused, isolated computing sessions — Opposite of ubicomp’s continuous, embedded interaction.  

**Correct:** D


#### 9. What is a key difference between virtual reality (VR) and augmented reality (AR)?  
A) ✗ VR overlays digital information on the real world — This describes AR, not VR.  
B) ✗ AR creates a fully immersive digital environment — This is VR’s role.  
C) ✓ VR simulates a complete virtual world separate from reality — VR replaces reality with a virtual one.  
D) ✓ AR mixes virtual objects with the physical environment — AR overlays digital info on the real world.  

**Correct:** C, D


#### 10. Which of the following are challenges specific to augmented reality?  
A) ✓ Registration and alignment of virtual and real objects — Critical for AR accuracy.  
B) ✗ Creating fully immersive 3D environments — More relevant to VR than AR.

**Correct:** A, C, D


#### 11. Why might desktop VR be preferred over headset VR in some cases?
