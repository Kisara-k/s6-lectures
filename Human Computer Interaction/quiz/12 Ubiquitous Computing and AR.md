## Answers

#### 1. What is a defining characteristic of ubiquitous computing?  
A) ✓ Computing devices are embedded throughout the physical environment — This is a key feature of ubiquitous computing.  
B) ✗ Users must explicitly interact with every device at all times — Ubiquitous computing often uses implicit input, reducing explicit interaction.  
C) ✗ Computing is confined to a single workstation — This contradicts the core idea of ubicomp.  
D) ✓ Technology aims to become invisible and seamlessly integrated — Mark Weiser’s vision emphasizes disappearing technology.  

**Correct:** A, D


#### 2. Which of the following device scales correspond to personal, always-carried devices?  
A) ✗ Kilometer-scale devices — Not discussed in the lecture.  
B) ✓ Inch-scale devices — These include PDAs and smartphones, typically always carried.  
C) ✗ Yard-scale devices — Large shared displays, not personal or portable.  
D) ✗ Foot-scale devices — Usually notebooks/tablets, not always carried.  

**Correct:** B


#### 3. Implicit input in ubiquitous computing is best described as:  
A) ✓ Sensor-based input that may be ambiguous or uncertain — Implicit input relies on sensors and can be imperfect.  
B) ✗ Explicit commands given by the user through voice or touch — Explicit input requires conscious user action.  
C) ✓ Input that requires no conscious effort from the user — Implicit input is often automatic and unconscious.  
D) ✗ Input from traditional devices like keyboard and mouse only — This is explicit input.  

**Correct:** A, C


#### 4. Which of the following are examples of ambient displays?  
A) ✓ The Dangling String showing network activity — Classic ambient display example.  
B) ✗ A smartphone notification sound — This is explicit and attention-grabbing, not ambient.  
C) ✗ A flashing error message on a computer screen — Explicit and disruptive, not ambient.  
D) ✓ The Water Lamp changing light based on data flow — Another ambient display example.  

**Correct:** A, D


#### 5. What challenges arise from using sensor-based implicit input?  
A) ✓ The need to interpret uncertain or noisy data — Systems must handle uncertainty.  
B) ✓ Ambiguity due to imperfect recognition technologies — Recognition errors cause ambiguity.  
C) ✗ Users must constantly correct sensor errors manually — Usually systems try to handle errors automatically.  
D) ✗ Sensors always provide perfectly accurate data — Sensors are often noisy or ambiguous.  

**Correct:** A, B


#### 6. How does ubiquitous computing change traditional HCI evaluation methods?  
A) ✓ Success metrics may include playfulness and non-distraction — Different from traditional efficiency metrics.  
B) ✗ Technologies are mature and well-understood for evaluation — Ubicomp is still emerging and evolving.  
C) ✓ Long-term authentic evaluation is often difficult — New tech and continuous use complicate evaluation.  
D) ✗ It makes task-centric evaluation more straightforward — Ubicomp is less task-centric, making evaluation harder.  

**Correct:** A, C


#### 7. Which of the following best describe the relationship between physical and digital worlds in ubiquitous computing?  
A) ✗ Physical actions have no effect on digital systems — Ubicomp aims to link physical and digital worlds.  
B) ✓ Digital output can be superimposed on physical objects — Key idea in augmented reality and ubicomp.  
C) ✓ Actions on physical objects can trigger electronic responses — Physical-digital interaction is central.  
D) ✗ Physical and digital worlds remain completely separate — Ubicomp merges these worlds.  

**Correct:** B, C


#### 8. Which of these is NOT a typical application theme of ubiquitous computing?  
A) ✗ Continuous interaction without clear start or end — Characteristic of ubicomp.  
B) ✗ Automated capture and access — Important application area.  
C) ✗ Context-aware computing — Core theme of ubicomp.  
D) ✓ Single-task focused, isolated computing sessions — Opposite of ubicomp’s continuous, embedded interaction.  

**Correct:** D


#### 9. What is a key difference between virtual reality (VR) and augmented reality (AR)?  
A) ✓ VR simulates a complete virtual world separate from reality — VR replaces reality with a virtual one.  
B) ✓ AR mixes virtual objects with the physical environment — AR overlays digital info on the real world.  
C) ✗ AR creates a fully immersive digital environment — This is VR’s role.  
D) ✗ VR overlays digital information on the real world — This describes AR, not VR.  

**Correct:** A, B


#### 10. Which of the following are challenges specific to augmented reality?  
A) ✗ Creating fully immersive 3D environments — More relevant to VR than AR.  
B) ✓ Ensuring virtual objects interact realistically with the physical world — Key AR challenge.  
C) ✓ Eye gaze direction tracking — Important for aligning AR content and interaction.  
D) ✓ Registration and alignment of virtual and real objects — Critical for AR accuracy.  

**Correct:** B, C, D


#### 11. Why might desktop VR be preferred over headset VR in some cases?  
A) ✓ It is cheaper and more convenient — Desktop VR uses existing hardware.  
B) ✗ It requires expensive specialized hardware — Desktop VR uses ordinary PCs.  
C) ✗ It provides a more immersive experience — Headsets are more immersive.  
D) ✓ It uses ordinary monitors and PCs — Makes it accessible and convenient.  

**Correct:** A, D


#### 12. Which of the following statements about VRML (Virtual Reality Markup Language) is true?

C) ✓ It is used to create VR scenes on the web — VRML is a web-based VR description language.

#### 13. In the context of ubiquitous computing, what does “knowledge in the world” emphasize?
