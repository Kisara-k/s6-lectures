## 12. Ubiquitous Computing and AR

## Questions

#### 1. Which of the following best describe the concept of ubiquitous computing?  
A) Computing that requires explicit user input only  
B) Devices that disappear from user awareness by blending into the environment  
C) Computing technology integrated seamlessly into everyday environments  
D) Computing limited to a single workstation or desktop  

#### 2. According to Weiser’s device scale classification, which of the following devices would be considered "foot-scale"?  
A) Tablets  
B) Smartphones  
C) Digital paper  
D) Electronic whiteboards  

#### 3. What are the main challenges introduced by implicit input in ubiquitous computing systems?  
A) Ambiguity due to imperfect recognition technologies  
B) Extending traditional explicit input methods like keyboard and mouse  
C) Eliminating the need for any user interaction  
D) Perfect accuracy of sensor data  

#### 4. Which of the following statements about ambient and peripheral displays are true?  
A) Ambient displays are designed to grab full user attention immediately  
B) Peripheral displays provide information in the background without distraction  
C) Peripheral displays require explicit user interaction to function  
D) Ambient displays use features of the physical environment to convey information  

#### 5. In the context of merging physical and digital worlds, which of the following are examples of this integration?  
A) A standalone desktop computer with no sensors  
B) A digital desk where physical papers interact with digital files  
C) An augmented calendar combining physical notes and digital reminders  
D) A traditional keyboard and mouse setup  

#### 6. Which of the following are key themes in ubiquitous computing applications?  
A) Context-aware computing that senses environmental phenomena  
B) Interaction limited to clearly defined start and end points  
C) Automated capture and access of live experiences for future use  
D) Continuous interaction embedded in everyday activities  

#### 7. Why do traditional HCI evaluation methods face challenges when applied to ubiquitous computing?  
A) Success metrics may include playfulness and non-distraction rather than efficiency  
B) Ubicomp systems always have clear, measurable goals  
C) Technologies are new, making long-term authentic evaluation difficult  
D) Ubicomp activities are highly task-centric and easy to measure  

#### 8. Which of the following statements about virtual reality (VR) technology are correct?  
A) VR headsets use stereoscopic displays to create a 3D immersive effect  
B) Desktop VR is less immersive but more affordable than headset VR  
C) VRML is a language used to create VR scenes on the web  
D) VR systems rely solely on visual input without sound or haptic feedback  

#### 9. What are the main challenges in augmented reality (AR) systems?  
A) Creating fully immersive virtual environments replacing the real world  
B) Using semi-transparent displays or head-up displays to overlay information  
C) Perfectly aligning virtual objects with the real world (registration)  
D) Handling unrelated information displayed in the user’s field of view  

#### 10. When visualizing complex data in VR or AR, which of the following approaches are used?  
A) Visualizing only static 2D charts without interactivity  
B) Projecting time as a spatial dimension in timelines or Gantt charts  
C) Using 3D cone trees to represent hierarchical data structures  
D) Representing networks as planar or non-planar graphs with nodes and links

## Answers

#### 1. Which of the following best describe the concept of ubiquitous computing?  
A) ✗ Computing that requires explicit user input only (ubicomp includes implicit input)  
B) ✓ Devices that disappear from user awareness by blending into the environment  
C) ✓ Computing technology integrated seamlessly into everyday environments  
D) ✗ Computing limited to a single workstation or desktop (opposite of ubicomp)  

**Correct:** B, C


#### 2. According to Weiser’s device scale classification, which of the following devices would be considered "foot-scale"?  
A) ✓ Tablets are foot-scale devices  
B) ✗ Smartphones are inch-scale devices  
C) ✓ Digital paper is foot-scale  
D) ✗ Electronic whiteboards are yard-scale devices  

**Correct:** A, C


#### 3. What are the main challenges introduced by implicit input in ubiquitous computing systems?  
A) ✓ Ambiguity arises because recognition technologies are not perfect  
B) ✓ Implicit input extends traditional explicit input methods like keyboard and mouse  
C) ✗ Implicit input does not eliminate user interaction but complements it  
D) ✗ Sensor data is often imperfect, so perfect accuracy is not a challenge but an unrealistic expectation  

**Correct:** A, B


#### 4. Which of the following statements about ambient and peripheral displays are true?  
A) ✗ Ambient displays are designed to be subtle, not to grab full attention immediately  
B) ✓ Peripheral displays provide background information without distraction  
C) ✗ Peripheral displays do not require explicit user interaction; they work passively  
D) ✓ Ambient displays use physical environment features to signal information  

**Correct:** B, D


#### 5. In the context of merging physical and digital worlds, which of the following are examples of this integration?  
A) ✗ A standalone desktop computer with no sensors does not merge physical and digital worlds  
B) ✓ A digital desk where physical papers interact with digital files is a clear example  
C) ✓ An augmented calendar combining physical notes and digital reminders merges both worlds  
D) ✗ A traditional keyboard and mouse setup is a conventional interface, not merging physical and digital  

**Correct:** B, C


#### 6. Which of the following are key themes in ubiquitous computing applications?  
A) ✓ Context-aware computing senses environmental phenomena to facilitate interaction  
B) ✗ Interaction is usually continuous, not limited to clear start and end points  
C) ✓ Automated capture and access of live experiences for later use is a key theme  
D) ✓ Continuous interaction embedded in everyday activities is central to ubicomp  

**Correct:** A, C, D


#### 7. Why do traditional HCI evaluation methods face challenges when applied to ubiquitous computing?  
A) ✓ Success metrics may include playfulness and non-distraction, differing from efficiency  
B) ✗ Ubicomp systems often have fluid goals, not always clear or measurable  
C) ✓ New technologies make long-term authentic evaluation difficult  
D) ✗ Ubicomp activities are often not task-centric, making traditional evaluation hard  

**Correct:** A, C


#### 8. Which of the following statements about virtual reality (VR) technology are correct?  
A) ✓ VR headsets use stereoscopic displays to create 3D immersive effects  
B) ✓ Desktop VR is less immersive but more affordable than headset VR  
C) ✓ VRML is a language used to create VR scenes on the web  
D) ✗ VR includes sound, haptic feedback, and gesture recognition, not just visual input  

**Correct:** A, B, C


#### 9. What are the main challenges in augmented reality (AR) systems?  
A) ✗ Creating fully immersive virtual environments is VR, not AR’s goal  
B) ✓ Using semi-transparent displays or head-up displays is a common AR technique  
C) ✓ Precise registration (alignment) of virtual and real objects is critical and challenging  
D) ✓ Handling unrelated information displayed in the user’s field of view can be an issue  

**Correct:** B, C, D


#### 10. When visualizing complex data in VR or AR, which of the following approaches are used?  
A) ✗ Static 2D charts without interactivity are insufficient; interactivity is important  
B) ✓ Time can be mapped to space in timelines or Gantt charts for visualization  
C) ✓ 3D cone trees are used to represent hierarchical data structures  
D) ✓ Networks are represented as planar or non-planar graphs with nodes and links  

**Correct:** B, C, D
