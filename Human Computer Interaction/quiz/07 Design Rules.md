## 7. Design Rules

## Questions

#### 1. Which of the following correctly describe the relationship between principles, guidelines, and standards in design rules?  
A) Principles are abstract and apply broadly across many contexts.  
B) Principles have high authority and low generality.  
C) Standards have high authority but limited application.  
D) Guidelines have lower authority but broader application than standards.  

#### 2. Which of the following are key aspects of learnability in usability design?  
A) Familiarity, leveraging users’ prior knowledge to ease learning.  
B) Predictability, allowing users to foresee the effect of future actions.  
C) Observability, allowing users to evaluate the system’s internal state.  
D) Multithreading, enabling users to perform multiple tasks simultaneously.  

#### 3. In the context of flexibility, which statements are true?  
A) Substitutivity supports using different but equivalent input and output methods.  
B) Customizability refers to the system’s ability to adapt the interface without user input.  
C) Task migratability allows shifting responsibility for task execution between user and system.  
D) Dialogue initiative means the system controls all user inputs to prevent errors.  

#### 4. Which of the following best describe robustness principles?  
A) Task conformance ensures the system supports all user tasks completely.  
B) Observability helps users understand the system’s state through visible feedback.  
C) Responsiveness relates to how quickly the system processes background tasks.  
D) Recoverability enables users to undo errors with minimal effort.  

#### 5. Regarding standards and guidelines, which statements are accurate?  
A) Standards are often created by international bodies and require stable underlying technology.  
B) Guidelines are always more authoritative than standards.  
C) Hardware standards are less common than software standards.  
D) Abstract guidelines are typically used in early design phases, while detailed guidelines apply later.  

#### 6. Which of the following are true about Shneiderman’s 8 Golden Rules?  
A) They emphasize reducing short-term memory load to ease user cognitive effort.  
B) They promote supporting an internal locus of control, giving users a sense of control.  
C) They include enabling frequent users to use shortcuts to improve efficiency.  
D) They require strict adherence as formal standards in design.  

#### 7. Norman’s principles include which of the following?  
A) Standardizing only when all other design options have failed.  
B) Using both knowledge in the world and knowledge in the head to aid user understanding.  
C) Prioritizing system-driven dialogue initiative to reduce user errors.  
D) Designing for error by anticipating and mitigating user mistakes.  

#### 8. Which statements about HCI design patterns are correct?  
A) Patterns are isolated and do not connect with other design solutions.  
B) Patterns capture theoretical design knowledge rather than practical examples.  
C) Patterns are invariant solutions to recurring problems within specific contexts.  
D) Patterns form languages that help generate complete designs by linking related patterns.  

#### 9. Consider the principle of predictability in learnability. Which of the following best illustrate this principle?  
A) Users can multitask by switching between different system functions.  
B) Users can guess the outcome of an action based on previous similar actions.  
C) The system allows users to customize the interface to their preferences.  
D) The system provides immediate feedback after each user action.  

#### 10. Which of the following statements about the use of design rules in usability are true?  
A) Creative insight is unnecessary if design rules are strictly followed.  
B) Standards and guidelines serve as directions to guide design activity.  
C) Design rules guarantee perfect usability without further user testing.  
D) Design rules help maximize the benefit of one good design by abstracting general properties.

## Answers

#### 1. Which of the following correctly describe the relationship between principles, guidelines, and standards in design rules?  
A) ✓ Principles are abstract and apply broadly across many contexts.  
B) ✗ Principles have low authority, not high, and high generality, not low.  
C) ✓ Standards have high authority but limited application, typically specific contexts.  
D) ✓ Guidelines have lower authority than standards but broader application.  

**Correct:** A, C, D


#### 2. Which of the following are key aspects of learnability in usability design?  
A) ✓ Familiarity uses prior knowledge to ease learning, part of learnability.  
B) ✓ Predictability helps users anticipate effects of future actions, key to learnability.  
C) ✗ Observability is a robustness principle, not directly related to learnability.  
D) ✗ Multithreading relates to flexibility, not learnability.  

**Correct:** A, B


#### 3. In the context of flexibility, which statements are true?  
A) ✓ Substitutivity supports equivalent input/output substitutions, enhancing flexibility.  
B) ✗ Customizability can be by user (adaptability) or system (adaptivity), not only system-driven.  
C) ✓ Task migratability allows shifting task responsibility between user and system.  
D) ✗ Dialogue initiative means freedom from system constraints, not system control.  

**Correct:** A, C


#### 4. Which of the following best describe robustness principles?  
A) ✓ Task conformance ensures system supports all user tasks, part of robustness.  
B) ✓ Observability helps users understand system state via visible feedback, robustness aspect.  
C) ✗ Responsiveness relates to user perception of communication speed, not background processing.  
D) ✓ Recoverability allows users to correct errors easily, a robustness feature.  

**Correct:** A, B, D


#### 5. Regarding standards and guidelines, which statements are accurate?  
A) ✓ Standards are created by official bodies and require stable technology.  
B) ✗ Guidelines have lower authority than standards, not higher.  
C) ✗ Hardware standards are more common than software standards, not less.  
D) ✓ Abstract guidelines apply early in design; detailed guidelines apply later.  

**Correct:** A, D


#### 6. Which of the following are true about Shneiderman’s 8 Golden Rules?  
A) ✓ Reducing short-term memory load is emphasized to reduce cognitive effort.  
B) ✓ Supporting internal locus of control means users feel in charge, a golden rule.  
C) ✓ Enabling shortcuts for frequent users is one of the golden rules.  
D) ✗ They are heuristics, not formal standards requiring strict adherence.  

**Correct:** A, B, C


#### 7. Norman’s principles include which of the following?  
A) ✓ Standardizing is recommended when other options fail.  
B) ✓ Using both external knowledge and memory aids user understanding.  
C) ✗ Norman’s principles favor user control, not system-driven dialogue initiative.  
D) ✓ Designing for error anticipates and mitigates mistakes.  

**Correct:** A, B, D


#### 8. Which statements about HCI design patterns are correct?  
A) ✗ Patterns are connected, not isolated, to support comprehensive design.  
B) ✗ Patterns capture practical design knowledge, not just theory.  
C) ✓ Patterns are invariant solutions to recurring problems in specific contexts.  
D) ✓ Patterns form languages linking related patterns to create complete designs.  

**Correct:** C, D


#### 9. Consider the principle of predictability in learnability. Which of the following best illustrate this principle?  
A) ✗ Multitasking relates to flexibility, not predictability.  
B) ✓ Predictability means users can guess outcomes based on past actions.  
C) ✗ Customizing interfaces relates to flexibility, not predictability.  
D) ✗ Immediate feedback relates to synthesizability, not directly predictability.  

**Correct:** B


#### 10. Which of the following statements about the use of design rules in usability are true?  
A) ✗ Creative insight is necessary alongside design rules; rules alone are insufficient.  
B) ✓ Standards and guidelines direct and guide design activities.  
C) ✗ Design rules do not guarantee perfect usability without user testing and iteration.  
D) ✓ Design rules help abstract general properties to maximize design benefits.  

**Correct:** B, D
