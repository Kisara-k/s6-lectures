## Answers

#### 1. What are the main components involved in Abowd and Beale’s interaction framework?  
A) ✓ Correct. These are the four parts: user, input, system, output.  
B) ✗ These are interaction styles, not components of the framework.  
C) ✗ These are stages from Norman’s model, not the framework components.  
D) ✗ These are general interaction terms but not the components of Abowd and Beale’s framework.  

**Correct:** A


#### 2. In Norman’s seven-stage model of interaction, which of the following correctly describes the sequence of stages?  
A) ✗ Incorrect order; execution and perception come after specifying actions.  
B) ✗ Incorrect order; goal is established before formulating intention.  
C) ✗ Missing some stages and incorrect sequence.  
D) ✓ Correct. This is the full and correct sequence of Norman’s seven stages.  

**Correct:** D


#### 3. Which of the following best describe the "Gulf of Execution" and "Gulf of Evaluation"?  
A) ✗ Reverses the definitions of the two gulfs.  
B) ✓ Correct. Gulf of Execution is the gap between user intentions and system actions; Gulf of Evaluation is the gap between system state and user perception.  
C) ✗ Slips and mistakes are types of errors but not definitions of the gulfs.  
D) ✗ Gulfs relate to cognitive gaps, not physical ergonomics or social context.  

**Correct:** B


#### 4. Which of the following are true about slips and mistakes in human error?  
A) ✗ Slips occur when the user has the correct goal but performs the wrong action.  
B) ✓ Correct. Better interface design can reduce slips by preventing wrong actions.  
C) ✓ Correct. Mistakes require better understanding or training to fix.  
D) ✓ Correct. Mistakes involve incorrect goals or misunderstandings.  

**Correct:** B, C, D


#### 5. Regarding ergonomics in interface design, which statements are correct?  
A) ✗ Ergonomics covers much more than visual design; it includes physical and environmental factors.  
B) ✓ Correct. Color use must consider color-blindness and cultural meanings.  
C) ✓ Correct. Ergonomics includes control arrangement, environment, and health considerations.  
D) ✗ Ergonomics is very relevant in industrial interfaces, especially due to harsh environments.  

**Correct:** B, C


#### 6. Which of the following statements about interaction styles are accurate?  
A) ✓ Correct. Menus reduce memory load by relying on recognition.  
B) ✗ Natural language interfaces are difficult to implement and often ambiguous.  
C) ✓ Correct. Form-fills are for structured data entry and need good design for corrections.  
D) ✗ Command line interfaces are better suited for expert users, not novices.  

**Correct:** A, C


#### 7. In WIMP interfaces, which of the following are true?  
A) ✓ Correct. Windows can be moved, resized, and overlapped.  
B) ✗ Icons can represent both physical objects and abstract actions.  
C) ✓ Correct. Menus are often hierarchical and support keyboard accelerators.  
D) ✗ Pointers can be controlled by mouse, keyboard shortcuts, trackpads, etc.  

**Correct:** A, C


#### 8. Which of the following best describe the challenges and trade-offs in physical design of interfaces?  
A) ✗ Aesthetic design is important and not always sacrificed; it is balanced with other constraints.  
B) ✓ Correct. Physical size and safety can conflict, requiring multifunction controls or reduced functionality.  
C) ✗ Trade-offs are necessary in all environments, including office systems.  
D) ✗ Ergonomics does not always take priority; trade-offs depend on context.  

**Correct:** B


#### 9. How does context influence interaction?  
A) ✗ Organizational culture and rules do impact user interaction.  
B) ✓ Correct. Social factors like competition and fear affect motivation.  
C) ✓ Correct. Ignoring context can cause frustration and poor adoption.  
D) ✓ Correct. Motivation can be driven by fear, ambition, or self-satisfaction.  

**Correct:** B, C, D


#### 10. Which of the following statements about managing value in system use are correct?  
A) ✗ Value is not always financial gain; it can be fun, utility, or social benefit.  
B) ✓ Correct. Organizational value can be enforced through coercion, enculturation, or emergence.  
C) ✓ Correct. People heavily discount future benefits and costs, preferring immediate rewards.  
D) ✓ Correct. Users adopt systems only if perceived value exceeds cost.  

**Correct:** B, C, D
