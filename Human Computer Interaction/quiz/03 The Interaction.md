## Answers

#### 1. What does the "Gulf of Execution" primarily refer to in user-system interaction?  
A) ✓ The gap between what the user wants to do and what the system allows them to do.  
B) ✗ This describes the Gulf of Evaluation, not Execution.  
C) ✗ Delay is not the main focus of the Gulf of Execution.  
D) ✗ Misunderstanding feedback relates to evaluation, not execution.  

**Correct:** A


#### 2. Which of the following stages is NOT part of Norman’s seven-stage model of interaction?  
A) ✗ Formulating intention is part of the model.  
B) ✗ Executing action is included.  
C) ✓ Designing the interface is not a user stage; it’s a development activity.  
D) ✗ Evaluating system state is included.  

**Correct:** C


#### 3. In Abowd and Beale’s interaction framework, what is the role of "input"?  
A) ✗ User’s mental model is not input; it’s internal to the user.  
B) ✗ System’s internal state changes are not input but system processing.  
C) ✓ Input translates user intentions into interface actions.  
D) ✗ Output is the system’s response, not input.  

**Correct:** C


#### 4. Which of the following best describes the difference between slips and mistakes?  
A) ✗ This reverses the definitions.  
B) ✓ Slips are errors in execution despite correct intentions; mistakes are due to wrong goals or understanding.  
C) ✗ Both can be caused by design, but mistakes often relate to misunderstanding, not just design.  
D) ✗ Slips are easier to fix by interface design; mistakes require better understanding.  

**Correct:** B


#### 5. Ergonomics in interaction design primarily focuses on:  
A) ✗ Logical flow is not the main focus of ergonomics.  
B) ✓ Physical characteristics and constraints of users and environment.  
C) ✗ Social context is separate from ergonomics.  
D) ✗ Programming language is unrelated to ergonomics.  

**Correct:** B


#### 6. Which of the following is a key challenge of glass (touchscreen) interfaces in industrial settings?
