## Answers

#### 1. What does the "Gulf of Execution" primarily refer to in user-system interaction?  
A) ✗ Misunderstanding feedback relates to evaluation, not execution.  
B) ✗ This describes the Gulf of Evaluation, not Execution.  
C) ✗ Delay is not the main focus of the Gulf of Execution.  
D) ✓ The gap between what the user wants to do and what the system allows them to do.  

**Correct:** D


#### 2. Which of the following stages is NOT part of Norman’s seven-stage model of interaction?  
A) ✗ Evaluating system state is included.  
B) ✗ Executing action is included.  
C) ✗ Formulating intention is part of the model.  
D) ✓ Designing the interface is not a user stage; it’s a development activity.  

**Correct:** D


#### 3. In Abowd and Beale’s interaction framework, what is the role of "input"?  
A) ✓ Input translates user intentions into interface actions.  
B) ✗ Output is the system’s response, not input.  
C) ✗ System’s internal state changes are not input but system processing.  
D) ✗ User’s mental model is not input; it’s internal to the user.  

**Correct:** A


#### 4. Which of the following best describes the difference between slips and mistakes?  
A) ✗ Slips are easier to fix by interface design; mistakes require better understanding.  
B) ✗ This reverses the definitions.  
C) ✓ Slips are errors in execution despite correct intentions; mistakes are due to wrong goals or understanding.  
D) ✗ Both can be caused by design, but mistakes often relate to misunderstanding, not just design.  

**Correct:** C


#### 5. Ergonomics in interaction design primarily focuses on:  
A) ✓ Physical characteristics and constraints of users and environment.  
B) ✗ Programming language is unrelated to ergonomics.  
C) ✗ Logical flow is not the main focus of ergonomics.  
D) ✗ Social context is separate from ergonomics.  

**Correct:** A


#### 6. Which of the following is a key challenge of glass (touchscreen) interfaces in industrial settings?  
A) ✗ Glass interfaces are not physically located like knobs.  
B) ✗ While true, this is not a challenge but a benefit.  
C) ✓ Loss of physical context and complexity are key challenges.  
D) ✗ Glass interfaces are not always cheaper.  

**Correct:** C


#### 7. What is a major difference between office and industrial interfaces?
