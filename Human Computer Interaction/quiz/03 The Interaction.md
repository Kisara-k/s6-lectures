## Answers

#### 1. What does the "Gulf of Execution" primarily refer to in user-system interaction?  
A) ✗ Delay is not the main focus of the Gulf of Execution.  
B) ✓ The gap between what the user wants to do and what the system allows them to do.  
C) ✗ Misunderstanding feedback relates to evaluation, not execution.  
D) ✗ This describes the Gulf of Evaluation, not Execution.  

**Correct:** B


#### 2. Which of the following stages is NOT part of Norman’s seven-stage model of interaction?  
A) ✗ Formulating intention is part of the model.  
B) ✗ Evaluating system state is included.  
C) ✗ Executing action is included.  
D) ✓ Designing the interface is not a user stage; it’s a development activity.  

**Correct:** D


#### 3. In Abowd and Beale’s interaction framework, what is the role of "input"?  
A) ✓ Input translates user intentions into interface actions.  
B) ✗ User’s mental model is not input; it’s internal to the user.  
C) ✗ Output is the system’s response, not input.  
D) ✗ System’s internal state changes are not input but system processing.  

**Correct:** A


#### 4. Which of the following best describes the difference between slips and mistakes?  
A) ✗ Both can be caused by design, but mistakes often relate to misunderstanding, not just design.  
B) ✗ This reverses the definitions.  
C) ✗ Slips are easier to fix by interface design; mistakes require better understanding.  
D) ✓ Slips are errors in execution despite correct intentions; mistakes are due to wrong goals or understanding.  

**Correct:** D


#### 5. Ergonomics in interaction design primarily focuses on:  
A) ✗ Social context is separate from ergonomics.  
B) ✗ Logical flow is not the main focus of ergonomics.  
C) ✓ Physical characteristics and constraints of users and environment.  
D) ✗ Programming language is unrelated to ergonomics.  

**Correct:** C


#### 6. Which of the following is a key challenge of glass (touchscreen) interfaces in industrial settings?
