## Answers

#### 1. What are the three essential "use" qualities that HCI design aims to achieve in interactive systems?  
A) ✗ Useful, Usable, User Experience — User experience is broader but not one of the three "use" words.  
B) ✓ Useful, Usable, Used — These are the core qualities emphasized in HCI design.  
C) ✗ Usable, Used, Understandable — "Understandable" is not explicitly one of the three core qualities.  
D) ✗ Useful, Universal, User-friendly — "Universal" is not one of the three core qualities.  

**Correct:** B


#### 2. Which of the following statements about ubiquitous and wearable computing are true?  
A) ✓ Ubiquitous computing eliminates the distinction between computer and artifact — This is a key idea in ubicomp.  
B) ✗ Ubiquitous computing primarily focuses on desktop and laptop computers — It focuses on embedding computing everywhere, not just traditional computers.  
C) ✓ Wearable computing blurs the line between the computer and the user — Wearables integrate closely with the user, sometimes called cyborg computing.  
D) ✗ Wearable computing is unrelated to cyborg concepts — Wearable computing is closely related to cyborg concepts.  

**Correct:** A, C


#### 3. In the context of gesture keyboards like ShapeWriter, which of the following describe the transition from novice to expert users?  
A) ✓ Experts gesture word shapes quickly but less accurately (open-loop) — This describes expert behavior.  
B) ✗ Novices use open-loop control, gesturing whole words quickly but inaccurately — Novices use closed-loop, slow, accurate tracing.  
C) ✓ Novices trace letter to letter with slow, accurate movements (closed-loop) — This describes novice behavior.  
D) ✗ Experts rely on closed-loop control, tracing letter by letter slowly and accurately — Experts use open-loop, fast gesturing.  

**Correct:** A, C


#### 4. Which challenges are currently significant when designing intelligent interactive systems involving multimodal input?  
A) ✓ Developing flexible unimodal and multimodal error correction methods — Essential for practical multimodal systems.  
B) ✗ Ignoring context modeling to simplify sensor data processing — Context modeling is important, not ignored.  
C) ✓ Seamlessly fusing multiple input modalities like speech, gestures, and eye-tracking — A key challenge in multimodal interaction.  
D) ✗ Avoiding the use of crowdsourcing in language modeling to maintain data purity — Crowdsourcing is encouraged to improve models.  

**Correct:** A, C


#### 5. Regarding the influence of experimental psychology on HCI research, which of the following are accurate?  
A) ✓ The controlled experiment paradigm involves independent and dependent variables and hypothesis testing — This is fundamental to experimental psychology in HCI.  
B) ✓ Internal validity refers to how well an experiment controls variables to establish cause-effect relationships — Correct definition.  
C) ✗ Experiments in HCI do not require reproducibility since user behavior is unpredictable — Reproducibility is a core requirement.  
D) ✓ External validity concerns how well experimental results generalize to real-world use — Correct definition.  

**Correct:** A, B, D


#### 6. Why might controlled experiments in HCI sometimes have low ecological validity?  
A) ✗ Because qualitative methods are inherently less valid than controlled experiments — Qualitative methods address ecological validity differently, not less valid.  
B) ✗ Because experiments always perfectly replicate real-world conditions — This is false; they often do not.  
C) ✓ Because internal validity is prioritized at the expense of external validity — This tradeoff can lower ecological validity.  
D) ✓ Because the experimental model may oversimplify real-world use, missing everyday nuances — This reduces ecological validity.  

**Correct:** C, D


#### 7. Which of the following research methods are commonly used in HCI beyond controlled experiments?  
A) ✓ Automated log analysis and participatory design — Important for understanding real use and involving users.  
B) ✗ Purely theoretical modeling without user involvement — HCI emphasizes user-centered methods, not just theory.  
C) ✓ Ethnographic research and think-aloud protocols — Common qualitative methods in HCI.  
D) ✓ Anecdotal experiences and structured interviews — Used to gather subjective data.  

**Correct:** A, C, D


#### 8. Which historical milestones contributed directly to the development of modern graphical user interfaces (GUIs)?  
A) ✗ Microsoft Kinect’s introduction of motion sensing technology — A recent input innovation, not foundational to GUIs.  
B) ✓ Ivan Sutherland’s Sketchpad and Douglas Engelbart’s mouse invention — Early GUI and input device innovations.  
C) ✓ Xerox PARC’s WIMP paradigm and Apple’s Macintosh release — Key developments in GUI commercialization.  
D) ✗ Mark Weiser’s coining of “Ubiquitous Computing.” — Important concept but not directly a GUI milestone.  

**Correct:** B, C


#### 9. What is a key reason why HCI research must combine knowledge from multiple disciplines such as psychology, social science, and computer science?  
A) ✓ Because understanding human behavior and perception is essential to designing effective interfaces — Core to HCI’s interdisciplinary nature.  
B) ✗ Because HCI focuses only on hardware development, not user behavior — HCI focuses heavily on user behavior and experience.  
C) ✗ Because computer science alone can fully address usability and user experience challenges — Computer science alone is insufficient.  
D) ✓ Because social and psychological theories help model user interactions and context — These theories enrich understanding of users.  

**Correct:** A, D


#### 10. Which of the following statements about the Gesture Keyboard (ShapeWriter) are true?  
A) ✓ It exploits language redundancies to improve text input speed — This is a key feature.  
B) ✗ It requires users to tap each letter individually for accuracy — It uses continuous gestures, not tapping.  
C) ✗ It was never commercialized or released publicly — It was commercialized (e.g., Swype).  
D) ✓ It supports a continuous transition from novice to expert use patterns — Skill acquisition is gradual and supported.  

**Correct:** A, D
