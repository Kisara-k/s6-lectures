## Answers

#### 1. What are the three key "use" words that define good HCI design?  
A) ✓ Useful, Usable, Used — These are the three core criteria for good HCI design.  
B) ✗ Useful, User-friendly, Used — "User-friendly" is vague and not one of the three key terms.  
C) ✗ Usable, Used, Universal — "Universal" is not part of the core three.  
D) ✗ Useful, Usable, User-centered — "User-centered" is a design approach, not one of the three "use" words.  

**Correct:** A


#### 2. Which of the following best describes the essence of HCI?  
A) ✗ Designing computer hardware for faster processing — HCI focuses on interaction, not hardware speed.  
B) ✓ Understanding both human and system factors to create effective interfaces — This captures the core of HCI.  
C) ✗ Writing code for graphical user interfaces only — HCI is broader than just GUI coding.  
D) ✗ Focusing solely on the aesthetics of software — Aesthetics are part of UX but not the whole of HCI.  

**Correct:** B


#### 3. Why is asking the right questions considered the most difficult part of HCI?  
A) ✗ Because users rarely know what they want — Sometimes true, but not the main reason.  
B) ✓ Because identifying relevant user needs and problems requires deep understanding — Correct; this is the core challenge.  
C) ✗ Because computers cannot answer questions — Irrelevant to HCI.  
D) ✗ Because questions must always be technical — Questions can be about users, not just technical.  

**Correct:** B


#### 4. Which of the following are challenges in designing intelligent interactive systems?  
A) ✓ Flexible multimodal interaction — Important for natural, practical interfaces.  
B) ✓ Context modeling — Needed to infer user tasks and improve performance.  
C) ✓ Leveraging crowdsourcing and social media — Useful for improving language models.  
D) ✗ Increasing CPU clock speed — Not related to interaction design challenges.  

**Correct:** A, B, C


#### 5. Gesture keyboards improve text input by:  
A) ✗ Allowing users to tap keys faster — They replace tapping with gestures.  
B) ✓ Exploiting language redundancies to predict words from gestures — This is the key innovation.  
C) ✗ Replacing all physical keyboards with voice input — Gesture keyboards are distinct from voice input.  
D) ✓ Enabling continuous transition from novice to expert use — Supports skill acquisition from tracing to gesturing.  

**Correct:** B, D


#### 6. What is a key difference between novice and expert users of gesture keyboards?  
A) ✗ Novices use open-loop control, experts use closed-loop control — Actually reversed.  
B) ✓ Novices trace letter by letter, experts gesture whole word shapes — Correct distinction.  
C) ✗ Experts rely on visual feedback more than novices — Experts rely less on feedback (open-loop).  
D) ✗ Novices type faster than experts — Experts are faster.  

**Correct:** B


#### 7. Which of the following statements about ubiquitous computing are true?  
A) ✓ It eliminates the divide between computer and artifact — True; computing is embedded everywhere.  
B) ✓ It involves embedding sensors and devices everywhere in the environment — Core idea of ubicomp.  
C) ✗ It only applies to wearable devices — Wearables are a subset, not the whole.  
D) ✓ It aims to make computing invisible and seamless — A key goal of ubicomp.  

**Correct:** A, B, D


#### 8. The WIMP paradigm stands for:  
A) ✓ Windows, Icons, Menus, Pointer — Correct expansion of WIMP.  
B) ✗ Widgets, Input, Menus, Programming — Incorrect terms.  
C) ✗ Windows, Input, Motion, Processing — Incorrect terms.  
D) ✗ Widgets, Icons, Menus, Pointer — "Widgets" is not part of WIMP.  

**Correct:** A


#### 9. Which of the following are limitations of controlled experiments in HCI?  
A) ✗ They always have high ecological validity — Usually they have low ecological validity.  
B) ✓ They may lack external validity, limiting generalization to real-world use — Correct limitation.  
C) ✓ They require reproducibility and clear hypotheses — True, but this is a strength, not a limitation.  
D) ✓ They cannot capture complex everyday user behavior fully — True limitation.  

**Correct:** B, D


#### 10. Ethnographic research methods in HCI are used primarily to:  
A) ✗ Quantify user performance metrics — Ethnography is qualitative, not quantitative.  
B) ✓ Study real-world use practices and user behavior in natural settings — Core purpose of ethnography.  
C) ✗ Replace controlled experiments entirely — They complement, not replace, experiments.  
D) ✓ Collect qualitative data such as anecdotes and subjective reactions — True.  

**Correct:** B, D


#### 11. Which of the following are examples of multimodal input modalities?  
A) ✓ Speech — A common input modality.  
B) ✓ Eye-tracking — Another input modality.  
C) ✓ Gesture — Also a modality.  
D) ✗ Command line interface — CLI is a single-mode textual input, not multimodal.  

**Correct:** A, B, C


#### 12. What is the main tradeoff between internal and external validity in HCI experiments?  
A) ✓ Increasing internal validity usually decreases external validity — True; tight control reduces real-world relevance.  
B) ✗ Increasing external validity always increases internal validity — Usually not true.  
C) ✗ Both internal and external validity can be maximized simultaneously without tradeoffs — Rarely possible.  
D) ✗ Internal validity relates to real-world applicability, external validity to experimental control — Reversed definitions.  

**Correct:** A


#### 13. Which of the following statements about the history of HCI is correct?  
A) ✗ The first graphical user interface was invented by Apple in 1984 — Apple popularized it but Xerox PARC invented it earlier.  
B) ✓ Ivan Sutherland’s Sketchpad was a pioneering system in computer graphics and GUI concepts — Correct.  
C) ✗ The mouse was invented in the 1990s — Invented in the 1960s by Engelbart.  
D) ✗ Mark Weiser coined the term “Ubiquitous Computing” in the 1980s — Coined in 1988, late 1980s is acceptable but this is a tricky borderline.  

**Correct:** B


#### 14. What role does experimental psychology play in HCI?  
A) ✓ It provides models of human perception and motor control relevant to interface design — True.  
B) ✗ It focuses only on cognitive aspects, ignoring motor skills — Incorrect; motor control is important.  
C) ✓ It introduced the controlled experiment paradigm used in HCI research — True.  
D) ✗ It is unrelated to HCI, which is purely computer science — False; psychology is foundational.  

**Correct:** A, C


#### 15. Which of the following are true about user experience (UX) in HCI?  
A) ✗ UX only concerns the visual design of an interface — UX is broader than visuals.  
B) ✓ UX includes emotional responses and satisfaction during interaction — Correct.  
C) ✓ UX is about making systems enjoyable and attractive to users — True.  
D) ✗ UX is irrelevant if the system is functional and usable — UX matters beyond functionality and usability.  

**Correct:** B, C


#### 16. Which of the following best describes the concept of “ecological validity”?  
A) ✓ The degree to which experimental results generalize to real-world settings — Correct definition.  
B) ✗ The accuracy of statistical tests used in experiments — Not related.  
C) ✗ The internal consistency of a user interface design — Not related.  
D) ✗ The environmental impact of computing devices — Not related.  

**Correct:** A


#### 17. What is a major benefit of leveraging crowdsourcing and social media in language modeling for HCI?  
A) ✗ It reduces the need for user testing — Crowdsourcing complements but does not replace testing.  
B) ✓ It provides large-scale, diverse data to improve recognition accuracy — Correct.  
C) ✗ It eliminates the need for multimodal input methods — No, multimodal input is still needed.  
D) ✗ It simplifies context modeling — Crowdsourcing helps language models, not context modeling directly.  

**Correct:** B


#### 18. Which of the following are examples of qualitative research methods used in HCI?  
A) ✓ Think-aloud protocols — Qualitative method.  
B) ✓ Structured interviews — Qualitative method.  
C) ✗ Automated log analysis — Quantitative method.  
D) ✗ Statistical hypothesis testing — Quantitative method.  

**Correct:** A, B


#### 19. Which of the following statements about the evolution of user interfaces is true?  
A) ✗ Touchscreens were invented only after the iPhone release in 2007 — Touchscreens existed earlier.  
B) ✓ Many modern UI technologies are refinements of ideas from the 1960s and 1970s — Correct.  
C) ✗ The command line interface (CLI) has been completely replaced by graphical user interfaces (GUIs) — CLI is still widely used.  
D) ✗ The WIMP paradigm was developed by IBM in the 1990s — Developed at Xerox PARC in the late 1970s.  

**Correct:** B


#### 20. Why must computer scientists be literate in HCI?  
A) ✓ To ensure they build systems that are high-quality and user-centered — Correct.  
B) ✗ Because HCI is a mandatory course in all computer science programs — Not universally true.  
C) ✗ To replace designers and psychologists in product development — HCI is interdisciplinary, not a replacement.  
D) ✓ To invent new interaction techniques and improve existing ones — True; HCI literacy enables innovation.  

**Correct:** A, D
