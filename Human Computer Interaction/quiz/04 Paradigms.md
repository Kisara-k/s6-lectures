## Answers

#### 1. Which of the following best describes a paradigm in the context of interactive system design?  
A) ✗ Hardware specs are not paradigms; paradigms are conceptual frameworks.  
B) ✓ Paradigms are dominant theoretical frameworks shaping design and understanding.  
C) ✗ Paradigms are not temporary trends but fundamental worldviews.  
D) ✗ A tool is not a paradigm; paradigms are broader frameworks.  

**Correct:** B


#### 2. What was the primary limitation of the batch processing paradigm?  
A) ✗ Graphical user interfaces came much later, not in batch processing.  
B) ✗ Batch processing was impersonal and not user-friendly.  
C) ✓ Users had no direct interaction during program execution in batch processing.  
D) ✗ Batch processing did not allow multiple users to interact simultaneously.  

**Correct:** C


#### 3. Time-sharing systems introduced which key feature to computing?  
A) ✓ Time-sharing allowed multiple users to interact with one computer simultaneously.  
B) ✗ Direct manipulation came after time-sharing.  
C) ✗ Batch job submission is pre-time-sharing.  
D) ✗ Embedding computers in objects is part of ubiquitous computing, much later.  

**Correct:** A


#### 4. Which of the following are characteristics of direct manipulation interfaces?  
A) ✓ Visibility of objects is a core feature.  
B) ✗ Direct manipulation replaces command-line language, not uses it exclusively.  
C) ✓ Incremental action with rapid feedback encourages exploration.  
D) ✓ Reversibility of actions reduces fear of errors and encourages trying.  

**Correct:** A, C, D


#### 5. The WIMP interface includes which of the following elements?  
A) ✓ Menus are included in WIMP.  
B) ✗ Programming toolkits are development tools, not part of WIMP.  
C) ✓ Icons are part of WIMP.  
D) ✓ Windows are fundamental to WIMP.  

**Correct:** A, C, D


#### 6. Which statements about metaphors in interface design are true?  
A) ✓ Metaphors help users relate new tech to familiar activities.  
B) ✓ Cultural bias can limit metaphor effectiveness.  
C) ✗ Metaphors do not always fit all tasks perfectly.  
D) ✓ Virtual reality places the user inside the metaphor.  

**Correct:** A, B, D


#### 7. Engelbart’s contribution to interactive systems primarily involved:  
A) ✗ He did not design WWW protocols.  
B) ✗ He did not develop the first GUI.  
C) ✓ He created programming toolkits to augment human intellect.  
D) ✗ Microprocessor invention was unrelated to Engelbart.  

**Correct:** C


#### 8. Which of the following are true about hypertext?  
A) ✗ Hypertext was not immediately widely adopted; it evolved over time.  
B) ✓ Hypertext allows non-linear browsing of information.  
C) ✓ Hypermedia extends hypertext to multimedia elements.  
D) ✗ Hypertext includes more than just text; hypermedia adds multimedia.  

**Correct:** B, C


#### 9. What distinguishes agent-based interfaces from direct manipulation interfaces?  
A) ✓ Agents use language and proactivity to assist users.  
B) ✗ Direct manipulation does not replace the underlying system but the interface mediates it.  
C) ✗ Direct manipulation does not rely on command-line input only.

#### 10. Ubiquitous computing aims to:  
A) ✗ It tries to reduce the need for constant user focus.

C) ✗ It aims to make computing less visible, not more.  
D) ✓ Design interactions that do not demand explicit user intention.

#### 11. Which of the following best explains the challenge of sensor-based, context-aware interaction?

B) ✗ Humans are good at recognizing context; systems try to emulate this.
