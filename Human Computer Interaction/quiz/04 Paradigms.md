## 4. Paradigms

## Questions

#### 1. Which of the following best describe what a paradigm is in the context of interactive system design?  
A) A fixed set of usability guidelines that never change  
B) A dominant theoretical framework or worldview shaping how systems are designed and understood  
C) A specific software tool used for building user interfaces  
D) A set of programming languages used in early computing  

#### 2. Which paradigm shifts contributed to the transition from impersonal to personal computing?  
A) Networking to graphical displays  
B) Batch processing to time-sharing  
C) Microprocessor development enabling personal computers  
D) Ubiquitous computing to agent-based interfaces  

#### 3. What are key characteristics of direct manipulation interfaces?  
A) Replacement of language commands with physical actions  
B) Use of complex command languages for interaction  
C) Visibility of objects and immediate feedback  
D) Incremental actions that can be reversed  

#### 4. How does the metaphor paradigm assist users in interacting with computers, and what are its limitations?  
A) It guarantees universal understanding across all cultures  
B) It eliminates the need for any user training or documentation  
C) Some tasks do not fit well into a given metaphor, causing confusion  
D) It relates computing tasks to familiar real-world activities, making learning easier  

#### 5. Which statements about hypertext and the World Wide Web are true?  
A) Ted Nelson’s Xanadu project fully realized the vision of universal hypertext  
B) Hypertext allows non-linear browsing of information through linked nodes  
C) The WWW is a closed system with restricted access to information  
D) Simple protocols like HTTP and HTML enabled easy publishing and access on the Web  

#### 6. In what ways do agent-based interfaces differ from traditional command-line and direct manipulation interfaces?  
A) They rely solely on typed commands without any graphical elements  
B) They eliminate the need for user input by automating all tasks  
C) They often use avatars or natural language processing to interact with users  
D) They combine language-based commands with proactive, intelligent behavior  

#### 7. What challenges and goals are associated with ubiquitous computing?  
A) Making computers more visible and attention-demanding  
B) Replacing all physical devices with a single, centralized computer  
C) Designing interactions that do not require constant user focus  
D) Embedding computing seamlessly into everyday objects and environments  

#### 8. Why was time-sharing a significant paradigm shift in the 1960s?  
A) It reduced the need for programming toolkits in system development  
B) It allowed multiple users to share a single computer simultaneously, enabling interactive use  
C) It introduced batch processing as the primary mode of operation  
D) It made graphical user interfaces possible for the first time  

#### 9. Which of the following statements about multimodality and CSCW are accurate?  
A) Multimodality reduces the complexity of interfaces by limiting input modes to one at a time  
B) Electronic mail is a prominent example of CSCW success  
C) CSCW focuses exclusively on single-user systems and ignores social aspects  
D) Multimodality involves using multiple human communication channels simultaneously for input and output  

#### 10. How do sensor-based and context-aware interactions improve usability in ubiquitous computing environments?  
A) By automatically sensing physical phenomena and adapting interactions accordingly  
B) By requiring users to manually input all environmental data  
C) By enabling systems to behave as if they are aware of their surroundings and user needs  
D) By ignoring the physical context to maintain consistent system behavior

## Answers

#### 1. Which of the following best describe what a paradigm is in the context of interactive system design?  
A) ✗ Paradigms are not fixed usability guidelines; they evolve over time.  
B) ✓ Paradigms are dominant theoretical frameworks shaping design and understanding.  
C) ✗ A paradigm is not a specific software tool but a broader framework.  
D) ✗ Programming languages are tools, not paradigms.  

**Correct:** B


#### 2. Which paradigm shifts contributed to the transition from impersonal to personal computing?  
A) ✓ Networking to graphical displays improved interaction and community computing, important for personal use.  
B) ✓ Batch processing to time-sharing enabled interactive use, a key step toward personal computing.  
C) ✓ Microprocessor development was crucial for affordable personal computers.  
D) ✗ Ubiquitous computing is a later paradigm beyond personal computing, not part of the initial transition.  

**Correct:** A, B, C


#### 3. What are key characteristics of direct manipulation interfaces?  
A) ✓ Actions replace language commands in direct manipulation.  
B) ✗ Direct manipulation replaces complex command languages with actions.  
C) ✓ Visibility and immediate feedback are core to direct manipulation.  
D) ✓ Incremental, reversible actions encourage exploration.  

**Correct:** A, C, D


#### 4. How does the metaphor paradigm assist users in interacting with computers, and what are its limitations?  
A) ✗ Metaphors are not universally understood and can have cultural biases.  
B) ✗ Metaphors do not eliminate the need for training or documentation entirely.  
C) ✓ Some tasks do not fit well into metaphors, limiting their usefulness.  
D) ✓ Metaphors relate computing to familiar real-world activities, aiding learning.  

**Correct:** C, D


#### 5. Which statements about hypertext and the World Wide Web are true?  
A) ✗ Nelson’s Xanadu project remains unrealized and is not fully operational.  
B) ✓ Hypertext enables non-linear browsing through linked information.  
C) ✗ The WWW is an open system, unlike the originally closed hypertext concepts.  
D) ✓ HTTP and HTML made publishing and access easy, fueling the Web’s growth.  

**Correct:** B, D


#### 6. In what ways do agent-based interfaces differ from traditional command-line and direct manipulation interfaces?  
A) ✗ Agent-based interfaces do not rely solely on typed commands; they add intelligence.  
B) ✗ They do not automate all tasks; user input is still needed.  
C) ✓ Use of avatars and natural language processing is common in agent-based interfaces.  
D) ✓ They combine language commands with proactive, intelligent behavior.  

**Correct:** C, D


#### 7. What challenges and goals are associated with ubiquitous computing?  
A) ✗ The goal is to make computing less visible, not more.  
B) ✗ Ubiquitous computing does not aim to replace all devices with one centralized computer.  
C) ✓ Designing interactions that don’t demand constant attention is key.  
D) ✓ Embedding computing seamlessly into everyday objects is a core goal.  

**Correct:** C, D


#### 8. Why was time-sharing a significant paradigm shift in the 1960s?  
A) ✗ Programming toolkits were developed independently of time-sharing.  
B) ✓ It allowed multiple users to share a computer simultaneously, enabling interactivity.  
C) ✗ Batch processing preceded time-sharing; time-sharing replaced it.  
D) ✗ Graphical user interfaces came later, not with time-sharing.  

**Correct:** B


#### 9. Which of the following statements about multimodality and CSCW are accurate?  
A) ✗ Multimodality increases flexibility by combining modes, not limiting them.  
B) ✓ Electronic mail is a prominent CSCW success.  
C) ✗ CSCW focuses on group systems and social aspects, not single-user systems.  
D) ✓ Multimodality uses multiple communication channels simultaneously.  

**Correct:** B, D


#### 10. How do sensor-based and context-aware interactions improve usability in ubiquitous computing environments?  
A) ✓ Automatic sensing of physical phenomena allows adaptive interactions.  
B) ✗ Users do not manually input all environmental data; sensing is automatic.  
C) ✓ Systems behave as if aware of surroundings, improving natural interaction.  
D) ✗ Ignoring physical context would reduce usability, not improve it.  

**Correct:** A, C
