## 11. User Support

## Questions

#### 1. Which of the following are essential requirements for an effective user support system?  
A) Consistency between help system and paper documentation  
B) Providing help only after the user requests it  
C) Continuous availability concurrent with the main application  
D) Allowing the system to interrupt the user without control options  

#### 2. What are the main differences between help and documentation in user support?  
A) Both help and documentation must follow the same design principles  
B) Help is problem-oriented and specific, while documentation is system-oriented and general  
C) Help is designed for beginners, documentation is only for experts  
D) Documentation is always available online, help is only in printed manuals  

#### 3. Which of the following statements about adaptive help systems and user modeling are true?  
A) Overlay models compare actual user behavior to an ideal expert model  
B) User modeling always involves a single generic user profile  
C) Adaptive help systems never interrupt the user to offer assistance  
D) Adaptive help systems require detailed knowledge of the user, task, and domain  

#### 4. In the context of user support, what are the advantages and limitations of wizards?  
A) Wizards guide users step-by-step through complex tasks  
B) Wizards offer maximum flexibility for all types of tasks  
C) Wizards must allow users to go back to previous steps  
D) Wizards constrain task execution, limiting flexibility

A) Command assistance (e.g., UNIX man pages)  
B) Context-sensitive help (e.g., tooltips)  
C) On-line tutorials

#### 6. What are the main challenges in knowledge representation for intelligent help systems?  
A) Acquiring and encoding domain knowledge  
B) Ensuring the help system uses only rule-based knowledge representation

#### 9. Which of the following describe issues related to initiative and scope in adaptive help systems?  
A) The system should adapt all aspects of the user interface regardless of context  
B) Scope refers to whether adaptation happens at the application or system level  
C) Adaptive help systems always model user expertise across all installed applications  
D) Initiative concerns whether the user or system controls the help interaction  

#### 10. What are the characteristics and potential drawbacks of assistants in user support?  
A) Assistants monitor user behavior and offer contextual advice  
B) Assistants must be under user control to avoid annoyance  
C) Examples include Microsoft’s Clippy and XP smart tags  
D) They are always welcomed by users and never considered irritating

## Answers

#### 1. Which of the following are essential requirements for an effective user support system?  
A) ✓ Consistency between help system and paper documentation — Consistency avoids confusion and builds trust.  
B) ✗ Providing help only after the user requests it — Help should be available but not necessarily only on request; adaptive systems may offer proactive help.  
C) ✓ Continuous availability concurrent with the main application — Help must be accessible while users work.  
D) ✗ Allowing the system to interrupt the user without control options — Interruptions must be under user control to avoid annoyance.  

**Correct:** A, C


#### 2. What are the main differences between help and documentation in user support?  
A) ✓ Both help and documentation must follow the same design principles — Consistency and clarity apply to both.  
B) ✓ Help is problem-oriented and specific, while documentation is system-oriented and general — This distinction is fundamental.  
C) ✗ Help is designed for beginners, documentation is only for experts — Both can serve users of all levels depending on design.  
D) ✗ Documentation is always available online, help is only in printed manuals — Both can be online or printed; this is not a defining difference.  

**Correct:** A, B


#### 3. Which of the following statements about adaptive help systems and user modeling are true?  
A) ✓ Overlay models compare actual user behavior to an ideal expert model — This is a common user modeling approach.  
B) ✗ User modeling always involves a single generic user profile — Many systems use adaptable or adaptive models, not just generic ones.  
C) ✗ Adaptive help systems never interrupt the user to offer assistance — Some systems may interrupt but should do so carefully and with user control.  
D) ✓ Adaptive help systems require detailed knowledge of the user, task, and domain — This is necessary for effective adaptation.  

**Correct:** A, D


#### 4. In the context of user support, what are the advantages and limitations of wizards?  
A) ✓ Wizards guide users step-by-step through complex tasks — This is their main purpose.  
B) ✗ Wizards offer maximum flexibility for all types of tasks — Wizards constrain task flow and limit flexibility.  
C) ✓ Wizards must allow users to go back to previous steps — This is important for correcting mistakes or changing answers.  
D) ✓ Wizards constrain task execution, limiting flexibility — They restrict user choices to ensure safe completion.  

**Correct:** A, C, D


#### 5. Which of the following approaches to user support assume that the user already knows what they are looking for?  
A) ✓ Command assistance (e.g., UNIX man pages) — Assumes user knows the command name.  
B) ✗ Context-sensitive help (e.g., tooltips) — Provides help based on current context, no prior knowledge assumed.  
C) ✗ On-line tutorials — Designed for beginners who may not know what to look for.  
D) ✓ Command prompts after errors — Assumes user tried a command and needs correction, so some knowledge is assumed.  

**Correct:** A, D


#### 6. What are the main challenges in knowledge representation for intelligent help systems?  
A) ✓ Acquiring and encoding domain knowledge — Knowledge acquisition is difficult and time-consuming.  
B) ✗ Ensuring the help system uses only rule-based knowledge representation — Multiple representation methods exist; rule-based is not the only option.  
C) ✓ Managing resource constraints like memory and processing speed — Practical limits affect system design.  
D) ✓ Interpreting user behavior accurately — Understanding user intentions is complex.  

**Correct:** A, C, D


#### 7. Which of the following statements about presentation and implementation of user support are correct?  
A) ✗ Large blocks of text improve clarity and user understanding — Large text blocks hinder readability and user engagement.  
B) ✓ Pop-up boxes and hint icons are examples of help display methods — These are common UI elements for help.  
C) ✓ Help data can be structured as a single file, file hierarchy, or database — Different structures support different system needs.  
D) ✓ Help can be requested via commands, buttons, or separate applications — Multiple methods exist for requesting help.  

**Correct:** B, C, D


#### 8. Regarding advisory strategies in user support systems, which are true?  
A) ✗ Advisory strategy is irrelevant to the effectiveness of help systems — It is important for tailoring help appropriately.  
B) ✓ Examples of advisory strategies include reminders and tutorials — These are common advisory styles.  
C) ✗ Most intelligent help systems explicitly model advisory strategy — Few systems do this explicitly.  
D) ✓ Advisory strategy involves choosing the correct style of advice for a situation — This improves relevance and effectiveness.  

**Correct:** B, D


#### 9. Which of the following describe issues related to initiative and scope in adaptive help systems?  
A) ✗ The system should adapt all aspects of the user interface regardless of context — Adaptation should be targeted and relevant, not indiscriminate.  
B) ✓ Scope refers to whether adaptation happens at the application or system level — This affects complexity and coverage.  
C) ✗ Adaptive help systems always model user expertise across all installed applications — This is rarely feasible due to complexity.  
D) ✓ Initiative concerns whether the user or system controls the help interaction — This is a key design decision.  

**Correct:** B, D


#### 10. What are the characteristics and potential drawbacks of assistants in user support?  
A) ✓ Assistants monitor user behavior and offer contextual advice — This defines their function.  
B) ✓ Assistants must be under user control to avoid annoyance — User control is essential for acceptance.  
C) ✓ Examples include Microsoft’s Clippy and XP smart tags — These are well-known examples.  
D) ✗ They are always welcomed by users and never considered irritating — Assistants can be annoying if intrusive or poorly designed.  

**Correct:** A, B, C
