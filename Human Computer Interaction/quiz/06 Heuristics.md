## 6. Heuristics

## Questions

#### 1. Which of the following best describe the primary purpose of heuristics in usability evaluation?  
A) To provide detailed, task-specific instructions for users  
B) To offer general guidelines that help identify usability problems quickly  
C) To replace user testing entirely  
D) To serve as rules of thumb for improving interface design  

#### 2. Nielsen’s heuristic "Recognition rather than recall" means:  
A) Interfaces should minimize users’ memory load by making options visible  
B) The system should require users to remember error codes  
C) Users should memorize commands to increase efficiency  
D) Users should recall information from previous screens to complete tasks  

#### 3. Which of the following are true about heuristic evaluation?  
A) A single expert can reliably find all usability issues in an interface  
B) It is a formal, quantitative method requiring extensive user data  
C) Aggregated evaluations from multiple experts improve problem detection coverage  
D) It is a holistic evaluation focusing on the entire system rather than specific tasks  

#### 4. Shneiderman and Plaisant’s golden rule "Support internal locus of control" means:  
A) The interface should limit user freedom to avoid mistakes  
B) Users should feel in charge of initiating and controlling actions  
C) The system should control user actions to prevent errors  
D) Users should be able to easily undo or redo actions  

#### 5. Which of the following statements correctly compare Nielsen’s heuristics and Shneiderman & Plaisant’s golden rules?  
A) Both emphasize consistency and error prevention  
B) Both sets are vendor-specific guidelines tailored to particular platforms  
C) Shneiderman & Plaisant stress universal usability and user empowerment more explicitly  
D) Nielsen’s heuristics focus more on psychological user experience than system behavior  

#### 6. Vendor-specific guidelines such as Apple’s Human Interface Guidelines and Microsoft’s UI Guidelines are:  
A) Useful for designing applications that fit well within a specific ecosystem  
B) More prescriptive and focused on platform consistency  
C) Designed primarily to replace heuristic evaluation  
D) Broad theoretical principles applicable to all systems  

#### 7. Which of the following are characteristics of effective error messages according to Nielsen’s heuristics?  
A) Express errors in plain language that users can understand  
B) Precisely indicate the problem and suggest constructive solutions  
C) Use technical error codes to help developers diagnose problems  
D) Avoid providing any error messages to prevent user confusion  

#### 8. In the context of usability inspection, what is a key difference between heuristic evaluation and user studies?  
A) Heuristic evaluation is faster and less expensive than user studies  
B) Heuristic evaluation involves real users performing tasks  
C) User studies rely on experts inspecting the interface based on heuristics  
D) User studies do not provide insights into actual user behavior  

#### 9. The heuristic "Flexibility and efficiency of use" implies:  
A) Forcing all users to follow the same interaction path to maintain consistency  
B) Allowing users to customize the interface to suit their preferences  
C) The system should only cater to novice users to avoid confusion  
D) Providing shortcuts or accelerators for expert users while remaining easy for beginners  

#### 10. Which of the following statements about heuristic evaluation are correct?  
A) It focuses on evaluating specific user tasks in isolation  
B) It was developed by Jakob Nielsen in the late 1980s  
C) Combining evaluations from 3-5 experts tends to find more usability problems than a single expert  
D) It is an informal method that relies on experts’ knowledge and heuristics

## Answers

#### 1. Which of the following best describe the primary purpose of heuristics in usability evaluation?  
A) ✗ Heuristics are not detailed task instructions for users.  
B) ✓ Heuristics provide general guidelines to quickly identify usability problems.  
C) ✗ Heuristics do not replace user testing entirely; they complement it.  
D) ✓ Heuristics serve as practical rules of thumb for improving interface design.  

**Correct:** B, D


#### 2. Nielsen’s heuristic "Recognition rather than recall" means:  
A) ✓ It emphasizes making options visible to minimize memory load.  
B) ✗ It advises against requiring users to remember error codes.  
C) ✗ It discourages memorization to reduce user memory load.  
D) ✗ It avoids requiring users to recall information from previous screens.  

**Correct:** A


#### 3. Which of the following are true about heuristic evaluation?  
A) ✗ A single expert usually misses many usability issues.  
B) ✗ It is informal, not a formal quantitative method requiring extensive data.  
C) ✓ Multiple experts improve coverage of identified problems.  
D) ✓ It is holistic, focusing on the entire system rather than specific tasks.  

**Correct:** C, D


#### 4. Shneiderman and Plaisant’s golden rule "Support internal locus of control" means:  
A) ✗ It does not limit user freedom; it empowers users.  
B) ✓ Users should feel in charge of initiating and controlling actions.  
C) ✗ It encourages user control, not system control over users.  
D) ✓ Easy undo/redo supports user control and reduces anxiety.  

**Correct:** B, D


#### 5. Which of the following statements correctly compare Nielsen’s heuristics and Shneiderman & Plaisant’s golden rules?  
A) ✓ Both emphasize consistency and error prevention.  
B) ✗ Neither set is vendor-specific; they are general usability principles.  
C) ✓ Shneiderman & Plaisant explicitly stress universal usability and empowerment.  
D) ✗ Nielsen’s heuristics focus more on system behavior than psychological experience.  

**Correct:** A, C


#### 6. Vendor-specific guidelines such as Apple’s Human Interface Guidelines and Microsoft’s UI Guidelines are:  
A) ✓ Useful for designing apps that fit well within a specific ecosystem.  
B) ✓ More prescriptive and focused on platform consistency.  
C) ✗ They do not replace heuristic evaluation but complement it.  
D) ✗ They are not broad theoretical principles but platform-specific.  

**Correct:** A, B


#### 7. Which of the following are characteristics of effective error messages according to Nielsen’s heuristics?  
A) ✓ Error messages should be in plain language users understand.  
B) ✓ Messages should precisely indicate the problem and suggest solutions.  
C) ✗ Technical codes confuse users; messages should be user-friendly.  
D) ✗ Avoiding error messages is bad; clear messages help users recover.  

**Correct:** A, B


#### 8. In the context of usability inspection, what is a key difference between heuristic evaluation and user studies?  
A) ✓ Heuristic evaluation is faster and less expensive than user studies.  
B) ✗ Heuristic evaluation uses experts, not real users.  
C) ✗ User studies involve real users, not experts inspecting heuristics.  
D) ✗ User studies provide insights into actual user behavior, unlike heuristic evaluation.  

**Correct:** A


#### 9. The heuristic "Flexibility and efficiency of use" implies:  
A) ✗ Forcing one interaction path reduces flexibility and efficiency.  
B) ✓ Allowing customization supports flexibility and user efficiency.  
C) ✗ It should cater to both novices and experts, not only novices.  
D) ✓ Providing shortcuts for experts while remaining easy for beginners.  

**Correct:** B, D


#### 10. Which of the following statements about heuristic evaluation are correct?  
A) ✗ It evaluates the whole system, not isolated tasks.  
B) ✓ Developed by Jakob Nielsen in the late 1980s.  
C) ✓ Multiple experts find more problems than a single expert.  
D) ✓ It is an informal method relying on expert knowledge and heuristics.  

**Correct:** B, C, D
