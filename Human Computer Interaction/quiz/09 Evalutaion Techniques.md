## 9. Evalutaion Techniques

## Questions

#### 1. Which of the following are primary goals of evaluation in HCI?  
A) Ensuring the system uses the latest technology  
B) Assessing the extent of system functionality  
C) Identifying specific usability problems  
D) Assessing the effect of the interface on the user  

#### 2. In a Cognitive Walkthrough, what aspects are typically analyzed for each task?  
A) The impact of interaction on the user  
B) The cognitive processes required  
C) The system’s hardware performance  
D) Potential learning problems users may face  

#### 3. Which statements about Heuristic Evaluation are true?  
A) It is primarily used to debug design issues early in development  
B) It involves experts checking if usability heuristics are violated  
C) It requires direct user participation during the evaluation  
D) It relies on cognitive psychology principles to predict user errors  

#### 4. When is a laboratory study more appropriate than a field study for user evaluation?  
A) When studying long-term user behavior in natural contexts  
B) When multiple users need to be observed cooperating naturally  
C) When the system is used in a dangerous or impractical location  
D) When controlled manipulation of variables is necessary  

#### 5. In experimental evaluation, which of the following correctly describe independent and dependent variables?  
A) Independent variables are factors changed to observe effects  
B) Dependent variables are outcomes measured to assess impact  
C) Dependent variables are manipulated to create different conditions  
D) Independent variables are characteristics measured during the experiment  

#### 6. What are the advantages and disadvantages of within-groups experimental design?  
A) It is less costly and requires fewer participants than between-groups design  
B) It eliminates transfer of learning effects between conditions  
C) It reduces user variation by having each subject experience all conditions  
D) It can suffer from learning effects that bias results  

#### 7. Which challenges are commonly associated with group experiments in HCI evaluation?  
A) Ensuring tasks encourage cooperation among participants  
B) Recruiting sufficient numbers of participants within time and budget constraints  
C) Managing large volumes of data such as video and logs  
D) Avoiding any variation in user behavior across groups  

#### 8. Regarding Think Aloud and Cooperative Evaluation methods, which statements are accurate?  
A) Think Aloud requires users to verbalize their thoughts while performing tasks  
B) Think Aloud can alter task performance due to the act of describing actions  
C) Cooperative Evaluation allows interaction and questioning between user and evaluator  
D) Both methods are completely objective and free from user bias  

#### 9. Which physiological measurements can be used to infer user emotional responses during interface interaction?  
A) Screen resolution and refresh rate  
B) Heart rate and blood pressure monitoring  
C) Electroencephalogram (EEG) measuring brain electrical activity  
D) Galvanic Skin Response (GSR) measuring sweat gland activity  

#### 10. When choosing an evaluation method, which factors should be considered to ensure effectiveness?  
A) Whether the evaluation is conducted in a laboratory or field setting  
B) The availability of the latest hardware and software technologies  
C) The level of interference the evaluation causes to normal user activity  
D) The stage of the design process (design vs. implementation)

## Answers

#### 1. Which of the following are primary goals of evaluation in HCI?  
A) ✗ Ensuring the system uses the latest technology — Technology currency is not a goal of evaluation.  
B) ✓ Assessing the extent of system functionality — This is a core goal to verify what the system can do.  
C) ✓ Identifying specific usability problems — Finding problems is essential to improve design.  
D) ✓ Assessing the effect of the interface on the user — Understanding user impact is fundamental.  

**Correct:** B, C, D


#### 2. In a Cognitive Walkthrough, what aspects are typically analyzed for each task?  
A) ✓ The impact of interaction on the user — Cognitive walkthrough focuses on user experience at each step.  
B) ✓ The cognitive processes required — It examines mental steps users must perform.  
C) ✗ The system’s hardware performance — Hardware is outside the scope of cognitive walkthrough.  
D) ✓ Potential learning problems users may face — Identifying learning difficulties is a key focus.  

**Correct:** A, B, D


#### 3. Which statements about Heuristic Evaluation are true?  
A) ✓ It is primarily used to debug design issues early in development — It helps find usability problems early.  
B) ✓ It involves experts checking if usability heuristics are violated — This is the core method.  
C) ✗ It requires direct user participation during the evaluation — It is expert-based, not user-based.  
D) ✗ It relies on cognitive psychology principles to predict user errors — That is more related to cognitive walkthrough.  

**Correct:** A, B


#### 4. When is a laboratory study more appropriate than a field study for user evaluation?  
A) ✗ When studying long-term user behavior in natural contexts — This is better suited for field studies.  
B) ✗ When multiple users need to be observed cooperating naturally — Field studies better capture natural cooperation.  
C) ✓ When the system is used in a dangerous or impractical location — Labs provide safe, controlled environments.  
D) ✓ When controlled manipulation of variables is necessary — Labs allow precise control over conditions.  

**Correct:** C, D


#### 5. In experimental evaluation, which of the following correctly describe independent and dependent variables?  
A) ✓ Independent variables are factors changed to observe effects — Correct definition of IV.  
B) ✓ Dependent variables are outcomes measured to assess impact — Correct definition of DV.  
C) ✗ Dependent variables are manipulated to create different conditions — This describes independent variables.  
D) ✗ Independent variables are characteristics measured during the experiment — This describes dependent variables.  

**Correct:** A, B


#### 6. What are the advantages and disadvantages of within-groups experimental design?  
A) ✓ It is less costly and requires fewer participants than between-groups design — Fewer participants needed.  
B) ✗ It eliminates transfer of learning effects between conditions — Transfer of learning is a known disadvantage.  
C) ✓ It reduces user variation by having each subject experience all conditions — Controls for individual differences.  
D) ✓ It can suffer from learning effects that bias results — Learning effects can influence outcomes.  

**Correct:** A, C, D


#### 7. Which challenges are commonly associated with group experiments in HCI evaluation?  
A) ✓ Ensuring tasks encourage cooperation among participants — Cooperation is necessary for valid group tasks.  
B) ✓ Recruiting sufficient numbers of participants within time and budget constraints — Larger groups are costly and hard to schedule.  
C) ✓ Managing large volumes of data such as video and logs — Group studies generate complex data.  
D) ✗ Avoiding any variation in user behavior across groups — Variation is inevitable and a challenge, not something avoided.  

**Correct:** A, B, C


#### 8. Regarding Think Aloud and Cooperative Evaluation methods, which statements are accurate?  
A) ✓ Think Aloud requires users to verbalize their thoughts while performing tasks — This is the method’s essence.  
B) ✓ Think Aloud can alter task performance due to the act of describing actions — Verbalizing can interfere with natural behavior.  
C) ✓ Cooperative Evaluation allows interaction and questioning between user and evaluator — It is a more flexible variant.  
D) ✗ Both methods are completely objective and free from user bias — Both are subjective and can be biased.  

**Correct:** A, B, C


#### 9. Which physiological measurements can be used to infer user emotional responses during interface interaction?  
A) ✗ Screen resolution and refresh rate — These are technical display properties, not physiological measures.  
B) ✓ Heart rate and blood pressure monitoring — Linked to emotional responses.  
C) ✓ Electroencephalogram (EEG) measuring brain electrical activity — Can indicate emotional and cognitive states.  
D) ✓ Galvanic Skin Response (GSR) measuring sweat gland activity — Reflects emotional arousal.  

**Correct:** B, C, D


#### 10. When choosing an evaluation method, which factors should be considered to ensure effectiveness?  
A) ✓ Whether the evaluation is conducted in a laboratory or field setting — Environment affects method choice.  
B) ✗ The availability of the latest hardware and software technologies — Not a primary factor in method selection.  
C) ✓ The level of interference the evaluation causes to normal user activity — Important to consider user disruption.  
D) ✓ The stage of the design process (design vs. implementation) — Different methods suit different stages.  

**Correct:** A, C, D
