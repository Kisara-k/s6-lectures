## Answers

#### 1. What are the primary goals of evaluation in HCI?  
A) ✗ Reducing costs is a benefit but not a primary goal of evaluation.  
B) ✓ Evaluation assesses if the system functions as intended.  
C) ✓ Identifying user problems is a key goal of evaluation.  
D) ✓ Understanding the interface’s effect on users is essential.  

**Correct:** B, C, D


#### 2. Which of the following best describes a Cognitive Walkthrough?  
A) ✓ It involves an expert simulating user tasks to evaluate learning support.  
B) ✗ Heuristic evaluation checks heuristics, not cognitive walkthrough.  
C) ✗ Statistical analysis is unrelated to cognitive walkthrough.  
D) ✗ Think aloud is a user-driven method, not a cognitive walkthrough.  

**Correct:** A


#### 3. In Heuristic Evaluation, which of the following are typical heuristics used?  
A) ✓ Providing feedback is a standard heuristic.  
B) ✓ Consistency is a core heuristic.  
C) ✓ Predictability is a key heuristic.  
D) ✗ Full customization is not a common heuristic.  

**Correct:** A, B, C


#### 4. What is a key limitation of Review-Based Evaluation?  
A) ✗ Cognitive models can be combined with review-based evaluation.  
B) ✗ It does not require user participation necessarily.  
C) ✗ It can be used at various stages, not only full implementation.  
D) ✓ Literature results may not always apply to new designs.  

**Correct:** D


#### 5. Which of the following are advantages of laboratory studies in user evaluation?  
A) ✗ Observing multiple cooperating users is difficult in labs.  
B) ✓ Labs have specialist equipment available.  
C) ✓ Labs provide an uninterrupted environment.  
D) ✗ Natural environment is a field study advantage, not lab.  

**Correct:** B, C


#### 6. Field studies are most appropriate when:  
A) ✗ Single-user constrained tasks are better suited to labs.  
B) ✗ Dangerous locations favor lab studies for safety.  
C) ✓ Context is crucial and must be preserved.  
D) ✓ Longitudinal studies are possible in the field.  

**Correct:** C, D


#### 7. In experimental evaluation, what does the independent variable represent?  
A) ✗ Hypothesis is a prediction, not a variable.  
B) ✗ Subjects are participants, not variables.  
C) ✗ This describes the dependent variable.  
D) ✓ The independent variable is what the experimenter changes.  

**Correct:** D


#### 8. Which of the following statements about within-groups experimental design is true?  
A) ✗ This describes between-groups design.  
B) ✗ Within-groups usually requires fewer participants.  
C) ✗ Transfer of learning is a risk in within-groups design.  
D) ✓ Within-groups reduces variability from subject differences.  

**Correct:** D


#### 9. When analyzing experimental data, parametric tests:  
A) ✗ Parametric tests are generally more powerful than non-parametric.  
B) ✓ Parametric tests are more powerful when assumptions hold.  
C) ✗ Parametric tests are less reliable if data is non-normal.  
D) ✓ Assume data follows a normal distribution.  

**Correct:** B, D


#### 10. What are common challenges when conducting group experiments in HCI?  
A) ✓ Recruiting enough subjects is difficult and costly.  
B) ✓ Tasks must encourage cooperation for valid group data.  
C) ✗ Variation in user behavior is inevitable, not avoidable.  
D) ✓ Managing large data volumes like video is challenging.  

**Correct:** A, B, D


#### 11. Which of the following are true about Think Aloud protocols?  
A) ✓ Users verbalize thoughts during task performance.  
B) ✗ Think Aloud requires little technical equipment.  
C) ✗ Data is subjective, not completely objective.  
D) ✓ Verbalizing can alter how users perform tasks.  

**Correct:** A, D


#### 12. Cooperative evaluation differs from Think Aloud in that:  
A) ✗ Post-task analysis is still often needed.  
B) ✓ User and evaluator collaborate and ask questions.  
C) ✓ It encourages open criticism from users.  
D) ✗ It is less constrained and more flexible, not more constrained.  

**Correct:** B, C


#### 13. Which of the following are advantages of post-task walkthroughs?  
A) ✓ Helps identify reasons behind user actions.  
B) ✓ Useful when Think Aloud is not feasible.  
C) ✓ Immediate playback helps keep memory fresh.  
D) ✗ Interpretation bias can still occur in analysis.  

**Correct:** A, B, C


#### 14. What is a major disadvantage of questionnaires compared to interviews?  
A) ✗ Questionnaires can reach large groups quickly.  
B) ✓ Questionnaires are less flexible and probing.  
C) ✗ Questionnaires are quicker, not more time-consuming.  
D) ✗ Questionnaires can be analyzed rigorously.  

**Correct:** B


#### 15. Eye tracking measurements include:  
A) ✓ Fixations indicate cognitive effort and difficulty.  
B) ✗ Heart rate is a physiological measure but not eye tracking.  
C) ✓ Scan paths show the route of eye movement.  
D) ✓ Saccades are rapid eye movements between points.  

**Correct:** A, C, D


#### 16. Physiological measurements such as Galvanic Skin Response (GSR) and EEG:  
A) ✗ Interpretation is complex, not straightforward.  
B) ✓ More research is needed to improve interpretation.  
C) ✓ They provide insights into emotional reactions.  
D) ✗ They are rarely used alone as the sole method.  

**Correct:** B, C


#### 17. Which factors should influence the choice of an evaluation method?  
A) ✓ Whether the evaluation is subjective or objective is important.  
B) ✓ Stage of design or implementation matters.  
C) ✗ Programming language does not affect evaluation method choice.  
D) ✓ Available resources like time and equipment are crucial.  

**Correct:** A, B, D


#### 18. In experimental design, the null hypothesis:  
A) ✓ The experiment aims to disprove the null hypothesis.  
B) ✗ This describes the alternative hypothesis.  
C) ✓ States no difference between conditions.  
D) ✗ Null hypothesis is rejected if data shows difference, not accepted.  

**Correct:** A, C


#### 19. Which of the following statements about field studies is correct?  
A) ✗ Field studies are not controlled and have distractions.  
B) ✓ They allow study of real-world social and physical contexts.  
C) ✗ Field studies are well suited for longitudinal studies.  
D) ✓ Observer presence may alter user behavior.  

**Correct:** B, D


#### 20. Which of the following are true about protocol analysis methods?  
A) ✗ Video recording requires special equipment and can be obtrusive.  
B) ✗ User notebooks are subjective, not objective.  
C) ✓ Audio is good for Think Aloud but hard to synchronize.  
D) ✓ Computer logging produces large, complex data sets.  

**Correct:** C, D
