## Answers

#### 1. What are the primary goals of evaluation in HCI?  
A) ✗ Reducing costs is a benefit but not a primary goal of evaluation.  
B) ✓ Understanding the interface’s effect on users is essential.  
C) ✓ Evaluation assesses if the system functions as intended.  
D) ✓ Identifying user problems is a key goal of evaluation.  

**Correct:** B, C, D


#### 2. Which of the following best describes a Cognitive Walkthrough?  
A) ✗ Heuristic evaluation checks heuristics, not cognitive walkthrough.  
B) ✗ Think aloud is a user-driven method, not a cognitive walkthrough.  
C) ✗ Statistical analysis is unrelated to cognitive walkthrough.  
D) ✓ It involves an expert simulating user tasks to evaluate learning support.  

**Correct:** D


#### 3. In Heuristic Evaluation, which of the following are typical heuristics used?  
A) ✓ Consistency is a core heuristic.  
B) ✗ Full customization is not a common heuristic.  
C) ✓ Predictability is a key heuristic.  
D) ✓ Providing feedback is a standard heuristic.  

**Correct:** A, C, D


#### 4. What is a key limitation of Review-Based Evaluation?  
A) ✗ Cognitive models can be combined with review-based evaluation.  
B) ✗ It does not require user participation necessarily.  
C) ✗ It can be used at various stages, not only full implementation.  
D) ✓ Literature results may not always apply to new designs.  

**Correct:** D


#### 5. Which of the following are advantages of laboratory studies in user evaluation?  
A) ✓ Labs have specialist equipment available.  
B) ✗ Natural environment is a field study advantage, not lab.  
C) ✗ Observing multiple cooperating users is difficult in labs.  
D) ✓ Labs provide an uninterrupted environment.  

**Correct:** A, D


#### 6. Field studies are most appropriate when:  
A) ✗ Dangerous locations favor lab studies for safety.  
B) ✗ Single-user constrained tasks are better suited to labs.  
C) ✓ Longitudinal studies are possible in the field.  
D) ✓ Context is crucial and must be preserved.  

**Correct:** C, D


#### 7. In experimental evaluation, what does the independent variable represent?  
A) ✗ Hypothesis is a prediction, not a variable.  
B) ✗ This describes the dependent variable.  
C) ✗ Subjects are participants, not variables.  
D) ✓ The independent variable is what the experimenter changes.  

**Correct:** D


#### 8. Which of the following statements about within-groups experimental design is true?  
A) ✗ Transfer of learning is a risk in within-groups design.  
B) ✗ This describes between-groups design.  
C) ✓ Within-groups reduces variability from subject differences.  
D) ✗ Within-groups usually requires fewer participants.  

**Correct:** C


#### 9. When analyzing experimental data, parametric tests:  
A) ✓ Assume data follows a normal distribution.  
B) ✗ Parametric tests are generally more powerful than non-parametric.  
C) ✗ Parametric tests are less reliable if data is non-normal.  
D) ✓ Parametric tests are more powerful when assumptions hold.  

**Correct:** A, D


#### 10. What are common challenges when conducting group experiments in HCI?  
A) ✓ Recruiting enough subjects is difficult and costly.  
B) ✗ Variation in user behavior is inevitable, not avoidable.  
C) ✓ Managing large data volumes like video is challenging.  
D) ✓ Tasks must encourage cooperation for valid group data.  

**Correct:** A, C, D


#### 11. Which of the following are true about Think Aloud protocols?  
A) ✗ Think Aloud requires little technical equipment.  
B) ✗ Data is subjective, not completely objective.  
C) ✓ Users verbalize thoughts during task performance.  
D) ✓ Verbalizing can alter how users perform tasks.  

**Correct:** C, D


#### 12. Cooperative evaluation differs from Think Aloud in that:  
A) ✓ It encourages open criticism from users.  
B) ✗ Post-task analysis is still often needed.  
C) ✗ It is less constrained and more flexible, not more constrained.  
D) ✓ User and evaluator collaborate and ask questions.  

**Correct:** A, D


#### 13. Which of the following are advantages of post-task walkthroughs?  
A) ✓ Useful when Think Aloud is not feasible.  
B) ✓ Helps identify reasons behind user actions.  
C) ✓ Immediate playback helps keep memory fresh.  
D) ✗ Interpretation bias can still occur in analysis.  

**Correct:** A, B, C


#### 14. What is a major disadvantage of questionnaires compared to interviews?  
A) ✗ Questionnaires can reach large groups quickly.  
B) ✓ Questionnaires are less flexible and probing.  
C) ✗ Questionnaires can be analyzed rigorously.  
D) ✗ Questionnaires are quicker, not more time-consuming.  

**Correct:** B


#### 15. Eye tracking measurements include:  
A) ✓ Saccades are rapid eye movements between points.  
B) ✓ Fixations indicate cognitive effort and difficulty.  
C) ✗ Heart rate is a physiological measure but not eye tracking.  
D) ✓ Scan paths show the route of eye movement.  

**Correct:** A, B, D


#### 16. Physiological measurements such as Galvanic Skin Response (GSR) and EEG:  
A) ✗ They are rarely used alone as the sole method.  
B) ✓ More research is needed to improve interpretation.  
C) ✗ Interpretation is complex, not straightforward.  
D) ✓ They provide insights into emotional reactions.  

**Correct:** B, D


#### 17. Which factors should influence the choice of an evaluation method?  
A) ✓ Available resources like time and equipment are crucial.  
B) ✓ Whether the evaluation is subjective or objective is important.  
C) ✓ Stage of design or implementation matters.  
D) ✗ Programming language does not affect evaluation method choice.  

**Correct:** A, B, C


#### 18. In experimental design, the null hypothesis:  
A) ✓ States no difference between conditions.  
B) ✗ Null hypothesis is rejected if data shows difference, not accepted.  
C) ✓ The experiment aims to disprove the null hypothesis.

#### 19. Which of the following statements about field studies is correct?  
A) ✓ Observer presence may alter user behavior.  
B) ✗ Field studies are well suited for longitudinal studies.  
C) ✓ They allow study of real-world social and physical contexts.

#### 20. Which of the following are true about protocol analysis methods?

B) ✗ User notebooks are subjective, not objective.  
C) ✓ Audio is good for Think Aloud but hard to synchronize.  
D) ✗ Video recording requires special equipment and can be obtrusive.  

**Correct:** A, C
