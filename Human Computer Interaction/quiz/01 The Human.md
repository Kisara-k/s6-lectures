## 1. The Human

## Questions

#### 1. Which of the following statements about human vision are true?

B) Rods are responsible for color vision, while cones detect low light.  
C) The brain uses cues like overlapping objects to perceive depth and size.

#### 2. Regarding memory types, which of the following are accurate?

B) Semantic memory is structured to support inference through relationships between concepts.  
C) Short-term memory capacity is typically limited to about 7±2 chunks.

#### 3. Which of the following correctly describe the auditory system and hearing?

B) Pitch is determined by the amplitude of sound waves.  
C) The cocktail party effect demonstrates the auditory system’s ability to focus on specific sounds amid noise.  
D) Humans can hear frequencies roughly between 20 Hz and 15,000 Hz.  

#### 4. Fitts’ Law predicts movement time based on which factors?  
A) The size of the target.  
B) The color contrast of the target.  
C) The distance to the target.  
D) Empirically determined constants specific to the task and user.  

#### 5. Which of the following statements about reasoning types are correct?  
A) Abductive reasoning infers the most likely cause from an observed effect but can be unreliable.  
B) Inductive reasoning can prove a hypothesis true by observing multiple cases.  
C) Deductive reasoning always produces true conclusions if the premises are true.  
D) Humans are generally good at using negative evidence in inductive reasoning tasks.  

#### 6. Which of the following are characteristics of slips and mistakes in human error?  
A) Mistakes result from incorrect intentions due to misunderstanding.  
B) Slips are usually caused by incorrect mental models.  
C) Slips occur when the intention is correct but the execution fails.  
D) Mistakes can be caused by poor physical skill or inattention.  

#### 7. Which of the following statements about emotion and its effects on cognition are true?

C) Stress increases the difficulty of problem solving.  
D) Emotion only involves physical responses, not cognitive evaluation.  

#### 8. Regarding long-term memory models, which are accurate?  
A) Semantic networks allow child nodes to inherit properties from parent nodes.  
B) Frames organize information with fixed and variable slots for different instances.  
C) Production rules model stereotypical event sequences in familiar situations.  
D) Scripts represent procedural knowledge as condition-action pairs.  

#### 9. Which of the following statements about visual perception and reading are correct?  
A) Saccades are the brief pauses during which perception occurs.  
B) Negative contrast on screens can improve reading performance.  
C) Reading involves decoding visual patterns using knowledge of syntax, semantics, and pragmatics.  
D) Word shape plays an important role in word recognition during reading.  

#### 10. When designing interactive systems, which considerations related to human factors are important?  
A) Stress and emotion can influence how users respond to interface design.  
B) Individual differences such as age, sex, and fatigue can affect user interaction.  
C) Using blue for critical interface details is advisable because blue acuity is high.  
D) Guidelines and cognitive models help apply psychological knowledge effectively in design.

## Answers

#### 1. Which of the following statements about human vision are true?  
A) ✗ The retina focuses images upside-down, not right-side up.  
B) ✗ Rods detect low light; cones are responsible for color vision.  
C) ✓ The brain uses cues like overlapping to perceive depth and size.  
D) ✓ Visual acuity improves as luminance increases.  

**Correct:** C, D


#### 2. Regarding memory types, which of the following are accurate?  
A) ✓ Long-term memory access is slower than short-term memory.  
B) ✓ Semantic memory is structured to support inference via relationships.  
C) ✓ Short-term memory capacity is about 7±2 chunks.  
D) ✗ Sensory memory lasts only milliseconds, not several minutes.  

**Correct:** A, B, C


#### 3. Which of the following correctly describe the auditory system and hearing?  
A) ✗ The middle ear transmits vibrations, chemical signals are generated in the inner ear.  
B) ✗ Pitch depends on frequency, not amplitude.  
C) ✓ The cocktail party effect shows selective auditory attention amid noise.  
D) ✓ Humans hear roughly between 20 Hz and 15,000 Hz.  

**Correct:** C, D


#### 4. Fitts’ Law predicts movement time based on which factors?  
A) ✓ Target size affects movement time (larger targets reduce time).  
B) ✗ Color contrast is not part of Fitts’ Law formula.  
C) ✓ Distance to target affects movement time (longer distances increase time).  
D) ✓ Constants a and b are empirically determined for specific tasks/users.  

**Correct:** A, C, D


#### 5. Which of the following statements about reasoning types are correct?  
A) ✓ Abductive reasoning infers likely causes but can be unreliable.  
B) ✗ Inductive reasoning cannot prove hypotheses true, only falsify them.  
C) ✓ Deductive reasoning produces logically necessary conclusions if premises are true.  
D) ✗ Humans are generally poor at using negative evidence in induction.  

**Correct:** A, C


#### 6. Which of the following are characteristics of slips and mistakes in human error?  
A) ✓ Mistakes result from incorrect intentions due to misunderstanding.  
B) ✗ Slips are caused by execution failure, not incorrect mental models.  
C) ✓ Slips occur when intention is correct but execution fails.  
D) ✗ Mistakes are caused by misunderstanding, not poor physical skill or inattention.  

**Correct:** A, C


#### 7. Which of the following statements about emotion and its effects on cognition are true?  
A) ✓ James-Lange theory states emotion arises from interpreting physiological responses.  
B) ✗ Positive affect promotes creative thinking, not narrowing it.  
C) ✓ Stress increases difficulty in problem solving.  
D) ✗ Emotion involves both cognitive evaluation and physical responses.  

**Correct:** A, C


#### 8. Regarding long-term memory models, which are accurate?  
A) ✓ Semantic networks allow inheritance of properties from parent to child nodes.  
B) ✓ Frames organize information with fixed and variable slots.  
C) ✗ Production rules represent condition-action pairs, not event sequences.  
D) ✗ Scripts represent stereotypical event sequences, not condition-action pairs.  

**Correct:** A, B


#### 9. Which of the following statements about visual perception and reading are correct?  
A) ✗ Saccades are rapid eye movements; fixations are the pauses where perception occurs.  
B) ✓ Negative contrast improves reading from screens.  
C) ✓ Reading involves decoding visual patterns using syntax, semantics, and pragmatics.  
D) ✓ Word shape is important for word recognition.  

**Correct:** B, C, D


#### 10. When designing interactive systems, which considerations related to human factors are important?  
A) ✓ Stress and emotion influence user responses to design.  
B) ✓ Individual differences like age, sex, and fatigue affect interaction.  
C) ✗ Blue should not be used for critical details because blue acuity is poor.  
D) ✓ Guidelines and cognitive models help apply psychology in design.  

**Correct:** A, B, D
