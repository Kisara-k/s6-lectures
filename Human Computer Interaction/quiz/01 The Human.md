## Answers

#### 1. Which of the following are true about the physical reception of visual stimuli?  
A) ✗ Rods are for low light vision, cones are for color vision.  
B) ✓ Ganglion cells detect patterns and movement and send signals to the brain.  
C) ✓ Light is transformed into electrical energy by photoreceptors in the retina.  
D) ✗ Images are focused upside-down, not right-side up, on the retina.  

**Correct:** B, C


#### 2. Visual acuity is influenced by which of the following factors?  
A) ✓ Familiarity helps perceive objects as constant size despite changes in visual angle.  
B) ✓ Luminance affects visual acuity; higher luminance improves detail perception.  
C) ✗ Size of the retina is not a factor discussed in visual acuity.  
D) ✓ Visual angle relates to how much of the view an object occupies, affecting acuity.  

**Correct:** A, B, D


#### 3. Which statements about color vision are correct?  
A) ✗ Blue cones have the lowest acuity, not the highest.  
B) ✓ About 8% of males are color blind; much fewer females are affected.  
C) ✓ Hue, intensity, and saturation are components of color perception.  
D) ✗ Color blindness affects more males than females, not the other way around.  

**Correct:** B, C


#### 4. The visual system compensates for which of the following to maintain stable perception?  
A) ✗ Auditory input is unrelated to visual compensation.  
B) ✓ Compensates for movement to keep stable images.  
C) ✓ Uses context to resolve ambiguity in perception.  
D) ✓ Adjusts for changes in luminance to maintain perception.  

**Correct:** B, C, D


#### 5. Which of the following are characteristics of reading as a visual process?  
A) ✓ Word shape is important for word recognition.  
B) ✓ Syntax, semantics, and pragmatics are involved in interpreting text.  
C) ✗ Perception occurs mainly during fixations, not saccades.  
D) ✓ Negative contrast improves reading from computer screens.  

**Correct:** A, B, D


#### 6. Regarding the human auditory system, which are true?  
A) ✓ Cocktail party phenomenon shows selective auditory attention.  
B) ✓ Humans hear roughly 20 Hz to 15 kHz frequencies.  
C) ✗ Middle ear transmits vibrations, chemical signals are released in the inner ear.  
D) ✗ Loudness depends on amplitude, not frequency.  

**Correct:** A, B


#### 7. Which receptors in the skin are responsible for detecting pressure?  
A) ✗ Photoreceptors are in the eye, not skin.  
B) ✗ Thermoreceptors detect temperature, not pressure.  
C) ✓ Mechanoreceptors detect pressure stimuli.  
D) ✗ Nociceptors detect pain, not pressure.  

**Correct:** C


#### 8. Kinesthesia refers to:  
A) ✗ Temperature sense is thermoreception.  
B) ✓ Awareness of body position and movement.  
C) ✗ Detecting pain is nociception, not kinesthesia.  
D) ✗ Visual pattern recognition is unrelated to kinesthesia.  

**Correct:** B


#### 9. Reaction time varies depending on stimulus type. Which of the following correctly orders reaction times from fastest to slowest?  
A) ✗ Visual reaction time (~200 ms) is slower than auditory (~150 ms).  
B) ✗ Visual is slower than auditory, so this order is incorrect.  
C) ✓ Auditory (~150 ms) is fastest, then visual (~200 ms), then pain (~700 ms).  
D) ✗ Pain is slowest, but auditory is faster than visual.  

**Correct:** C


#### 10. According to Fitts’ Law, which design choice will reduce movement time?  
A) ✗ Increasing distance increases movement time.  
B) ✓ Placing targets closer reduces movement time.  
C) ✗ Decreasing target size increases movement time.  
D) ✓ Larger targets reduce movement time.  

**Correct:** B, D


#### 11. Which of the following statements about short-term memory (STM) are correct?  
A) ✗ STM is temporary, not permanent storage.  
B) ✓ STM capacity is about 7 ± 2 chunks.  
C) ✗ STM decay is about 20 seconds, not 200 milliseconds (lecture states rapid decay ~200 ms but typical STM decay is longer; 200 ms here refers to rapid decay of sensory memory).  
D) ✓ STM allows rapid access (~70 ms).  

**Correct:** B, D


#### 12. Long-term memory (LTM) differs from STM in that:  
A) ✓ LTM access is slower than STM.  
B) ✓ LTM decay is very slow or negligible.  
C) ✓ LTM includes episodic and semantic memory types.  
D) ✗ LTM capacity is huge or unlimited, not limited to 7 ± 2 chunks.  

**Correct:** A, B, C


#### 13. Which of the following best describe semantic networks in LTM?  
A) ✗ Information is connected, not unconnected facts.  
B) ✓ Supports inference through inheritance.  
C) ✗ Relationships are explicit, not vague.  
D) ✓ Child nodes inherit properties from parent nodes.  

**Correct:** B, D


#### 14. Scripts in memory models are:  
A) ✗ Scripts include roles, props, and scenes.  
B) ✓ Instantiated with values depending on context.  
C) ✗ Condition-action rules describe production rules, not scripts.  
D) ✓ Data structures representing stereotypical event sequences.  

**Correct:** B, D


#### 15. Which of the following are true about deductive reasoning?  
A) ✓ If premises are true and reasoning valid, conclusion must be true.  
B) ✓ Deduction derives necessary conclusions from premises.  
C) ✗ Logical validity alone does not guarantee truth if premises are false.  
D) ✓ False premises can lead to false conclusions despite valid logic.  

**Correct:** A, B, D


#### 16. Inductive reasoning is characterized by:  
A) ✓ Generalizing from specific to broader cases.  
B) ✗ Humans are generally poor at using negative evidence.  
C) ✓ Induction is unreliable but useful.  
D) ✗ Induction cannot prove hypotheses true with certainty, only falsify.  

**Correct:** A, B, C


#### 17. Abductive reasoning involves:  
A) ✓ Can lead to false explanations due to assumptions.  
B) ✗ Reasoning from cause to effect is deduction or induction.  
C) ✗ Abduction can be unreliable, not always reliable.  
D) ✓ Reasoning from effect to cause (inferring cause from observed event).  

**Correct:** A, D


#### 18. Which of the following statements about problem solving are correct?  
A) ✓ Problem space theory involves generating states with legal operators.  
B) ✓ Skilled problem solving involves chunking information.  
C) ✓ Gestalt theory emphasizes insight and restructuring.  
D) ✗ Analogical mapping is difficult when domains differ semantically.  

**Correct:** A, B, C


#### 19. Errors in human behavior can be classified as:  
A) ✓ Incorrect mental models can cause errors.  
B) ✗ Errors are not always caused by lack of attention; other causes exist.  
C) ✓ Slips occur when intention is correct but execution fails.  
D) ✓ Mistakes occur when intention itself is wrong.  

**Correct:** A, C, D


#### 20. Emotion influences human capabilities in which ways?  
A) ✓ Stress increases difficulty in problem solving.  
B) ✗ Relaxed users tend to be more forgiving, not less.  
C) ✓ Negative affect can make even easy tasks harder.  
D) ✗ Positive affect broadens thinking and enhances creativity, not narrows it.  

**Correct:** A, C
