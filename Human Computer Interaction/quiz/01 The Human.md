## Answers

#### 1. Which of the following are true about the physical reception of visual stimuli?  
A) ✗ Images are focused upside-down, not right-side up, on the retina.  
B) ✗ Rods are for low light vision, cones are for color vision.  
C) ✓ Ganglion cells detect patterns and movement and send signals to the brain.  
D) ✓ Light is transformed into electrical energy by photoreceptors in the retina.  

**Correct:** C, D


#### 2. Visual acuity is influenced by which of the following factors?  
A) ✓ Luminance affects visual acuity; higher luminance improves detail perception.  
B) ✗ Size of the retina is not a factor discussed in visual acuity.  
C) ✓ Visual angle relates to how much of the view an object occupies, affecting acuity.  
D) ✓ Familiarity helps perceive objects as constant size despite changes in visual angle.  

**Correct:** A, C, D


#### 3. Which statements about color vision are correct?  
A) ✗ Blue cones have the lowest acuity, not the highest.  
B) ✓ About 8% of males are color blind; much fewer females are affected.  
C) ✓ Hue, intensity, and saturation are components of color perception.  
D) ✗ Color blindness affects more males than females, not the other way around.  

**Correct:** B, C


#### 4. The visual system compensates for which of the following to maintain stable perception?  
A) ✓ Compensates for movement to keep stable images.  
B) ✓ Adjusts for changes in luminance to maintain perception.  
C) ✗ Auditory input is unrelated to visual compensation.  
D) ✓ Uses context to resolve ambiguity in perception.  

**Correct:** A, B, D


#### 5. Which of the following are characteristics of reading as a visual process?  
A) ✗ Perception occurs mainly during fixations, not saccades.  
B) ✓ Word shape is important for word recognition.  
C) ✓ Syntax, semantics, and pragmatics are involved in interpreting text.  
D) ✓ Negative contrast improves reading from computer screens.  

**Correct:** B, C, D


#### 6. Regarding the human auditory system, which are true?  
A) ✗ Middle ear transmits vibrations, chemical signals are released in the inner ear.  
B) ✓ Humans hear roughly 20 Hz to 15 kHz frequencies.  
C) ✓ Cocktail party phenomenon shows selective auditory attention.  
D) ✗ Loudness depends on amplitude, not frequency.  

**Correct:** B, C


#### 7. Which receptors in the skin are responsible for detecting pressure?  
A) ✗ Thermoreceptors detect temperature, not pressure.  
B) ✗ Nociceptors detect pain, not pressure.  
C) ✓ Mechanoreceptors detect pressure stimuli.  
D) ✗ Photoreceptors are in the eye, not skin.  

**Correct:** C


#### 8. Kinesthesia refers to:  
A) ✓ Awareness of body position and movement.  
B) ✗ Detecting pain is nociception, not kinesthesia.  
C) ✗ Temperature sense is thermoreception.  
D) ✗ Visual pattern recognition is unrelated to kinesthesia.  

**Correct:** A


#### 9. Reaction time varies depending on stimulus type. Which of the following correctly orders reaction times from fastest to slowest?  
A) ✗ Visual reaction time (~200 ms) is slower than auditory (~150 ms).  
B) ✓ Auditory (~150 ms) is fastest, then visual (~200 ms), then pain (~700 ms).  
C) ✗ Pain is slowest, but auditory is faster than visual.  
D) ✗ Visual is slower than auditory, so this order is incorrect.  

**Correct:** B


#### 10. According to Fitts’ Law, which design choice will reduce movement time?  
A) ✗ Increasing distance increases movement time.  
B) ✗ Decreasing target size increases movement time.  
C) ✓ Larger targets reduce movement time.  
D) ✓ Placing targets closer reduces movement time.  

**Correct:** C, D


#### 11. Which of the following statements about short-term memory (STM) are correct?  
A) ✓ STM capacity is about 7 ± 2 chunks.  
B) ✗ STM decay is about 20 seconds, not 200 milliseconds (lecture states rapid decay ~200 ms but typical STM decay is longer; 200 ms here refers to rapid decay of sensory memory).  
C) ✗ STM is temporary, not permanent storage.  
D) ✓ STM allows rapid access (~70 ms).  

**Correct:** A, D


#### 12. Long-term memory (LTM) differs from STM in that:  
A) ✓ LTM access is slower than STM.  
B) ✗ LTM capacity is huge or unlimited, not limited to 7 ± 2 chunks.  
C) ✓ LTM decay is very slow or negligible.  
D) ✓ LTM includes episodic and semantic memory types.  

**Correct:** A, C, D


#### 13. Which of the following best describe semantic networks in LTM?  
A) ✓ Child nodes inherit properties from parent nodes.  
B) ✗ Relationships are explicit, not vague.  
C) ✓ Supports inference through inheritance.  
D) ✗ Information is connected, not unconnected facts.  

**Correct:** A, C


#### 14. Scripts in memory models are:  
A) ✓ Data structures representing stereotypical event sequences.  
B) ✗ Condition-action rules describe production rules, not scripts.  
C) ✓ Instantiated with values depending on context.  
D) ✗ Scripts include roles, props, and scenes.  

**Correct:** A, C


#### 15. Which of the following are true about deductive reasoning?  
A) ✓ If premises are true and reasoning valid, conclusion must be true.  
B) ✗ Logical validity alone does not guarantee truth if premises are false.  
C) ✓ Deduction derives necessary conclusions from premises.  
D) ✓ False premises can lead to false conclusions despite valid logic.  

**Correct:** A, C, D


#### 16. Inductive reasoning is characterized by:  
A) ✓ Generalizing from specific to broader cases.  
B) ✗ Induction cannot prove hypotheses true with certainty, only falsify.  
C) ✓ Induction is unreliable but useful.  
D) ✗ Humans are generally poor at using negative evidence.  

**Correct:** A, C, D


#### 17. Abductive reasoning involves:  
A) ✗ Reasoning from cause to effect is deduction or induction.  
B) ✓ Reasoning from effect to cause (inferring cause from observed event).  
C) ✗ Abduction can be unreliable, not always reliable.  
D) ✓ Can lead to false explanations due to assumptions.  

**Correct:** B, D


#### 18. Which of the following statements about problem solving are correct?  
A) ✓ Gestalt theory emphasizes insight and restructuring.  
B) ✓ Problem space theory involves generating states with legal operators.  
C) ✗ Analogical mapping is difficult when domains differ semantically.  
D) ✓ Skilled problem solving involves chunking information.  

**Correct:** A, B, D


#### 19. Errors in human behavior can be classified as:  
A) ✓ Slips occur when intention is correct but execution fails.  
B) ✓ Mistakes occur when intention itself is wrong.  
C) ✗ Errors are not always caused by lack of attention; other causes exist.  
D) ✓ Incorrect mental models can cause errors.  

**Correct:** A, B, D


#### 20. Emotion influences human capabilities in which ways?  
A) ✗ Positive affect broadens thinking and enhances creativity, not narrows it.  
B) ✓ Negative affect can make even easy tasks harder.  
C) ✓ Stress increases difficulty in problem solving.  
D) ✗ Relaxed users tend to be more forgiving, not less.  

**Correct:** B, C
