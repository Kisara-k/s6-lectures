## 7. Heuristics

## Questions

#### 1. What is the primary purpose of heuristics in usability evaluation?

A) Visibility of system status  
B) Support internal locus of control  
C) Recognition rather than recall  
D) Design dialogues to yield closure  

#### 3. Which statement best describes the difference between Nielsen’s heuristics and Shneiderman and Plaisant’s golden rules?

B) Both sets are identical in content and application

D) Nielsen’s heuristics only apply to web interfaces

B) It reduces the cognitive load by making options visible rather than hidden

#### 5. Which of the following best exemplifies “User control and freedom” in an interface?  
A) Providing undo and redo options  
B) Automatically saving user progress without notification  
C) Restricting navigation to prevent errors  
D) Forcing users to complete tasks in a fixed order  

#### 6. What is a key limitation of heuristic evaluation when performed by a single expert?

B) It tends to miss many usability problems

#### 7. According to research, what is the optimal number of evaluators in heuristic evaluation to balance cost and problem detection?  
A) One  
B) Two  
C) Four  
D) Ten  

#### 8. Which of the following are characteristics of vendor-specific guidelines like Apple’s or Microsoft’s?

B) They are general usability principles applicable to all systems

D) They replace the need for heuristic evaluation  

#### 9. What does “Aesthetic and minimalist design” in Nielsen’s heuristics emphasize?  
A) Including as much information as possible to inform users  
B) Removing irrelevant or rarely needed information to avoid clutter  
C) Using complex graphics to impress users  
D) Prioritizing decorative elements over functionality  

#### 10. Which of the following best describes the “Help users recognize, diagnose, and recover from errors” heuristic?

#### 12. Which of the following is NOT a feature of heuristic evaluation?

B) It requires users to perform tasks during evaluation  
C) It is an informal and relatively inexpensive method  
D) Multiple experts improve the coverage of usability issues found  

#### 13. What is meant by “Support internal locus of control” in Shneiderman and Plaisant’s rules?  
A) The system should control the user’s actions to prevent errors  
B) Users should feel they are in charge and that the system responds to their inputs  
C) The system should automate all decisions to reduce user effort

#### 14. Which of the following best illustrates “Design dialogues to yield closure”?  
A) Providing clear confirmation after completing a task  
B) Allowing users to leave tasks incomplete without feedback  
C) Forcing users to restart tasks if interrupted  
D) Avoiding any feedback to keep the interface simple  

#### 15. Why might vendor-specific guidelines be considered less flexible than general heuristics?

B) They ignore usability principles entirely  
C) They are only suggestions and rarely enforced  
D) They focus on theoretical rather than practical advice  

#### 16. What does “Reduce short-term memory load” encourage in interface design?  
A) Making users memorize instructions before using the system

D) Using complex navigation paths to challenge users  

#### 17. Which of the following statements about error prevention is true?

B) Error prevention is less important than providing detailed error messages  
C) Users should be allowed to make errors freely to learn from them  
D) Error prevention is only relevant for novice users  

#### 18. What is a major difference between usability inspection and user studies?  
A) Usability inspection involves experts evaluating the interface without users  
B) User studies rely on expert opinions only  
C) Usability inspection is more expensive and time-consuming  
D) User studies do not involve task performance  

#### 19. Which of the following is true about the “Flexibility and efficiency of use” heuristic?  
A) It suggests providing shortcuts for expert users while keeping the system simple for beginners  
B) It discourages customization to maintain consistency  
C) It focuses only on novice users’ needs  
D) It requires users to learn all commands before use  

#### 20. According to Nielsen and Landauer’s mathematical model, what kind of distribution predicts the number of usability problems found as more evaluators are added?  
A) Normal distribution  
B) Poisson distribution  
C) Uniform distribution  
D) Binomial distribution

## Answers

#### 1. What is the primary purpose of heuristics in usability evaluation?  
A) ✗ Heuristics are guidelines, not strict rules.  
B) ✓ Heuristics provide practical advice for assessing usability.  
C) ✗ Heuristics complement, not replace, user testing.  
D) ✓ Some heuristics are theoretically grounded, but the main purpose is practical guidance.  

**Correct:** B, D


#### 2. Which of the following are included in Nielsen’s 10 usability heuristics?  
A) ✓ Visibility of system status is one of Nielsen’s heuristics.  
B) ✗ Support internal locus of control is from Shneiderman and Plaisant’s rules.  
C) ✓ Recognition rather than recall is a Nielsen heuristic.  
D) ✗ Design dialogues to yield closure is from Shneiderman and Plaisant.  

**Correct:** A, C


#### 3. Which statement best describes the difference between Nielsen’s heuristics and Shneiderman and Plaisant’s golden rules?  
A) ✓ Nielsen focuses on error prevention and minimalist design; Shneiderman emphasizes user control and universal usability.  
B) ✗ The sets are similar but not identical.  
C) ✗ Shneiderman’s rules are general, not vendor-specific.  
D) ✗ Nielsen’s heuristics apply broadly, not just to web interfaces.  

**Correct:** A


#### 4. Why is “Recognition rather than recall” important in usability?  
A) ✗ It reduces memory load rather than encouraging memorization.  
B) ✓ It minimizes cognitive load by making options visible.  
C) ✗ It avoids forcing users to remember information.  
D) ✗ It applies to all users, not just experts.  

**Correct:** B


#### 5. Which of the following best exemplifies “User control and freedom” in an interface?  
A) ✓ Undo and redo options give users freedom to correct mistakes.  
B) ✗ Saving progress without notification reduces user control.  
C) ✗ Restricting navigation limits user freedom.  
D) ✗ Forcing task order reduces user control.  

**Correct:** A


#### 6. What is a key limitation of heuristic evaluation when performed by a single expert?  
A) ✗ It is inexpensive, not expensive.  
B) ✓ A single expert tends to miss many usability problems.  
C) ✗ It does not require user involvement.  
D) ✗ It evaluates the whole system, not just specific tasks.  

**Correct:** B


#### 7. According to research, what is the optimal number of evaluators in heuristic evaluation to balance cost and problem detection?  
A) ✗ One evaluator misses many issues.  
B) ✗ Two is often insufficient.  
C) ✓ Four evaluators provide the best cost-benefit ratio.  
D) ✗ Ten evaluators are usually unnecessary and costly.  

**Correct:** C


#### 8. Which of the following are characteristics of vendor-specific guidelines like Apple’s or Microsoft’s?  
A) ✓ They are prescriptive and platform-centered.  
B) ✗ They are not general principles for all systems.  
C) ✓ They focus on consistent look and feel within their ecosystem.  
D) ✗ They do not replace heuristic evaluation.  

**Correct:** A, C


#### 9. What does “Aesthetic and minimalist design” in Nielsen’s heuristics emphasize?  
A) ✗ Too much information causes clutter.  
B) ✓ Removing irrelevant info avoids clutter and distraction.  
C) ✗ Complex graphics can reduce usability.  
D) ✗ Functionality is prioritized over decoration.  

**Correct:** B


#### 10. Which of the following best describes the “Help users recognize, diagnose, and recover from errors” heuristic?

B) ✓ Clear, plain language error messages with solutions are best.  
C) ✗ Preventing all errors is ideal but not always possible.  
D) ✗ Blaming users is poor design practice.  

**Correct:** B


#### 11. How does “Cater to universal usability” differ from other heuristics?  
A) ✓ It focuses on designing for diverse users with different needs.  
B) ✗ It applies broadly, not only to users with disabilities.  
C) ✗ It does not focus only on experts.  
D) ✗ It encourages flexibility, not limiting options.

#### 12. Which of the following is NOT a feature of heuristic evaluation?  
A) ✗ Experts do evaluate the whole system.  
B) ✓ It does not require users to perform tasks.  
C) ✗ It is informal and inexpensive.  
D) ✗ Multiple experts improve issue coverage.  

**Correct:** B


#### 13. What is meant by “Support internal locus of control” in Shneiderman and Plaisant’s rules?

C) ✗ Automating all decisions reduces user control.
