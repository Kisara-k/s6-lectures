## Answers

#### 1. Which of the following are principles of Universal Design as outlined in the content?  
A) ✓ Size and space for approach and use ensures accessibility for various users.  
B) ✓ Flexibility in use allows different ways to use the design.  
C) ✓ Equitable use is a core principle ensuring accessibility for all users.  
D) ✗ High physical effort is contrary to the principle of low physical effort.  

**Correct:** A, B, C


#### 2. Multi-modal systems differ from multi-media systems primarily because:  
A) ✗ Multi-modal systems are not limited to visual media only.  
B) ✓ Multi-media systems use multiple media but may rely on a single sensory mode (e.g., all visual).  
C) ✓ Multi-modal systems use more than one sensory mode (e.g., visual and auditory).  
D) ✗ Multi-media systems do not always include sound and speech; they may but are not required to.  

**Correct:** B, C


#### 3. Which of the following statements about speech recognition challenges are true?  
A) ✗ Recognition systems perform worse on untrained speakers and accents.  
B) ✓ Semantics and context are needed for meaningful understanding beyond word recognition.  
C) ✓ Background noise interferes with recognition accuracy.  
D) ✗ Syntax variations do affect recognition because sentence structure can vary widely.  

**Correct:** B, C


#### 4. Regarding speech synthesis, which of the following are valid concerns or limitations?  
A) ✓ Requires headphones or creates ambient noise, which can be problematic.  
B) ✓ Prosody is difficult to replicate naturally, affecting naturalness.  
C) ✓ It can be intrusive in shared or quiet environments.  
D) ✗ Speech synthesis is harder to review and browse than text, so not always preferred.  

**Correct:** A, B, C


#### 5. Non-speech sounds are useful in interfaces because:  
A) ✓ Auditory feedback like key clicks can reduce typing errors.  
B) ✗ They are effective for transient information and background status.  
C) ✓ Redundant presentation with visual info helps resolve ambiguity.  
D) ✓ They are language and culture independent, unlike speech.  

**Correct:** A, C, D


#### 6. Which of the following correctly describe earcons?  
A) ✗ Earcons are synthetic sounds, not natural sounds (those are auditory icons).  
B) ✓ Family earcons group similar sounds for related actions or errors.  
C) ✓ Earcons are structured combinations of notes conveying information.  
D) ✗ Earcons lack natural mapping, making them harder to interpret than auditory icons.  

**Correct:** B, C


#### 7. In haptic interaction, which of the following are true?  
A) ✓ Cutaneous perception involves tactile sensations like skin vibrations.  
B) ✗ Electronic braille displays are cutaneous, not kinesthetic devices.  
C) ✓ Kinesthetics refers to movement, position, and force feedback.  
D) ✓ Haptic feedback can convey texture and resistance information.  

**Correct:** A, C, D


#### 8. Handwriting recognition technology faces which of the following challenges?  
A) ✓ Co-articulation effects between strokes complicate recognition.  
B) ✓ Stroke-based methods like Graffiti improve recognition accuracy and usability.  
C) ✗ Current systems are usable even without extensive training, though keyboards are often preferred.  
D) ✓ Personal differences in letter formation cause recognition difficulties.  

**Correct:** A, B, D


#### 9. Which of the following are appropriate assistive technologies or adaptations for users with disabilities?  
A) ✓ Screen readers and SonicFinder assist visually impaired users.  
B) ✓ Speech input/output can help users with dyslexia.  
C) ✓ Predictive systems and eyegaze assist users with physical impairments.  
D) ✓ Gesture and captions support hearing-impaired users.  

**Correct:** A, B, C, D


#### 10. Cultural differences can influence interface design by affecting:  
A) ✓ Gestures and color meanings differ across cultures.  
B) ✓ Language and symbol interpretation varies culturally.  
C) ✗ Physical size of input devices is not directly influenced by culture.  
D) ✓ Generation and political persuasion can affect interpretation of interface features.  

**Correct:** A, B, D
