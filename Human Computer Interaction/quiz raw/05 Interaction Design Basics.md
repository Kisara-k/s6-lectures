## 5. Interaction Design Basics

## Questions

#### 1. What does designing interactions rather than just interfaces emphasize in interaction design?  
A) Ignoring user behavior under stress since it is unpredictable  
B) Focusing solely on the visual appearance of buttons and menus  
C) Considering the entire sequence of user actions, not just the immediate interface elements  
D) Designing the system as well as supporting materials like manuals and tutorials  

#### 2. Which of the following best describe the "golden rule of design" in Human-Computer Interaction?  
A) Design systems assuming users will never make errors  
B) Treat users as carefully as physical materials, anticipating human error  
C) Prioritize aesthetics over functionality to attract users  
D) Understand both the capabilities and limitations of computers and people  

#### 3. In the design process, what is the primary purpose of scenarios?  
A) To communicate design ideas, validate models, and understand user dynamics  
B) To serve as fictional stories unrelated to actual user needs  
C) To provide a single, linear path through the system without alternatives  
D) To replace prototypes and detailed specifications entirely  

#### 4. Which statements about personas are true?  
A) Personas are used as surrogate users to guide design decisions  
B) Personas should always represent the designer’s own characteristics for accuracy  
C) Personas help designers empathize with typical users by providing detailed, realistic profiles  
D) Personas must be real individuals who will use the system  

#### 5. When designing navigation for a system, which of the following are important considerations?  
A) Using breadcrumbs to show the path through a website hierarchy  
B) Maximizing the depth of menu hierarchies to reduce screen clutter  
C) Avoiding any form of global navigation to keep users focused on the current screen  
D) Providing clear indicators of current location, possible actions, and navigation history  

#### 6. What are the potential pitfalls of prototyping in interaction design?  
A) Prototyping guarantees a perfect design on the first attempt  
B) Prototyping should replace user evaluation and feedback  
C) Incrementally improving without a clear goal can lead to wasted effort  
D) Starting with a well-understood problem and clear objectives is essential  

#### 7. Which of the following statements about affordances in user interface design are correct?  
A) Affordances are culturally universal and do not depend on user experience  
B) Icons that resemble physical objects can help users understand their function  
C) Screen objects that look like buttons afford clicking, regardless of actual functionality  
D) Affordances are physical or visual cues that suggest how an object should be used  

#### 8. Regarding alignment and layout in screen design, which principles are valid?  
A) Centered text in buttons always improves scanning and usability  
B) Logical grouping of related items should be reflected by physical proximity and visual cues  
C) Text in left-to-right languages should generally be left-aligned for readability  
D) Numbers should be aligned by their decimal points or right-aligned to aid comparison  

#### 9. What challenges arise in localization and internationalization of interfaces?  
A) Cultural differences can affect the meaning of symbols like ticks and crosses  
B) Layout changes such as text direction and size must be considered  
C) Simply translating text is sufficient for global usability  
D) Using platform standards and consistent styles can help manage cross-cultural issues  

#### 10. Which of the following statements about navigation structures and their cognitive impact are true?  
A) Network diagrams show possible paths including branches and are more task-oriented than hierarchies  
B) Deep hierarchical menus are easier for users to navigate than broad menus  
C) Optimal navigation balances breadth and depth to reduce cognitive load  
D) Miller’s 7 ± 2 rule applies to menu size, so menus should have no more than 7 items

## Answers

#### 1. What does designing interactions rather than just interfaces emphasize in interaction design?  
A) ✗ Ignoring user behavior under stress contradicts the design principle of designing for human error  
B) ✗ Focuses only on visual appearance, which is interface design, not interaction design  
C) ✓ Considers the full sequence of user actions, not just immediate interface elements  
D) ✓ Includes system and supporting materials like manuals and tutorials  

**Correct:** C, D


#### 2. Which of the following best describe the "golden rule of design" in Human-Computer Interaction?  
A) ✗ Assuming users never make errors is unrealistic and poor design  
B) ✓ Treating users as carefully as physical materials and designing for errors is key  
C) ✗ Prioritizing aesthetics over functionality is not the golden rule  
D) ✓ Understanding both computer and human capabilities and limitations is essential  

**Correct:** B, D


#### 3. In the design process, what is the primary purpose of scenarios?  
A) ✓ Scenarios communicate design ideas, validate models, and understand dynamics  
B) ✗ Scenarios are related to real user needs, not unrelated fiction  
C) ✗ Scenarios are not limited to a single linear path; multiple scenarios are used  
D) ✗ Scenarios complement, not replace, prototypes and specifications  

**Correct:** A


#### 4. Which statements about personas are true?  
A) ✓ Personas serve as surrogate users to guide design decisions  
B) ✗ Personas should represent typical users, not the designer’s own traits  
C) ✓ Personas help designers empathize by providing detailed, realistic profiles  
D) ✗ Personas are often fictional or composite, not necessarily real individuals  

**Correct:** A, C


#### 5. When designing navigation for a system, which of the following are important considerations?  
A) ✓ Breadcrumbs effectively show the path through a website hierarchy  
B) ✗ Deep hierarchies are difficult to navigate and should be minimized  
C) ✗ Avoiding global navigation reduces usability and user orientation  
D) ✓ Clear indicators of location, actions, and history are crucial for navigation  

**Correct:** A, D


#### 6. What are the potential pitfalls of prototyping in interaction design?  
A) ✗ Prototyping does not guarantee a perfect first design  
B) ✗ Prototyping should be combined with user evaluation, not replace it  
C) ✓ Incremental improvement without clear goals wastes effort  
D) ✓ Starting with a clear understanding and objectives is essential  

**Correct:** C, D


#### 7. Which of the following statements about affordances in user interface design are correct?  
A) ✗ Affordances depend on culture and user experience, not universal  
B) ✓ Icons resembling physical objects help users understand function  
C) ✗ Objects that look like buttons only afford clicking if they actually function as buttons  
D) ✓ Affordances are cues suggesting how to use an object  

**Correct:** B, D


#### 8. Regarding alignment and layout in screen design, which principles are valid?  
A) ✗ Centered text in buttons often hinders scanning and usability  
B) ✓ Group related items physically and visually for clarity  
C) ✓ Left-align text in left-to-right languages for readability  
D) ✓ Align numbers by decimal or right-align for easy comparison  

**Correct:** B, C, D


#### 9. What challenges arise in localization and internationalization of interfaces?  
A) ✓ Cultural differences affect symbol meanings like ticks and crosses  
B) ✓ Layout changes such as text direction and size must be addressed  
C) ✗ Translation alone is insufficient for global usability  
D) ✓ Platform standards and consistent styles help manage cultural issues  

**Correct:** A, B, D


#### 10. Which of the following statements about navigation structures and their cognitive impact are true?  
A) ✓ Network diagrams show branching paths and are more task-oriented than hierarchies  
B) ✗ Deep hierarchies are harder to navigate than broad menus  
C) ✓ Balancing breadth and depth reduces cognitive load and improves navigation  
D) ✗ Miller’s 7 ± 2 applies to short-term memory, not strict menu size limits  

**Correct:** A, C
