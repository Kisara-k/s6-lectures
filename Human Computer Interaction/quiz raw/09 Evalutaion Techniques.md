## 9. Evalutaion Techniques

## Questions

#### 1. Which of the following are primary goals of evaluation in HCI?  
A) Maximize system performance speed  
B) Assess the effect of the interface on the user  
C) Assess the extent of system functionality  
D) Identify specific usability problems  

#### 2. In a Cognitive Walkthrough, which aspects are explicitly considered during task analysis?  
A) The impact of interaction on the user  
B) The cognitive processes required by the user  
C) Whether the design leads the user to generate correct goals  
D) The aesthetic appeal of the interface  

#### 3. Heuristic Evaluation involves which of the following?  
A) Experts checking if usability heuristics are violated  
B) Using psychological principles to predict user errors  
C) Users performing tasks while thinking aloud  
D) Debugging design based on established usability criteria  

#### 4. Which statements about laboratory studies in HCI evaluation are true?  
A) They provide a natural environment for user interaction  
B) They are ideal for observing multiple users cooperating in context  
C) They allow use of specialist equipment and controlled conditions  
D) They may lack real-world context affecting user behavior  

#### 5. In experimental evaluation, what distinguishes an independent variable (IV) from a dependent variable (DV)?  
A) DV is the characteristic changed to create different conditions  
B) DV is the outcome measured to observe effects of IV changes  
C) IV is manipulated by the evaluator to test hypotheses  
D) IV is the characteristic measured to assess performance  

#### 6. Which of the following are advantages of within-groups experimental design?  
A) It eliminates transfer of learning effects between conditions  
B) Each subject experiences all experimental conditions  
C) It completely removes user variation from results  
D) It requires fewer subjects than between-groups design  

#### 7. When analyzing experimental data, which of the following statements are correct?  
A) Contingency tables classify data by discrete attributes and count occurrences  
B) Parametric tests assume normal distribution and are generally more powerful  
C) The choice of statistical test depends on the type of data and information needed  
D) Non-parametric tests require data to be normally distributed  

#### 8. Which of the following are challenges specific to group-based experimental studies in HCI?  
A) Difficulty in designing tasks that encourage cooperation and multiple communication channels  
B) Coordinating larger numbers of subjects and scheduling difficulties  
C) Simplified data gathering due to fewer data sources  
D) Reduced variation in user behavior compared to single-user studies  

#### 9. Regarding Think Aloud and Cooperative Evaluation methods, which statements are true?  
A) Cooperative Evaluation tends to be less constrained and encourages user criticism  
B) Think Aloud is completely objective and free from user bias  
C) Think Aloud requires users to verbalize their thoughts during task performance  
D) Cooperative Evaluation allows interaction and questioning between user and evaluator  

#### 10. Which physiological measurements can be used to infer user emotional or cognitive states during interface interaction?  
A) Electroencephalogram (EEG) measuring brain electrical activity  
B) Keyboard typing speed as a direct physiological measure  
C) Galvanic Skin Response (GSR) measuring sweat gland activity  
D) Eye tracking fixations and saccades

## Answers

#### 1. Which of the following are primary goals of evaluation in HCI?  
A) ✗ Maximize system performance speed — Not a primary evaluation goal; speed may be measured but not always maximized.  
B) ✓ Assess the effect of the interface on the user — Understanding user impact is fundamental.  
C) ✓ Assess the extent of system functionality — This is a core goal to verify what the system can do.  
D) ✓ Identify specific usability problems — Finding problems is essential to improve design.  

**Correct:** B, C, D


#### 2. In a Cognitive Walkthrough, which aspects are explicitly considered during task analysis?  
A) ✓ The impact of interaction on the user — Evaluates how interaction affects user cognition and behavior.  
B) ✓ The cognitive processes required by the user — Central to understanding user learning and problem areas.  
C) ✓ Whether the design leads the user to generate correct goals — Key to ensuring users can form correct intentions.  
D) ✗ The aesthetic appeal of the interface — Not part of cognitive walkthrough focus, which is on usability and learning.  

**Correct:** A, B, C


#### 3. Heuristic Evaluation involves which of the following?  
A) ✓ Experts checking if usability heuristics are violated — Core activity in heuristic evaluation.  
B) ✗ Using psychological principles to predict user errors — More related to cognitive walkthrough.  
C) ✗ Users performing tasks while thinking aloud — This is a different method (Think Aloud).  
D) ✓ Debugging design based on established usability criteria — Heuristic evaluation aims to identify design flaws.  

**Correct:** A, D


#### 4. Which statements about laboratory studies in HCI evaluation are true?  
A) ✗ They provide a natural environment for user interaction — Labs are controlled, not natural environments.  
B) ✗ They are ideal for observing multiple users cooperating in context — Labs often limit natural group interaction.  
C) ✓ They allow use of specialist equipment and controlled conditions — Labs are ideal for controlled setups.  
D) ✓ They may lack real-world context affecting user behavior — A known disadvantage of lab studies.  

**Correct:** C, D


#### 5. In experimental evaluation, what distinguishes an independent variable (IV) from a dependent variable (DV)?  
A) ✗ DV is the characteristic changed to create different conditions — This describes the IV.  
B) ✓ DV is the outcome measured to observe effects of IV changes — DV is what is measured in response.  
C) ✓ IV is manipulated by the evaluator to test hypotheses — IV is the factor changed deliberately.  
D) ✗ IV is the characteristic measured to assess performance — This describes the DV.  

**Correct:** B, C


#### 6. Which of the following are advantages of within-groups experimental design?  
A) ✗ It eliminates transfer of learning effects between conditions — Transfer of learning is a potential problem, not eliminated.  
B) ✓ Each subject experiences all experimental conditions — Defining feature of within-groups design.  
C) ✗ It completely removes user variation from results — User variation still exists but is reduced.  
D) ✓ It requires fewer subjects than between-groups design — Because each subject acts as their own control.  

**Correct:** B, D


#### 7. When analyzing experimental data, which of the following statements are correct?  
A) ✓ Contingency tables classify data by discrete attributes and count occurrences — Correct description of contingency tables.  
B) ✓ Parametric tests assume normal distribution and are generally more powerful — True for parametric tests.  
C) ✓ The choice of statistical test depends on the type of data and information needed — Essential consideration in analysis.  
D) ✗ Non-parametric tests require data to be normally distributed — They do not assume normality.  

**Correct:** A, B, C


#### 8. Which of the following are challenges specific to group-based experimental studies in HCI?  
A) ✓ Difficulty in designing tasks that encourage cooperation and multiple communication channels — Group tasks must foster interaction.  
B) ✓ Coordinating larger numbers of subjects and scheduling difficulties — More subjects complicate logistics.  
C) ✗ Simplified data gathering due to fewer data sources — Data gathering is more complex with multiple participants.  
D) ✗ Reduced variation in user behavior compared to single-user studies — Group studies often have more variation.  

**Correct:** A, B


#### 9. Regarding Think Aloud and Cooperative Evaluation methods, which statements are true?  
A) ✓ Cooperative Evaluation tends to be less constrained and encourages user criticism — It fosters open dialogue and critique.  
B) ✗ Think Aloud is completely objective and free from user bias — It is subjective and can influence task performance.  
C) ✓ Think Aloud requires users to verbalize their thoughts during task performance — Core feature of Think Aloud.  
D) ✓ Cooperative Evaluation allows interaction and questioning between user and evaluator — Distinguishing feature of cooperative evaluation.  

**Correct:** A, C, D


#### 10. Which physiological measurements can be used to infer user emotional or cognitive states during interface interaction?  
A) ✓ Electroencephalogram (EEG) measuring brain electrical activity — Provides data on brain states.  
B) ✗ Keyboard typing speed as a direct physiological measure — Behavioral measure, not physiological.  
C) ✓ Galvanic Skin Response (GSR) measuring sweat gland activity — Indicates emotional arousal.  
D) ✓ Eye tracking fixations and saccades — Reflect cognitive processing and attention.  

**Correct:** A, C, D
