## Answers

#### 1. What are the three key aspects of design emphasized in Human-Computer Interaction?  
A) ✗ Efficient, effective, error-free — Important but not the core triad highlighted.  
B) ✗ Functional, enjoyable, attractive — Partially correct but not the exact three emphasized terms.  
C) ✗ Available, acceptable, ubiquitous — Related to usage but not the three key design aspects.  
D) ✓ Useful, usable, used — These are the three “use” words defining design goals in HCI.  

**Correct:** D


#### 2. Which of the following statements about ubiquitous computing (ubicomp) and wearable computing are true?  
A) ✓ Ubiquitous computing eliminates the divide between computer and artefact — This is the essence of ubicomp.  
B) ✓ Wearable computing eliminates the divide between computer and user — Wearable/cyborg concept merges user and computer.  
C) ✗ Wearable computing is unrelated to pervasive sensor technologies — Incorrect; wearables rely heavily on sensors.  
D) ✗ Ubiquitous computing primarily focuses on desktop computing environments — Incorrect; ubicomp is about pervasive, everywhere computing.  

**Correct:** A, B


#### 3. Why is it often difficult to identify the right questions to ask in HCI research?  
A) ✗ Because HCI only focuses on technical implementation, not user needs — False; HCI focuses heavily on users.  
B) ✓ Because the right questions require deep understanding of both humans and systems — Correct; understanding both is crucial.  
C) ✓ Because the complexity of human behavior and technology interaction makes it challenging — Correct; complexity is emphasized.  
D) ✗ Because users are always changing their preferences — True but not the main reason given.  

**Correct:** B, C


#### 4. Which of the following are challenges in designing intelligent interactive systems?  
A) ✗ Designing interfaces that rely solely on single-modal input for accuracy — Incorrect; multimodal input is preferred.  
B) ✓ Developing flexible multimodal interaction algorithms that fuse multiple input modalities — Correct; explicitly stated as a challenge.  
C) ✗ Ignoring context modeling to simplify system design — Incorrect; context modeling is needed to improve performance.  
D) ✓ Leveraging crowdsourcing and social media to improve language models — Correct; mentioned as a research direction.  

**Correct:** B, D


#### 5. The Gesture Keyboard (ShapeWriter) exemplifies which of the following characteristics?  
A) ✓ It exploits language redundancies to amplify text input speed — Correct; this is a key feature.  
B) ✓ It supports a continuous transition from novice to expert user behavior — Correct; skill acquisition described as continuous.  
C) ✓ It enables users to write text at speeds up to 99 words per minute for phrases — Correct; record speeds mentioned.  
D) ✗ It was first released commercially as a standalone hardware device — Incorrect; it was software-based, released on IBM alphaWorks.  

**Correct:** A, B, C


#### 6. Which of the following best describe the influence of experimental psychology on HCI research?  
A) ✗ It discourages the use of qualitative research methods like ethnography — Incorrect; qualitative methods are widely used beyond experiments.  
B) ✓ It provides models of human neuromuscular motor control and perceptual abilities — Correct; important theoretical foundation.  
C) ✓ It introduced the controlled experiment paradigm with independent and dependent variables — Correct; fundamental influence.  
D) ✗ It ensures all HCI experiments have perfect ecological validity — Incorrect; ecological validity is often a challenge.  

**Correct:** B, C


#### 7. What is the tradeoff between internal and external validity in HCI experiments?  
A) ✓ External validity refers to how well results generalize to real-world use — Correct; this is the definition.  
B) ✗ Internal validity is irrelevant if the experiment uses large sample sizes — Incorrect; internal validity is always important.  
C) ✓ High internal validity can reduce the ecological validity of findings — Correct; tightly controlled experiments may lack real-world relevance.  
D) ✗ Increasing internal validity always improves external validity — False; often a tradeoff exists.  

**Correct:** A, C


#### 8. Which of the following methods are used in HCI research beyond controlled experiments?  
A) ✓ Think-aloud protocols and structured interviews — Correct; qualitative methods mentioned.  
B) ✓ Automated log analysis and participatory design — Correct; also common methods.  
C) ✗ Only quantitative surveys and statistical tests — Incorrect; qualitative methods are also important.  
D) ✓ Video coding and transcription practices — Correct; used for qualitative data analysis.  

**Correct:** A, B, D


#### 9. Which historical milestones are correctly matched with their contributions to HCI?  
A) ✓ Mark Weiser – coined the term “Ubiquitous computing” — Correct; he introduced the term.  
B) ✗ Apple Newton – first commercial computer with a GUI — Incorrect; Macintosh was first commercial GUI computer.  
C) ✓ Xerox PARC – invention of the WIMP paradigm (Windows, Icons, Menus, Pointer) — Correct; foundational GUI concept.  
D) ✓ Ivan Sutherland’s Sketchpad – first graphical user interface and computer graphics — Correct; key milestone.  

**Correct:** A, C, D


#### 10. Which statements about the current research frontier in HCI are accurate?  
A) ✓ Developing refined theories for modeling human behavior remains important — Correct; ongoing research area.  
B) ✗ Crowdsourcing is irrelevant to modern HCI language modeling — Incorrect; crowdsourcing is important for language models.  
C) ✓ Pervasive and ubiquitous computing are key focus areas — Correct; explicitly stated.  
D) ✗ Interaction with wall-sized displays is considered outdated technology — Incorrect; still a current research frontier.  

**Correct:** A, C
