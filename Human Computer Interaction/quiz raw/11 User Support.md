## 11. User Support

## Questions

#### 1. Which of the following are essential requirements for effective user support systems?  
A) Consistency between help system and paper documentation  
B) Continuous availability concurrent with the main application  
C) Help content that is problem-oriented and specific only  
D) Flexibility allowing interaction appropriate to user experience and task  

#### 2. What are the main differences between help and documentation in user support?  
A) Help is designed for quick reference, documentation is designed for tutorials  
B) Both help and documentation must follow the same design principles  
C) Help is problem-oriented and specific, while documentation is system-oriented and general  
D) Documentation is always available online, help is only in printed manuals  

#### 3. Which of the following statements about command assistance and command prompts are true?  
A) Command prompts provide information about correct usage after an error occurs  
B) Command assistance assumes the user knows what to look for  
C) Both command assistance and command prompts are effective for complex task guidance  
D) Command prompts are primarily useful for handling syntactic errors  

#### 4. Regarding context-sensitive help and online tutorials, which statements are accurate?  
A) Online tutorials typically require a test environment for user practice  
B) Tooltips are an example of context-sensitive help  
C) Context-sensitive help interprets help requests based on the current user context  
D) Online tutorials are always flexible and adapt to user needs  

#### 5. What are the characteristics and limitations of wizards and assistants in user support?  
A) Assistants monitor user behavior and offer contextual advice  
B) Wizards guide users step-by-step through tasks using user responses  
C) Assistants must be under user control to avoid irritation  
D) Wizards provide unlimited flexibility in task execution  

#### 6. Which challenges are associated with adaptive help systems?  
A) Deciding the scope and extent of adaptation  
B) Determining who controls the interaction between user and system  
C) High knowledge requirements for context, user, task, and domain  
D) Ensuring the help system is always unobtrusive and never interrupts the user  

#### 7. In user modeling for help systems, which approaches are commonly used?  
A) Stereotypes classifying users into predefined categories  
B) Overlay models comparing actual user behavior to an ideal expert model  
C) Quantification based on a quantitative measure of user knowledge  
D) Randomized user profiling to ensure diverse help delivery  

#### 8. What are typical problems encountered in knowledge representation and modeling for user support?  
A) Interpretation of user behavior  
B) Unlimited resources for knowledge storage and processing  
C) Knowledge acquisition difficulties  
D) Representing interleaved and complex user tasks  

#### 9. When designing user support, which presentation issues must be considered?  
A) Use of complex, technical language to ensure precision  
B) Clear indication of summary and example information  
C) Display methods such as pop-up boxes, split screen, or new windows  
D) How help is requested (e.g., command, button, separate application)  

#### 10. Which implementation issues affect the design of help systems?  
A) Availability of resources like screen space, memory, and processing speed  
B) Whether help is implemented as an operating system command, meta command, or application feature  
C) Ensuring help systems are inflexible to maintain consistency  
D) Structure of help data, such as single file, file hierarchy, or database

## Answers

#### 1. Which of the following are essential requirements for effective user support systems?  
A) ✓ Consistency between help system and paper documentation — Consistency avoids confusion and supports user learning.  
B) ✓ Continuous availability concurrent with the main application — Availability is critical so users can access help when needed.  
C) ✗ Help content that is problem-oriented and specific only — Help should be problem-oriented, but documentation is also important; this option is too narrow.  
D) ✓ Flexibility allowing interaction appropriate to user experience and task — Flexibility ensures help suits different user needs and contexts.  

**Correct:** A, B, D


#### 2. What are the main differences between help and documentation in user support?  
A) ✗ Help is designed for quick reference, documentation is designed for tutorials — Help includes quick reference but tutorials are a separate type of support, not necessarily documentation.  
B) ✓ Both help and documentation must follow the same design principles — Consistent design principles apply to both for usability.  
C) ✓ Help is problem-oriented and specific, while documentation is system-oriented and general — This distinction is fundamental in user support design.  
D) ✗ Documentation is always available online, help is only in printed manuals — Both can be online or printed; this is inaccurate.  

**Correct:** B, C


#### 3. Which of the following statements about command assistance and command prompts are true?  
A) ✓ Command prompts provide information about correct usage after an error occurs — They help correct syntactic mistakes by prompting usage.  
B) ✓ Command assistance assumes the user knows what to look for — It requires prior knowledge to request help on a specific command.  
C) ✗ Both command assistance and command prompts are effective for complex task guidance — They are mainly for simple, command-level help, not complex tasks.  
D) ✓ Command prompts are primarily useful for handling syntactic errors — They address simple syntax errors effectively.  

**Correct:** A, B, D


#### 4. Regarding context-sensitive help and online tutorials, which statements are accurate?  
A) ✓ Online tutorials typically require a test environment for user practice — Tutorials often use a safe environment for learning basics.  
B) ✓ Tooltips are an example of context-sensitive help — Tooltips provide help relevant to the current interface element.  
C) ✓ Context-sensitive help interprets help requests based on the current user context — This is the defining feature of context-sensitive help.  
D) ✗ Online tutorials are always flexible and adapt to user needs — Tutorials are often inflexible, as noted in the content.  

**Correct:** A, B, C


#### 5. What are the characteristics and limitations of wizards and assistants in user support?  
A) ✓ Assistants monitor user behavior and offer contextual advice — Assistants provide proactive, context-aware help.  
B) ✓ Wizards guide users step-by-step through tasks using user responses — This is the core function of wizards.  
C) ✓ Assistants must be under user control to avoid irritation — User control is necessary to prevent annoyance (e.g., MS paperclip).  
D) ✗ Wizards provide unlimited flexibility in task execution — Wizards constrain task execution to ensure safe completion.  

**Correct:** A, B, C


#### 6. Which challenges are associated with adaptive help systems?  
A) ✓ Deciding the scope and extent of adaptation — Defining what and how much to adapt is a major challenge.  
B) ✓ Determining who controls the interaction between user and system — Control and initiative are key design issues.  
C) ✓ High knowledge requirements for context, user, task, and domain — Adaptive systems need extensive knowledge to personalize help.  
D) ✗ Ensuring the help system is always unobtrusive and never interrupts the user — Adaptive help may interrupt if designed to do so; unobtrusiveness is a goal but not guaranteed.  

**Correct:** A, B, C


#### 7. In user modeling for help systems, which approaches are commonly used?  
A) ✓ Stereotypes classifying users into predefined categories — Categorization simplifies modeling.  
B) ✓ Overlay models comparing actual user behavior to an ideal expert model — Overlay models track deviations from expert use.  
C) ✓ Quantification based on a quantitative measure of user knowledge — Users can be modeled by expertise levels.  
D) ✗ Randomized user profiling to ensure diverse help delivery — Random profiling is not a recognized or effective approach.  

**Correct:** A, B, C


#### 8. What are typical problems encountered in knowledge representation and modeling for user support?  
A) ✓ Interpretation of user behavior — Understanding user actions accurately is complex.  
B) ✗ Unlimited resources for knowledge storage and processing — Resources are limited, posing constraints.  
C) ✓ Knowledge acquisition difficulties — Gathering and encoding knowledge is challenging.  
D) ✓ Representing interleaved and complex user tasks — Modeling overlapping tasks is difficult.  

**Correct:** A, C, D


#### 9. When designing user support, which presentation issues must be considered?  
A) ✗ Use of complex, technical language to ensure precision — Help should use clear, familiar, instructional language, not complex jargon.  
B) ✓ Clear indication of summary and example information — Summaries and examples aid comprehension.  
C) ✓ Display methods such as pop-up boxes, split screen, or new windows — Presentation format impacts user experience.  
D) ✓ How help is requested (e.g., command, button, separate application) — Access method affects usability.  

**Correct:** B, C, D


#### 10. Which implementation issues affect the design of help systems?  
A) ✓ Availability of resources like screen space, memory, and processing speed — Resource constraints influence design choices.  
B) ✓ Whether help is implemented as an operating system command, meta command, or application feature — Implementation affects integration and access.  
C) ✗ Ensuring help systems are inflexible to maintain consistency — Flexibility and extensibility are important, inflexibility is a drawback.  
D) ✓ Structure of help data, such as single file, file hierarchy, or database — Data structure impacts flexibility and browsing.  

**Correct:** A, B, D
