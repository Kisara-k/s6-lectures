## Answers

#### 1. Which of the following are considered input devices in human-computer interaction?  
A) ✓ Touch-sensitive screens detect finger or stylus input, so are input devices.  
B) ✓ Keyboard is a primary input device for text entry.  
C) ✗ RAM is memory, not an input device.  
D) ✓ Digital paper (scan) can be used as input by scanning documents.  

**Correct:** A, B, D


#### 2. What are the main reasons why the QWERTY keyboard layout remains dominant despite alternative layouts like Dvorak offering speed improvements?  
A) ✓ Large social base of QWERTY typists creates market resistance to change.  
B) ✗ Dvorak is biased towards the right hand, not the left, and this bias is not a main reason for QWERTY dominance.  
C) ✗ QWERTY was designed to prevent typewriter jamming, but this is historical, not a current reason for dominance.  
D) ✓ Retraining and reluctance to change due to social and market pressures keep QWERTY dominant.  

**Correct:** A, D


#### 3. Which characteristics correctly describe a computer mouse as a pointing device?  
A) ✓ Mouse movement is relative, moving the cursor based on changes, not fixed position.  
B) ✗ Mouse detects relative movement, not absolute position on the desk.  
C) ✗ Mouse on desktop requires physical space but usually does not cause arm fatigue; arm fatigue is more common with touchscreens or prolonged use.  
D) ✓ Mouse moves in (x, z) plane (desk surface), cursor moves in (x, y) plane (screen).  

**Correct:** A, D


#### 4. Which of the following are advantages and disadvantages of touch-sensitive screens?  
A) ✓ Touchscreens are fast and require no specialized pointer.  
B) ✓ Lifting the arm repeatedly to interact can cause fatigue.  
C) ✓ Finger marks and imprecision are common disadvantages.  
D) ✗ Touchscreens are generally imprecise, making small region selection difficult.  

**Correct:** A, B, C


#### 5. What are the main challenges faced by handwriting recognition systems?  
A) ✓ Capturing stroke path and pressure naturally is technically difficult.  
B) ✓ Segmenting joined-up writing into letters is a major challenge.  
C) ✓ Interpreting different handwriting styles complicates recognition.  
D) ✗ Large vocabularies and external noise are challenges for speech recognition, not handwriting.  

**Correct:** A, B, C


#### 6. Which statements about virtual reality (VR) headsets and related issues are correct?  
A) ✗ VR sickness is not mainly due to low resolution but due to conflicting sensory cues.  
B) ✓ Motion sickness is caused by lag between head movement and display update.  
C) ✓ Depth perception conflicts arise because eyes focus on a fixed plane while stereo images suggest different distances.  
D) ✓ VR headsets provide slightly different images to each eye to create 3D effect.  

**Correct:** B, C, D


#### 7. Which of the following are true about bitmap display characteristics?  
A) ✓ Anti-aliasing reduces jagged edges by smoothing with shades of line colour.  
B) ✓ Aspect ratio is the ratio of width to height of the display.  
C) ✓ Colour depth defines how many colours each pixel can display.  
D) ✗ Resolution can mean pixel count (width x height) or pixel density (dpi), not always dpi alone.  

**Correct:** A, B, C


#### 8. Regarding printing technologies, which statements are accurate?  
A) ✓ Laser printers use electrostatic charge on a drum to pick up toner powder.  
B) ✓ Higher dpi generally improves resolution but can reduce printing speed.  
C) ✗ Ink-jet printers spray tiny blobs of ink, not melted wax.  
D) ✓ Dot-matrix printers use pins striking an inked ribbon to form dots on paper.  

**Correct:** A, B, D


#### 9. What are the main limitations on interactive performance in computer systems?  
A) ✗ Faster networks improve performance but can introduce latency or congestion; not always without drawbacks.  
B) ✓ Storage channel bound refers to bottlenecks transferring data from disk to memory.  
C) ✓ Graphics bound means display updates require heavy processing.  
D) ✓ Computation bound means slow processing frustrates users.  

**Correct:** B, C, D


#### 10. Which of the following correctly describe compression techniques used for storage?  
A) ✗ JPEG is a lossy compression format, not lossless.  
B) ✓ Lossy compression reduces data size by exploiting human perception limits.  
C) ✓ Lossless compression allows exact recovery of original data.  
D) ✓ MP3 reduces accuracy of sounds that are masked or drowned out, a lossy method.  

**Correct:** B, C, D
