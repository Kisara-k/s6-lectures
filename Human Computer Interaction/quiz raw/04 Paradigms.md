## 4. Paradigms

## Questions

A) Programming languages  
B) Time-sharing  
C) Batch processing  
D) Graphical displays

B) By relating computing tasks to familiar real-world activities

B) It was a closed system before the WWW

## Answers

#### 1. What are considered paradigm shifts in the history of interactive system design?  
A) ✗ Programming languages are important but not listed as a paradigm shift here.  
B) ✓ Time-sharing introduced interactive computing, a major shift.  
C) ✓ Batch processing is the initial paradigm and a foundational shift.  
D) ✓ Graphical displays changed interaction methods significantly.  

**Correct:** B, C, D


#### 2. Which of the following statements about direct manipulation interfaces are true?  
A) ✓ Direct manipulation replaces language commands with actions.  
B) ✓ Visibility of objects and incremental action are key features.  
C) ✗ Command-line input is contrary to direct manipulation principles.  
D) ✓ Reversibility encourages exploration, a hallmark of direct manipulation.  

**Correct:** A, B, D


#### 3. How does the metaphor paradigm aid human-computer interaction?  
A) ✓ Metaphors serve as effective teaching techniques by leveraging familiar concepts.  
B) ✓ Metaphors relate computing to familiar real-world activities, aiding understanding.  
C) ✗ Metaphors can introduce cultural bias, so they are not culturally neutral.  
D) ✗ Not all tasks fit perfectly into a single metaphor; this is a known limitation.  

**Correct:** A, B


#### 4. Which of the following best describe the characteristics of the WIMP interface?  
A) ✓ Icons, menus, and pointers are core WIMP interaction elements.  
B) ✗ WIMP interfaces are action-based, not primarily natural language commands.  
C) ✓ Windows partition dialogue and support multitasking.  
D) ✗ Batch processing is an earlier paradigm, not related to WIMP interfaces.  

**Correct:** A, C


#### 5. What challenges or limitations are associated with hypertext as originally conceived?  
A) ✗ Universal protocols like HTTP were introduced later with the WWW.  
B) ✓ Hypertext was originally a closed system before the WWW opened it up.  
C) ✗ Nelson’s Xanadu project remains unrealized, so it did not fully realize hypertext’s potential.  
D) ✗ Hypertext is non-linear browsing, not linear.  

**Correct:** B


#### 6. Which of the following are true about ubiquitous computing?  
A) ✗ It aims to make computers disappear, not more apparent.  
B) ✓ Designing interactions that don’t demand user intention is key.  
C) ✗ Ubiquitous computing was conceptualized in the late 1980s/early 1990s, not the 1940s.  
D) ✓ Embedding computing invisibly into the physical world is a core goal.  

**Correct:** B, D


#### 7. What roles do programming toolkits play in interactive system development?  
A) ✓ They provide building blocks for complex interactive systems.  
B) ✓ They augment human intellect by simplifying programming tasks.  
C) ✗ They do not replace user interfaces but support their creation.  
D) ✗ Demonstrations like Engelbart’s NLS were in the 1960s, not the 1980s.  

**Correct:** A, B


#### 8. Which of the following statements about agent-based interfaces are correct?  
A) ✗ They do not eliminate direct manipulation but complement it.  
B) ✓ They return to language-based interaction with added proactivity and intelligence.  
C) ✗ Agent interfaces rely on language input, not solely graphical interfaces.  
D) ✓ Avatars and natural language processing are examples of agent-based interfaces.  

**Correct:** B, D


#### 9. How did time-sharing contribute to the evolution of interactive computing?  
A) ✓ Video display units provided more suitable visual media, linked to interactive computing.  
B) ✗ Time-sharing was developed mainly in the 1960s, not the 1980s.  
C) ✗ Batch processing preceded time-sharing and was not interactive.  
D) ✓ It allowed multiple users to share a single computer simultaneously.  

**Correct:** A, D


#### 10. What are the key features of multimodality in human-computer interaction?  
A) ✗ Emphasis is on simultaneous, not sequential, use of modes.  
B) ✓ Integration of various input/output channels enhances interaction.  
C) ✗ Multimodality explicitly moves beyond single-user, single-computer systems.  
D) ✓ Use of multiple communication channels simultaneously is central.  

**Correct:** B, D
