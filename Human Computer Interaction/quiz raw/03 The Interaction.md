## Answers

#### 1. What are the main components of Abowd and Beale's interaction framework?  
A) ✓ The framework explicitly includes user, input, system, and output as four parts.  
B) ✗ These are stages in Norman’s model, not Abowd and Beale’s components.  
C) ✗ These are terms related to interaction but not the four parts of Abowd and Beale’s model.  
D) ✗ These are interaction styles, not components of the framework.  

**Correct:** A


#### 2. In Norman's model of interaction, which sequence correctly represents the stages a user goes through?  
A) ✗ Incorrect order; goal establishment comes before formulating intention.  
B) ✗ Incorrect order and missing stages.  
C) ✗ Incorrect order; perceiving system state happens after executing action.  
D) ✓ Correct full sequence of the seven stages in Norman’s model.  

**Correct:** D


#### 3. Which of the following best describes the "Gulf of Execution" and "Gulf of Evaluation"?  
A) ✗ These are not stages in Abowd and Beale’s framework.  
B) ✗ Reverses the definitions of the two gulfs.  
C) ✓ Correctly describes Gulf of Execution as gap between user’s intended actions and system’s allowed actions, and Gulf of Evaluation as gap between user’s expectation and actual system state.  
D) ✗ Slips and mistakes are types of human error, not definitions of the gulfs.  

**Correct:** C


#### 4. Which of the following are typical characteristics of industrial interfaces compared to office interfaces?  
A) ✗ Clean environment and direct manipulation are more typical of office interfaces.  
B) ✓ Industrial interfaces typically handle numeric data and fast rate of change.  
C) ✗ Textual data and slow rate of change describe office interfaces, not industrial.  
D) ✓ Industrial environments tend to be dirty and use indirect manipulation.  

**Correct:** B, D


#### 5. What are the main advantages and challenges of natural language interfaces?  
A) ✗ They are not limited to expert users; often aimed at novices but with limited success.  
B) ✗ While familiar, natural language interfaces are not easy to implement well.  
C) ✓ Focusing on subsets and key words is a common solution to improve performance.  
D) ✓ Vague and ambiguous nature makes them difficult to do well.  

**Correct:** C, D


#### 6. Which statements about WIMP interfaces are true?  
A) ✓ WIMP stands for Windows, Icons, Menus, Pointers, so these are core elements.  
B) ✗ Modal dialog boxes and pre-emptive interface parts mean feedback is not always immediate or uninterrupted.  
C) ✗ WIMP is the default style for most desktop systems, so it is widely used.  
D) ✓ Buttons, toolbars, palettes, and dialog boxes are common WIMP elements.  

**Correct:** A, D


#### 7. Regarding menus, which design considerations are important?  
A) ✓ Logical grouping and meaningful names improve usability.  
B) ✗ Hierarchical (cascading) menus help organize many options, not something to avoid.  
C) ✗ Only using pull-down menus is limiting; other menu types are useful.  
D) ✓ Keyboard accelerators speed up access and are important design features.  

**Correct:** A, D


#### 8. How does ergonomics influence interface design?  
A) ✓ Environmental factors like lighting and noise are part of ergonomics considerations.  
B) ✗ Ergonomics explicitly considers user physical characteristics, not ignores them.  
C) ✓ Ergonomics defines standards for physical layout and grouping of controls.  
D) ✗ Ergonomics focuses on physical and environmental factors, not just software usability.  

**Correct:** A, C


#### 9. What factors contribute to the perceived value of a system for users?  
A) ✓ Value must exceed cost, including time and money, for users to adopt.  
B) ✗ High learning effort with no immediate benefit reduces perceived value.  
C) ✓ Helping users get work done is a key value factor.  
D) ✓ Fun and engagement also contribute to perceived value.  

**Correct:** A, C, D


#### 10. Which of the following statements about error types and their fixes are correct?  
A) ✗ Slips are user errors, not system faults; mistakes are not simply negligence but cognitive errors.  
B) ✓ Slips occur when the goal is correct but the action is wrong; better interface design helps reduce slips.  
C) ✗ Errors cannot be completely eliminated by feedback, only mitigated.  
D) ✓ Mistakes arise from incorrect goals or misunderstandings; better system understanding helps reduce mistakes.  

**Correct:** B, D
