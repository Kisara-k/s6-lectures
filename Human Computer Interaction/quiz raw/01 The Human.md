## Answers

#### 1. Which of the following statements about human vision are correct?  
A) ✓ The visual system uses context to resolve ambiguous stimuli and avoid misinterpretation.  
B) ✓ Visual angle relates to how much of the visual field an object occupies, affecting perceived size and depth.  
C) ✗ Blue acuity is the lowest among cone sensitivities, not the highest.  
D) ✗ Rods are for low light vision; cones are for colour vision, so this is reversed.  

**Correct:** A, B


#### 2. Regarding memory types, which of the following are true?  
A) ✓ Short-term memory has limited capacity (~7±2 chunks) and rapid decay (~200ms).  
B) ✗ Long-term memory retrieval is slower (~1/10 second) than short-term memory access.  
C) ✓ Semantic memory is structured to support inference via inheritance in semantic networks.  
D) ✓ Sensory memory buffers stimuli separately (iconic, echoic, haptic) and is continuously overwritten.  

**Correct:** A, C, D


#### 3. Which of the following accurately describe aspects of hearing and auditory processing?  
A) ✓ Humans hear roughly from 20 Hz to 15 kHz frequencies.  
B) ✓ The cocktail party phenomenon illustrates selective auditory attention amid background noise.  
C) ✗ The middle ear transmits vibrations to the inner ear; electrical impulses are generated in the inner ear.  
D) ✗ Timbre refers to the quality or type of sound, not loudness (which is amplitude).  

**Correct:** A, B


#### 4. Which statements about problem solving and reasoning are correct?  
A) ✓ Means-ends analysis is a heuristic used in problem space theory to reduce differences between current and goal states.  
B) ✗ Inductive reasoning cannot prove a hypothesis true, only support it; it can be falsified but not confirmed absolutely.  
C) ✗ Deductive reasoning produces logically valid conclusions if premises are true, but conclusions may not be factually true if premises are false or unrealistic.  
D) ✓ Abductive reasoning infers the most likely cause from an observed effect, though it can be unreliable.  

**Correct:** A, D


#### 5. Concerning movement and reaction time, which are true?  
A) ✓ Kinethesis is awareness of body position and affects comfort and performance.  
B) ✓ Auditory reaction time (~150 ms) is generally faster than visual (~200 ms).  
C) ✗ Increasing reaction time decreases accuracy only in unskilled operators, not skilled ones.  
D) ✓ Fitts’ Law states movement time increases with distance and decreases with target size.  

**Correct:** A, B, D


#### 6. Which of the following statements about emotion and its influence on cognition are correct?  
A) ✓ Negative affect narrows thinking and can impair even simple tasks.  
B) ✗ James-Lange theory states emotion is interpretation of physiological response, not a direct psychological response.  
C) ✗ Stress generally impairs problem solving by increasing difficulty, not improving it.  
D) ✓ Positive affect enhances creative problem solving.  

**Correct:** A, D


#### 7. Regarding errors and mental models, which are accurate?  
A) ✓ Mistakes arise from incorrect intentions due to misunderstanding or wrong knowledge.  
B) ✓ Slips occur when the intention is correct but the execution fails.  
C) ✓ Changes in skilled behavior can disrupt automaticity and increase slips.  
D) ✗ Mental models are often imperfect; incorrect models cause errors.  

**Correct:** A, B, C


#### 8. Which of the following are true about reading and visual perception during reading?  
A) ✓ Negative contrast improves reading performance on computer screens.  
B) ✓ Syntax, semantics, and pragmatics are involved in interpreting visual patterns during reading.  
C) ✓ Word shape is important for word recognition.  
D) ✗ Perception occurs primarily during fixations, not saccades (which are rapid eye movements).  

**Correct:** A, B, C


#### 9. Which statements about sensory receptors and touch are correct?  
A) ✗ Kinethesis relates to body position awareness, not visual perception, but is related to proprioception, not tactile feedback alone.  
B) ✓ Some skin areas (e.g., fingers) are more sensitive due to higher receptor density.  
C) ✓ Mechanoreceptors respond to pressure and can be instant or continuous.  
D) ✗ Thermoreceptors detect heat and cold; nociceptors detect pain.  

**Correct:** B, C


#### 10. About long-term memory models, which are true?  
A) ✗ Production rules represent procedural knowledge, not declarative knowledge.  
B) ✓ Frames organize information with fixed and variable slots to represent instances.  
C) ✓ Scripts model stereotypical event sequences with roles, props, scenes, and tracks.  
D) ✓ Semantic networks support inference via explicit relationships and inheritance.  

**Correct:** B, C, D
