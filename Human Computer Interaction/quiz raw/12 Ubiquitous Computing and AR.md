## 12. Ubiquitous Computing and AR

## Questions

#### 1. Which of the following best describe the concept of ubiquitous computing?  
A) Computing limited to a single workstation environment  
B) Computing technology embedded seamlessly in the real world  
C) Virtual reality simulations on desktop computers  
D) Interaction with computers away from a fixed location  

#### 2. Weiser proposed three scales of ubiquitous computing devices. Which of the following correctly pairs a scale with typical devices?  
A) Yard scale – smart bulletin boards and shared displays  
B) Foot scale – notebooks, tablets, and digital paper  
C) Inch scale – electronic whiteboards and plasma displays  
D) Yard scale – PDAs and smartphones  

#### 3. What are the challenges introduced by implicit input in ubiquitous computing?  
A) It relies solely on explicit user commands like keyboard and mouse  
B) It eliminates the need for any user interaction or feedback  
C) Sensor-based input can introduce ambiguity due to imperfect recognition  
D) It extends traditional input methods by adding awareness of context  

#### 4. Which of the following statements about output in ubiquitous computing environments is true?  
A) Ambient and peripheral displays use physical environment features to convey information subtly  
B) Distributed output means screens are coordinated but confined to a single device  
C) Examples of ambient displays include devices like The Dangling String and The Water Lamp  
D) Output is always focused on large, eye-grabbing raster displays  

#### 5. How does augmented reality (AR) differ from virtual reality (VR) in terms of user experience?  
A) VR projects images onto physical objects, whereas AR uses headsets to simulate entire worlds  
B) VR is primarily used for maintenance tasks, while AR is mainly for gaming and simulation  
C) AR requires perfect registration to align virtual and real elements, which is often challenging  
D) AR overlays virtual images onto the real world, while VR fully immerses users in a virtual environment  

#### 6. Which of the following are typical applications or themes associated with ubiquitous computing?  
A) Context-aware computing that uses sensed phenomena to facilitate interaction  
B) Automated capture and access of live experiences for future use  
C) Continuous interaction where everyday activities have fluid boundaries  
D) Strictly task-centric activities with clear start and end points  

#### 7. In the context of visualizing hierarchical data, what is a key advantage of using 3D cone trees over traditional 2D organization charts?  
A) 3D cone trees allow levels to become rings, managing wide hierarchies more effectively  
B) 2D charts are better for very wide hierarchies because they avoid complexity  
C) 3D visualizations always provide clearer understanding regardless of data size  
D) 3D cone trees eliminate all overlap and crossing of hierarchy branches  

#### 8. Which of the following statements about VRML (Virtual Reality Markup Language) are correct?  
A) VRML requires expensive VR headsets to be experienced  
B) VRML is used to create virtual reality scenes accessible via the web  
C) VRML scenes can include 3D objects like spheres and cones with textures  
D) VRML supports interaction and navigation within virtual environments on ordinary PCs  

#### 9. What evaluation challenges are unique to ubiquitous computing compared to traditional HCI?  
A) Success metrics may include playfulness and non-distraction rather than just efficiency  
B) Ubicomp activities are often not task-centric, complicating evaluation metrics  
C) Long-term authentic summative evaluation is difficult due to the novelty of technologies  
D) Ubicomp systems are easier to evaluate because they rely on explicit user commands  

#### 10. Which of the following statements about time and interactivity in data visualization are accurate?  
A) Visualizing time always requires 3D representations for clarity  
B) Fast or slow replay of events is an example of mapping time to itself in visualization  
C) Interactivity allows users to influence visualizations dynamically, such as with the Influence Explorer  
D) Time can be mapped to space to visualize changing values like sales graphs or timelines

## Answers

#### 1. Which of the following best describe the concept of ubiquitous computing?  
A) ✗ Computing limited to a single workstation environment (opposite of ubicomp)  
B) ✓ Computing technology embedded seamlessly in the real world  
C) ✗ Virtual reality simulations on desktop computers (not ubicomp)  
D) ✓ Interaction with computers away from a fixed location  

**Correct:** B, D


#### 2. Weiser proposed three scales of ubiquitous computing devices. Which of the following correctly pairs a scale with typical devices?  
A) ✓ Yard scale includes smart bulletin boards and shared displays  
B) ✓ Foot scale includes notebooks, tablets, and digital paper  
C) ✗ Inch scale does not include large displays like whiteboards  
D) ✗ Yard scale, not inch scale, includes shared displays; PDAs are inch scale  

**Correct:** A, B


#### 3. What are the challenges introduced by implicit input in ubiquitous computing?  
A) ✗ Implicit input extends beyond explicit commands, not limited to keyboard/mouse  
B) ✗ Implicit input still requires interaction and feedback, not eliminated  
C) ✓ Sensor-based input can introduce ambiguity due to imperfect recognition  
D) ✓ It extends traditional input by adding awareness of context  

**Correct:** C, D


#### 4. Which of the following statements about output in ubiquitous computing environments is true?  
A) ✓ Ambient and peripheral displays use physical environment features to convey info subtly  
B) ✗ Distributed output is coordinated across multiple devices, not confined to one  
C) ✓ The Dangling String and The Water Lamp are examples of ambient displays  
D) ✗ Output is not always eye-grabbing; ambient/peripheral displays are subtle  

**Correct:** A, C


#### 5. How does augmented reality (AR) differ from virtual reality (VR) in terms of user experience?  
A) ✗ VR uses headsets for full immersion; AR projects onto real objects or uses semi-transparent goggles  
B) ✗ VR is used for simulation and training; AR is often used for maintenance and overlay tasks  
C) ✓ Registration (alignment) is critical and challenging in AR  
D) ✓ AR overlays virtual images on real world; VR fully immerses in virtual environment  

**Correct:** C, D


#### 6. Which of the following are typical applications or themes associated with ubiquitous computing?  
A) ✓ Context-aware computing uses sensed phenomena to ease interaction  
B) ✓ Automated capture and access of live experiences is a key theme  
C) ✓ Continuous interaction with fluid activity boundaries is typical  
D) ✗ Ubicomp activities are often not strictly task-centric  

**Correct:** A, B, C


#### 7. In the context of visualizing hierarchical data, what is a key advantage of using 3D cone trees over traditional 2D organization charts?  
A) ✓ Levels become rings in 3D cone trees, helping manage wide hierarchies  
B) ✗ 2D charts struggle with wide hierarchies due to overlap and space limits  
C) ✗ 3D visualizations are not always clearer; depends on data and context  
D) ✗ 3D cone trees do not eliminate all overlap but manage it better  

**Correct:** A


#### 8. Which of the following statements about VRML (Virtual Reality Markup Language) are correct?  
A) ✗ VRML can be experienced on ordinary PCs without expensive VR headsets  
B) ✓ VRML is used to create virtual reality scenes accessible via the web  
C) ✓ VRML scenes can include 3D objects like spheres and cones with textures  
D) ✓ VRML supports interaction and navigation within virtual environments on ordinary PCs  

**Correct:** B, C, D


#### 9. What evaluation challenges are unique to ubiquitous computing compared to traditional HCI?  
A) ✓ Success metrics may include playfulness and non-distraction, not just efficiency  
B) ✓ Ubicomp activities are often not task-centric, complicating evaluation  
C) ✓ New technologies make long-term authentic summative evaluation difficult  
D) ✗ Ubicomp systems are harder, not easier, to evaluate due to implicit and distributed interaction  

**Correct:** A, B, C


#### 10. Which of the following statements about time and interactivity in data visualization are accurate?  
A) ✗ Visualizing time does not always require 3D; 2D timelines are common and effective  
B) ✓ Fast or slow replay of events is an example of mapping time to itself in visualization  
C) ✓ Interactivity allows users to influence visualizations dynamically, e.g., Influence Explorer  
D) ✓ Time can be mapped to space to visualize changing values like sales graphs or timelines  

**Correct:** B, C, D
