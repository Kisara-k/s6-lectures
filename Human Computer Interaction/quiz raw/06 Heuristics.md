## 6. Heuristics

## Questions

#### 1. Which of the following statements accurately describe heuristic evaluation?  
A) It involves experts evaluating an interface based on a set of heuristics.  
B) A single expert is usually sufficient to identify all usability issues in an interface.  
C) It is a formal, task-specific usability testing method.  
D) It provides a holistic evaluation of the entire system rather than focusing on specific tasks.  

#### 2. Which of the following are included in Nielsen’s (1994) list of heuristics?  
A) Support internal locus of control  
B) Help users recognize, diagnose, and recover from errors  
C) Reduce short-term memory load  
D) Recognition rather than recall  

#### 3. Shneiderman and Plaisant’s (2010) golden rules include which of the following?  
A) Offer informative feedback  
B) Flexibility and efficiency of use  
C) Strive for consistency  
D) Aesthetic and minimalist design  

#### 4. What are some key differences between vendor-specific guidelines and general heuristics?  
A) General heuristics are often more theoretical and broadly applicable.  
B) Vendor-specific guidelines focus exclusively on error prevention.  
C) Vendor-specific guidelines tend to be more prescriptive and vendor-centered.  
D) General heuristics are usually less flexible than vendor-specific guidelines.  

#### 5. Which of the following statements about heuristic evaluation are true?  
A) Aggregated evaluations from 3-5 experts tend to have better issue coverage than a single expert.  
B) It was created by Jakob Nielsen in the late 1980s.  
C) It is primarily a user study method involving end-users performing tasks.  
D) It requires a minimum of 10 experts to be effective.  

#### 6. Which heuristics or rules explicitly address error handling and recovery?  
A) User control and freedom (Nielsen)  
B) Help users recognize, diagnose, and recover from errors (Nielsen)  
C) Prevent errors (Shneiderman and Plaisant)  
D) Recognition rather than recall (Nielsen)  

#### 7. When comparing Nielsen’s heuristics and Shneiderman and Plaisant’s golden rules, which of the following are true?  
A) Both emphasize consistency as a key principle.  
B) Shneiderman and Plaisant explicitly include “Design dialogues to yield closure.”  
C) Nielsen’s heuristics include “Support internal locus of control.”  
D) Only Nielsen’s heuristics address reducing short-term memory load.  

#### 8. Which of the following best describes the relationship between usability inspection methods and user studies?  
A) Usability inspections rely on expert evaluations, while user studies involve actual users performing tasks.  
B) Usability inspections are generally more expensive and time-consuming than user studies.  
C) User studies focus on expert opinions rather than user behavior.  
D) Both methods require large sample sizes of end-users.  

#### 9. Which of the following heuristics or rules focus on minimizing cognitive load for users?  
A) Help and documentation (Nielsen)  
B) Flexibility and efficiency of use (Nielsen)  
C) Reduce short-term memory load (Shneiderman and Plaisant)  
D) Recognition rather than recall (Nielsen)  

#### 10. Regarding the effectiveness of heuristic evaluation, which statements are correct?  
A) A single expert can reliably find all usability problems in an interface.  
B) It focuses on detailed task performance metrics rather than overall system usability.  
C) Combining evaluations from multiple experts improves the coverage of usability issues found.  
D) Heuristic evaluation is considered a “cheap and cheerful” usability analysis method.

## Answers

#### 1. Which of the following statements accurately describe heuristic evaluation?  
A) ✓ Experts evaluate interfaces based on heuristics.  
B) ✗ A single expert is poor at finding all issues.  
C) ✗ It is informal and holistic, not formal or task-specific.  
D) ✓ It evaluates the entire system, not just specific tasks.  

**Correct:** A, D


#### 2. Which of the following are included in Nielsen’s (1994) list of heuristics?  
A) ✗ Support internal locus of control is from Shneiderman and Plaisant.  
B) ✓ Helping users recognize, diagnose, and recover from errors is Nielsen’s heuristic.  
C) ✗ Reducing short-term memory load is from Shneiderman and Plaisant.  
D) ✓ Recognition rather than recall is one of Nielsen’s heuristics.  

**Correct:** B, D


#### 3. Shneiderman and Plaisant’s (2010) golden rules include which of the following?  
A) ✓ Offering informative feedback is a golden rule.  
B) ✗ Flexibility and efficiency of use is from Nielsen’s heuristics.  
C) ✓ Strive for consistency is one of their golden rules.  
D) ✗ Aesthetic and minimalist design is from Nielsen’s heuristics.  

**Correct:** A, C


#### 4. What are some key differences between vendor-specific guidelines and general heuristics?  
A) ✓ General heuristics tend to be more theoretical and broadly applicable.  
B) ✗ Vendor guidelines do not focus exclusively on error prevention.  
C) ✓ Vendor guidelines are more prescriptive and vendor-centered.  
D) ✗ General heuristics are usually more flexible, not less.  

**Correct:** A, C


#### 5. Which of the following statements about heuristic evaluation are true?  
A) ✓ Aggregated evaluations from multiple experts improve coverage.  
B) ✓ Created by Jakob Nielsen in the late 1980s.  
C) ✗ It is not a user study; it involves experts, not end-users performing tasks.  
D) ✗ Effective evaluations typically use 3-5 experts, not 10 minimum.  

**Correct:** A, B


#### 6. Which heuristics or rules explicitly address error handling and recovery?  
A) ✓ User control and freedom (Nielsen) supports easy reversal, related to error recovery.  
B) ✓ Nielsen’s heuristic focuses on error recognition and recovery.  
C) ✓ Shneiderman and Plaisant include preventing errors as a rule.  
D) ✗ Recognition rather than recall relates to memory, not error handling.  

**Correct:** A, B, C


#### 7. When comparing Nielsen’s heuristics and Shneiderman and Plaisant’s golden rules, which of the following are true?  
A) ✓ Both emphasize consistency.  
B) ✓ “Design dialogues to yield closure” is a Shneiderman and Plaisant rule.  
C) ✗ Supporting internal locus of control is from Shneiderman and Plaisant, not Nielsen.  
D) ✗ Reducing short-term memory load is only in Shneiderman and Plaisant.  

**Correct:** A, B


#### 8. Which of the following best describes the relationship between usability inspection methods and user studies?  
A) ✓ Inspections use experts; user studies involve actual users performing tasks.  
B) ✗ Inspections are generally cheaper and quicker than user studies.  
C) ✗ User studies focus on user behavior, not expert opinions.  
D) ✗ User studies require end-users, but inspections do not; sample sizes vary.  

**Correct:** A


#### 9. Which of the following heuristics or rules focus on minimizing cognitive load for users?  
A) ✗ Help and documentation supports users but does not directly minimize cognitive load.  
B) ✗ Flexibility and efficiency of use relates to user expertise, not cognitive load.  
C) ✓ Reduce short-term memory load is explicitly from Shneiderman and Plaisant.  
D) ✓ Recognition rather than recall reduces memory load (Nielsen).  

**Correct:** C, D


#### 10. Regarding the effectiveness of heuristic evaluation, which statements are correct?  
A) ✗ A single expert cannot reliably find all problems.  
B) ✗ It focuses on overall system usability, not detailed task metrics.  
C) ✓ Multiple experts improve coverage of issues found.  
D) ✓ It is considered a “cheap and cheerful” method.  

**Correct:** C, D
