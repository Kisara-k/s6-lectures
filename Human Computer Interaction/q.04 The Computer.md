## Answers

#### 1. Which of the following are true about the QWERTY keyboard layout?  
A) ✗ It was designed to maximize typing speed for beginners. (It was designed to prevent typewriter jams, not speed.)  
B) ✓ It was originally created to prevent typewriter jams. (True, to avoid mechanical jamming.)  
C) ✓ It remains dominant due to a large social base of users. (Social inertia keeps it dominant.)  
D) ✗ It places the most common letters under the strongest fingers. (This is true for Dvorak, not QWERTY.)  

**Correct:** B, C


#### 2. What are the main challenges in handwriting recognition technology?  
A) ✓ Capturing stroke path and pressure naturally. (Important for natural input.)  
B) ✓ Segmenting joined-up writing into individual letters. (Joined letters are hard to separate.)  
C) ✓ Handling different handwriting styles. (Varied styles complicate recognition.)  
D) ✗ Converting handwriting directly into speech. (Not a typical function of handwriting recognition.)  

**Correct:** A, B, C


#### 3. Which characteristics describe a computer mouse?  
A) ✗ Detects absolute position on the desk surface. (Mouse detects relative movement, not absolute.)  
B) ✓ Detects relative movement in the (x, z) plane. (Correct; mouse movement is relative.)  
C) ✓ Usually has between 1 to 3 buttons for selection. (Standard mouse design.)  
D) ✗ Movement of the mouse directly moves the device on the screen. (The device moves the cursor, not the mouse itself.)  

**Correct:** B, C


#### 4. Why might alternative keyboard layouts like Dvorak fail to replace QWERTY?  
A) ✗ They offer no speed improvement over QWERTY. (Dvorak offers 10-15% speed improvement.)  
B) ✓ Social resistance due to the large number of QWERTY users. (Social inertia is a major barrier.)  
C) ✗ They cause more fatigue than QWERTY. (Dvorak reduces fatigue.)  
D) ✓ They are biased towards one hand, which limits usability. (Dvorak is biased towards the right hand.)  

**Correct:** B, D


#### 5. Which of the following are advantages of touchscreens?  
A) ✓ Require no specialized pointer device. (Finger or stylus can be used directly.)  
B) ✗ Allow precise selection of very small screen regions. (Finger is blunt, making precision difficult.)  
C) ✓ Suitable for use in hostile or dirty environments. (No moving parts, easy to clean.)  
D) ✗ Finger contact never leaves marks on the screen. (Fingerprints and smudges are common.)  

**Correct:** A, C


#### 6. What are the limitations of speech recognition systems?  
A) ✗ They perform best with large vocabularies and multiple users. (Best with limited vocabularies and single users.)  
B) ✓ External noise can interfere with recognition accuracy. (Noise is a known problem.)  
C) ✓ Initial training improves recognition of a single user’s speech. (Training helps adapt to user.)  
D) ✗ They can easily handle different accents without training. (Accents cause recognition issues.)  

**Correct:** B, C


#### 7. Which statements about virtual reality (VR) headsets are correct?  
A) ✓ They provide different images to each eye to create a 3D effect. (Stereo vision creates depth.)  
B) ✗ They eliminate all causes of motion sickness in users. (Motion sickness is still a problem.)  
C) ✓ They track head motion to adjust the displayed scene accordingly. (Head tracking is essential.)  
D) ✓ Depth perception conflicts can cause discomfort or sickness. (Conflicting cues cause sickness.)  

**Correct:** A, C, D


#### 8. What are the key differences between CRT and LCD displays?  
A) ✗ CRTs emit light directly, while LCDs reflect ambient light. (LCDs modulate light but often use backlighting.)  
B) ✓ CRTs use electron beams to illuminate phosphor dots. (True for CRT technology.)  
C) ✓ LCDs are lighter and produce no radiation. (LCDs are thinner and safer.)  
D) ✗ LCDs have higher resolution than CRTs by default. (Resolution depends on model, not technology.)  

**Correct:** B, C


#### 9. Which of the following describe the role of memory in a computer system?  
A) ✗ RAM stores data permanently even when the computer is off. (RAM is volatile.)  
B) ✓ Permanent media stores data even when power is off. (Hard drives, SSDs are permanent.)  
C) ✓ Memory capacity affects how much data can be handled simultaneously. (More memory means more data can be processed.)  
D) ✓ Faster memory access speeds improve interactive performance. (Speed affects responsiveness.)  

**Correct:** B, C, D


#### 10. What are common bottlenecks that limit interactive performance in computers?  
A) ✓ Computation bound delays caused by slow processing. (Slow CPU causes delays.)  
B) ✓ Storage channel bound delays due to slow data transfer. (Disk-to-memory transfer can bottleneck.)  
C) ✓ Graphics bound delays from updating complex displays. (Graphics updates can be costly.)  
D) ✗ Unlimited network capacity improving performance. (Network capacity is limited and can cause bottlenecks.)  

**Correct:** A, B, C


#### 11. Which of the following are true about printing technologies?  
A) ✓ Dot-matrix printers use pins to strike an inked ribbon. (Correct description.)  
B) ✓ Laser printers use electrostatic charges to transfer toner. (True for laser printing.)  
C) ✓ Inkjet printers spray tiny blobs of ink onto paper. (Accurate description.)  
D) ✗ All printers produce output at the same resolution. (Resolution varies widely.)  

**Correct:** A, B, C


#### 12. What is the purpose of anti-aliasing in bitmap displays?  
A) ✗ To increase the number of pixels on the screen. (Anti-aliasing does not change pixel count.)  
B) ✓ To smooth jagged edges on diagonal lines. (Main purpose of anti-aliasing.)  
C) ✗ To reduce the color depth of images. (Anti-aliasing does not reduce color depth.)  
D) ✓ To blend line colors for better visual quality. (Blending reduces jaggies.)

#### 13. Which of the following are characteristics of chord keyboards?

#### 15. Which of the following describe the function of page description languages like PostScript?
