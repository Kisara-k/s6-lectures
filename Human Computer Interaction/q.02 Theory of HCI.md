## Answers

#### 1. Which of the following were significant milestones in the development of graphical user interfaces?  
A) ✓ Ivan Sutherland’s Sketchpad was the first graphical system.  
B) ✓ Douglas Engelbart’s mouse enabled intuitive pointing.  
C) ✓ IBM’s PC popularized personal computing, enabling GUIs.  
D) ✗ Mark Weiser coined “Ubiquitous Computing,” not a GUI milestone.  

**Correct:** A, B, C


#### 2. The WIMP paradigm, invented at Xerox PARC, includes which of the following elements?  
A) ✓ Windows are a core part of WIMP.  
B) ✓ Icons represent objects visually.  
C) ✓ Menus provide selectable options.  
D) ✗ Touchscreens are not part of the original WIMP paradigm.  

**Correct:** A, B, C


#### 3. What distinguishes the Apple Macintosh computer released in 1984 from earlier personal computers?  
A) ✗ It used a GUI, not a CLI.  
B) ✓ First commercial computer with a GUI.  
C) ✗ Ubiquitous computing was coined later by Weiser.  
D) ✗ Physical keyboards existed before Macintosh.  

**Correct:** B


#### 4. Mark Weiser’s term “Ubiquitous Computing” primarily refers to:  
A) ✓ Embedding computing seamlessly in everyday life.  
B) ✗ Large displays are unrelated to ubiquitous computing.  
C) ✗ Mouse invention predates ubiquitous computing.  
D) ✗ Handheld computers are related but not the core idea.  

**Correct:** A


#### 5. Which of the following statements about the influence of experimental psychology on HCI are true?  
A) ✓ Controlled experiments use independent/dependent variables.  
B) ✗ Results do not always generalize to real-world use.  
C) ✓ Hypotheses and reproducible methods are key.  
D) ✗ Qualitative methods are still needed beyond experiments.  

**Correct:** A, C


#### 6. What is the main tradeoff between internal and external validity in HCI experiments?  
A) ✓ Increasing internal validity often reduces external validity.  
B) ✗ External validity does not always improve internal validity.  
C) ✓ Internal validity means measuring what is intended.  
D) ✓ External validity means generalizing to real-world settings.  

**Correct:** A, C, D


#### 7. Which of the following methods are used in HCI research to capture qualitative data beyond controlled experiments?  
A) ✓ Think-aloud protocols capture user thoughts.  
B) ✓ Structured interviews gather detailed feedback.  
C) ✗ Statistical tests analyze quantitative data, not qualitative.  
D) ✓ Video coding helps analyze behavior qualitatively.  

**Correct:** A, B, D


#### 8. Which of the following best describes the role of ethnographic research in HCI?  
A) ✗ Ethnography studies natural, not controlled, settings.  
B) ✓ Observes users in natural environments.  
C) ✗ Ethnography focuses on qualitative, not just quantitative data.  
D) ✗ It complements, not replaces, experimental psychology.  

**Correct:** B


#### 9. The “Eight Golden Rules of User Interface Design” are primarily used to:  
A) ✓ Guide usability and interface design.  
B) ✗ They do not model neuromuscular systems.  
C) ✗ They are design principles, not hardware development.  
D) ✗ They are not for statistical analysis.  

**Correct:** A


#### 10. Which of the following technologies or concepts were introduced or popularized in the late 1990s to mid-2000s?
