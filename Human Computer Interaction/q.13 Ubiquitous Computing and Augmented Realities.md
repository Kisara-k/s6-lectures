## Answers

#### 1. What is a defining characteristic of ubiquitous computing?  
A) ✗ Computing confined to a single workstation — Opposite of ubicomp’s core idea.  
B) ✓ Computing technology embedded throughout the environment — This is the essence of ubiquitous computing.  
C) ✗ Interaction only through keyboards and mice — Ubiquitous computing extends beyond traditional input.  
D) ✓ Computers that disappear from user awareness — Weiser’s idea that technology “disappears” into the background.  

**Correct:** B, D


#### 2. Which of the following device scales are correctly matched with their typical ownership and usage?  
A) ✗ Inch-scale devices are usually shared by many people in a building — Inch-scale devices are personal.  
B) ✓ Foot-scale devices are personal but not always carried everywhere — Correct description of foot-scale devices.  
C) ✓ Yard-scale devices are large and typically institutionally owned — Yard-scale devices are shared and large.  
D) ✗ Inch-scale devices are rarely networked with each other — They often communicate with each other and environment.  

**Correct:** B, C


#### 3. Implicit input in ubiquitous computing refers to:  
A) ✗ Direct commands entered via keyboard — This is explicit input.  
B) ✓ Sensor-based data collection without explicit user action — Implicit input is automatic sensing.  
C) ✗ Perfectly accurate recognition of user intentions — Recognition is imperfect, causing ambiguity.  
D) ✓ Input methods that extend traditional explicit input — Implicit input complements explicit input.  

**Correct:** B, D


#### 4. Which of the following are challenges introduced by recognition technologies in ubicomp?  
A) ✓ Ambiguity due to imperfect recognition — Recognition errors cause ambiguity.  
B) ✗ Complete elimination of user errors — Recognition is not perfect, so errors remain.  
C) ✓ Increased reliance on sensor data — Recognition depends on sensor inputs.  
D) ✓ Reduced need for explicit user input — Implicit input reduces explicit commands.  

**Correct:** A, C, D


#### 5. Ambient displays are designed to:  
A) ✗ Grab full user attention immediately — Ambient displays are subtle, not attention-grabbing.  
B) ✓ Signal information subtly using physical environment features — Ambient displays use environment cues.  
C) ✓ Operate primarily in the user’s peripheral awareness — Designed to be in the background.  
D) ✗ Replace traditional screens entirely — They complement, not replace, traditional displays.  

**Correct:** B, C


#### 6. How does ubiquitous computing blur the boundary between physical and digital worlds?  
A) ✓ By making physical actions trigger digital responses — Physical actions have electronic meaning.  
B) ✓ By projecting digital output onto physical objects — Digital info can be overlaid on real objects.  
C) ✗ By isolating digital data from physical context — Opposite of ubicomp’s goal.  
D) ✗ By removing all physical interfaces — Physical interfaces remain important.  

**Correct:** A, B


#### 7. Context-aware computing primarily relies on:  
A) ✗ User manual input to adjust settings — Context-aware systems sense automatically.  
B) ✓ Sensed environmental or user data to adapt interactions — Core of context-aware computing.  
C) ✗ Static user profiles that never change — Context changes dynamically.  
D) ✗ Randomized system behavior to surprise users — Behavior is purposeful, not random.  

**Correct:** B


#### 8. Which theoretical approach emphasizes improvisational and opportunistic behavior in ubicomp?  
A) ✗ Activity theory — Focuses on goals and actions adapting to physical state, but less on improvisation.  
B) ✓ Situated action and distributed cognition — Emphasizes improvisation and opportunism.  
C) ✗ Knowledge in the world — Focuses on knowledge embedded in environment, not behavior style.  
D) ✗ Ethnography — Method for study, not a theory of behavior.  

**Correct:** B


#### 9. Why is long-term summative evaluation difficult in ubiquitous computing?  
A) ✗ Technologies are well-established and stable — Ubicomp tech is often new and evolving.  
B) ✓ Activities are not task-centric and often continuous — Makes traditional evaluation hard.  
C) ✗ Users always provide consistent feedback — Feedback can be inconsistent or unavailable.  
D) ✗ Metrics like playfulness and non-distraction are easy to measure — These are subjective and hard to quantify.  

**Correct:** B


#### 10. Which of the following best describes the main goal of virtual reality (VR)?  
A) ✗ To overlay digital information on the real world — This is augmented reality.  
B) ✓ To immerse users in a fully computer-generated environment — Core goal of VR.  
C) ✗ To provide subtle ambient cues in the background — Ambient displays, not VR.  
D) ✗ To replace physical objects with digital equivalents — VR simulates environments but not necessarily replaces objects.  

**Correct:** B


#### 11. What are typical input methods used in VR systems?  
A) ✗ Keyboard and mouse only — VR uses more immersive inputs.  
B) ✓ DataGloves for gesture recognition — Common VR input device.  
C) ✓ Eye gaze tracking — Used to indicate direction or focus.  
D) ✗ Voice commands exclusively — Voice may be used but not exclusive.  

**Correct:** B, C


#### 12. Which of the following are true about augmented reality (AR)?  
A) ✗ It always replaces the real world with a virtual one — AR overlays, does not replace.  
B) ✓ It can project images onto semi-transparent goggles — Common AR method.  
C) ✓ Registration is critical to align virtual and real objects — Essential for believable AR.  
D) ✗ It is unrelated to maintenance or engineering applications — AR is widely used in these fields.  

**Correct:** B, C


#### 13. In AR applications for maintenance, why might schematic overlays be used instead of precise registration?  
A) ✗ Because precise registration is always easy to achieve — It is often difficult.  
B) ✓ Because schematic overlays are simpler when exact alignment is too difficult — Practical workaround.  
C) ✗ Because users prefer unrelated information — Users need relevant info.  
D) ✗ Because virtual objects never interact with the real world — Interaction is often key.  

**Correct:** B


#### 14. Which of the following are common applications of VR?  
A) ✓ Military training simulators — Widely used for safe training.  
B) ✓ Virtual holidays and tourism — VR can simulate travel experiences.  
C) ✗ Reading emails on wearable devices — More related to ubiquitous computing.  
D) ✓ Phobia treatment through controlled exposure — VR is effective for this.  

**Correct:** A, B, D


#### 15. What is a key advantage of VR visualization over real-world experiments like wind tunnels?  
A) ✗ It disrupts airflow to provide more accurate data — VR does not disrupt airflow.  
B) ✓ It is cheaper and faster without physical constraints — VR simulations save cost and time.  
C) ✗ It requires physical models to be built first — VR uses digital models.  
D) ✗ It cannot simulate invisible fields or values — VR excels at visualizing invisible phenomena.  

**Correct:** B


#### 16. When visualizing hierarchical data, what is a challenge of using 2D organization charts?  
A) ✓ They become difficult to read when hierarchies are wide — Wide hierarchies clutter 2D charts.  
B) ✗ They perfectly represent all complex relationships — They struggle with complexity.  
C) ✗ They cannot be extended into 3D visualizations — 3D visualizations like cone trees exist.  
D) ✗ They are always better than network graphs — Depends on data type and complexity.  

**Correct:** A


#### 17. What distinguishes planar graphs from non-planar graphs in network visualization?  
A) ✓ Planar graphs can be drawn without any crossing links — This is the definition of planar graphs.  
B) ✗ Non-planar graphs never have crossing links — Non-planar graphs have unavoidable crossings.  
C) ✗ Planar graphs are always simpler than non-planar graphs — Simplicity depends on context.  
D) ✗ Non-planar graphs can be represented only in 3D — They can be drawn in 2D but with crossings.  

**Correct:** A


#### 18. How is time often represented in data visualization?  
A) ✗ As a static, unchanging dimension — Time is dynamic and often mapped spatially.  
B) ✓ Mapped to space to show changes over time — Common technique in timelines and graphs.  
C) ✗ Ignored in favor of purely spatial data — Time is critical in many visualizations.  
D) ✗ Only used in 2D histograms — Time can be used in many visualization types.  

**Correct:** B


#### 19. Which of the following statements about ubiquitous computing and VR/AR is true?  
A) ✓ Ubiquitous computing fills the real world with computers — Core definition.  
B) ✓ VR represents the real world inside a computer — VR simulates or models reality digitally.  
C) ✓ AR and ambient displays mix physical and digital worlds — They blend real and virtual.  
D) ✗ VR and AR technologies are declining in use — They are growing and becoming more common.  

**Correct:** A, B, C


#### 20. What is a major difference between desktop VR and headset VR?  
A) ✗ Desktop VR is more immersive but less convenient — Desktop VR is less immersive.  
B) ✓ Headset VR is expensive and can be uncomfortable — True for many current headsets.  
C) ✓ Desktop VR uses ordinary monitors and is cheaper — Desktop VR is more accessible.  
D) ✗ Headset VR cannot track body position or gestures — Many headsets include tracking.  

**Correct:** B, C
