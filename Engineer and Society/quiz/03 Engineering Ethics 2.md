## Answers

#### 1. Which of the following characteristics best define a professional?  
A) ✓ A professional requires specialized education and training.  
B) ✓ Exercising judgment and following standards is essential for professionalism.  
C) ✗ Being employed by a large company is not a defining feature of professionalism.  
D) ✗ Professionals often collaborate; working independently is not a defining trait.  

**Correct:** A, B


#### 2. Professional values in the workplace typically include which of the following?  
A) ✗ Personal financial gain is not a professional value; ethics prioritize integrity.  
B) ✓ Continuous learning is essential for professional growth.  
C) ✓ Teamwork is a key value in professional settings.  
D) ✓ Accountability is a core professional value.  

**Correct:** B, C, D


#### 3. What distinguishes professional ethics from personal ethics?  
A) ✗ Personal ethics apply broadly, not only to family and friends.  
B) ✓ Professional ethics are codified rules for a group.  
C) ✓ Professional ethics govern behavior in occupational environments.  
D) ✗ Personal ethics are not legally enforceable, unlike some professional codes.  

**Correct:** B, C


#### 4. Engineering ethics primarily focuses on the engineer’s obligations to which groups?  
A) ✓ Clients rely on engineers for competent service.  
B) ✓ Public safety and welfare are paramount.  
C) ✓ Employers expect loyalty and responsibility.  
D) ✗ Competitors are not a primary ethical focus.  

**Correct:** A, B, C


#### 5. Which of the following best describes the difference between skill and competence?  
A) ✗ This reverses the definitions; skill is specific, competence is broader.  
B) ✓ Competence includes knowledge, experience, attitude, and applying skills.  
C) ✗ Skill is easily measurable; competence is measured by quality of outcomes.  
D) ✗ Competence develops over time; skill can be learned more quickly.
