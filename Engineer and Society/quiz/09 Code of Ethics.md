## Answers

#### 1. Which of the following are included in the General Ethical Principles of the IFIP Code of Ethics?  
A) ✓ Contribute to society and human well-being is a core principle.  
B) ✗ Ensuring software delivery regardless of quality contradicts ethical quality standards.  
C) ✓ Respect privacy and honor confidentiality are explicitly stated principles.  
D) ✓ Avoid harm and be honest and trustworthy are fundamental ethical requirements.  

**Correct:** A, C, D


#### 2. A computing professional is faced with a project outside their area of expertise. According to the IFIP Code, what should they do?  
A) ✗ Learning on the job without competence risks harm and violates ethical standards.  
B) ✓ Professionals must perform work only in areas of competence.  
C) ✓ Delegating to qualified colleagues aligns with ethical practice.  
D) ✗ Ignoring professional review is unethical and discouraged.  

**Correct:** B, C


#### 3. Which of the following best describe the role of professional leadership according to the IFIP Code?  
A) ✗ Prioritizing profit over public good contradicts the Code’s emphasis on public interest.  
B) ✓ Enhancing quality of working life is a leadership responsibility.  
C) ✓ Supporting ethical policies is required of leaders.  
D) ✓ Creating growth opportunities is part of leadership principles.  

**Correct:** B, C, D


#### 4. When a violation of the Code of Ethics occurs, what is the expected response?  
A) ✗ Ignoring violations undermines ethical standards.  
B) ✓ Violations are inconsistent with professional values and must be addressed.  
C) ✓ Promoting the Code’s principles helps prevent violations.  
D) ✗ Reporting only for reputation ignores broader ethical obligations.  

**Correct:** B, C


#### 5. Which of the following are responsibilities of software engineers under the ACM Code regarding client and employer relationships?  
A) ✗ Using illegally obtained software is unethical and prohibited.  
B) ✓ Respecting confidentiality is a key responsibility.  
C) ✓ Promptly reporting problems is required.  
D) ✓ Refusing conflicting outside work aligns with ethical practice.  

**Correct:** B, C, D


#### 6. What does the ACM Code say about balancing competing interests in software engineering?  
A) ✗ Public interest is paramount but does not always override client interests without context.  
B) ✓ Accepting full responsibility is essential.  
C) ✗ Deception is never acceptable.  
D) ✓ Ethical judgment must consider all stakeholders fairly.  

**Correct:** B, D


#### 7. Which of the following are true about privacy as described in the lecture?  
A) ✗ Privacy includes more than physical access; it also covers informational access.  
B) ✓ Privacy supports individual growth and freedom.  
C) ✓ Privacy violations can prevent people from getting help.  
D) ✗ Privacy is recognized as a human right.  

**Correct:** B, C


#### 8. How does modern information technology affect privacy?  
A) ✓ It makes data collection and sharing easier, reducing privacy.  
B) ✗ It does not guarantee complete protection of personal data.

D) ✗ Technology does not eliminate the need for confidentiality.

#### 9. What is the relationship between the Right to Information (RTI) and privacy?

C) ✓ Destroying data responsibly when no longer needed is required.
