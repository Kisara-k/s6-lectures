## Answers

#### 1. Which of the following are included in the General Ethical Principles of the IFIP Code of Ethics?  
A) ✗ Ensuring software delivery regardless of quality contradicts ethical quality standards.  
B) ✓ Respect privacy and honor confidentiality are explicitly stated principles.  
C) ✓ Contribute to society and human well-being is a core principle.  
D) ✓ Avoid harm and be honest and trustworthy are fundamental ethical requirements.  

**Correct:** B, C, D


#### 2. A computing professional is faced with a project outside their area of expertise. According to the IFIP Code, what should they do?  
A) ✗ Ignoring professional review is unethical and discouraged.  
B) ✓ Professionals must perform work only in areas of competence.  
C) ✗ Learning on the job without competence risks harm and violates ethical standards.  
D) ✓ Delegating to qualified colleagues aligns with ethical practice.  

**Correct:** B, D


#### 3. Which of the following best describe the role of professional leadership according to the IFIP Code?  
A) ✓ Supporting ethical policies is required of leaders.  
B) ✓ Creating growth opportunities is part of leadership principles.  
C) ✗ Prioritizing profit over public good contradicts the Code’s emphasis on public interest.  
D) ✓ Enhancing quality of working life is a leadership responsibility.  

**Correct:** A, B, D


#### 4. When a violation of the Code of Ethics occurs, what is the expected response?  
A) ✓ Violations are inconsistent with professional values and must be addressed.  
B) ✗ Ignoring violations undermines ethical standards.  
C) ✓ Promoting the Code’s principles helps prevent violations.  
D) ✗ Reporting only for reputation ignores broader ethical obligations.  

**Correct:** A, C


#### 5. Which of the following are responsibilities of software engineers under the ACM Code regarding client and employer relationships?  
A) ✓ Respecting confidentiality is a key responsibility.  
B) ✗ Using illegally obtained software is unethical and prohibited.  
C) ✓ Promptly reporting problems is required.  
D) ✓ Refusing conflicting outside work aligns with ethical practice.  

**Correct:** A, C, D


#### 6. What does the ACM Code say about balancing competing interests in software engineering?  
A) ✗ Public interest is paramount but does not always override client interests without context.  
B) ✓ Ethical judgment must consider all stakeholders fairly.  
C) ✓ Accepting full responsibility is essential.  
D) ✗ Deception is never acceptable.  

**Correct:** B, C


#### 7. Which of the following are true about privacy as described in the lecture?  
A) ✓ Privacy supports individual growth and freedom.  
B) ✗ Privacy is recognized as a human right.  
C) ✓ Privacy violations can prevent people from getting help.  
D) ✗ Privacy includes more than physical access; it also covers informational access.  

**Correct:** A, C


#### 8. How does modern information technology affect privacy?  
A) ✓ Electronic trails are created and can be used in many ways.

C) ✗ Technology does not eliminate the need for confidentiality.
