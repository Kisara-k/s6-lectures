## Answers

#### 1. Which of the following are included in the General Ethical Principles of the IFIP Code of Ethics?  
A) ✗ Ensuring software delivery regardless of quality contradicts ethical quality standards.  
B) ✓ Avoid harm and be honest and trustworthy are fundamental ethical requirements.  
C) ✓ Contribute to society and human well-being is a core principle.  
D) ✓ Respect privacy and honor confidentiality are explicitly stated principles.  

**Correct:** B, C, D


#### 2. A computing professional is faced with a project outside their area of expertise. According to the IFIP Code, what should they do?  
A) ✗ Learning on the job without competence risks harm and violates ethical standards.  
B) ✓ Professionals must perform work only in areas of competence.  
C) ✓ Delegating to qualified colleagues aligns with ethical practice.  
D) ✗ Ignoring professional review is unethical and discouraged.  

**Correct:** B, C


#### 3. Which of the following best describe the role of professional leadership according to the IFIP Code?  
A) ✓ Enhancing quality of working life is a leadership responsibility.  
B) ✓ Supporting ethical policies is required of leaders.  
C) ✓ Creating growth opportunities is part of leadership principles.  
D) ✗ Prioritizing profit over public good contradicts the Code’s emphasis on public interest.  

**Correct:** A, B, C


#### 4. When a violation of the Code of Ethics occurs, what is the expected response?  
A) ✗ Reporting only for reputation ignores broader ethical obligations.  
B) ✓ Violations are inconsistent with professional values and must be addressed.  
C) ✗ Ignoring violations undermines ethical standards.  
D) ✓ Promoting the Code’s principles helps prevent violations.  

**Correct:** B, D


#### 5. Which of the following are responsibilities of software engineers under the ACM Code regarding client and employer relationships?  
A) ✓ Refusing conflicting outside work aligns with ethical practice.  
B) ✓ Respecting confidentiality is a key responsibility.  
C) ✗ Using illegally obtained software is unethical and prohibited.  
D) ✓ Promptly reporting problems is required.  

**Correct:** A, B, D


#### 6. What does the ACM Code say about balancing competing interests in software engineering?  
A) ✓ Accepting full responsibility is essential.  
B) ✗ Public interest is paramount but does not always override client interests without context.  
C) ✓ Ethical judgment must consider all stakeholders fairly.  
D) ✗ Deception is never acceptable.  

**Correct:** A, C


#### 7. Which of the following are true about privacy as described in the lecture?  
A) ✗ Privacy includes more than physical access; it also covers informational access.
