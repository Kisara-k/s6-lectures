## Answers

#### 1. Which of the following are included in the General Ethical Principles of the IFIP Code of Ethics?  
A) ✓ Contribute to society and human well-being is a core principle.  
B) ✗ Ensuring software delivery regardless of quality contradicts ethical quality standards.  
C) ✓ Avoid harm and be honest and trustworthy are fundamental ethical requirements.  
D) ✓ Respect privacy and honor confidentiality are explicitly stated principles.  

**Correct:** A, C, D


#### 2. A computing professional is faced with a project outside their area of expertise. According to the IFIP Code, what should they do?  
A) ✓ Professionals must perform work only in areas of competence.  
B) ✗ Learning on the job without competence risks harm and violates ethical standards.  
C) ✓ Delegating to qualified colleagues aligns with ethical practice.  
D) ✗ Ignoring professional review is unethical and discouraged.  

**Correct:** A, C


#### 3. Which of the following best describe the role of professional leadership according to the IFIP Code?  
A) ✓ Creating growth opportunities is part of leadership principles.  
B) ✓ Supporting ethical policies is required of leaders.  
C) ✓ Enhancing quality of working life is a leadership responsibility.  
D) ✗ Prioritizing profit over public good contradicts the Code’s emphasis on public interest.  

**Correct:** A, B, C


#### 4. When a violation of the Code of Ethics occurs, what is the expected response?  
A) ✗ Ignoring violations undermines ethical standards.  
B) ✓ Promoting the Code’s principles helps prevent violations.  
C) ✗ Reporting only for reputation ignores broader ethical obligations.  
D) ✓ Violations are inconsistent with professional values and must be addressed.  

**Correct:** B, D


#### 5. Which of the following are responsibilities of software engineers under the ACM Code regarding client and employer relationships?  
A) ✓ Refusing conflicting outside work aligns with ethical practice.  
B) ✓ Respecting confidentiality is a key responsibility.  
C) ✓ Promptly reporting problems is required.  
D) ✗ Using illegally obtained software is unethical and prohibited.  

**Correct:** A, B, C


#### 6. What does the ACM Code say about balancing competing interests in software engineering?  
A) ✗ Public interest is paramount but does not always override client interests without context.  
B) ✗ Deception is never acceptable.  
C) ✓ Accepting full responsibility is essential.  
D) ✓ Ethical judgment must consider all stakeholders fairly.  

**Correct:** C, D
